# 统一下载任务展示

下载中心将持久下载任务、旧磁链计划、HTTP 直链与漫画目录队列适配成 `DownloadTaskEntry`，交给同一个 `DownloadTaskBrowser` 排序、过滤与分组。后台服务继续拥有下载、重试、取消、删除和导入语义，展示层不复制队列或把操作写成数据库更新。

`DownloadTaskCard` 默认显示标题、状态和进度；展开后保留来源既有动作。任务展开状态按 taskId 存在 PageStorage，分组折叠、筛选和排序在页面会话内保留。

合集优先使用真实 collectionId，其次使用已知作品 provider/id；漫画目录使用精确 seriesName。无身份的资源进入“未归属合集”。不截断标题猜合集，也不按标题跨来源去重。迁移旧计划与持久任务只按精确 legacy-plan ID 去重。

未知进度和时间在正反排序中都排末尾；同值以真实创建时间和任务 ID 稳定排序。批量重试和清理仅作用于当前过滤后具备对应能力的队列任务，清理不删除文件。保留各来源独立页面的现有展示行为。
