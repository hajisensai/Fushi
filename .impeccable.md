## Design Context

### Users

Hibiki serves immersion language learners who read, listen to, and watch real media while looking up unfamiliar words and making their own Anki cards. In the browser extension they are usually already watching a streaming video, so subtitle loading, navigation, lookup, and connection repair must preserve focus and require as few context switches as possible.

### Brand Personality

Calm, capable, and grounded. Hibiki should feel like a dependable study instrument: technically powerful without looking like a developer console, encouraging without becoming playful or noisy, and direct whenever local services or permissions need attention.

### Aesthetic Direction

Refined utilitarian Material 3, using Hibiki's muted green palette and warm, green-tinted neutrals in both light and dark themes. Dense controls should use clear hierarchy, restrained surfaces, and progressive disclosure. Avoid neon-on-dark, decorative gradients, excessive cards, generic dashboard grids, and oversized icon-led headings.

### Design Principles

1. Protect immersion flow: common subtitle actions stay one click away and never require memorizing connection details.
2. Make system state explicit: connected, disabled, unauthorized, and port-conflict states use distinct language and actionable recovery steps.
3. Reveal complexity progressively: automatic configuration is primary; host, port, and token overrides live behind an advanced section.
4. Respect the host page: injected overlays are isolated, reversible, keyboard accessible, and visually subordinate to the video.
5. Use one visual and behavioral vocabulary across the app, extension popup, options page, subtitle list, and lookup popup.
