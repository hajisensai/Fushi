## BUG-1074 · 书籍编辑封面更新按钮Windows无反应
- **报告**：2026-07-25（用户：）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/pages/implementations/media_item_edit_dialog_page.dart:117`（修复前）：书架书籍编辑弹窗封面行的上传按钮（`Icons.file_upload_outlined`，tooltip=`t.pick_image`）直接调 `ImagePicker().pickImage(source: ImageSource.gallery)`。本仓钉的 image_picker 0.8.7+5 只带 android / ios / for_web 三个平台实现（见 `hibiki/pubspec.lock`，无 image_picker_windows / _macos / _linux——老版本未 endorse 桌面实现）。桌面端没有任何实现注册 `ImagePickerPlatform.instance`，保持默认 `MethodChannelImagePicker`（image_picker_platform_interface-2.9.2 `lib/src/platform_interface/image_picker_platform.dart:26`）；`pickImage` → `_getImagePath` → `_channel.invokeMethod<String>('pickImage', ...)`（同包 `lib/src/method_channel/method_channel_image_picker.dart:107`，channel `plugins.flutter.io/image_picker`）。Windows 原生侧无该 channel handler，`invokeMethod` 抛 **`MissingPluginException`**（不是静默返回 null）；异常发生在 async `onTap` 回调里无人捕获，UI 零反馈——表现为「点了没反应」。
- **[x] ① 已修复** — 新增平台感知统一入口 `hibiki/lib/src/utils/misc/gallery_image_picker.dart` 的 `pickGalleryImageFile(): Future<File?>`：移动端（Android/iOS）维持 image_picker 系统相册体验；桌面端（Windows/macOS/Linux）走 file_picker 的 `FileType.image` 原生文件对话框。替换两处桌面可达调用点：`media_item_edit_dialog_page.dart`（本 bug 入口）与 `pick_image_enhancement.dart`（制卡器「选择图片」增强，同病同修，`XFile.saveTo` 等价替换为 `File.copy`）。`camera_enhancement.dart` 保留 image_picker（`ImageSource.camera` 无 file_picker 等价物，且已有 `isMobilePlatform` 门禁，桌面不可达）；音频选取 `pick_audio_enhancement.dart` 早已走 file_picker 系的 `pickRealFilePath`，不受影响。**取舍**：不升级 image_picker、不新增 image_picker_windows 依赖——老 Flutter 钉版环境升级爆炸半径大；file_picker 已是本仓直接依赖且是既有桌面文件选取路径（`real_path_directory_picker.dart` / `miscellaneous_settings_page.dart` TODO-1239 同款处理）。commit：（待主代理提交）
- **[x] ② 已加自动化测试** — `hibiki/test/utils/gallery_image_picker_test.dart`（平台分流单测：五平台后端断言 + Windows override 下走假 file_picker、image_picker MethodChannel 哨兵必须零调用）；`hibiki/test/tools/image_picker_usage_guard_test.dart`（源码扫描守卫：lib/ 下除 gallery_image_picker.dart 与 camera_enhancement.dart 外禁止 import image_picker / 实例化 ImagePicker）。
- **备注**：`miscellaneous_settings_page.dart:192` 的注释早已记录同一根因（TODO-1239），本次把散落的图片选取统一收敛到单一入口并加守卫防复发。
