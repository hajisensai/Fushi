## BUG-4756 · Lapis 下选中弹窗释义后制卡，SelectionText 是空的
- **报告**：2026-11-16（GitHub issue #3407，fushi-bot 代提交，reporter Fsrs2333：「选中弹窗的词典的文本后制卡，selection text 字段里面没有东西」，MainDefinition 里选中段有高亮；拍板台 dYWFMfCEF2）
- **真实性**：✅ 现象属实。原是刻意设计：`packages/fushi_anki/lib/src/anki_note_composer.dart` `shouldYieldSelectionText`（commit 0548868a04）在「高亮落进导出释义 && 笔记类型是 Lapis && 映了 glossary 类占位符」时让 `{popup-selection-text}` / `{popup-selection-html}` 渲染成空（`anki_models.dart` `_handlebarToValue` 的 `yieldSelectionText ? '' : ...`），理由是 Lapis 卡背会用非空 SelectionText 占住默认页。维护者拍板（2026-11-16）：SelectionText 就是放选中文字的字段，有就填，不让位——按 bug 处理。
- **[x] ① 已修复** — 删除让位机制本身：去掉 `AnkiNoteComposer.shouldYieldSelectionText` 与 `BaseAnkiRepository` 的转发、`AnkiHandlebarRenderer.render` / `_handlebarToValue` 的 `yieldSelectionText` 参数，`{popup-selection-text}` / `{popup-selection-html}` 总是渲染选中内容。释义字段里的 `<mark class="fushi-selection">` 高亮照旧保留，两者并存。`glossarySelectionHighlighted` 线上键保留（互联 host 白名单、草稿持久化、BUG-2089 类型容错契约），只是不再参与渲染；popup.js 三份副本只改注释。
- **[x] ② 已加自动化测试** — `packages/fushi_anki/test/selection_text_fill_test.dart`（替换原 `selection_text_yield_test.dart`）：Lapis + 高亮落地 + 各种 glossary 占位符下 SelectionText 都等于选中文本，`{popup-selection-html}` 同理，非 Lapis / 未选笔记类型 / 高亮未落地照填；`popup_selection_html_test.dart` 的让位用例改为断言照填。
- **备注**：Lapis 模板本身是 `{{#SelectionText}}<div id="selection">…{{/SelectionText}}`，有值时卡背默认显示选中段，这正是该字段在 Lapis / Yomitan 里的原本用法；带高亮的完整释义仍在 MainDefinition，翻页可见。真机制卡未复测。
