## BUG-2914 · iOS 2.9.0 crashes on launch: SceneDelegate calls super for a scene callback FlutterSceneDelegate does not implement
- **报告**：2026-10-03（用户：TestFlight 反馈「打开闪退」，2.9.0 (16898)，iPhone18,3 / iOS 27.2）
- **真实性**：✅ 真 bug。崩溃日志 `EXC_CRASH (SIGABRT)`，`-[(dynamic class) windowScene:didUpdateCoordinateSpace:interfaceOrientation:traitCollection:]: unrecognized selector`，栈底是 `-[UIWindowScene initWithSession:connectionOptions:]` → `_computeTraitCollectionAndCoordinateSpaceForcingDelegateCallback:`——建 scene 时 UIKit 就回调这条方法。根因 `fushi/ios/Runner/SceneDelegate.swift` 的 `windowScene(_:didUpdate:interfaceOrientation:traitCollection:)`（BUG-2911 加的界面方向回调）调了 `super.windowScene(...)`。Flutter 3.44 的 `FlutterSceneDelegate` 只声明遵守 `UIWindowSceneDelegate`（`FlutterSceneDelegate.h`），`.mm` 里没有这条可选回调的实现；Swift 因父类遵守该 `@objc` 协议要求子类写 `override`（#1912 的 iOS CI 编译红就是这条），于是被误读成「父类有实现、须交回 super」，运行时 super 消息找不到实现直接 abort。编译器与 iOS CI 只编译不运行，拦不住。Android / Windows 不经这条路径（模拟器全新安装与 2.7.0→2.9.0 升级均正常启动）。
- **[x] ① 已修复** — 保留 `override`、删除 super 调用，注释写明父类没有实现、不得调 super。2.9.0 正式版已撤回（Release 转 draft、update-manifest stable 清单回退 2.7.0、R2 镜像回滚到 v2.7.0）。
- **[x] ② 已加自动化测试** — `fushi/test/floating_ball/app_floating_ball_viewport_test.dart` 的界面方向回调结构断言由「必须含 `super.windowScene(`」反转为「回调体内不得出现 `super.`」。
- **备注**：同文件其余三处 super（`scene(_:willConnectTo:options:)`、`scene(_:openURLContexts:)`、`windowScene(_:performActionFor:completionHandler:)`）在 `FlutterSceneDelegate.mm` 都有实现，保留。真机 / 模拟器冷启动复测须走 iOS 构建（远程 Mac 或 TestFlight）。
