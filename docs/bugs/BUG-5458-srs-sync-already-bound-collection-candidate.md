## BUG-5458 · 复习同步冲突把本机其他资料库已绑定的集合列为可采用

- **报告**：2026-11-25（应用内反馈 5-8sfIbHd1，Windows 3.4.0+32563）。更新后当前复习页显示默认牌组 0 张，从其他设备同步回来也失败。
