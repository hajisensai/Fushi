## BUG-2609 · 动画扩展播放进度条一进去就拉满、换集无反馈
- **报告**：2026-09-20（用户：动画扩展播放直接进度条拉满、无法切换集数；起播还要先选源，应默认选线路、进播放器后可换）
- **真实性**：✅ 真 bug，三个根因叠加（真流取证：`tool/mihon` 桌面 sidecar 对 yuzono `kotokai v16.8`（AnimeKai）取流后，用 app 随包 `libmpv-2.dll`（mpv 0.41 / ffmpeg N-126123）经 app 中继播放）
  1. **进度条拉满** = 流一打开就 EOF。AnimeKai / MegaPlay 把 HLS 分片伪装成图片：`image/png` 响应，前 252 字节是一张真 1×1 PNG（IEND 在 62），之后才是 MPEG-TS。ffmpeg hls demuxer 逐分片探测容器，探到 PNG 判 `Video: png, unspecified size` 一个包读不出，整条流 open 后 3 s 内 `eof-reached=true`、`time-pos == duration`（1420 s）、`percent-pos=100`——seekbar 直读 media_kit 的 `position/duration`（`third_party/media_kit_video/.../material_desktop.dart:1268`），于是拉满；每一集都如此，看起来「换集也没用」。KickAssAnime / AnimeGG / AnimeOnsen 的流（裸 TS / mp4 / DASH）同一链路正常，证明不是播放器通用问题。
  2. **换集零反馈**：`episode.part.dart` `_switchEpisode` 远端分支不 `pause()` 旧集、`_loadRemoteEpisode` 的 `connecting` 阶段只改 `_loadingPhase` 而页级加载态被 `_videoReadyToShow` 门死（`video_fushi_page.dart` Scaffold 分支），扩展取流是秒到几十秒级（桥超时 45 s），用户看到旧集照播、进度条照走、没圈没文案。失败后 `_activeRemoteMember` 已切到目标集而 `_currentEpisode` 没推进，`_retryLoad → _initRemote` 又按 `initialEpisodeIndex` 回到起播集。
  3. **起播先弹「选一条流」**：`anime_source_detail_page.dart` `_play` 预解析后多候选 `showAppDialog` 拦一道，选完钉住，进播放器后再无处可换。
- **[x] ① 已修复** — 提交见 PR 分支 `pr/anime-ext-player`：
  - 中继 `fushi/lib/src/utils/net/app_native_proxy.dart` `_relayBody`（纯函数在 `hls_relay_normalizer.dart`）：播放列表里的绝对 https 分片 / 变体 / `URI="…"` 改写成 `nativePlaybackUri` 形式让分片以明文回到中继（否则 libmpv 对 https 分片走 CONNECT 隧道，中继看不到字节）；图片魔数开头、后面是 TS（4 个 188 字节步长的 0x47）/ fMP4（`ftyp`/`styp`）的伪装分片剥掉前缀、Content-Length 减去偏移、206 完整范围回 200。上游一律 `Accept-Encoding: identity`（megap 不问也回 Brotli，Dart 解不了就改写不了）。ffmpeg 首请求带 `Range: bytes=0-`，与无 Range 同等视为整包。
  - 播放页：远端换集先 `pause()` 旧集；新增 `_remoteSwitchPhase` 驱动非模态换集 OSD（转圈 + 阶段文案 + 读取速度）；取流失败把 `_activeRemoteMember` 拨回旧集、`_remoteLastAttemptedEpisode` 让重试落到要切的那集；`NO_VIDEOS` 映射成 `video_online_stream_none` 文案。
  - 作品页点集直接进播放器；`AnimeSourceVideoClient` 实现新能力接口 `RemoteVideoStreamVariants`（`remote_video_client.dart`），画质菜单（`quality.part.dart`）列出当前集全部线路、换线路 = 钉住 + 重新取流回到当前位置；同 url 的集 id 追加集号去重。
  - 顺带：所有网络流加载 / 中途缓冲显示读取速度（controller 1 s 轮询 mpv `cache-speed`，`VideoLoadingOverlay` / `VideoBufferingIndicator`）。
- **[x] ② 已加自动化测试** — `fushi/test/utils/net/hls_relay_normalizer_test.dart`（伪装前缀 / TS·fMP4 起点 / 播放列表改写 / Range 判据）、`fushi/test/utils/net/app_native_proxy_hls_test.dart`（真中继 + 本地上游：播放列表改写、PNG 前缀剥除、真图片 / 部分 Range 不动）、`fushi/test/media/video/online/anime_source_video_client_test.dart`（线路能力、id 去重）、`fushi/test/media/video/online/anime_source_detail_page_test.dart`（直接进播放器 + 默认线路 + 播放器换线路）、`fushi/test/pages/remote_episode_switch_feedback_guard_test.dart`（换集先 pause / OSD 挂载 / 失败回滚 / 重试落点）、`fushi/test/widgets/video_loading_overlay_test.dart`（读取速度行）。
