## BUG-545 · Windows 高显卡占用时视频黑屏闪烁
- **报告**：2026-07-04（用户：看板 TODO-1116/1119）
- **真实性**：✅ 真 bug（已由只读调查坐实）。根因在 Windows 视频渲染链：`media_kit_video 2.0.1`（MPV-OpenGL + ANGLE EGL→D3D11 `CopyResource` 到共享句柄纹理交 Flutter 合成）。默认 `hwdec=auto-safe` 在 Windows 落 d3d11va 硬解，ANGLE legacy 共享纹理无 KeyedMutex，高 GPU 负载时 `CopyResource`/`glFinish` 赶不上刷新，Flutter 拿到旧/半更新纹理 → 黑帧闪烁。字幕是独立 Flutter overlay，不吃视频纹理管线，故不闪。hwdec 默认值：`hibiki/lib/src/utils/player/video_mpv_config.dart`。
- **[x] ① 根因修复（本轮=明示交付）** — 在视频「画质」设置组内新增一条 Windows-only「已知问题」说明行，告知用户高显卡占用时可能黑屏闪烁，并指向该组内真实存在的画质控件（关闭画质增强 / S 形上采样 / 去色带，或把硬件解码切到「复制」）降低 GPU 负载。改动：`hibiki/lib/src/settings/settings_schema_video.dart:317`（`SettingsCustomItem id: 'video.quality.windows_black_flash_notice'`，`visible: (_) => isWindowsPlatform`）+ builder `_buildWindowsBlackFlashNotice`（同文件 `:624`）。i18n key：`video_windows_black_flash_notice_title` / `video_windows_black_flash_notice_body`（经 `tool/i18n_sync.dart` 补齐 17 语言 + `dart run slang` 重生成 `strings.g.dart`）。纯说明文案，不新增开关 / 不改 schema / 不改任何默认值。
  - **待后续（device-gated，本轮未做）**：hwdec 真修（新增纯函数 `resolveWindowsHwdec` 把 Windows `auto-safe`→`auto-copy` 绕开共享纹理竞态）需要 AMD GPU + 可见窗真机坐实，盲落会让本来正常出画的多数 Windows 用户掉性能（软/copy 回退降速），违反 never-break-userspace，故留待真机验证后单独落。**不要盲改 `video_mpv_config.dart` 的 hwdec 默认值。**
- **[x] ② 自动化测试守卫** — `hibiki/test/pages/video_settings_schema_guard_test.dart` 新增 `TODO-1116/1119: Windows video quality group carries a black-flicker known-issue notice`：源码扫描守卫锁定「画质组含该已知问题说明项、经 `isWindowsPlatform` 仅 Windows 展示、i18n-backed、且两个 i18n key 存在于基础翻译」，防回归。
- **备注**：这是「明示等解决方案」路径（用户已接受）；真正的 hwdec 代码修复是后续 device-gated 项。
