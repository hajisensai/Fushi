## BUG-821 · beta/debug通道装无后缀X.Y.Z包永判已是最新
- **报告**：2026-07-15（用户：手机点检查更新说是最新版本，实际不是，当前 1.2.0）
- **真实性**：✅ 真 bug。真机取证：`app.hibiki.reader` versionName=`1.2.0`（无 `-debug` 后缀），versionCode=`1000786300`（= `1e9 + 100*7863`，seq 7863）；远端 debug 通道最新为 `1.2.0-debug.7920`（`update-manifest/latest-debug.json`，seq 7920）。7920 > 7863 确有新版，却被判「已是最新」。
  - 根因 `hibiki/lib/src/utils/misc/update_checker_release.dart:isUpdateVersionNewer`（基版本相同分支）：本机版本 `1.2.0` 无预发布段，`_prereleasePart('1.2.0')==null` → 早退 `return false`。语义上 semver 里 `1.2.0-debug.7920 < 1.2.0`（预发布早于正式版），加 BUG-480 的严格同通道判据（同基需本机也是本通道预发布），导致「装无后缀 `X.Y.Z` release 包 + beta/debug 通道」时同基预发布更新永远推不动。
  - 触发前提：本机 `PackageInfo.version` 是无预发布后缀的 `X.Y.Z`（如本地 `flutter build apk --release` 出的包 versionName 直接取 pubspec 基版本 `1.2.0`，而非 CI channel 步骤写入的 `1.2.0-debug.7863`），且用户切到 beta/debug 通道。stable 通道不受影响（`1.1.0 < 1.2.0` 正确判「已是最新」）。
  - 历史：同类修复曾在分支 `codex/fix-beta-update-repeat`（commit `ade12a87c`，BUG-457）实现并作为 beta.6096 发布，但**从未合入 develop**，故 develop 一直带此缺陷。
- **[x] ① 已修复** — commit（见下）。新增纯函数 `effectiveCurrentVersionForUpdateChannel`（`update_checker_release.dart`）：beta/debug 通道下本机 versionName 无本通道预发布后缀时，用平台构建号 `buildNumber` 还原 release sequence（Android versionCode `1e9+100*seq+abi` 反解 / 桌面 raw build number 直取，`_releaseSequenceFromPlatformBuildNumber`），重建 `<base>-<channel>.<seq>` 再比较。`1.2.0`(seq 7863) → `1.2.0-debug.7863`，远端 `1.2.0-debug.7920` 正确判更新。`scheduleCheck` 新增 `currentBuildNumber` 形参并内部还原；两个调用点（`home_page.dart` 自动检查、`settings_schema_system.dart` 手动检查 + 缓存乐观比较）都传入 `packageInfo.buildNumber`。fail-open：buildNumber 缺失/不可解析/别通道后缀 → 原样返回，绝不误升；stable 通道路径零变化。
- **[x] ② 已加自动化测试** — `hibiki/test/utils/misc/version_comparison_test.dart` group `effectiveCurrentVersionForUpdateChannel (BUG-457)`：复现设备场景（`1.2.0`+`1000786300`→`1.2.0-debug.7863`→见 7920 更新）、同 seq 不重复提示、桌面 raw seq、Android ABI offset 反解、stable 不变、已带后缀不改写、buildNumber 缺失/畸形 fail-open、别通道后缀不改写。`update_checker_structure_guard_test.dart` release 天花板 1650→1720（跨切功能容纳，附 BUG-457 理由）。
- **备注**：`flutter analyze`（4 文件）无问题；`flutter test --no-pub test/utils/misc/ test/settings/manual_update_check_guard_test.dart` 全绿（含 29 条版本比较 + 结构守卫 + 缓存/手动检查接线守卫）。真机点「检查更新」复测待用户在 debug 通道设备上确认弹出 `1.2.0-debug.7920` 更新。
