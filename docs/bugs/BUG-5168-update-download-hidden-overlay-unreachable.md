## BUG-5168 · update-download-hidden-overlay-unreachable
- **报告**：2026-11-22（用户：应用内反馈 t0mmZroouh，「检查更新后隐藏了没办法拉起看进度」，Windows）
- **真实性**：✅ 真 bug。下载浮层点「隐藏」只做 `overlayVisible.value = false`（`fushi/lib/src/utils/misc/update_checker_headless.dart:50`，修前行号），下载会话 `_UpdateDownloadSession` 是 `_runDownloadAndInstall` 的局部变量（`fushi/lib/src/utils/misc/update_checker_release.dart:1053`，修前），没登记在任何地方；除 Android 装包权限重试外没有任何路径把它设回 true。再点「检查更新」命中版本互斥 `_notifyIfUpdateFlowActive` / `onAlreadyActive`（`update_checker_release.dart:66-74`、`911-917`，修前），只弹一句「正在下载」snackbar，浮层与进度再也看不到。
- **[x] ① 已修复** — 下载会话构造时按版本 key（与 `_activeUpdateFlows` 同 key）登记进 `UpdateChecker._activeDownloadSessions`、`dispose` 时注销（`update_checker_headless.dart:26/102`）；新增 `_UpdateDownloadSession.reveal()` 与 `UpdateChecker.revealActiveDownload()`（`update_checker_release.dart:75`）。同版本再检查（`_notifyIfUpdateFlowActive` / `_downloadAndInstall` 的 `onAlreadyActive`）先把浮层拉回来，本机没有浮层（互联远程触发未给 overlay）才退回 snackbar；手动「立即检查更新」入口 `checkAppUpdateNow` 有在途下载时直接拉起浮层、不再查网（`fushi/lib/src/updates/app_update_check.dart:41`）。本机 UI 流、Flatpak 部署、互联远程 `downloadAndApply` / `download` / `stage` 全部会话都登记。
- **[x] ② 已加自动化测试** — `fushi/test/utils/misc/update_download_session_overlay_test.dart`：隐藏后同版本再检查浮层回来、进度 42% 保留、不弹 snackbar；手动入口 `revealActiveDownload()` 拉回浮层、会话收尾后注销。变异实测：把 `reveal()` 里的 `overlayVisible.value = true` 注掉，两条新测试变红；恢复后绿。
- **备注**：分诊建议的「设置页检查更新条目显示『下载中 x%』」未做：点同一个条目已能直接拉回浮层，另加常驻进度文案属 UI 扩展，需要时另立项。
