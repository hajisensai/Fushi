## BUG-750 · 远端视频/书切 tab 每次重新加载（顶层 tab 无保活）

- **报告**：2026-07-12（用户：远端视频/书应该有缓存，每次都要进到书架/视频重新加载）
- **真实性**：✅ 真 bug。双层根因：
  - **① 顶层 tab 无保活（核心）**：`hibiki/lib/src/pages/implementations/home_page.dart:846` `buildBody()` 用 `switch(_visibleTab)` 每次返回**新页面 widget**，无 `IndexedStack` / 保活（466、667 行注释假设 IndexedStack 存在，实为失真/回归）。切走再切回 → 旧页面 State 销毁重建 → `initState` 重跑：视频 `home_video_page.dart:133` `_remoteFuture = _loadRemoteVideos()`；书架 `reader_hibiki_history_page.dart:303` `_remoteBooksFuture ??= _loadRemoteBooks()`（State 销毁后字段归 null，重来）。
  - **② 远端数据零持久缓存（放大症状）**：`listRemoteVideos()` / `listRemoteBooks()` 每次实打实 HTTP GET（云盘书还逐本 `listChildren` 探测），只存内存 Future；远端封面 `remote_cover_image.dart` 的 `RemoteCoverImage` 只走进程内 `ImageCache`、**无磁盘缓存**。本地书/视频不受影响（Drift + 本地 FileImage）。
- **[x] ① 已修复** — 只让**书架 + 视频**两个 tab 保活（`home_page.dart` 新增 `_keepAliveTabs = {books, video}`，`buildBody` 改为「Offstage 保活未选中者 + 惰性构建 + 关 TickerMode」；`_visitedKeepAliveTabs` 惰性门控避免启动即预拉未访问 tab 的远端）。其余 tab（词典/texthooker/设置）**故意不保活**、按需重建，保留 `HomeDictionaryPage` 靠 re-mount 消费桌面悬浮字幕 pending 的语义（TODO-376）。保活省掉「切回隐式重拉」，另给视频/书架远端区补**下拉刷新**（`RefreshIndicator` → 复用 `_pullToRefresh` / `_pullToRefreshBooks`），保留显式强制刷新入口。提交：`cb844154a`。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/home_tab_keepalive_guard_test.dart`（源码守卫：`_keepAliveTabs` 恰为 books+video、dict/settings/texthooker 不保活、buildBody 用 Offstage 而非 switch）+ `hibiki/test/pages/home_tab_keepalive_mechanism_test.dart`（同构机制 widget 测试：保活 tab initState 只跑一次、按需 tab 每次重建）。另跑 `desktop_lookup_to_dictionary_tab_test.dart`（TODO-376 守卫）确认查词 tab 重挂未被破坏。提交：`cb844154a`。
- **备注**：HomePage 运行时表面在 headless 测试无法稳定挂载（AppModel 未初始化，同 `desktop_lookup_to_dictionary_tab_test.dart` 的说明），故 tab 保活用「源码守卫 + 同构机制测试」两层覆盖。**待真机目视**：切 tab 返回不重拉远端 + 下拉刷新在三端（Android/Windows/Mac）观感与手势无冲突（尤其书架 CardDropScope 拖拽 vs 下拉）。
