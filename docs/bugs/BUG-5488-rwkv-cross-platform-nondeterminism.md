## BUG-5488 · RWKV 同一复习日志在电脑与手机上回放出的 R 不同，到期数差一张（73 vs 72）
- **报告**：2026-11-26（用户：）
- **真实性**：✅ 真 bug。RWKV 牌组「今天到期」= 本机回放出的 R ≤ 目标保留率，各设备各自回放同步来的日志；而 `native/fushi_rwkv` 的浮点算术各平台不同：同一张卡 x86 AVX2+FMA 路径 R = 0.91486245、标量路径 0.9148693（14715 卡 / 167061 条复习实测），R 压在阈值边上的卡两端判定不同。分叉点（修前 `b876b0196f2`）：
  - 点积 / axpy 各平台一套内核、求和顺序与是否 FMA 各异：`src/rwkv/mod.rs:4421` `dot_product`（`dot_product_arch` ×3，`:4428/4436/4448`）、`:3810` `add_scaled_in_place`（NEON `:3843` 尾部不融合、AVX2+FMA `:4150`、标量 `:4414`）。
  - 大模型 R 查询在 macOS / aarch64 走批量路径 `mod.rs:1884` `review_retrievability_query_refs_batched`：Accelerate `cblas_sgemm`（`src/rwkv/matmul.rs:53`）、`vvexpf`（`matmul.rs:74`）、`query_kernels.rs` 的 NEON 内核与改写的衰减公式；x86 走逐行 `mod.rs:1867`。
  - 超越函数用平台 libm（MSVC / glibc / bionic / Apple 末位各不相同）：如衰减 `mod.rs:3013`、`:3148` `(-d.exp()).exp()`、softplus / tanh / sin / cos / powf，小模型 `src/rwkv/small/model.rs` 同样。
- **[x] ① 已修复** — 本 PR（`52f107c4bb4` 起）。新增 `src/rwkv/det.rs` 定一套规范运算序：点积 32 条交错 lane + FMA + 固定归约树（AVX2 / NEON / 可移植实现同序），axpy 每元素一次 FMA（尾部也融合）；无硬件 FMA 的 CPU 走可移植内核 + 软件 FMA（`det::soft_fma`，与硬件 FMA 逐位相同）；`exp` / `ln` / `ln_1p` / `tanh` / `sigmoid` / `sin` / `cos` / `powf` 自写（f64 精确规约 + 多项式 / 查表，一次舍入到 f32），衰减用等价闭式 `exp(-e^-0.5·sigmoid(x))`（`det::decay`）。删 `matmul.rs` / `query_kernels.rs` 与批量查询路径，所有平台走逐行。数值一变旧状态作废：快照魔数升 `FRWKVSNAP2\0` / `FRWKVSMALL2\0`，v1 快照 / 检查点被拒、宿主全量重放一次（ABI 不变，Dart 无需改）。
- **[x] ② 已加自动化测试** — `native/fushi_rwkv/tests/bitexact.rs`：每个模型 × 精度的回放预测、R 位模式与快照字节压成 SHA-256，(a) 本机向量内核与子进程里强制可移植内核（`FUSHI_RWKV_PORTABLE_KERNELS=1`）必须相同（改 AVX2 归约树一处即红，已变异实测），(b) 必须等于 x86_64 生成的黄金值——`native-rwkv-gate.yml` 在 linux-x86_64 / linux-aarch64 / macos-arm64 都跑，即跨平台对拍；`det.rs` 单元测试（向量 vs 参考顺序逐长度 0–299、软件 vs 硬件 FMA 200 万随机 + 边界、超越函数 ≤1 ulp）；`snapshot_tests::version_1_snapshots_are_refused`。
- **备注**：aarch64 / macOS 上的逐位一致只能由 CI 的 gate 任务实测（本机只有 x86_64；已对 aarch64-linux / aarch64-apple-darwin / armv7-android / aarch64-ios 做 `cargo check --tests`）。性能前后对比见 `native/fushi_rwkv/README.md`「跨平台逐位一致前后」：向量路径持平；无硬件 FMA 的平台（含 armeabi-v7a）走软件 FMA 慢约 4–5 倍，另登记 BUG-5491。
