## BUG-3263 · MD3 胶囊分段估宽与绘制不同源导致段被钳窄截断
- **报告**：2026-10-10（PR #2034 审查遗留疑点）
- **真实性**：✅ 真 bug。MD3 下 `adaptiveSegmentedButton` 渲染 `FushiPillSegmentedButton`（每段 = 文案 + 2×16，纯图标段 18 + 2×12，轨道再加 2×4，`fushi/lib/src/utils/components/fushi_pill_segmented_button.dart:37` / `:164`），而 `estimateSegmentedStripWidth` 仍按 Material `SegmentedButton` 每段 +28、无轨道估（`fushi/lib/src/utils/components/settings_shared.dart:1428`）；`FushiSegmentedStrip` 判「放得下」后把条钉死在这个偏小的估宽上（`settings_shared.dart:2411`），胶囊段被钳窄、文案省略号截断。`AdaptiveSettingsSegmentedRow` 的 MD3 分支则还在按早已不渲染的「连接式按钮组」手补每段 +26 与段间缝（`settings_shared.dart:1438`），纯图标段估 98 实宽 42，系统性高估、无谓退回菜单。`style`（`kSettingsSegmentedStyle`）不被胶囊读取属有意：调用方传的只是 Material 密度 / 命中区，胶囊本身就是 36 高的紧凑几何，已在类文档写明。
- **[x] ① 已修复** — 新增 `SegmentedStripMetrics`（`material` / `pill`，`pill` 直接取 `FushiPillSegmentedButton` 的几何常量，新增 `iconSize` / `iconLabelGap` 常量并在绘制中使用）+ `SegmentedStripMetrics.of(context)`（与 `adaptiveSegmentedButton` 共用判据 `adaptiveSegmentedUsesPill`）；估宽函数加 `metrics` / `segmentHasIcon`，所有调用点（设置行 MD3 分支、`_SegmentedStripHost`、`FushiSegmentedStrip`、滚动定位、动画下载对话框）按上下文取几何；删除 `_kConnectedGroupSegmentExtra`。`FushiSegmentedStrip` 对胶囊改为「至少估宽、至多可用宽」，字距等细差由控件自身 IntrinsicWidth 吸收。提交 fix(ui): derive segmented strip width from the pill geometry
- **[x] ② 已加自动化测试** — `fushi/test/widgets/fushi_pill_segmented_width_estimate_test.dart`（MD3 下短标签不被截断；估宽 = 胶囊实际固有宽；带图标文字段计入图标 + 间距）。
