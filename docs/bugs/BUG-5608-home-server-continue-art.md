## BUG-5608 · 首页「继续」里的服务器条目没有背景图 / 艺术字
- **报告**：2026-11-27（用户：首页「继续」色块里，不在本机库里的 Jellyfin / Emby / Plex 条目只有封面取色的平铺色块，本机库里的视频却有斜放海报 + 背景图 + logo 的系列色块；证据在本地，未入库）
- **真实性**：✅ 真 bug。首页的系列色块元数据只来自本机刮削库：`_seriesMetaKey` 对服务器条目直接返回 null（`fushi/lib/src/pages/implementations/home_dashboard_page.dart:2660`，基线 develop），`_seriesMetaFor`（`:2684`）因此从不为服务器条目产出 `FushiSeriesMeta`，`_continueBlock` / `_seriesBlock` 只能画平铺色块。根本原因在数据结构：`ServerContinueCandidate`（`fushi/lib/src/utils/misc/dashboard_server_continue.dart:21`）只带封面地址，服务器明明报了的背景图 / logo / 类型年份在映射成候选时被丢掉，首页手里没有任何可画的作品图。另外 `MediaServerItem` 没有「上级 logo」字段（只有上级 Thumb / Backdrop），集拿不到所属剧的艺术字：Jellyfin / Emby 的 `ParentLogoItemId` 没解析，Plex 集的 `clearLogo` 图实际挂在剧的 ratingKey 上，却被记成集自己的 logo（拿集 id 拼的 clearLogo 地址取不到）。
- **[x] ① 已修复** — 服务器条目的作品图随候选带来：`mediaServerContinueCandidates` 新增 `backdropOf` / `logoOf`，候选带 `backdrop` / `logo`（ImageProvider，构造不发请求，卡画出来才经服务器自己的取图器取图，走 `RemoteCoverImage` 的内存 + 磁盘缓存，缓存键按剧共享）以及 `coverIsPoster` / `isEpisode` / `genres` / `year` / `rating`（清单里已有的字段，不多发请求；集不带年份 / 评分，那是这一集的）。新函数 `serverContinueSeriesMeta` 把候选折成与本地视频同形的 `FushiSeriesMeta`（背景、logo、海报位只放真海报、概览、「电影 / 剧集 · 年份」chip），首页 `_seriesMetaFor` 对服务器条目直接用它，「继续」拼贴首块 / 半高块与本地视频走同一个 `_seriesBlock` / `fushiSeriesCoverBlock`。取图工厂（封面 / hero 大图 / 库封面 / 背景 / 新增 logo）从服务器页面文件挪到非页面层 `fushi/lib/src/media/video/media_server/media_server_images.dart`，服务器页与首页共用一份；集的背景图 / logo 一律先取所属剧的（`mediaServerBackdropImage` / 新 `mediaServerLogoImage`），服务器页自己的「继续」色块因此也画剧的艺术字。`MediaServerItem.parentLogoItemId` 新字段：Jellyfin / Emby 解析 `ParentLogoItemId` + `ParentLogoImageTag`；Plex 解析 `clearLogo` 图地址里的 ratingKey（`PlexMetadata.clearLogoRatingKey`），挂在别的条目上就记成上级 logo。Audiobookshelf 没有横版图，不变；互联设备条目不在本次范围。主卡（`_continueMainEntry`）与横滑行（`_continueSideEntry`）本地视频也不画刮削图，服务器条目与之一致、未改。
- **[x] ② 已加自动化测试** — `fushi/test/utils/dashboard_server_continue_test.dart`（候选映射：集用剧的背景 / logo 而非集自己的、剧没图时退回集自己的、没有剧海报时封面不当海报、电影带年份 / 评分；`serverContinueSeriesMeta`：带背景图时产出含背景 / logo / 海报 / 概览 / chip 的元数据，ABS 或无图为 null）；`fushi/test/pages/home_dashboard_page_test.dart`「色块「继续」：服务器条目带背景图 / logo 时画系列色块（BUG-5608）」（拼贴首块里画出服务器背景图与艺术字，封面经服务器取图器取）；`fushi/test/media/video/media_server/jellyfin_media_server_test.dart`（`ParentLogoItemId` 有 tag 才给并透传）；`fushi/test/sync/plex_video_client_test.dart`（集的 clearLogo 挂在剧上记成上级 logo、剧自身 logo 不变、地址认不出按旧口径）。
- **备注**：真机像素复测需要可达的媒体服务器，本次环境未配置，靠上述测试覆盖。
