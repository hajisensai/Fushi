## BUG-2108 · 视频回放/重看被重复计入观看时长
- **报告**：2026-09-04（用户：统计中心「本周」明细里《リズと青い鳥》片长 90 分钟却记 2 小时 0 分；《響け！ユーフォニアム 2》单集 24 分钟记 59/46 分钟；且明细行没法删）
- **真实性**：✅ 真 bug（口径问题，用户拍板「重听不要记录在内」）。生产库逐段核验：单时钟、零重叠、无 EOF 卡 playing、倍速 1.0；用 srt 全片字数逐 cue 累计反推，两次会话各覆盖片内 58 / 36 分钟内容却分别记了 76 / 44 分钟——多出的 20~30% 全是回放上一句 / 拖回重听的**真实播放态时间**。根因是口径：`packages/fushi_audio/lib/src/audiobook/study_clock.dart` 的 `_accrue`（tick 末刻按 `isActive()`= `isPlaying` 整窗计 60s，重听照计、且一个 20s 回放可能记 60s 或 0s），`fushi/lib/src/media/video/video_watch_tracker.dart` 只把 `isPlaying` 挂给时钟，对位置推进到「看过没有」毫无感知。
- **[x] ① 已修复** — 观看时长改为**只计首次覆盖**：新增 `fushi/lib/src/media/video/watch_coverage.dart`（每部视频「已看过的片内区间并集」，按 `video_watch_coverage_<bookUid>` 偏好持久化，删该视频统计 / 清空全部时连带清）；`VideoWatchTracker` 每秒 + 每次播放源通知采样位置，连续播放推进（`isContinuousPlaybackAdvance`：媒体推进 ≤ 墙钟×倍速×1.25+500ms，否则是 seek 跳变）才把区间并入并集，只有新增部分按比例折成墙钟时间经 `StudyClock.addActiveMs` 记账（时钟新增 `StudyAccrual.explicit` 模式：tick 不再按墙钟计，只裁决段生命周期）。本次会话前已整段看过的 cue 字幕字数同律不计。附带：时段明细 sheet（`stat_period_detail_sheet.dart`）条目长按 / 右键 → 确认 → 删该媒体在本时段内那几天的统计（段按 uid 写零经 LWW 同步传播，legacy 日行本地删，游戏删 `galgame_sessions`；`FushiDatabase.deleteStatFactsOnDays`），五个调用方删后重聚合；`getLatestStudyEndAtByMedia` 排除零行。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/watch_coverage_test.dart`（并集代数 / JSON 往返 / 非标量水位）、`fushi/test/media/video/video_watch_tracker_test.dart`「观看时长 = 首次覆盖」组（回放不计 / 前跳不计 / 倍速 / 暂停 / 次日重看 0 / 部分重叠按比例 / 已看 cue 不计字）、`fushi/test/media/audiobook/study_clock_test.dart`「显式记账模式」组、`fushi/test/pages/stat_period_detail_sheet_test.dart`（长按删除 / 取消）、`fushi/test/database/study_segments_test.dart`「用户按日删统计」组。
