## BUG-1933 · 全屏与取消全屏时闪一帧白色
- **报告**：2026-08-29（用户：「全屏和取消全屏的时候会有一帧白色，怎么解决」；BUG-1916/1917 同批跟进）
- **真实性**：✅ 真 bug。Windows 全屏切换（F11 → `windowManager.setFullScreen`，`window_manager-0.5.2/windows/window_manager.cpp:568`；视频页 F 键 → media_kit `Utils.EnterNativeFullscreen`，同一技法）靠**剥掉 `WS_CAPTION|WS_THICKFRAME` + SWP_FRAMECHANGED** 实现：风格变更迫使 DWM 重建窗口 frame visual，至少一帧合成里 Flutter 子窗图层缺席，整窗露出主窗**重定向表面**——表面色是 BUG-1916 之后的主题 surface 色，**浅色主题下 ≈ 白色**，暗内容页（视频/夜间阅读）上就是用户看到的「一帧白色」。洋红示踪实测（把 `Win32Window::PaintBackdrop` 临时改洋红 + 屏幕采样 ~8ms/次，隔离 Release 实例、视频页、3840×2160@150%）：window_manager 路径**进/出各 6/6 全露、整个采样区 100%**；media_kit 路径与「去边框但单次 SetWindowPos」变体间歇露出（1/6、3/6）；对照组 **SC_MAXIMIZE/SC_RESTORE 0/6 不露**、「保留边框、只把窗口放大到客户区盖满显示器」0/6 不露——坐实露出不是 DWM 固有行为，而是**风格剥离**触发的。
- **[x] ① 已修复** — 本提交。全屏改为 **runner 唯一拥有**（`fushi/windows/runner/win32_window.cpp` `Win32Window::SetFullscreen/IsFullscreen`），Dart 三个入口全部改走 `app.fushi/window` channel（`flutter_window.cpp` `setFullscreen`/`isFullscreen`；`window_caption_channel.dart`；F11 `global_navigation.dart` Windows 分支；视频页 `fullscreen.part.dart` `_enter/_exitVideoNativeFullscreen` Windows 分支；macOS/Linux 原路径不动）。实现四要素：a) **保留边框风格**，按**实测边框**（窗口矩形 vs 客户区屏幕原点；`AdjustWindowRectExForDpi` 在 window_manager hidden 标题栏的 WM_NCCALCSIZE 魔改下会算错）把窗口放大到客户区恰好盖满显示器（边框悬屏外），与最大化同合成路径；b) **`HWND_TOPMOST` 盖任务栏**（shell 的全屏检测不认带边框超尺寸窗，rude-app 隐藏任务栏不触发），全屏中失焦（`WM_ACTIVATE` WA_INACTIVE）降 `HWND_NOTOPMOST`、回焦恢复，其它 app 可正常置前；c) **`WM_GETMINMAXINFO` 抬高 `ptMaxTrackSize`**（在 `FlutterWindow::MessageHandler` 插件分发后覆写——window_manager 委托会消费该消息；默认 SM_C*MAXTRACK 会把 2216 高钳到 2186，底部露 30px 任务栏）；d) **过渡快照兜底**：`SetFullscreen` 进/出各截一次当前客户区屏幕像素，`FillSurfaceBackdrop` 有快照时 StretchBlt 垫进表面（残余竞态露出的将是拉伸旧帧而非纯色），快照只活在一次 SetFullscreen 内，普通拖边缩放仍走纯色刷（BUG-1917 节奏零影响）。退出用保存的 `WINDOWPLACEMENT` 还原；**最大化态两边都要特判**（均实测踩到）：进入时 zoomed 窗口的 SetWindowPos 尺寸不生效，先 `SetWindowPlacement(SW_SHOWNORMAL, rcNormalPosition=显示器矩形)` 原地解除最大化再放大；退出时要先落 `SW_SHOWNORMAL` 再 `ShowWindow(SW_MAXIMIZE)`——直接 `SetWindowPlacement(SW_SHOWMAXIMIZED)` 对 zoomed 标志仍在的窗口是几何 no-op，会卡在巨窗矩形。`desktop_window_placement.dart` 的 bounds 保存判据加 `WindowCaptionChannel.isFullscreen()`（window_manager 在 Windows 不再拥有全屏态，否则会把巨窗矩形当普通 bounds 存盘、下次启动整窗贴屏——实测踩到）。修复后同测法：F11 24+ 次、视频 F 键 6 次切换**零露出**，几何/置顶每次精确还原；任务栏全盖住（截图取证）；最大化→全屏→退出精确回最大化；失焦降置顶/回焦恢复实测通过。
- **[x] ② 已加自动化测试** — `fushi/test/build/win_fullscreen_flash_guard_test.dart`：8 条源码扫描守卫（runner `SetFullscreen` 存在且不剥风格（win32_window.cpp 全文件禁 `GWL_STYLE` 写）、快照优先于纯色刷的顺序守卫（剥注释后 indexOf）、TOPMOST + AdjustWindowRectExForDpi + GETMINMAXINFO 抬限、channel 两方法注册、Dart 三入口 Windows 分支走 `WindowCaptionChannel.setFullscreen`、placement 保存判据含 `isFullscreen`）；变异实测全红（见提交信息）。
