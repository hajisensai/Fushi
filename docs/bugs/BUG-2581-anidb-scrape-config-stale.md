## BUG-2581 · 手动刮削协调器指纹漏掉AniDB哈希开关与账号
- **报告**：2026-09-18（用户：AniDB 用户名/密码已填、哈希开关已开、客户端留空用内置身份，刮削仍报「AniDB 哈希识别未执行：哈希识别不可用，缺少账号或注册客户端配置」；设置页也没有任何入口能确认登录是否成功）
- **真实性**：✅ 真 bug。根因 `fushi/lib/src/pages/implementations/home_page.dart` `_videoSourceScrapeController`（修前 `fingerprint = <Object>[...]` 手抄块）：`_videoSourceScrapeController` 用手抄的配置指纹决定要不要重建 `VideoSourceScrapeCoordinator`，指纹只含 `tmdbApiKey / anidbClientName / anidbClientVersion / locale / primaryProvider / identifierWords`，**漏掉 `hashEnabled` / `anidbUsername` / `anidbPassword`**。而协调器构造时把这三个字段烘进 `AnidbHashIdentityService(enabled: config.hashEnabled, config: config.anidbUdpConfig)`（`packages/fushi_engine/lib/media/video/metadata/video_source_scrape_coordinator.dart` 构造函数）。同一次运行里先刮过一次（当时账号没填 / 开关没开），之后到设置页填账号、开开关，再回来刮削——指纹没变 → 复用旧协调器 → 旧 `AnidbHashIdentityService.isConfigured` 仍为假 → `_identifyWork` 一直发「缺少账号或注册客户端配置」警告（`video_source_scrape_coordinator.dart` `_identifyWork`）。同文件 `_productionVideoDiscoveryController` 的指纹是含这三个字段的，两处手抄不一致。内置客户端 `fushiplayer` v1（`anidb_app_client.dart`）满足 `AnidbUdpConfig.isAvailable` 的 `^[a-z]{4,16}$`，留空客户端本身没问题。
- **[x] ① 已修复** — `VideoSourceScrapeGlobalConfig.runtimeFingerprint`（`packages/fushi_engine/lib/media/video/metadata/video_source_scrape_config.dart`）成为唯一指纹，覆盖所有会进协调器/发现服务构造快照的字段；`home_page.dart` 两个装配点都改用它，不再手抄。顺带补「测试 AniDB 登录」设置项（`settings_schema_services.dart` → `testAniDbLogin`，`video_settings_actions.dart`）：`AnidbUdpFileClient.verifyLogin()`（`fushi_engine` 的 `anidb_udp_file_client.dart`）只发 AUTH、`close()` 时 LOGOUT，不算哈希，失败原因按认证/客户端/网络/限流四组落设置页 snackbar。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/metadata/anidb_hash_config_test.dart`（`runtimeFingerprint (BUG-2581)`：九个字段逐个改动都必须改变指纹 + 源码守卫 `home_page.dart` 不得再出现 `fingerprint = <Object>[`、两处装配点都引用 `runtimeFingerprint`）；`fushi/test/media/video/metadata/anidb_udp_file_client_test.dart`（`verifyLogin` 组：AUTH→LOGOUT 不发 FILE、201 记录新版本提示、500 归认证失败且不发 LOGOUT、配置不全不开 socket）。
- **备注**：「视频首页那条『配置可选在线服务』提醒」不是 AniDB 判定——它是 AniDB / Jimaku / OpenSubtitles 三者任一未配就显示（`video_online_services_preferences.dart`），只配 AniDB 不会消失，要么把另外两个也配上、要么点「永久关闭提示」。
