## BUG-2008 · 合集字幕批量搜索只用合集名与裸 anilistId，无视已刮削的规范身份
- **报告**：2026-09-01（刮削重设计调查：字幕域 7 处「身份→请求」构造盘点中定位）
- **真实性**：✅ 真 bug。`subtitle_collection_panel.dart`（修前 :210-213/:393-403）：查询词 = 合集显示名过一遍文件名解析（中文名对 Jimaku/AniList 命中率最差）；请求身份只有 `media_collections.anilistId`，`mediaKind` 写死 tv、无 originalTitle、无 tmdb id——而同一合集刮削出的 `video_metadata_works`（日文原名 + 全套 provider 身份）就躺在库里没人读。播放页单集面板（`subtitle.part.dart` 的 seed）早已接了规范身份，合集批量是掉队的那个。
- **[x] ① 已修复** — `d44bebbe78`（首版 `147ff99e5f` 因审查阻断被撤销重做）：面板 initState 读回合集的规范作品与身份（`_loadCanonicalIdentity`）：用户未改过查询词时替换为日文原名；请求带 originalTitle / tmdb id、mediaKind 取刮削结论、合集未绑 AniList 而身份里有 anilist id 时直接按 id 搜。首版额外把 AniDB 全量别名灌进刮削后补齐（`video_subtitle_backfill.dart`）的 `alternateTitles`——被审查判死（一部番 20~60 条别名 × Jimaku「逐条试、首个非空即停」× 逐集调用 = 请求爆炸，且 SnK/HxH 类短别名 first-hit-wins 误配整部字幕），重做已撤销该接线：backfill 的 `scrapedMediaReference` 本就带外部 id 与日文原名（见 `scraped_subtitle_targets.dart`），身份精度不依赖别名兜底。
- **[x] ①b 复审补修** — 重做版本仍有两处没堵住原失败路径，已就地根因修复：
  1. **首搜时序**：`initState` 同时 `unawaited(_searchSources(...))` 与 `unawaited(_loadCanonicalIdentity())`，而 `_searchSources` 在第一个 `await` 之前就把请求身份**同步**构造完了 —— 于是「合集已绑 AniList」这条最常见路径（= 绝大多数刮过的合集）首搜恒用裸显示名 + 裸 anilistId，规范身份只在用户手动再搜一次时才生效。改为由 `_loadCanonicalIdentity()` 读回身份后**独占**发起首搜（读库失败 fail-open 回旧路径）。
  2. **身份仍是手搓**：面板自己 new 了一份 `VideoMediaReference`，丢掉 imdbId（OpenSubtitles 的强键）/ tvdbId / anidbId / year，并**硬写 `discoveryCategory: anime`** —— 真人剧合集直接踩回 BUG-1694 的 Jimaku anime 硬过滤。现收敛到 `scraped_subtitle_targets.dart` 新增的去模型化原语 `identityMediaReference` / `identityDiscoveryCategory`（`scrapedMediaReference` / `scrapedDiscoveryCategory` 一并改为委托，判据只剩一份）；面板只负责把 `video_metadata_works` 行 + provider 身份行喂进去。没刮过的合集逐字节走旧路径。
- **[x] ② 已加自动化测试** — `fushi/test/pages/subtitle_collection_panel_test.dart` 新增两条 widget 断言，直接钉住交给 provider 的 `VideoMediaReference`：①「已刮削合集的首搜带规范身份」——anidb/tmdb/imdb/原名/年份全带、查询词换成日文原名、分类 = anime；②「真人剧合集不再写死 anime 分类」——只有 tmdb/imdb 身份时 `discoveryCategory` 必须是 `tv`（写死 anime 会踩回 BUG-1694），且 imdb（OpenSubtitles 强键）与 year 原样带过去。此前这一条勾成 `[x]` 却只写「既有测试全绿」，身份构造零新增断言 —— 那不算测试。
- **备注**：字幕域其余独立身份构造点（发现页 / 旧番剧订阅链 / 浏览器扩展桥）各属独立功能面，未在本轮收敛——见 docs/bugs 索引与 P3 PR 描述的后续清单。
