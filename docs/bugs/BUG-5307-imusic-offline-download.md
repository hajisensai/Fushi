## BUG-5307 · 互联音乐库：把 host 曲目下载到本机离线听（design-imusic-q12）
- **报告**：2026-11-23（拍板台 design-imusic-q0..q12 实现分期，PR #4271 分支 `claude/imusic-impl`）
- **真实性**：✅ 真缺口（拍板「做」）。原先客户端只能串流 host 曲目。
- **[x] ① 已修复** — 接进与 Jellyfin / Subsonic 同一条离线副本管线（`fushi/lib/src/media/music/server/music_server_downloads.dart`，v175 `music_server_downloads`）：`InterconnectMusicBrowser` 实现 `MusicServerDownloading` / `MusicServerCoverBytes`（`fushi/lib/src/media/music/server/interconnect_music_client.dart`），`downloadSourceFor` 每次开跑 / 续传现签一张 `forDownload` 票（原样音质 + `segment`：CUE 曲目由 host 无损截段），并带回通道的证书指纹；下载服务按 `MusicServerDownloadSource.pinnedFingerprint` 用钉扎证书的 HTTP 客户端直取（`createPinnedHttpClient`），封面经通道取字节，host 上生效的歌词经 `MusicLyricsService.storeHostLyrics` 存进歌词缓存（来源 / 偏移 / 手动指定原样）。uid 不变（host 的 `track_uid`），曲库行是 `fushi_host` 种类，播放项与曲库行有副本时放本机文件（`music_server_play_item.dart` / `music_remote_tracks.dart`）；单曲 / 专辑 / 艺人的「下载 / 删除下载」入口与已下载角标全部复用。host 播放项不带 `serverTrack`（host 没有播放上报 / 收藏接口，带上会永远排进离线补发队列）。合并 develop 时撤掉了第一版自建的插件下载管线 + 本机曲目别名合并方案（两套下载并存、uid 改变），改用这一条。MV 画面不随副本下载（体积大，MV 由歌词页按需取）。
- **[x] ② 已加自动化测试** — `fushi/test/media/music/server/interconnect_music_offline_copy_test.dart`（签票参数、钉扎传输拿到指纹、封面走通道、host 歌词入缓存、副本行 `fushi_host`、曲库行与服务器页播放项换成本机文件且不带服务器身份；无副本时占位路径不带服务器身份）；host 侧 `segment` 选项在 `packages/fushi_engine/test/sync/music_library_host_module_test.dart`。
- **备注**：设计与拍板见 `docs/specs/2026-11-23-interconnect-music-library-design.md` §9。
