## BUG-811 · 互联开启后手机视频列表为空(host listVideos 每视频串行 ffmpeg 探测超过 client 15s 超时)
- **报告**：2026-07-14（用户：手机开启 Hibiki 互联后视频页空的）
- **真实性**：✅ 真 bug。根因链：host `app_model_library_host_service.dart:863`（`listVideos` 逐视频串行 `await _embeddedSubtitleTracksForVideo` → `video_subtitle_source.dart:585` spawn `ffmpeg -i`，每项超时基线 60s、大文件到 1200s，无缓存、每次 GET 全量重跑）；client `hibiki_client_sync_backend.dart:145`（`listTimeout=15s` 封顶 `/api/library/videos` 请求）；`home_video_page.dart:418/491`（超时 → `failed:true` → 远端视频空）+ `1952`（本地空 + 远端空 → 整页 `_buildEmpty()`）。用户库 511 个视频，逐个 ffmpeg 远超 15s → 手机无本地视频 → 整页空。书/有声书正常因 host 列书零 ffmpeg + client 列书无超时（不对称对照 `app_model_library_host_service.dart:293-337` / `hibiki_client_sync_backend.dart:713`）。
- **[x] ① 已修复** — `app_model_library_host_service.dart` `_videoInfoFromRow` 删除 `_embeddedSubtitleTracksForVideo` 调用（连同现已无引用的私有方法与 `video_subtitle_source.dart` import），列表端点变纯 DB/stat 读、与 listBooks 对称毫秒返回；内嵌轨已由 `/streamurl` 端点 `hibiki_sync_server.dart` `_embeddedSubtitleTracksForRequest` 在播放时按需探测并下发（client 唯一消费者 `video_hibiki_page.dart:1759` 读的是 streamurl 响应，列表 embeddedSubtitleTracks 零消费）。
- **[x] ② 已加自动化测试** — `test/sync/hibiki_library_collections_test.dart`（BUG-811 行为：存在视频文件下 listVideos 返回 embeddedSubtitleTracks 空 + 源码守卫：host service 不得引用 `listEmbeddedSubtitleTracks`）+ `test/sync/hibiki_library_host_service_video_test.dart`（注入会返 3 轨的 mock ffmpeg 后端，断言 listVideos 仍不探测、内嵌轨空）。
- **备注**：与本地不入库的 REGRESSION_BUGS 区分。取 811 避让 origin/develop 已用的 808/809/810（有声书片段导出 PR#124/125）。
