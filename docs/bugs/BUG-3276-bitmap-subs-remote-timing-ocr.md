## BUG-3276 · VobSub/DVB 图形字幕与远程播放没有逐句时间与整轨 OCR
- **报告**：2026-10-11（用户：VobSub / DVB 图形字幕和远程播放的图形字幕没有逐句时间（制卡锚不到句子音频）、整轨 OCR 入口不出现、模糊只能糊整条字幕带）
- **真实性**：✅ 真 bug（基线 develop `e863ddadb5b`）
  - **整轨链路写死 PGS**：`fushi/lib/src/media/video/graphic_subtitle_track_ocr.dart:29-30` `graphicSubtitleTrackOcrSupportsCodec` 只认 `codec.contains('pgs')`；抽轨参数 `:72` 恒 `-f sup`（VobSub / DVB 被 sup 封装器拒收：`Invalid data`），解析 `:200` `readGraphicSubtitleSupInBackground` 只会 `PgsSubtitleParser.parse`。于是 VobSub / DVB 既抽不出时间表也解不出位图。
  - **按位图模糊 / 逐句时间表拒绝一切远端**：`fushi/lib/src/media/video/video_graphic_subtitle_regions.dart:234-241` `graphicSubtitleRegionRequestFor` 先过同一个 PGS 门（`:239`），再对任何带 scheme 的地址 `return null`（`:241`）；控制器 `fushi/lib/src/media/video/video_player_controller.dart:3991-3998` `_loadGraphicSubtitleTimings` 只经它取数，远端播放（互联 / 媒体服务器 / URL 流）的图形轨永远没有逐句时间。
  - **远端菜单与整轨 OCR**：`fushi/lib/src/pages/implementations/video_fushi/subtitle.part.dart:325` 远端内封图形轨行 `enabled: track.isText`（图形轨点不了），`:367` 整轨 OCR 入口只在 `if (!_isRemote)` 分支、`:397` 再过 PGS 门；`:2173` 抽轨不传 `codec`，`:2211` 读取按 PGS 段流解析。
- **[x] ① 已修复**（未提交，工作区 `.worktrees/bitmap-subs`）—
  - 位图字幕栈编码无关化并搬进引擎 `packages/fushi_engine/lib/media/video/bitmap_subtitle/`（纯 Dart，过 `fushi_engine_purity_guard_test`）：PGS 解析器、`BitmapSubtitleCue` 接口、VobSub（`dvd_subtitle`）/ DVB 解码器、单轨 MPEG-TS 解复用、轨头（extradata 经 ffprobe 读）与 `GraphicSubtitleInput`（本地 / http(s) + 播放会话请求头）；抽取 / 探测 / 后台解码在 `graphic_subtitle_track_extract.dart`（PGS `-f sup`，VobSub / DVB `-f mpegts -muxdelay 0`）。app 只留 OCR / SRT 层与依赖 `dart:ui` 的 `Rect` 位图时间表，删掉 app 副本、全仓改 import。
  - 远端逐句时间：边播边记（mpv `sub-start` / `sub-end`）+ 整轨来源按播放源分流——互联 host 新端点 `GET /api/library/videos/<id>/graphicsubtitle`（`?part=header` 取轨头）回传 host 抽好的整轨，client 不读整片；媒体服务器 / URL 流按流地址 + 同一份请求头抽。整轨抽取实现 `InterconnectGraphicSubtitleExporter` 搬进引擎（`packages/fushi_engine/lib/sync/interconnect_graphic_subtitle_export.dart`），app 的 `FushiSyncServerController` 与无头服务端 `packages/fushi_server/lib/src/headless_host.dart` 注入同一份（服务端缓存落 `<数据根>/tmp/graphic_sub_tracks`，ffmpeg 走引擎 CLI 后端 + 配置的 ffmpeg 路径）。
  - 互联按位图模糊：控制器公开整轨抽取 / host 下回来的那份位图时间表（`VideoPlayerController.graphicSubtitleRegionTrack`，换轨换片清空），`VideoGraphicSubtitleObscureLayer` 新增 `regionTrack` 来源且优先使用（`layout.part.dart` 接线），互联播放不再退回整条字幕带，也不为遮蔽整片读流。
  - 整轨 OCR：本地与远端共用 `_runGraphicTrackOcr`，取数口径与控制器逐句时间表一致（`graphicSubtitleTimingInputForTrack` / `materializeGraphicSubtitleTrack`：本地读盘、网络流带请求头、互联下载 host 整轨），带 `codec`、按轨头解码（抽轨完成后 `complete: true` 收尾包也交出）；VobSub / DVB 与远端图形轨（原始容器直出）都出整轨 OCR 入口。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/bitmap_subtitle/`（VobSub / DVB 解码、TS 解复用、真实 fixture 抽轨）、`fushi/test/media/video/graphic_subtitle_remote_timing_test.dart`（边播边记、host 整轨合并、位图时间表发布 / 清空、`materializeGraphicSubtitleTrack` host 分支、整轨 OCR 取数口径）、`fushi/test/media/video/video_graphic_subtitle_regions_test.dart`（遮蔽层用控制器位图时间表、不发抽轨请求）、`fushi/test/sync/interconnect_graphic_subtitle_track_test.dart`（端点契约、client 下载、引擎抽取缓存、app 与 fushi_server 装配守卫）、`fushi/test/pages/video_graphic_subtitle_guard_test.dart` / `video_graphic_subtitle_ocr_cancel_on_switch_guard_test.dart` / `video_remote_graphic_subtitle_wiring_guard_test.dart`（选轨签名、本地 / 远端整轨 OCR 取数与接线）。
- **备注**：互联 host 整轨下载不可中途撤销（载荷只有几百 KB，但 host 首次抽取要整片读盘，首字节可能几十秒）；老 host 无端点时远端时间表退回边播边记、远端整轨 OCR 报失败（不会退回读流）。
