## BUG-3412 · 阅读器查词框顶栏三组按钮尺寸不统一
- **报告**：2026-10-14（用户：iOS 手机小说阅读器贴底查词弹窗，顶栏左侧 A− / A+ / 制卡目标大胶囊、中间 ☆ / ↺ / ▷ / ⊙ 小胶囊、右侧 × 圆钮三种尺寸，要求「做到一样大、可以变小」）
- **真实性**：✅ 真 bug。三组本应共用 `dictionaryPopupTopActionConstraints()`（移动端 44），但中段 header 被布局压缩：
  - `fushi/lib/src/pages/implementations/dictionary_popup_layer.dart:1674`（修复前）`sideReserve = max(左簇宽, 右簇宽) + gap`，header 放进 `Padding(horizontal: sideReserve)`——按较宽的左簇两侧**对称预留**，手机 390 宽下左簇（A− / A+ / 制卡目标 3×44 + 内边距）一宽，中段只剩不到 4 颗按钮的宽度；
  - `fushi/lib/src/pages/implementations/reader_fushi_page.dart:5167`（修复前）header 外层 `FittedBox(fit: BoxFit.scaleDown)` 于是把整组等比缩到约一半——中段胶囊变小；右簇关闭圆钮是单独的 44 圆，又是第三种视觉尺寸。
  - 另：各处图标尺寸手写 `size: 20`（`dictionary_popup_layer.dart:1591/1601/1611/1650/1751/1777`、reader / video header、制卡目标按钮），没有单一来源。
- **[x] ① 已修复** — `dictionary_popup_layer.dart`：新增 `_PopupTopBarLayout`（`MultiChildLayoutDelegate`），左簇钉行首、右簇钉行尾，header 拿两簇之间（各留 gap）的**全部**剩余宽，能相对整条顶栏居中就居中、放不下时夹在剩余区内，只有剩余区仍放不下才轮到内容侧 FittedBox 收缩（BUG-822 / BUG-826 不重叠不变式保持）；顶栏高度有无 header 一律 `边长 + inset`。尺寸统一收到单一来源：边长仍是唯一的 `dictionaryPopupTopActionExtent`（移动端 44 触控下限、桌面 36；PR 初版曾把移动端收到 40，审查时恢复 44——中段被挤小的根因是对称预留布局，换成 `_PopupTopBarLayout` 后 390 宽下 44 边长的 4 颗中段按钮放得下，不该拿命中区换宽度），新增 `kDictionaryPopupTopActionIconSize = 18`（原 20），左簇 / 历史导航 / 溢出菜单 / 关闭 / 制卡目标（`dictionary_popup_mining_target.dart`）/ 阅读器 header（`reader_fushi_page.dart` `buildPopupAudioControls`）/ 视频 header（`video_fushi_page.dart` `buildPopupHeaderFor`）全部引用它。见提交 `fix(lookup): unify popup top bar control sizes (BUG-3412)`。
- **[x] ② 已加自动化测试** — `fushi/test/pages/popup_topbar_uniform_size_test.dart`：390 宽（iPhone）下真 `DictionaryPopupLayer` + 与生产同结构的 header，断言左簇两组胶囊 / 中段胶囊 / 关闭圆钮同高 = 边长、header 未被缩小（宽 ≥ 4×边长）、三处图标渲染尺寸相同 = 18、同一中线、header 落在两簇之间；640 宽下 header 相对整条顶栏居中（保住用户 10-09）；源码扫描守卫：reader / video / 制卡目标的顶栏按钮不得手写 `size: <数字>`。修复前代码上该文件红：中段胶囊实测高 11.68（期望 36，被 FittedBox 缩到 1/3）、源码守卫红，宽屏居中用例绿（保持行为）。同步更新 `dictionary_child_popup_close_guard_test.dart`、`popup_topbar_no_overlap_guard_test.dart`、`dictionary_popup_swipe_close_test.dart`（TODO-501）的字面量断言（移动端 ≥44 / 共享图标常量）。
- **备注**：定向测试（引用顶栏 / header 的 71 个测试文件）Mac 上首轮 656 过 / 1 红（TODO-501 仍断言旧 20px 图标，已更新），改后复跑 5 个相关文件 83 全过；`flutter analyze` 零 issue。iOS 真机未复测（本轮只做 widget 级几何验证）；顶栏整体仍随 `topBarScale`（界面大小 × 词典字号）等比缩放，三组同比例变化，不破坏统一。
