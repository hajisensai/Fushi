## BUG-5614 · youtube-music-cover-letterbox
- **报告**：2026-11-28（用户：内置 YouTube 音源曲目在歌词页 / 播放器的方形封面顶部和底部露黑边；复现：搜「碧天伴走 MyGO!!!!! Topic」→ `S7S4gUjXKjo`，播放后开歌词页）
- **真实性**：✅ 真 bug。`YoutubeMusicClient.coverUri`（`packages/fushi_engine/lib/media/music/youtube/youtube_music_client.dart:158` 旧）→ `youtubeThumbnailUrl`（`packages/fushi_engine/lib/media/video/youtube_source_resolver.dart:248` 旧）= `hqdefault.jpg`。实测 `S7S4gUjXKjo`：`hqdefault` 480x360、`sddefault` 640x480 都是 4:3 画布，首末行像素全黑（16:9 视频上下 letterbox）；`maxresdefault` / `hq720` 1280x720、`mqdefault` 320x180 是 16:9、无黑边。`MusicCover`（`fushi/lib/src/pages/implementations/music/music_cover.dart:204` `BoxFit.cover` + `:237` `AspectRatio(1)`）方形居中裁切 480x360 → 360x360 时上下各 45px 黑条进了画面。另：`maxresdefault` 对没高清源的视频 404（实测 `jNQXAC9IVRw` maxres / hq720 / sd 全 404，只有 hq / mq），所以不能只把同步 URL 换成 maxres。
- **[x] ① 已修复** — `youtubeThumbnailUrl` 改为恒存在且 16:9 的 `mqdefault`（4:3 老视频在 mq 上是左右留边，方形居中裁切正好裁掉）；新增 `youtubeHdThumbnailUrl`（maxres）与 `youtubeThumbnailFallbackUrl`（i.ytimg.com 视频缩略图 → 同一视频的 mqdefault）。音乐 `coverUri` 给 maxres；所有在线音乐封面的取字节层 `AppImageFileService.get`（`AppCachedHttpImage` 磁盘缓存，MusicCover / 歌词可视化 / 取色都经它）遇 404 按回退规则改取一次 mqdefault，缓存仍记在原 URL 下；系统媒体卡片（audio_service 自己下载、无 404 回退）经 `musicMediaSessionArtUri` 直接给 mqdefault。视频侧 `youtubeThumbnailCandidates` 去掉同样带黑边的 `sddefault` / `hqdefault`，改 maxres→mq；TMDB 预告片缩略图改用 `youtubeThumbnailUrl`。曲库行只存 videoId（`coverRef`），封面 URL 现算，已入库曲目不需迁移。
- **[x] ② 已加自动化测试** — `fushi/test/media/music/youtube_music_cover_letterbox_bug5614_test.dart`（coverUri 给 maxres、有 mq 退路；媒体卡片换 mq、其它地址原样）、`fushi/test/utils/net/app_image_file_service_retry_test.dart`（404 → 回退地址、回退也 404 不再回退、200 不查回退、生产回退规则）、`fushi/test/media/video/youtube_thumbnail_fallback_test.dart`（候选不含 4:3 变体、回退规则）、`youtube_import_cover_test.dart` / `music_server_test.dart` / engine `youtube_music_client_test.dart` 断言更新。
- **备注**：内置 YouTube 音源不实现 `MusicServerDownloading`，不会走 `MusicServerDownloadService._writeCover`，下载封面链路不涉及；互联 host 的 `cover()` 只出本机目录 / 内嵌封面，不代理远程封面。
