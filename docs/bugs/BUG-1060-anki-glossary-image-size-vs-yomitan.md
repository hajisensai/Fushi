## BUG-1060 · 制卡词典图片比 Yomitan 卡片小很多（导出把 em 折算成物理 px）
- **报告**：2026-07-24（用户：「制卡词典的图片和 yomtian 导入的不一样（好像小了很多）」）
- **真实性**：✅ **真 bug（沿真实代码路径 + 上游源码逐条比对）**。上游 Yomitan 的 `structured-content-generator.js`（`_createImage`，比对的是 master 版）导出 Anki 字段时，图片容器**永远**写 ``imageContainer.style.width = `${usedWidth}em` ``，1em 具体多大交给 CSS 决定：Yomitan 弹窗自带 `ext/css/structured-content.css` 的 `.gloss-image-container{font-size:calc(1em/var(--font-size-no-units))}`（≈1px），`[data-size-units=em]` 时才 `font-size:1em`；**Anki 卡片上没有这份 CSS**，`em` 于是按卡片正文字号解析——这正是 Yomitan 卡片里图片「大」的来源。本仓制卡走 `hibiki/assets/popup/popup.js` 的 `createDefinitionImage(data, dictionary, exporting=true)`：`hibiki/assets/popup/popup.js:1076`（修复前）把容器宽度写成 `${usedWidth}px`，`applyImageStyles`（`hibiki/assets/popup/popup.js:613`，仅导出路径调用）又内联 `font-size:${useEmUnits ? '1em' : '1px'}`。内联样式优先级最高，note type 的 CSS 也压不动，于是卡片图片被钉死成 `usedWidth` 个物理像素，比 Yomitan 卡片小「一个卡片字号」的倍数（十几到二十几倍）。附带同源缺陷：无尺寸 SVG 分支（`fontSize:'inherit'` + `height:1.2em`）也被随后追加的 `font-size:1px` 覆盖，`1.2em` 实际成了 1.2px，只有带 `data-sc-class="gaiji"` 的外字被 `anki_models.dart` 的 `!important` 中和样式救回来。根因 `file:line`：`hibiki/assets/popup/popup.js:613` + `:1076`（及两份 vendor 镜像同行）。
- **[x] ① 已修复** — 提交 `c30d2a556`。根因修（对齐上游语义，非事后 CSS 兜底）：① 容器宽度按路径分语义 ``imageContainer.style.width = exporting ? `${usedWidth}em` : `${usedWidth}px` ``——导出保留 Yomitan 的 em 语义，弹窗维持 px（弹窗自带那份把 1em 压成 1px 的 CSS，px 在那里才是对的）；② `applyImageStyles` 不再内联 `font-size:1px`，恒为 `font-size:1em`（即继承卡片字号），并删掉随之失效的 `useEmUnits` 形参；容器仍保留 `max-width:100%`，大图等比压到卡片宽度、不溢出。三份镜像（`hibiki/assets/popup/`、`hibiki/assets/browser_extension/vendor/`、`tools/browser-extension/vendor/`）同步改。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/popup_glossary_export_parity_test.js`（Node 真执行 popup.js 的 `createDefinitionImage`：导出 → `width:10em` + `font-size:1em` + 无 `font-size:1px` + 保留 `max-width:100%`；弹窗 → 仍 `10px`；`sizeUnits:'em'` 词典 → 仍 `2em` 不回归）+ Dart driver `hibiki/test/pages/popup_glossary_export_parity_test.dart`（跑 JS + 三镜像源码守卫）。已双向验证：把 `exporting ? em : px` 与 `font-size:1em` 回退成旧写法后测试变红（`'10px' !== '10em'`）。`flutter test test/pages/popup_glossary_export_parity_test.dart test/pages/popup_mining_hidden_dictionary_test.dart test/anki/ test/build/browser_extension_popup_parity_guard_test.dart --no-pub` → 170 绿。
- **备注**：与 BUG-1061（同一次用户报告的第二条：`{glossary}` 词典名前多一个自造序号）同批修复。**真机肉眼复测待用户**：桌面 Anki + AnkiConnect（或 AnkiDroid）用带插图的词典查词制卡 → 卡片里的词典图片尺寸应与 Yomitan 导入的卡片一致（大图按卡片宽度、`sizeUnits:em` 的小图标按字号），不再是原来的小方块。
