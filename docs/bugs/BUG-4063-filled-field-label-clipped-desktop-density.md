## BUG-4063 · 带标题输入框 / 下拉的浮起标题贴住或骑出填充块上沿（文字显示不全）
- **报告**：2026-11-02（开发者反馈 jIlpJV-xW4「这里文字显示不全...类似的问题根本性修复」，Windows 2560x1440@1.5，截图是字幕合集面板）
- **真实性**：✅ 真 bug（截图里有两类「显示不全」，分开结论）：
  - ⑴ 「来源」chip 摘要被 `…` 截断（`ConstrainedBox(maxWidth: 320)` + `maxLines: 2`）：**develop 已修**——`0a3749b29c`（2026-11-02 23:47，晚于反馈提交 21:52）把来源 chip + 偏好版本下拉换成整宽的聚合版本列表（`subtitle_collection_panel.dart` `_buildVersionPicker`），不再在本条改。
  - ⑵ 「Jimaku API 密钥」「番剧名」「偏好版本」三个字段的浮起标题紧贴填充块上沿、字形顶被切：**全仓同类根因**。InputDecorator 把填充式（非 outline）字段的浮起标题画在 `contentPadding.top + 密度dy/2`（`material_ui-1.8.0/lib/src/input_decorator.dart:1660-1662`），M3 默认 top 为 8（dense 4）；桌面主题默认 `VisualDensity.compact`（dy = -8），`fushiMd3FieldDecoration`（`fushi/lib/src/utils/components/glass/fushi_glass_inputs.dart:171-175` 修前直接透传 `decoration.contentPadding`）没有补偿 → dense 字段标题顶距 0、常规字段 4。实测（widget 测，修前）：FushiTextFieldControl / FushiDropdownButtonFormField 在 compact 密度 dense 标题顶距 0.0、常规 4.0。
  - ⑶ 同类第二处：`FushiDropdownMenu`（MD3 分支，`fushi_glass_overlays.dart` DropdownMenu）不经 `fushiMd3FieldDecoration`，落到全局输入框主题的「无描边 OutlineInputBorder」——浮起标题按描边式骑在边框线上，而填充框没有可见描边：实测标题顶距 **-6.0**（两种密度都是），一半露在填充块外。所有带 `label` 的 `FushiDropdown` / `FushiDropdownMenu` 调用点都中。
- **[x] ① 已修复** — `fushiFilledLabelContentPadding`（`fushi_glass_inputs.dart:209`）：带标题的填充式字段、调用方没给内边距时，把负密度从顶部补回（top = M3 默认 − dy/2，底部仍按密度收紧），标题顶距在所有平台都等于 M3 默认 8 / dense 4；`fushiMd3FieldDecoration` 对 labelled 字段改走它（`:171-175`）。`FushiDropdownMenu` MD3 分支带标题时由 `_md3LabelledDecoration`（`fushi_glass_overlays.dart:3448`）整份给装饰并经 `fushiMd3FieldDecoration`（填充式边框，标题在框内），调用方 `inputDecorationTheme` 的 dense / 内边距先并入；DropdownMenu 断言 decorationBuilder 与 label/hint/helper/error 互斥，这四个参数改由装饰携带。提交 `2b1a2f3c67`。
- **[x] ② 已加自动化测试** — `fushi/test/widgets/glass/fushi_filled_field_label_inset_test.dart`：FushiTextFieldControl（含调用方手写 OutlineInputBorder）、FushiDropdownButtonFormField、FushiDropdownMenu × compact / standard 密度 × dense / 常规共 16 条，量浮起标题相对 InputDecorator 上沿的顶距 ≥ M3 默认（8 / 4）且在填充块内。修前同一量法 compact dense = 0、DropdownMenu = -6，会红。
- **备注**：未在真机 / 桌面实机截图复测（本轮只有 widget 几何测）。裸 `TextField` 走全局主题的无描边 OutlineInputBorder 同样会骑边，但仓库已有 `raw_text_input_guard_test` 禁裸 TextField，未改全局主题（改成填充式边框会让所有无标题裸输入框整体变矮）。
