## BUG-1971 · 库页顶栏横向标签缺少后续内容提示
- **报告**：2026-08-30（用户截图：视频库窄窗只能看到「首页 / 系列 / 全部视频」，无法判断右侧仍有分区）
- **真实性**：✅ 真 bug。`fushi/lib/src/utils/components/library_section_tabs.dart` 的共享 `FushiSectionTabBar` 使用可横滚 `TabBar`，但转换控件时明确舍弃了原有两侧渐隐；当标签总宽超过页头标题槽时，尾部「发现 / 来源 / 设置」完整落在视口外，界面没有任何溢出线索。
- **[x] ① 已修复** — 监听 `TabBar` 内部 Scrollable 冒泡的横向 metrics，只在对应方向确有离屏内容时覆盖 24dp 边缘渐隐；到达首尾自动消失，不增加与选中指示器混淆的第二根滚动条，也不拦截 tab 点击/拖动。提交：本提交。
- **[x] ② 已加自动化测试** — `fushi/test/widgets/library_section_tabs_overflow_cue_test.dart` 固定窄视口，覆盖起点仅右提示、中段双侧提示、末尾仅左提示。按用户要求本轮不等待执行测试。提交：本提交。
- **备注**：修复落在书架 / 漫画 / 视频 / 游戏 / 下载共用组件，避免各页面各补一套提示。
