## BUG-998 · 覆盖导入取消勾选有声书仍恢复幽灵有声书
- **报告**：2026-07-13（值班审计发现，与 BUG-779 同类；用户「还有其他这种问题吗」后主动排查）
- **真实性**：✅ 真 bug（与视频 BUG-779 同一模式）。有声书记录（`Audiobooks` 表 + `audio_cues` + `srt` shelf entry）活在 DB blob，覆盖导入整库恢复。但：① 导入对话框判「有没有有声书」只数打包**文件**（`summarizeBackupArchive` 的 `audioDirs` = `audiobooks/` 目录段）；② 导入 step 3c 类别剥离只覆盖 books/videos/statistics/progress，**漏了 audiobooks**（`backup_service.dart`）；③ 导出侧根本不剥离有声书行（`wants(audiobooks)` 只 gate 文件打包）。合起来：取消勾选有声书类别只跳过音频文件恢复（`effAudiobooksRoot=null`），有声书行仍留在换入的 DB → 幽灵有声书（书架有条目 + 对齐行，但音频文件没跟过来）。注意「有声书类别」= `getAllAudiobooks()` = `Audiobooks` 表（epub 附属对齐）；独立 SRT 书（`srt_books`，bookKey='' 哨兵）是自己的书架项、不属此计数，**不动它**。
- **[x] ① 已修复** — 提交 `<pending>`。与视频 BUG-779 完全对齐：① 新增 `_retainAudiobooks(dbDir, keep)`（走 `deleteAudiobookByBookKey` 级联 audio_cues + srt shelf entry，不碰 srt_books）；② 导出取消勾选有声书→`_retainAudiobooks(tmp, {})` 剥 blob 行；③ 导入 step 3c 补 `if(!wants(audiobooks)) _retainAudiobooks(dbDir, {})`；④ `BackupMeta.audiobookCount`（导出记 blob 行数）；⑤ `summarizeBackupArchive` 有声书计数改 `meta.audiobookCount ?? dbAudiobookCount ?? 文件`；⑥ `summarizeBackupZip` 的 DB-peek 泛化为 `_peekContentRowCounts`（一次解 hibiki.db 同时数 video_books + audiobooks），旧备份也能显示有声书 toggle。
- **[x] ② 已加自动化测试** — `hibiki/test/sync/backup_audiobook_import_selectable_test.dart`：导出记 audiobookCount（勾/不勾）；summarizeBackupArchive 三态（meta 计数>0 无文件也显示 / meta=0 隐藏 / 旧备份走 dbAudiobookCount）；summarizeBackupZip 对手工旧备份 DB-peek 出有声书；导入取消勾选→行清零、保留→行恢复。既有 111 项备份回归全过。
