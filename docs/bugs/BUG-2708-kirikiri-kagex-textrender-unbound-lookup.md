- **报告**：2026-09-26（按用户「游戏适配成功」四条标准验收千恋＊万花光盘版原版时发现）
- **真实性**：✅ 真 bug，真机复现。`SenrenBanka.exe`（KiriKiri Z，SHA-256 `5b9cdea0a8c5b22cfb1a7df2ecb2e01484a190dce31b2cd6d6b101b178645727`，插件含 `textrender.dll` / `kagexopt.dll` / `KAGParserEx.dll` / `yuzuex.dll`）经 Fushi 启动、选定正文线程后点击台词里的词：`text_write_count` 28→30（剧情推进），lookup `hits=0 inputs=0 frames=0`，`lookup_diag=0xB0000041`（只有 sensor_installed / expression_ready；高位是对所有游戏都跑的 Siglus 身份检查，与 KiriKiri 无关）。`%TEMP%\fushi_galhook.log`：`instance.shape f=1`（无 msgwin 插件）、坐标事件恒 `N=0`。

  - 真机探针（临时诊断，未提交）确认结构：`kag.fore.messages[0]` = `CustomMessageLayer>MessageLayer>AnimKAGLayer>KAGLayer>Layer`，子层 `textLayer` = `CustomMessageTextLayer>MessageTextLayer>RelativeLayer`；消息层 / textLayer 上都没有渲染器实例，消息层有 `processCh` / `x` / `y` / `lineSpacing`——正文不走 TextRender，TextRender 类级包装永远采不到。
