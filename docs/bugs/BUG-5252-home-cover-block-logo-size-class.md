## BUG-5252 · home-cover-block-logo-size-class
- **报告**：2026-11-22（用户：「首页的媒体logo展示的不对」——首页「最近添加」/「继续」色块对刮削过的合集（BOCCHI THE ROCK!）只画标题文字 + 大字水印，主色块的 logo 缩在角落，而视频库同一张系列卡画的是整幅 logo）
- **真实性**：✅ 真 bug。取数没问题：首页 `_querySeriesMeta`（`fushi/lib/src/pages/implementations/home_dashboard_page.dart:2761`）与视频库 `_videoBlockMeta`（`home_video_page.dart:12891`）走同一个 `videoSeriesMeta`，用户库里合集 141「BOCCHI THE ROCK! 4」作品 1020 有 TMDB logo（只远程，本地 path 空），两边都能取到。错在**尺寸档**：首页小组件格子高度连续可调（「最近添加」一格约 96～210、主色块 300+），`home_dashboard_widget_cells.part.dart` 却不论格子多高一律给 `FushiCoverBlockSize.half`（「最近添加」网格块、「继续」其余条目的网格 / 横滑块）或固定 `regular`（「最近添加」主色块）。`FushiCoverBlock` 按档排版：半高档不画 logo（`fushi/lib/src/utils/components/fushi_cover_block.dart:842`，为库页 125 高的半高卡定的规则），logo 槽高按档取（`fushiCoverBlockLogoMaxHeight`，规整 52/64、首块 66/84）。实测（整页测试 1280×900 拼贴）「最近添加」小块高 119.6，正落在半高档，于是刮削过的合集只剩文字 + 大字水印；300+ 高的主色块只给 64 高的 logo 槽，logo 缩在左下角。半高档不画 logo 的理由（11-12 BLEACH 截图：logo 压到副行 / 进度）在 2026-11-21 改成固定标题槽 + 行预算之后已不成立：logo 与两行标题文字占同一个 40 高的槽，放不下时先丢次要行。
- **[x] ① 已修复** — 新增 `homeCoverBlockSizeFor(height, {allowHero})`（`home_dashboard_widget_cells.part.dart`）：格子不比库页半高卡（(264−14)/2 = 125）矮按规整档、更矮才半高档；「最近添加」主色块不矮于窄窗拼贴首块（250）按首块档。「继续」其余条目（网格 / 横滑）与「最近添加」网格块、主色块全部按格子实际高度取档，与库页同一份 logo 槽 / 排版。共享组件 `FushiCoverBlock`（`fushi_cover_block.dart` `_buildText`）：半高档不再丢 logo（墨水屏照旧不画），有 logo 时半高档也走固定标题槽（40 高）；半高档无 logo 时仍按剩余高度排两行文字。库页拼贴首块旁的半高卡因此也画 logo（与系列卡一致）。
- **[x] ② 已加自动化测试** — `fushi/test/pages/home_dashboard_page_test.dart`：`homeCoverBlockSizeFor` 纯函数档位边界；整页用例「色块「最近添加」：小块也画刮削 logo，尺寸档跟格子实际高度走」（合集 + 本地 logo，断言块的尺寸档跟格子高度走、`FushiLogoTitle` 画出来且收在块内）；`fushi/test/utils/components/fushi_logo_title_test.dart` 新增半高色块 300×125 / 230×100 两例：画 logo、槽高 ≤ 40、在文字区内、副行在 logo 下方不重叠。
- **备注**：「继续」拼贴首块本来就是首块档、有 logo 时会画；用户截图里「继续」块文字压水印若是没刮削到 logo 的条目，属设计内样式，未另改。
