## BUG-2521 · 阅读器章节列表 / 插图画廊缺少同合集卷切换
- **报告**：2026-09-13（用户：「小说画廊缺少同合集书级别切换。章节也是」，追问「能不能无感切换查看」）
- **真实性**：✅ 真 bug。阅读器 `ReaderFushiPage(bookKey)` 完全不知道自己属于哪个合集：章节列表 `ReaderQuickSettingsSheet._buildTocSection`（`fushi/lib/src/media/audiobook/reader_quick_settings_sheet.dart`）只画 `widget.toc`（当前 `_book`），插图画廊 `ReaderGalleryPage`（`fushi/lib/src/reader/reader_gallery_page.dart`）只画 `widget.images`；书合集（`media_collection_items`，epub 域 entryKey = uid）只在书架侧折叠展示，阅读器里没有任何消费点。多卷小说要看下一卷的目录 / 插图必须退出阅读器回书架。
- **[x] ① 已修复** — 新增 `fushi/lib/src/reader/reader_collection_volumes.dart`：`loadReaderVolumeContext`（当前书 uid → 主合集（最小 collectionId，与书架折叠同判据）→ 按 sortIndex 列卷，≥2 卷成立）、`buildTtuTocForBook`（与 `_buildTtuToc` 同规则的纯函数）、`ReaderVolumeBookCache`（兄弟卷在 isolate `parseVolumeBookForPeek` 解析并连插图表一起算好，按卷缓存；当前书 seed）、`volumeImageFile`（与 `_readerImageFileForUrl` 同越界判据）。章节列表：`ReaderTocVolumeSwitch` → 目录区顶部卷 chip，看别的卷**无感**（原地换列表，只列顶层章 + 「打开本卷」行），点别的卷的章 / 「打开本卷」才切书。画廊：`ReaderGalleryVolumeSwitch` → 头部下卷 chip，看别的卷插图无感（舞台 / 缩略图换成该卷，揭示只记本页不写当前书 DB），「跳到此插图」= 切书 + 跳章，看大图用该卷文件开查看器（不挂本书目录的右键分享菜单）。切书 `_switchToVolume`（`reader_fushi/chrome.part.dart`）：与返回键同一条退出链——位置 / 统计 flush 不等（BUG-2119 口径）、`closeMedia` 等完（否则它在后台把新书刚设好的 mediaOpen / wakelock 复位）、关书自动同步照旧——末尾 `openMedia(pushReplacement: true)`；与返回键共用 `_popInProgress` 单飞门。单卷 / 不在合集：两处 UI 零变化。
- **[x] ② 已加自动化测试** — `fushi/test/reader/reader_collection_volumes_test.dart`（归属 / 顺序 / 单卷退化 / 孤儿与非书成员过滤 / PDF 卷不可查看 / 最小 collectionId / toc 构建 / 插图越界）；`fushi/test/reader/reader_volume_switch_widgets_test.dart`（章节列表：无上下文零变化、看兄弟卷不切书且不重复解析、点兄弟章报 (卷, 章)、「打开本卷」报 (卷, null)、当前卷章仍走原回调；画廊：看兄弟卷换舞台、跳转 / 打开走卷回调、当前卷回调不变）。
- **备注**：跨卷跳章只能落**章首**——`Bookmark` 没有章内锚（fragment），子章目录项跨卷会到所在 spine 章开头。真正读另一卷必然要加载那本 EPUB（WebView 换内容），这一步不是无感，走与换章相同的路由过渡；「查看」（目录 / 插图）是无感的。i18n 新增 `reader_volume_open` / `reader_volume_peek_failed`。
