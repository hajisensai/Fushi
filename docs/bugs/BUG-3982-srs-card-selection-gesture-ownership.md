## BUG-3982 · srs-card-selection-gesture-ownership
- **报告**：2026-11-02（用户：应用内反馈 eo2pH56Ont「长按释义 / 空白选中了上面的例句」+ Z9APuG_imH「复习卡释义滚动卡顿」）
- **真实性**：✅ 真 bug。① 选区包得太宽：`SrsFushiCardView.build` 用一个 `SelectionArea` 包住整个视口（原 `fushi/lib/src/pages/implementations/srs/srs_fushi_card_view.dart:430`），释义 WebView 平台视图（`_definitions`，原 `:1182`）与留白都在它下面；长按这些位置时 SelectableRegion 的长按识别器赢下竞技场，落点下没有原生 Selectable，Flutter 按「夹到最近的 selectable」兜底选中了例句。② SRS 卡面 `InAppWebView` 没声明 `gestureRecognizers`（原 `srs_card_face.dart:2141`），Android 侧退化成空集合（`third_party/flutter_inappwebview_android/lib/src/in_app_webview/in_app_webview.dart:336`）：平台视图抢不到长按，拖动要等祖先识别器越过触摸阈值放弃后才补发给 WebView（Z9APuG_imH 的「一顿一跳」，推测，需真机 trace 证实）。
- **[x] ① 已修复** — 谁渲染谁吃手势：`SelectionArea` 只包原生文字列（`_selectable`：正面内容列、宽版式左栏内容列、窄版式「标题区」与「页脚」各一块，`mainAxisSize.min` 不含留白），释义 WebView 是兄弟节点；`SrsWebCardFace` 的 `InAppWebView` 传 `srsCardFaceGestureRecognizers(scrollsInPage: face.onContentHeight == null)`（长按 + 横拖，页内自己滚动时加纵拖；窄版式跟内容等高、由外层 Flutter 滚动时不认领纵拖），与查词弹窗同一做法。
- **[x] ② 已加自动化测试** — `fushi/test/srs/srs_card_view_ownership_test.dart`：窄 / 宽版式释义不是任何 SelectionArea 的后代；长按释义替身（声明同一组识别器）= 替身自己的长按、不上报选区；长按底部留白不触发 nearest 兜底；长按例句正向选中；宽版式纵拖越过 kTouchSlop 即归释义；正面预热释义不在选区里；`srsCardFaceGestureRecognizers` 集合与 `InAppWebView` 传参源码守卫。
