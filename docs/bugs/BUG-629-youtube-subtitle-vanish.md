## BUG-629 · YouTube 字幕快加载后整个消失（回归）
- **报告**：2026-07-08（用户：「直接没字幕了，这下」/ TODO-1302）。回归——修「YouTube 字幕不在字幕轨选择器」(BUG-602) + 「YouTube 加载慢」(TODO-1307) 后字幕**完全消失**（比之前更糟）。
- **真实性**：✅ 真 bug。回归根因是 **TODO-1307（BUG-605，commit b522c2797）与 BUG-602（字幕轨模型）的交互**：
  - `hibiki/lib/src/pages/implementations/video_hibiki_page.dart` 旧 `_resolveDeferredYoutubeCaptions`（TODO-1307 引入，约 :1745-1778）把 YouTube 字幕改成**单条** cue 后置异步解析：`resolveYoutubeCaptions(captionsUrl)`（`youtube_source_resolver.dart` 旧 `_resolveYoutubeCaptions`，盲选 `chosen ??= tracks.first`）拿一条 cue → `client.setPreresolvedCues(cues)` → overlay。
  - BUG-602 的字幕轨选择器行判据 `_youtubeCaptionsAvailable`（`subtitle.part.dart` 旧 :672-675）= `client.preresolvedCues.isNotEmpty`。**overlay 与字幕轨行双双吊在同一次 cue 解析成败上**：那次 deferred 解析空/失败/慢网未回/被 `_currentSubtitleSource!=null` 门控跳过时，`preresolvedCues` 恒空 → 字幕轨选择器无 YouTube 行（回退 BUG-602）**且** overlay 无字幕 = 「字幕直接没了」。快加载 `withCaptions:false`（`stream_video_launch.dart:38`）把起播时 `preresolvedCues` 清空后，字幕整个吊在这一个脆弱异步点上，一旦不成即全空。此外 `tracks.first` 盲选可能落到 ASR/错语言轨（TODO-1314 A3 缺失）。
