## BUG-3141 · 浏览器扩展查词弹窗收藏按钮无反应
- **报告**：2026-10-09（用户：用户群反馈「插件查词里的收藏点了没反应：图标不变，Fushi 收藏夹也没新增」）
- **真实性**：✅ 真 bug。共享弹窗 `vendor/popup.js:4205` 的 ☆ 按钮调 `callHandler('favoriteEntry')`、初始态调 `callHandler('favoriteCheck')`，但扩展的三个弹窗宿主都没接这两根桥：页内 `tools/browser-extension/bridge-shim.js:218` 落到 `default` 回 `null`，Side Panel 的 callHandler 末尾同样回 `null`，嵌套弹窗 `nested-popup-host.js` 的转发白名单里没有它们；background 没有对应消息，`YomitanApiServer` 也没有收藏端点。popup.js 把 `null` 当「没收藏」，于是图标不变、收藏夹无新行。真机（Chrome for Testing + 假 app）复现：改前点 ☆ 后 `favorited=false`、假 app 收到 0 次收藏请求。
- **[x] ① 已修复** — 新增端点 `POST /api/extension/favorite`（`fushi/lib/src/sync/yomitan_api_server.dart` `_handleExtensionFavorite` / `ExtensionFavoriteRequest`），app 侧 `AppModel._browserExtensionFavorite` 复用 app 外浮窗同一份 `overlayToggleOrCheckFavoriteWord`（跨源判 / 跨源删 / 单源写，来源用 `overlayStatSourceType()`）；扩展侧 `background.js` 新增 `favorite` 消息，`bridge-shim.js` / `side-panel.js` 接 `favoriteEntry` / `favoriteCheck`（只读失败 fail-soft 成 ☆，切换失败 toast；旧 app 404 提示更新），`nested-popup-host.js` 白名单补两根桥。收藏时附当前句（字幕行 / 页面句）。真机复测：点 ☆ → ★，假 app 收藏集合出现该词。提交见 PR。
- **[x] ② 已加自动化测试** — `tools/browser-extension/favorite-bridge.test.js`（bridge-shim 两根桥 / 绝不回 null / background 端点与鉴权 / 嵌套与侧栏宿主）；`fushi/test/sync/yomitan_api_server_extension_endpoints_test.dart` 的 `/api/extension/favorite (BUG-3141)` 组（体原样交 handler、只读、400、404、401）。
- **备注**：浏览器属于「app 外查词表面」，新增收藏的来源与 Windows 查词浮窗 / 剪贴板面板一致（书域，galgame 会话在跑时游戏域）。
