## BUG-3705 · dictionary-content-runs-js-with-native-bridge
- **报告**：2026-10-23（用户：开放用户提交词典前的安全审计）
- **真实性**：✅ 真 bug，手动导入一本恶意词典即可触发。三条通路：
  - `fushi/assets/popup/dict-media.js` `runDictScripts`：对每个词典块无条件 `new Function` 执行 `<script>`，window 代理对未知属性回落真 window，`window.flutter_inappwebview.callHandler('updateEntry', …)` 可改写任意 Anki 卡、`mineEntry` 批量制卡；
  - `fushi/assets/popup/popup.js` `renderStructuredContent`：`createElement(node.tag)` 无白名单，`{"tag":"script"}` 原样进 DOM；
  - `popup.js` `renderContent`：MDX / DSL / StarDict 的 HTML 释义直接 `innerHTML`，`<img onerror>` 可执行。
  - 另：导出卡片时词典 CSS 字符串拼进 `<style>`，`</style>` 能闭合标签往用户 Anki 卡片里注入 HTML。
  - 仅把脚本挪进 `sandbox` iframe **不够**：Android `addJavascriptInterface` 的桥对所有 frame 可见（`JavaScriptBridgeInterface._callHandler` 不校验调用方），iOS / macOS / Linux 桥脚本也注入所有 frame。
