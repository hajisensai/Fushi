## BUG-5384 · manga-ocr-page-identity
- **报告**：2026-11-24（用户：反馈 -5BJ11GqOk，Windows。漫画整卷 OCR 进行中翻到还没识别的页点词，查出来的是刚识别出的邻页的词，框也错位；截图里 OCR 胶囊「43/420」、阅读器滑条 419 页）
- **真实性**：✅ 真 bug。后台任务与阅读器用两份页表、却拿裸页号互用。任务按 `enumerateMangaPages(书目录)` 自己枚举页（`packages/fushi_engine/lib/ocr/manga_ocr_folder_job.dart:209`，扫整个书目录、自然序；Lens / 系统 OCR 执行器与 `manga_ocr_job_stream.dart` 同样各自枚举），阅读器用书的 `manga.json`（`_payload.images`）。书目录里多一张不在页表里的图（截图：任务 420 张、页表 419 页），排在它后面的页号全部错开一位，三处出错：(1) 逐页热替换 `manga_fushi_page.dart` `_handleWholeVolumeOcrEvent`（原 :5786-5800）用 `event.pageIndex` 直接写 `images[pageIndex]` 并 `__mangaReplaceOcr(pageIndex)`（`manga_overlay_html.dart:2461`），任务第 P 张（阅读器第 P-1 页）的框挂到阅读器第 P 页；(2) 改道 `focusPage(_currentPage)`（原 :5534 / :5734，另有 `companion.part.dart:198`、`read_aloud.part.dart:108`）把阅读器页号交给任务，任务去识别的是自己的第 P 张 = 阅读器第 P-1 页——于是读者翻到第 P 页，识别出的是 P-1 页的字、又按 P 挂回第 P 页，正是反馈的现象；(3) 任务结束时注册表 `_ingest`（`manga_ocr_job_registry.dart`）把 420 页结果整份写进书根 manga.json，`_finishWholeVolumeOcr` 再整份替换 `_payload`，页表被换成任务的枚举表（多出的图进页表、页数变化）。
- **[x] ① 已修复** — 两边按**页身份**对页，不再互用裸页号。新增 `packages/fushi_engine/lib/media/manga/manga_page_identity.dart`：`mangaPageId(url)`（相对书目录的 `images/...` 路径；同时吃导入器写法、旧 `.mokuro` 裸名与任务 `relativeUrl`）、`mangaPageIndexOf`、`alignMangaOcrResult`。(1) 热替换按 `event.page.url` 的身份在 `_payload` 里找页，不在页表里的图丢弃；(2) `MangaOcrPageFocus` / `MangaOcrRunningJob.focusPage` / `MangaOcrVolumeJob.focus` / isolate 的 `_JobFocusMessage` 改为携带页身份（String），执行器（本地 `runMangaOcrFolderJob`、Lens、系统 OCR）用 `mangaOcrFocusIndex` 在自己的页表里换算下标，不在表里的身份不改道；阅读器四处改道统一走 `_focusVolumeOcrOn`；(3) 注册表落盘前在 manga.json 写锁内读书的页表，`alignMangaOcrResult` 按身份把结果并进去：页表与页序以书为准，多识别的图丢弃并写错误日志，一页都对不上时任务以错误结束（不把别的页表写进这卷）。`_finishWholeVolumeOcr` 拿到的结果因此与阅读器页表同构。`startPage` 仍是执行器页表下标，只作起点提示；阅读器接上任务时立刻按身份改道。
- **[x] ② 已加自动化测试** — `fushi/test/media/manga/manga_page_identity_test.dart`（身份口径、「结果多一张不在页表里的图」时每页拿到自己那张图的结果且页表不变、零重叠抛错）；`fushi/test/ocr/manga_ocr_folder_job_test.dart`「BUG-5384 改道按页身份」（书目录 `images/` 多一张排最前的图，读者在阅读器第 3 页 → 任务先识别 p3，不是旧裸页号指向的 p2）与「改道到不在任务页表里的身份：忽略」；`fushi/test/media/manga/ocr/manga_ocr_job_registry_test.dart`「BUG-5384 结果按页身份并进书的页表」（书 2 页、结果 3 页错开一位 → 落盘仍 2 页且每页文字是自己的）。既有焦点 / 接回任务用例改为断言页身份。
- **备注**：书目录里那张多出的图来源未从反馈确认（日志未记目录内容）；修复不依赖它是什么。外部 mokuro / 配对主机引擎的进度事件不带页，只在完成时经同一条对齐落盘。
