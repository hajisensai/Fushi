## BUG-834 · 视频画质增强极高档(Anime4K UL)在 Windows ANGLE 后端黑屏
- **报告**：2026-07-15（用户：画质增强极高，黑屏。此电脑=Windows）
- **真实性**：✅ 真 bug（Windows 实机复现，拿到 mpv 真实报错）。根因：极高档 = Anime4K Mode A UL 链（`hibiki/lib/src/media/video/video_shader_downloader.dart` 原 `kAnime4kUlPreset` / `video_shader_tier.dart:83`）。Windows 上 media_kit 让 libmpv 走 **ANGLE 提供的 OpenGL ES 3.0**（`third_party/media_kit_video/windows/video_output.cc:55-61` + `angle_surface_manager.cc:245`，实机日志 `GL_VERSION='OpenGL ES 3.0.0 (ANGLE ...)'`、`GL_RENDERER='ANGLE (NVIDIA RTX 5090 Direct3D11)'`——旗舰卡也是 GLES）。mpv 经典 GL 渲染器给用户着色器 pass 里**每个绑定纹理配一个 `vertex_texcoord` 顶点属性**；UL 的 `Restore_CNN_UL` / `Upscale_CNN_x2_UL` 大 pass 绑定 15~16 个纹理 → 需 `vertex_texcoord0..15` + 顶点位置 = 17 个属性，**越过 `GL_MAX_VERTEX_ATTRIBS`=16**（GL/GLES 通用下限）→ 链接失败 → 该 pass 出不了帧 → **整屏黑**。BUG-759 修好让着色器真进管线后才暴露。**非编译时间/非 TDR/与显卡强弱无关**；该上限对 media_kit 的 `ra_gl` 后端在所有平台成立（Windows ANGLE / Android/iOS GLES），故 UL 在 hibiki 里根本无法渲染。
  - 实机 mpv 报错（`.codex-test/bug834-repro/ul-ultra.log`，不入库）：`libmpv_render|error| shader link log (status=0): Too many attributes (vertex_texcoord15)` → `after creating texture: OpenGL error INVALID_VALUE`。
  - 对照：高档 VL 链（`Restore_CNN_VL` / `Upscale_CNN_x2_VL`，每 pass 属性数在上限内）同机同源渲染无此错、正常出帧（与用户「高档正常」一致）。
- **[x] ① 已修复** — 全局把极高档从 UL 换成 **Anime4K Mode A VL + 额外 `Restore_CNN_Soft_VL` 去模糊/降噪 pass**（`kAnime4kUltraDeblurPreset`，`hibiki/lib/src/media/video/video_shader_downloader.dart` + `video_shader_tier.dart:83`）：全为 VL 类文件（每 pass 属性数在 ANGLE 上限内），Windows 实机验证无 `Too many attributes`、正常出帧；文件集比高档多一个 Soft_VL → `tierFromState` 集合相等反查无歧义；双重修复 → 强于高档。i18n 极高档提示（en/zh-CN/zh-HK/ja）改写去掉 UL/「需旗舰」错误宣称、保留真人承诺 + 推荐 GPU。
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/video_shader_tier_test.dart`：① 源码扫描守卫 `BUG-834: 任何档位都不下发 Anime4K UL 变体`（遍历 `kVideoShaderTiers` 断言无 `Anime4K_Restore_CNN_UL.glsl` / `Anime4K_Upscale_CNN_x2_UL.glsl`——UL 越 ANGLE 顶点属性上限会黑屏，钉死不回退）；② 极高档结构 + 与高档文件集恰好差一个 Soft_VL + `tierFromState` 反查断言。Windows 实机差分复现（诊断集成测试，非入库）已坐实 UL 崩、候选与 VL 干净。
- **备注**：Windows 实机差分（同机同源同 1080p 渲染）：UL→`Too many attributes` 链接失败黑屏；候选(高+Soft_VL)/VL(高档)→零错误正常出帧。极高在 media_kit 所有后端都不能用 UL（`ra_gl` 16 属性上限通用），故全局改而非平台分支。其余 13 语言 i18n 提示仍为旧 UL 文案（不影响构建/守卫，主用户 en/zh/ja 已改），可后续补译。
