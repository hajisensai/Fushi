## BUG-891 · 副字幕无法添加外挂字幕·应与主字幕共用同一可用字幕列表
- **报告**：2026-07-19（用户：）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/pages/implementations/video_hibiki/subtitle.part.dart:286-288`（修前）——`_buildSecondarySubtitleRows` 把可用字幕列表 `_subtitleMenuSources` 过滤成 `.where((s) => s.isEmbedded)`，只保留内嵌轨，把同目录外挂 sidecar 字幕文件（用户下载的 .srt/.ass，最常见的「添加字幕」方式）整批排除。主字幕轨行（`_buildSubtitleTrackRows:227`）遍历完整 `_subtitleMenuSources`（内嵌+外挂），两者列表不一致 → 用户报「副字幕没办法添加」。选择链路 `_selectSecondarySubtitleSource` → `loadCuesForSource`（内嵌 ffmpeg demux / 外挂读文件）→ `toPersistedValue`（外挂持久化为绝对路径）本就支持外挂，只有列表构建与恢复把外挂挡在门外。
- **[x] ① 已修复** — `subtitle.part.dart`：①`_buildSecondarySubtitleRows` 删 `isEmbedded` 过滤，改遍历完整 `_subtitleMenuSources`（与主字幕同一份可用列表），图标对齐主字幕轨行（图形轨 `image` / 内嵌 `movie` / 外挂 `subtitles`）；②`_restoreSecondarySubtitle` 对称扩展支持外挂绝对路径恢复（`SubtitleSource.external` + `File(persisted).existsSync()` 判据，镜像主字幕 `_restorePersistedSubtitle`），否则重开视频外挂副字幕会丢失。提交 `<pending>`。
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/video_secondary_subtitle_same_list_guard_test.dart`（源码扫描守卫，私有 State 方法无法直测）：锁死①副字幕行遍历完整 `_subtitleMenuSources` 且不得再引入 `isEmbedded` 过滤；②恢复须含 `SubtitleSource.external(` + `File(persisted).existsSync()` 分支且保留内嵌轨路径。2 test 通过。
- **备注**：副字幕行未加独立「打开字幕文件」导入入口——用户经主字幕「打开字幕文件」导入后，该外挂源即进入共享的 `_subtitleMenuSources`，副字幕列表随之可见，故「用同一份可用列表」已覆盖诉求。BUG 号 891 与本会话其它 worktree（ASS 字号/AnkiDroid 深链/图片遮罩）并发撞号，集成时由 owner 统一改号 + reindex。
