## BUG-1517 · 下载详情未区分后端任务已丢失
- **报告**：2026-08-11（用户：）

- **[x] ② 已加自动化测试** — `fushi/test/pages/torrent_detail_dialog_test.dart` 覆盖后端任务丢失提示及节点页降级。
