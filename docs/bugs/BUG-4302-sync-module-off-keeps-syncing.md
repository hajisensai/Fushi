## BUG-4302 · 关掉同步模块后在飞同步与定时同步仍继续跑
- **报告**：2026-11-10（用户：应用内反馈 SJeJd5EEZO 另一半，#3105 遗留；用户拍板「关模块可以立刻停掉同步」）
- **真实性**：✅ 真问题。同步层自己不知道「同步与备份 + 互联」模块关没关：模块门只在 UI 层零散地判，`fushi/lib/src/models/app_model.dart` 初始化处注释写明「只判启动、不 stop」；首页定时 sweep 在启动时把模块开关抄成常量（`fushi/lib/src/pages/implementations/home_page.dart` 原 `periodicAutoSync`），会话中途关模块照跑、启动时关着中途打开也永远不跑；同步编排（`fushi/lib/src/sync/sync_orchestrator.dart` `run()`）没有任何取消点；悬浮球「同步」（`fushi/lib/src/floating_ball/app_floating_ball_host.dart` `_manualSync`）与桌面控制通道 `sync run`（`fushi/lib/src/ops/ctl_data_routes.dart`）直调同步外壳绕过门。
- **[x] ① 已修复** — 新增同步层唯一真值 `fushi/lib/src/sync/sync_module_gate.dart`（`syncModuleGate`，AppModel 初始化与 `setModuleEnabled` 驱动）。五条同步路径经 `_beginSyncActivity` 领票，门关着不开跑；关门时在飞的票被取消，编排器在安全检查点（阶段之间、逐项循环头、拿到锁后、写冷却戳之前）抛 `SyncCancelledException`，结局记 `SyncOutcomeReason.cancelled`（不推进失败退避），锁 / 临时文件由各自 finally 收拾、`lastSyncMs` 不写。定时 tick 每次都交给门判；合集防抖观察者随模块撤 / 装。UI 外壳、悬浮球、ctl 共用这道门（`ManualSyncOutcome.moduleDisabled` / `cancelled`）。提交见 PR。
- **[x] ② 已加自动化测试** — `fushi/test/sync/sync_module_gate_cancel_test.dart`（门语义；编排器阶段间 / 逐项循环检查点、不写冷却戳；手动 / 自动入口门关不开跑、重开恢复；在飞手动同步途中关模块 → cancelled、后续通道不跑、锁与票全还、不退避）；`fushi/test/sync/pull_to_refresh_sync_module_gate_test.dart`（`AppModel.setModuleEnabled` 开合门）；`fushi/test/ops/ctl_data_routes_test.dart`（`sync run` 模块关 422）。
