## BUG-2053 · attached 校准表面弹出的桌面查词卡点外关闭时点击透传给游戏推进台词
- **报告**：2026-09-03（用户：点左键关闭查词弹窗的时候不要进入下一句；要求对库里六款游戏通用）
- **真实性**：✅ 真 bug。游戏内查词有三条表面：注入侧原生几何 provider 的 direct galCard（BUG-1882 已让 `GlobalLookupWindow::Reveal` 带 `consume_outside_owner` 走 `ArmLowLevelMouseHookAndWait`，点外 down/up 成对吞掉）、hook 台词浮窗、以及**通用回退的 attached 校准字形表面**。第三条的命中经 `attached_text_surface_window.cpp` `EndPointerGesture` → `flutter_window.cpp` 序列化 → `GalHookTextOverlayController._onAttachedLookupText` → `_onLookupText` → 普通桌面 `GlobalLookupController.lookupText`；桌面 route 的 `Reveal`/`RevealStack` 只 `ArmLowLevelMouseHook(hwnd_)`（无 consume owner），`low_level_mouse_hook.cpp` `HookProc` 对点外 down 只 `PostMessage` 通知窗口线程 Hide 再 `CallNextHookEx`，这一记 down 原样落进游戏——弹窗消失的同时台词推进。另外该表面没有 Shift+悬浮查词：`HookProc` 要求 `BareLeftClickModifiersClear()`，按住 Shift 反而什么都不发生（只有浮窗 `floating_lyric_window.cpp MaybeHoverLookup` 有）。
- **[x] ① 已修复** — `global_lookup_window.{h,cpp}` 新增 `SetOutsideClickConsumeOwner(HWND)`：`Reveal` 在参数为空时改用它，`RevealStack` 在它非空时走 `ArmLowLevelMouseHookAndWait(hwnd_, owner)`（ack 失败记日志、退回原穿透 arm，卡片照常显示），`Hide()` 在 `ReleaseDismissHooks()` 前清空；`low_level_mouse_hook.cpp` `DisarmLowLevelMouseHook` 补 `RemovePropW(kConsumeOutsideOwnerProperty)`（原实现假设桌面 HWND 永不带该属性、只在下一次 ArmAndWait 时替换）。`flutter_window.cpp` overlay handler 新增 `setOutsideClickOwner{hwnd}`；Dart `OverlayWindowChannel.setOutsideClickOwner` → `GlobalLookupController.lookupText(consumeOutsideClicksOwnerHwnd:)` 在 `hide(notify:false)` 之后、`showAt` 之前只在非空时调用；`_onAttachedLookupText` 传 `hit.target.targetHwnd`，浮窗路径不传、行为不变。弹窗关闭后 attached 表面靠自己的 500ms follow timer（`SyncToTarget → SetVisible(true) → ArmLowLevelMouseHookForAttachedGlyph`）在 ≤500ms 内重新装钩（已核实，无需改动）。同批补上 attached 表面的 Shift+悬浮查词：`attached_hover_tracker.h` 纯逻辑 tracker + 60ms `kHoverTimerId`（`GetAsyncKeyState(VK_SHIFT)` + `GetCursorPos` + `ClusterAt`，同簇去重、松 Shift/移出松锚、不走 shield 事务），`LookupEvent.hover` 经序列化 map `hover` 进入 `GalAttachedLookupHitV19.hover`，与点击走同一条查词链，悬浮弹出的卡同样带 consume owner。
- **[x] ② 已加自动化测试** — `fushi/test/lookup/gal_attached_desktop_popup_click_swallow_guard_test.dart`（runner 源码守卫：Reveal/RevealStack/Hide/Disarm/setOutsideClickOwner/hover timer/序列化/CMake 注册；Dart 守卫：attached hit 必带 owner、`_lookupExternal` 顺序与非空门；channel 契约）；`gal_attached_text_channel_v19_test.dart`（hover 字段解析）；`gal_attached_text_controller_test.dart`（hover 命中同门控）；runner C++ `tests/attached_hover_tracker_test.cpp`（`fushi_windows_attached_hover_tracker_gate`）。`flutter test test/lookup --no-pub` 729 通过。
