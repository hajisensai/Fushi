## BUG-2825 · 制卡导出释义 HTML 与 Yomitan 结构不一致（图片外层非 a、class 未转内联样式）
- **报告**：2026-10-01（用户：Lapis 笔记模板上 Fushi 卡显示错乱，逐条对照过 Yomitan 卡 / 旧卡；附「毒を食らわば皿まで」(絵でわかる慣用句) 两张 Anki 预览截图：Fushi 卡 4 格插图一张一行、每张约 780px，Yomitan 卡 2×2 并排、每张约 520px，且 Fushi 的图点不开）
- **真实性**：✅ 真 bug。上游对照（yomidevs/yomitan@67db60ddc2）：
  - `ext/js/display/structured-content-generator.js` `createDefinitionImage`：外层恒为 `<a class="gloss-image-link" target="_blank" rel="noreferrer noopener">`，Anki 导出时 `_setImageData` 写 `node.href = url`（url 即媒体文件名）。
  - `ext/js/templates/anki-template-renderer.js` `_getStructuredContentHtml` → `_getHtml` → `_normalizeHtml`：`CssStyleApplier.applyClassStyles`（`ext/js/dom/css-style-applier.js`）按 `ext/data/structured-content-style.json` 把命中规则写成内联样式（放在元素自身内联样式之前）并 `removeAttribute('class')`；再删除除 `/^sc([^a-z]|$)/` 以外的全部 dataset 键。
  - 词典 CSS：`ext/js/data/anki-note-data-creator.js` 生成 `dictScopedStyles = addGlossaryScopeToCss(addDictionaryScopeToCss(css, dictionary))`，`default-anki-field-templates.handlebars` 的 `glossary` 以 `<style>` 随卡下发、作用域 `.yomitan-glossary [data-dictionary="…"]`。**上游同样把词典 CSS 写进卡片**，只是 class 被剥掉，写给弹窗的 `.gloss-*` 选择器在卡上命中不到。Fushi 这一层（`popup.js` `constructDictCss(css, dict, '.yomitan-glossary [data-dictionary="…"]')`）本来就与上游一致，不是根因。
  - Fushi 根因（修复前 HEAD 6888ba364d）：
    1. `fushi/assets/popup/popup.js:1896` `document.createElement(exporting ? 'span' : 'a')`，导出不写 target/rel/href → Lapis 的 `.definition a span`（插图宽度上限）与 `.definition a:has(img)`（点击放大）全部落空。**症状 1 真**。
    2. `fushi/assets/popup/popup.js:1520` / `:1593` 两个制卡构建器只跑 `applyTableStyles` 正则，从不做 class→内联 + 剥 class + 剥 data-*；`createDefinitionImage` 只手工内联了 `applyImageStyles` 那几条，`data-vertical-align` / `data-size-units` 等属性驱动规则没有落成样式（`popup.js:1915` 只写了 `node.dataset.verticalAlign`）。于是词典 CSS 里写给弹窗的规则在卡片上生效（明鏡外字、旺文社 `[data-sc縦中横] > .gloss-sc-span` 绝对定位竖排），Pixiv logo 丢了 `vertical-align:middle`。**症状 2、3 真**。附带：`applyTableStyles` 给已有 `style` 的 `<td>` 再插一个 `style` 属性，浏览器只认第一个，词典自己的单元格样式被吞。
    3. `packages/fushi_anki/lib/src/anki_models.dart:1510`/`:1532` `normalizeAnkiDictionaryHtml` + `_ankiGaijiImageStyle`（由 `anki_note_composer.dart:484` 调用）：Fushi 自造的外字中和 `<style>`，`!important` 把外字框压成 1em + `text-bottom`。它存在的理由是对抗「class 留在卡上 → 词典 CSS 生效」，属于症状补丁，上游没有。**「明鏡外字压成 1em 并下沉」真**。
    4. 三省堂「句」图标：上游卡上是文本交叉引用 `<a>` 里又套图片 `<a>`，Anki 的 HTML 解析器把嵌套 `<a>` 拆开，图标落到 0.65em 上标 span 之外。Fushi 图片外层是 `<span>`，不触发拆分，图标留在上标里被缩成 13px。**真**，根因同 1——不是单独的缺陷，改成 `<a>` 后结构与上游一致，解析行为随之一致（导出 DOM 里两层 `<a>` 的嵌套与上游逐形相同，拆分发生在 Anki 侧解析）。
