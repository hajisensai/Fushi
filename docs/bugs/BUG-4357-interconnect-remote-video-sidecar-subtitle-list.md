## BUG-4357 · 互联远端视频只暴露一条 sidecar 字幕：host 多条外挂字幕菜单只列默认那条
- **报告**：2026-11-07（开发者自提，应用内反馈 -CaVsioFhG：「服务端那边下了好多字幕，怎么只显示一个，而且互联的应该标出来所有的，怎么就默认的标出来的」）
- **真实性**：✅ 真缺口，已沿代码路径确认。互联协议只有单值字段：`/streamurl` 只回 `subtitleUrl` + `subtitleFileName`（`packages/fushi_engine/lib/sync/fushi_sync_server/video.part.dart` `svc.resolveVideoSubtitle` 挑出的那一条），`GET .../subtitle` 不带参数时也只回这一条；`RemoteVideoStreamUrls`（`packages/fushi_engine/lib/sync/fushi_library_host_service.dart`）没有承载多条外挂字幕的字段。client 侧播放页 `_remoteSubtitlePath` 只放这一条（`video_fushi_page.dart` `_downloadRemoteBackendDefaultSubtitle`），菜单经 `remote_subtitle_catalog.dart` `remoteSubtitleFileEntries(backendDefaultPath:)` 只拼出一行「Fushi 互联服务端字幕」。host 视频旁的其余 sidecar（`movie.zh.ass` / `movie.en.vtt` …）client 根本无从得知。
  - 注：反馈 AI 总结把列表字段归到 `RemoteVideoInfo`（库清单）；实际播放页的字幕信息来自 `/streamurl`（`RemoteVideoStreamUrls`，按集），库清单自 BUG-814 起只给廉价的单值 `hasSubtitle` / `subtitleFileName`，所以列表加在 `/streamurl`。
- **[x] ① 已修复** —
  - host：新可选能力 `VideoSidecarSubtitleListHost.listVideoSidecarSubtitles`（`LocalLibraryHostService` 实现：这一集同目录全部 sidecar，判据 `listSidecarSubtitles`，按名排序；`fushi_server` 用同一个 `LocalLibraryHostService`，无需另做）。`/streamurl` 额外下发 `sidecarSubtitles[]`（文件名 / 格式 / 语言标记 / 大小 / 是否默认 / URL），默认字幕在别处时并进列表并标默认；`GET .../subtitle?sidecar=<文件名>` 只在 host 枚举出的文件里按 basename 精确匹配下载，别的名字 / 路径穿越一律 404。能力位 `liveLibrary.videoSidecarSubtitles`。旧单值字段照发，老 client 行为不变。
  - client：`RemoteVideoStreamUrls.sidecarSubtitles`；`InterconnectSyncBackend` 实现 `RemoteVideoSidecarSubtitleFetch.getRemoteVideoSidecarSubtitle`；`remoteSubtitleFileEntries(hostSidecars:)` 每条 host 外挂字幕一行（默认那条已下到本地时并入默认行），全部按互联来源标注、不可删；选中时按文件名懒下载（按集缓存，与默认字幕同口径），主 / 副字幕菜单与手机遥控共用；选择按 `hostsidecar:<文件名>` 持久化，重进按名重下（主字幕起播重放与副字幕恢复都接上）。老 host 不发列表 → 退回只有默认那条。
- **[x] ② 已加自动化测试** — `fushi/test/sync/interconnect_video_sidecar_subtitle_list_test.dart`（语言标记纯函数、JSON 往返 / 坏条目丢弃 / 老 host 不带键、host 同目录多条全部列出、真 server+host+client 端到端逐条下载与 404、能力位、不实现能力的老 host 混版本）；`fushi/test/pages/video_remote_subtitle_catalog_test.dart`（多条都成行且都标后端来源、默认行去重、选择编码往返、编码不被当本机路径）。
- **备注**：测试未在本分支运行，统一在合并后验证。未做真机复测（远端播放页菜单实际显示多行、选中后切换字幕）。
