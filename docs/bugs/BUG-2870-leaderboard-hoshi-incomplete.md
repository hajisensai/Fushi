## BUG-2870 · 排行榜书架漏书：Hoshi 导入的读完书没标读完 + 多 Profile 时无记录的书被丢
- **报告**：2026-10-01（用户：排行榜里我的数据不全，读过的书远不止这么多，不少是从 Hoshi 导入的）
- **真实性**：✅ 真 bug。用户安装版库（schema 116，2 个 Profile）实测：33 本书只有 10 本 `completed_at` 非空，另有 18 本全书字数进度 99.6%–100%（《無職転生》6–19、25，《汝、星のごとく》《謎解きはディナーのあとで》等）没标读完。三处根因：
  1. `fushi/lib/src/sync/external_reader_import/hoshi_position_mapping.dart` `_isCompleted`：导入只认「末章 + 章内 ≥ 99.9%」。轻小说正文后挂着后记 / 奥付 / 纯图页（实测 0–312 字），用户读完正文不再往后翻，Hoshi 书签停在正文最后一章，全部判成未读完。
  2. `fushi/lib/src/sync/external_reader_import/external_reader_import_service.dart` `_writePosition`：读完只在「写位置」分支里判；Fushi 已有更新的位置、或重复导入同一份备份（位置保留）时直接 return，读完永远补不上。
  3. `packages/fushi_engine/lib/leaderboard/local_shelf.dart` Profile 口径：有多个 Profile 时只上传「本 Profile 有学习记录」的作品——用户建了第二个 Profile「English」后，标了读完但没留统计的书（《無職転生》01 / 03 / 12）整批不上传，哪怕别的 Profile 也没读过它们。
- **[x] ① 已修复** — 导入另认「已读字数 ≥ 全书 99%」为读完（纯图书仍只认末章末尾）；读完判定挪到位置取舍之前，与位置写不写无关；排行榜书架改为只排除「别的 Profile 有记录、本 Profile 没有」的作品。已导入过的用户**重新导入一次 Hoshi 备份**即可补标（位置不会被覆盖）。
- **[x] ② 已加自动化测试** — `fushi/test/sync/external_reader_import/hoshi_position_mapping_test.dart`「正文读完、尾部后记 / 奥付没翻也算读完」；`external_reader_import_service_test.dart`「a finished Hoshi bookmark marks the book completed even when the Fushi position is kept」；`fushi/test/leaderboard/local_shelf_test.dart`「多个 Profile：别的 Profile 的作品不上报，谁都没记录的照常上报」。
- **后续（作者 2026-10-02 拍板）**：放开第 3 条后，同机多个开了上传的 Profile 会把「谁都没记录」的作品各报一次，作品读者数按 Profile 个数重复。修法：这类作品只由同机代表 Profile（开着上传的 Profile 里 id 最小）计入作品读者数，其余 Profile 带 `counted: false` 上报——仍上架、仍计入账户自己的读完数与计分；有学习记录的作品照常各自计入（换 Profile 重读不去重）。服务端 `services/leaderboard/migrations/0002_shelf_counted.sql` 加 `shelf.counted`，读者数增量 / 周月榜 / 作品页读者 / 管理重算 / 删号 / 隐藏账户全部按它过滤；客户端 `ShelfEntryUpload.counted` + `buildLocalShelf(countsUnattributed:)` + `LeaderboardStore.uploadingProfileIds`。测试：`services/leaderboard/test/shelf.test.js`「counted:false（同机另一 Profile）…」与对拍随机 counted；`fushi/test/leaderboard/local_shelf_test.dart`「谁都没记录的作品只由同机代表 Profile 计入读者数」；`leaderboard_store_test.dart`「uploadingProfileIds…」；`packages/fushi_engine/test/leaderboard/` 的 owner 选择与 `counted` 哈希不变。**需要手动对线上 D1 跑迁移 0002 再部署 Worker**，旧客户端不带 `counted`，按默认 1 计入。
- **备注**：阅读器自己的自动读完（`reader_fushi/navigation.part.dart`）仍是「末章 + 99.9%」边读边判，只在 Fushi 里读到正文末尾就停的书同样不会自动标读完（用户库里《無職転生》24 即此），本次未改，可在书架手动标记。同 PR 把排行榜从统计中心 tab 抽成首页统计中心入口旁的独立按钮。
