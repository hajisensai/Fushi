## BUG-1467 · 视频主页角标语义不一致
- **报告**：2026-08-09（用户：）
- **真实性**：✅ 真 bug。主页通用横卡只有 `episodeCount`，同一参数同时表示总集数、当前集与下一集；“新”固定左上而集数固定右上，语义和位置均不稳定。
- **[x] ① 已修复** — `home_video_page.dart:3146-3268` 将参数改成明确的 `episodeNumber + secondaryText`；继续观看显示“看到第 N 集”及可计算时的剩余分钟，下一集/最近添加显示各自语义；“新”和集数统一为右上角同组角标。
- **[x] ② 已加自动化测试** — `video_library_series_structure_guard_test.dart` 锁定继续观看/剩余时长文案数据路径，既有播放聚合测试继续约束当前集与下一集选择。
- **备注**：无可靠 runtime 时不伪造剩余时长，仅保留确定的季集/播放位置。
