## BUG-538 · mpv sigmoid upscaling default on (perf cost)
- **报告**：2026-07-03（用户：mpv 里默认开启了 S 形上采样，性能占用有点大，默认关闭吧）
- **真实性**：✅ 真配置项（非崩溃 bug，是默认值偏好问题）。根因 `file:line`=`hibiki/lib/src/media/video/video_mpv_config.dart:55`（`VideoMpvConfig.defaults` 里 `sigmoidUpscaling: true`）。「S 形上采样」= mpv 的 `sigmoid-upscaling`（S 曲线线性光上采样，减振铃但每帧多一次 sigmoid 变换 + 线性光转换，`buildMpvProperties` 第 367 行下发 `out['sigmoid-upscaling'] = 'yes'`）。默认开 → 每次上采样都吃这份 GPU 开销。
- **1120 需求改写（用户改口）**：不是硬关/写死 false，而是——「如果对画面提升很大，就加到着色器等级那边，一块开关」。新契约：① 默认关（性能）；② 做成用户可开的开关，并入现有「着色器等级」那组设置暴露。
- **[x] ① 已修复** — 两处：
  - **默认关（非写死）**：`hibiki/lib/src/media/video/video_mpv_config.dart`：`VideoMpvConfig.defaults.sigmoidUpscaling` 由 `true` 改 `false`（第 55 行）；`decode` 的默认迁移由 `d['sigmoidUpscaling'] != false`（缺键→true）改 `== true`（缺键→false，第 245 行），使**该键存在前存的旧配置也迁移到关**。`sigmoidUpscaling` 字段/copyWith/encode 全保留 → 仍是可开可关的活开关，不是删除。
  - **并入「着色器等级」设置组暴露开关（TODO-1120）**：`hibiki/lib/src/settings/settings_schema_video.dart` 的 `video_setting_mpv_group_quality` 段（即「画质增强/着色器等级」组，标题项 `video.quality.enhancement` = `t.video_shader_quality_tier`）里，紧接质量档开关新增 `SettingsSwitchItem(id: 'video.quality.sigmoid', title: t.video_setting_mpv_sigmoid, subtitle: t.video_setting_mpv_sigmoid_hint, ...)`，读写 `VideoMpvConfig.sigmoidUpscaling`（`_commitVideoMpvConfig`，纯 pref，下次开视频 `applyMpvConfigToPlayer` 应用）。默认档=关；想要更锐利放大的用户在此开。新增 i18n `video_setting_mpv_sigmoid_hint`（17 语言，经 `tool/i18n_sync.dart --add`）。in-player 快速设置表 `video_quick_settings_sheet.dart:1157` 原有 sigmoid 开关不变（同一字段，两处 UI 同源）。**结构无冲突**（着色器等级组即 mpv 画质组，sigmoid 作并列开关干净并入，非硬塞）。
- **[x] ② 已加自动化测试** — ① `hibiki/test/media/video/video_mpv_config_test.dart`：主守卫改断言 `buildMpvProperties(defaults)['sigmoid-upscaling'] == 'no'` + `defaults.sigmoidUpscaling == false` + `decode('').sigmoidUpscaling == false`；新增「legacy config missing sigmoid key migrates to off」（缺键旧配置迁移到关、下发 `no`）；新增「explicit sigmoid on round-trips + emits yes」（用户手动开时显式 `true` 存得住、下发 `yes` → 证明默认关不封死可选开启）。② `hibiki/test/pages/video_settings_schema_guard_test.dart`：把 `video.quality.sigmoid` 加进 home 设置「pref-only in-player parity」清单，锁定 sigmoid 开关必须出现在 home 视频设置里（与 quick sheet parity），防被删。
- **备注**：mpv 官方 `sigmoid-upscaling` 默认 yes，本 app 改默认 no 是权衡性能（用户报占用偏大）；开关并入画质增强/着色器等级组，想要画质的用户可开。sigmoid 是与 `highQuality`（内置缩放）/GLSL 着色器正交的 mpv 属性，**未**塞进 `VideoShaderTier` 五档枚举（那是 highQuality+GLSL 两态的派生投影，硬塞第三态会破坏其「无特殊情况」设计）——而是作同一设置组内的并列开关，符合「加到着色器等级那边一块开关」的意图且不污染档位模型。
