## BUG-1439 · 字幕列表把整首 OP 歌词链式合并成一条逐字交错的乱码

- **报告**：2026-08-02（用户：「这个字幕列表有问题」+ 截图，OP 段 3:17 一条 101 字乱码）
- **真实性**：✅ **真 bug**，BUG-1337 引入的合并判据回归。根因
  `hibiki/lib/src/media/video/video_subtitle_jump_panel.dart:76`（旧代码
  `if (c.startMs > spanEnd || c.endMs < spanStart) break;`，其中 `spanEnd` 是**并集**）。

### 片源真值

用户外挂的 `[Nekomoe kissaten&VCB-Studio] Tensei Oujo to Tensai Reijou no Mahou Kakumei
[10][Ma10p_1080p][x265_flac][JPN].ass`（Hibiki 落在 `HIBIKI_date/documents/video_subtitles/`，
`PlayResX 1280 / PlayResY 720`）。OP 逐字卡拉OK，同 `OP_JP` 样式、同 Layer、同 `y=672`：

```
第2句「一雫頬を濡らして」  首字 197470-201180 … 末字 197760-201470
第3句「切なく雨が降る」    首字 201350-204480 … 末字 201600-204730
```

**相邻两句在时间上交叠**：第 3 句首字 `201350` 淡入时，第 2 句末字（`…-201470`）还没淡出。
这是卡拉OK 的常态，不是坏文件。

### 根因

BUG-1337 的「同组要求时间重叠」判的是**新字 vs 本组已累积区间**，而该区间取的是**并集**、
只增不减：第 2 句累积到 `[197470, 201470]` 后，第 3 句首字 `201350 ≤ 201470` 判定为「同句」
被吞并，吞并后区间又被推到 `204730`，于是第 4 句、第 5 句……**链式**全部并进同一组。最后
按 `\pos` 的 x 升序拼接，几句歌词的字互相交错，就是用户截图里那条：

```
3:17.47-3:59.68 (101字) 憧空真それをっのて駆暗涙憧けながれて雲ま止て行がだま一く去切何っ雫想…
```

（2:44 那条同样是链式产物。用现行算法在该 .ass 上离线复跑，逐字复现了截图文本。）

### 修复

- **[x] ① 已修复** — 判据区间从**并集**改成**交集**（`liveStart = max(starts)` /
  `liveEnd = min(ends)`），即「全组必须有一段**同时在屏**的时间」。
  - 一句歌词的字逐个淡入后一起挂到句末，交集天然非空；下一句首字与前句**首字**的窗口
    （末端 `201180`）已错开，`201350 > 201180` → 断组。
  - 交集只会收窄，不会像并集那样被逐句续命，从根上消掉链式吞并（不是加个「最多 N 字」
    上限之类的封顶补丁）。
  - **输出仍取并集**：合成句的 `startMs/endMs` 用 `unionStart/unionEnd`，列表上整句仍是
    「首字亮起 → 末字消失」。判据与输出两个区间**刻意分离**，不能合成一个。
  - 判据整体比原来更严格，与 BUG-1337 的「宁可漏合也不错合」同向；原有 5 条同组要求
    （`\pos` / 单 grapheme / 同 y / 同 Layer / 组内 ≥2）一条未动。
  - 离线用同一份 .ass 复跑修复后算法，还原成 7 句正确歌词（`一雫頬を濡らして` /
    `切なく雨が降る` / `まだ何も君を知らないよ` / …），与画面逐句吻合。

- **[x] ② 已加自动化测试** —
  `hibiki/test/media/video/video_subtitle_list_per_char_merge_test.dart`（16 → 18 条）
  - 新增「片源真值：相邻两句首尾交叠 120ms 仍各自成句」——直接用上面两句的真实时间戳，
    断言分成 2 组且文本正确，并钉死合成句时间跨度仍是并集。
  - 新增「三句连续交叠也不滚雪球」——每句首字刻意落在**前句并集尾之内、交集尾之外**，
    专防「只跟上一条比重叠」这种半吊子实现（那样照样链成一条）。
  - **变异实测**：把 `liveStart/liveEnd` 的更新方向反向替换回并集语义，两条新用例各自
    变红、其余 16 条全绿；反向替换还原，未用 `git checkout --`。
