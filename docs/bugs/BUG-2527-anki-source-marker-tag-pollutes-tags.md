## BUG-2527 · 制卡给每张卡挂冗余 fushi_source_ 哈希 tag 污染 Anki 标签栏
- **报告**：2026-09-14（用户：「`fushi_source_5c7d7844104549a6b5ce22fe904a6191` 为啥会有这种标签，anki 制出来的卡」「肯定不能丢到那里」）
- **真实性**：✅ 真 bug。2026-09-10「卡片来源回跳」把每张新制卡的随机来源 UUID 写成了两份：字段里的 `fushi://source?…&sourceId=<uuid>` 超链接（`packages/fushi_anki/lib/src/anki_models.dart` `renderSourceLink`）**和**一个 `fushi_source_<32 位 hex>` 笔记标签（`packages/fushi_anki/lib/src/base_anki_repository.dart` 原 `buildNoteTags` 里 `sourceLink?.markerTag`，`card_source_link.dart` 原 `markerForSourceId`）。标签只服务于「回看后覆写时按 ID 查回原笔记」一个查询（原 `findSourceNoteIds` → AnkiConnect `tag:fushi_source_x` / AnkiDroid `AnkiChannelHandler.findNotesBySourceMarker`），而重制卡读原身份本来就从字段解析（`contextForExistingSourceNote` 用 `CardSourceLink.fromHtml`）。结果：每卡多一个人眼无意义、每卡都不同的哈希 tag，Anki 标签侧栏被 `fushi_source_*` 撑满。实测本机真实 Anki：23 张带该 tag 的卡按字段子串 `sourceId=<uuid>` 搜出的也正是同一批 23 张，单张 1:1 等价——tag 是纯冗余拷贝。
- **[x] ① 已修复** — 删掉 tag 发射与 `markerTag`/`markerForSourceId`；来源 ID 只保留字段链接一份。查回原笔记改为两段：三后端（AnkiConnect `findNotesBySourceId` / AnkiDroid `findNotesBySourceId`（Java 侧自校 UUID、自拼查询，不接受自由查询串）/ 互联转发）只做 Anki 浏览器语法的字段子串候选查询 `CardSourceLink.searchQueryForSourceId`；基类 `readSourceNote` 对每个候选读字段、`fromHtml` 解析、`sourceId` 精确相等才算命中（子串命中≠身份；候选间删除的跳过；多于一张判不唯一）。候选字段经新 `sourceNoteFields`（只在笔记不存在时回 null、后端失败必抛）读取，不走吞异常的 `noteFields`——审查抓到的坑：否则 AnkiConnect 超时会被报成「原笔记不存在」。旧卡字段里本就有链接，新查法照样命中；旧卡上残留的 tag 不批量改写用户笔记。
- **[x] ② 已加自动化测试** — `packages/fushi_anki/test/card_source_link_test.dart`：「mined notes carry no source marker tag」（tag 构建器不再产出任何 `fushi_source_`）、「source lookup confirms candidates by parsed href, not substring」（正文引用了 ID / 带别的 ID 的真链接 / 中途被删 / 旧卡带残留 tag 四类候选只认解析命中那张；无命中回 null；两张命中判不唯一）、AnkiConnect 查询字面量、AnkiDroid channel 参数、「source lookup propagates backend failure」（读取抛 SocketException 必须原样上抛而非回 null）；`fushi/test/platform/source_url_native_contract_test.dart` 守卫 Java 侧 `findNotesBySourceId` 的 UUID 校验、`"sourceId=" + sourceId` 查询字面量、且全文不得再出现 `fushi_source_`/`findNotesBySourceMarker`；`fushi/test/anki/ankimobile_repository_test.dart` 断言 AnkiMobile URI 的 tags 只剩用户自定义 tag。
- **备注**：设计文档 `docs/specs/2026-09-10-card-source-return.md` 同步改写。用户若想清掉旧卡上的残留标签，在 Anki 浏览器搜 `tag:fushi_source_*` 手动删即可，删了不影响回跳与覆写定位。
