## BUG-4008 · 迁移后打字输入卡变成基础卡
- **报告**：2026-11-04（用户：应用内反馈 DAgSPc8ixN「牌组迁移后卡片类型变了，打字卡变成了基础卡」）
- **真实性**：✅ 真 bug，但不在迁移：导入保留了笔记类型与模板（`{{type:Back}}` 原样在模板里）。根因是内置复习的模板渲染器不支持 Anki「打字输入答案」：`_applyFilters` / `_applyFilter` 对 `type` / `type-cloze` / `type-nc` 直接返回空串（修前 `packages/fushi_anki/lib/src/anki_template_render.dart:667`），卡面上既没有输入框也没有比对，看起来就跟基础卡一样。
- **[x] ① 已修复** — 对齐 Anki（rslib `typeanswer.rs` + `reviewer.py`）：渲染器把 `{{type:…}}` 输出成 `[[type:…]]` 标记；新 `packages/fushi_anki/lib/src/anki_type_answer.dart` 的 `ankiResolveTypeAnswer` 把问题面第一个标记换成 `<input id="typeans">`、答案面换成带期望答案的占位（去 HTML / `[sound:]`，`cloze:` 取本卡挖空，`nc:` 忽略组合附加符号），`ankiFillTypeAnswer` / `ankiTypeAnswerComparison` 按 LCS 对齐输出 Anki 同名类 `typeGood` / `typeBad` / `typeMissed`。`SrsDbStore.renderCard` 与模板 / 笔记预览 `srsRenderTemplatePreview` 都接上；WebView 卡面外壳装 `kSrsTypeAnswerScript`（输入上报 `onSrsTypeAnswer`、回车 = 显示答案）与样式，`SrsWebCardFace` 按卡 id 记住打的字，答案面经 `srsFaceWithTypedAnswer` 填比对。提交 `78099611d1`。
- **[x] ② 已加自动化测试** — `packages/fushi_anki/test/anki_type_answer_test.dart`（标记解析、输入框只放一个、cloze / nc、未知字段提示、属性往返转义、比对输出）、`packages/fushi_anki/test/anki_template_render_rslib_test.dart`（`{{type:…}}` 输出标记，对拍 rslib）、`packages/fushi_engine/test/srs/srs_type_answer_render_test.dart`（真实 `SrsDbStore.renderCard`：问题面有输入框、答案面有占位且期望答案正确）、`fushi/test/srs/srs_card_face_type_answer_test.dart`（外壳页装脚本与样式；答案面只用本卡打的字）。
- **备注**：WebView 里输入框的焦点、IME、回车交卷未在 Windows / Android 真机或桌面上肉眼复测（单测只覆盖 Dart 侧）。Anki 的 `<hr id=answer>` 挪到比对前的小 hack 未照搬。
