## BUG-3224 · 制卡把整份词典 CSS 内联进每个释义字段，AnkiDroid 预览 TransactionTooLargeException 打不开
- **报告**：2026-10-10（群反馈：Fushi 制的卡在 AnkiDroid 点「预览」打不开、编辑能开，重复卡尤其多。用户 ADB 抓到 `TransactionTooLargeException: data parcel size 740108 bytes` / `FAILED BINDER TRANSACTION` / `Exception when starting activity com.ichi2.anki/.previewer.CardViewerActivity`；手动删掉字段里的词典 CSS 后约 248 KB，预览正常）
- **真实性**：✅ 真 bug。AnkiDroid 预览把整条笔记的字段作为 Intent 参数过 Binder（1 MB 共享上限），而 Fushi 的释义字段背着整份词典 CSS：
  - `fushi/assets/popup/popup.js` `constructGlossaryHtml` / `constructSingleGlossaryHtml`（约 1597 / 1745 行）：与 Yomitan 同形，每段 `.yomitan-glossary` 末尾带该词典**整份** `styles.css`，经 `constructDictCss` 给每个选择器加 `.yomitan-glossary [data-dictionary="名"]` 前缀，注释原样保留；格式化 `.replace(/;\s*/g, '; ')` 还顺带把未加引号的 `url(data:image/png;base64,…)` 改成 `; base64`，让这类图标声明非法。
  - `packages/fushi_anki/lib/src/anki_models.dart` `AnkiHandlebarRenderer`：Lapis 出厂把 MainDefinition 映射 `{glossary-first}`、Glossary 映射 `{glossary}`，首本词典的 CSS 一张卡至少两份。
  - 实测（本机真实词典经 `fushidicts_ffi.dll` 查词、按 popup.js 导出形态拼字段）：OALDPE En-Cn 的 styles.css 210 KB（约七成是 hover 态 / 面板图标 data URI 与内嵌字体），「run」一张卡 `{glossary}` 与 `{glossary-first}` 各 357 KB、其中 CSS 247 KB，两字段合计约 714 KB，与用户的 740 KB 吻合。日语四词典（明鏡 / 大辞泉 / 旺文社国語 / 小学館例解）「走る」的 `{glossary}` 198 KB、其中 CSS 116 KB。
- **[x] ① 已修复** — `packages/fushi_anki/lib/src/anki_glossary_css.dart`（新）在 payload 进 handlebar 渲染前按**本段释义实际内容**裁剪词典 CSS：只裁 `.yomitan-glossary` 作用域规则（判命中前去掉伪类 / 伪元素，只会多留）；交互态（`:hover` / `:active` / `:focus*`）同样放宽后按命中判断（审查修订：Anki 桌面有鼠标 hover、Android WebView 点按也触发 `:hover`，整条丢会让「点一下显示」类写法失效）；条件组递归裁剪；`@font-face` / `@keyframes` 仅在被留下的规则或释义正文（MDX 内联 `style="font-family:…"` / `<font face>`）引用时保留；去注释、压空白（字符串内不动）；同一字段内相同 `<style>` 去重。接线在 `anki_note_composer.dart` `renderMediaPayload` 与 `fushi/lib/src/anki/ankimobile_repository.dart`（AnkiDroid / AnkiConnect / AnkiMobile / 互联转发都经这两处）。改后：OALDPE「run」每字段 357 KB → 195 KB（CSS 247 KB → 85 KB，剩下的是本条真用到的音标字体与 Oxford 3000 图标），两字段合计约 714 KB → 390 KB；日语「走る」`{glossary}` 198 KB → 100 KB（CSS 116 KB → 18 KB），`{glossary-first}` 68 KB → 54 KB（CSS 18 KB → 5 KB）。Chrome 逐元素比对计算样式（含 ::before/::after/::marker）：日语卡 2502 个元素零差异；OALDPE 卡差异只有 ① 自定义属性值里逗号后的空格（`var()` 使用等价）② 被 popup.js 格式化弄坏的 data URI 图标恢复显示（与弹窗一致）。
- **[x] ② 已加自动化测试** — `packages/fushi_anki/test/anki_glossary_css_test.dart`：裁剪语义（作用域 / 非作用域 / 伪类放宽 / 交互态 / 条件组 / 字体与动画引用 / 字符串保真 / data URI 空格 / 不认识的语法保留 / 去重）+ 真实落卡路径（`renderMediaPayload`，Lapis 默认映射）上三本 ~200 KB CSS 的多词典卡字段总大小 < 16 KB、每字段同一词典 CSS 至多一份、释义正文逐字不变。
- **备注**：存量卡不迁移（字段里已有的整份 CSS 仍在，需要的话用户可重新覆盖制卡）。代价：用户事后在 Anki 里手改字段、加进原本不存在的结构时，那部分不再有词典样式。未在 AnkiDroid 真机 / 模拟器上实测预览（本机无 adb 真机；模拟器路径需完整构建 APK + 准备 AnkiDroid）。仍保留的内嵌字体（OALDPE 27 KB）可后续改成媒体文件引用。
