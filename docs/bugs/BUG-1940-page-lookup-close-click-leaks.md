## BUG-1940 · 关弹窗的点击与 Esc 漏给站点
- **报告**：2026-08-29（用户：网飞在右边字幕列表查词时，点击左边会把视频暂停；按 Esc 会退出
  全屏而非关闭弹窗）
- **真实性**：✅ 真 bug（两条，同一处所有权问题）。根因
  `tools/browser-extension/content.js:2703` 一带的关窗监听：①关窗的 `mousedown` 挂在**冒泡**
  阶段且不截住事件，那一击照样传到站点——Netflix 把「点画面」当播放/暂停切换，用户点旁边只
  想关弹窗却把视频停了；②页面弹窗**根本没有** Esc 处理，全屏看片时按 Esc 只有浏览器的退出
  全屏生效，弹窗还留在原地。
- **[x] ① 已修复** — `content.js:2726` `fushiSwallowClosingClick`：关窗后在 capture 阶段截住
  紧随其后的那一个 click（不 `preventDefault`，聚焦/选区等默认行为保留），没产生 click 时由
  定时器撤掉监听；`content.js:2758` 新增 capture 阶段的 Esc：先关窗再截住该次按键。
- **[x] ② 已加自动化测试** — `side-panel-lookup-on-page.test.js`「关掉弹窗的那一击不再传给
  站点」+「Esc 关掉页面弹窗，并截住这次按键不让站点再处理」；变异实测：删掉吞击调用、或让
  Esc 分支直接 return，各自变红。
- **备注**：视频处于 Fullscreen API 全屏时，**Esc 退出全屏是浏览器保留行为，网页脚本拦不
  住**。这里能保证的只是「弹窗一定被关掉」，退全屏仍会同时发生——要「只关弹窗不退全屏」得
  换一个键，不是本条能修的范围。
