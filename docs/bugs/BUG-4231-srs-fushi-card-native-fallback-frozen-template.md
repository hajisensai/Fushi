## BUG-4231 · Fushi 卡片冻住的旧版内置模板让复习卡静默回退整面 WebView
- **报告**：2026-11-07（用户：反馈 O5YDP27Xko，Android 复习卡视频带 `<video controls>` 自带 ⋮ 控件，即整面 WebView 卡面）
- **真实性**：✅ 真 bug（结构性，具体卡未在库里定位：本机找不到开发者 PC 的 srs.db，只能从截图推断走了整面 WebView）。根因：内置 Fushi 卡片一有修改记录（外观页调区块、apkg 导入、恢复 / 撤销、同步）就冻成记录里的全文（`packages/fushi_engine/lib/srs/srs_builtin_template_restore.dart:3`）；原生判据却逐字比较**当前**内置样式与骨架（`packages/fushi_anki/lib/src/fushi_card_blocks.dart` 旧 `fushiCardCssIsDefault` / `fushiCardLayoutOf`），内置模板一升级（a6acbfb4d8 区块自定义），所有冻住的旧版本都不再算「内置」，`srsFushiCardNative`（`packages/fushi_engine/lib/srs/srs_fushi_card_native_media.dart`）返回 null，`renderCard` 把它当「没有原生信息」，复习页落到整面 WebView，且任何一道门槛都不留原因。反方向同样成立：旧代码读到新版本生成并同步过来的模板也会静默回退。
- **[x] ① 已修复** — A1：`fushi_card_template_history.dart` 登记内置模板每一版（样式哈希 + 正背面切分规格，生成脚本 `tool/gen_fushi_card_template_history.dart` 从 git 历史生成、只追加），`fushiCardCssIsBuiltin` / `fushiCardLayoutProbe` 认任一历史版本，命中旧样式时释义 WebView 用当前内置样式；A2：内置模板末尾带自证骨架标记 `<!--fushi-card-skeleton:<sha256>-->`，骨架未知但标记与实际骨架哈希一致时照样按区块切分。回退可观测：`srsFushiCardNative` 返回 `SrsCardNativeFallback`（notBuiltin / cssModified / frontTemplate / backTemplate / media + 第一处差异原文），`SrsRenderedCard.nativeFallback`；app 侧四处卡面统一经 `fushi/lib/src/srs/srs_card_face_route.dart`，复习页回退记 `SrsCardFace.webFallback` 诊断，外观页提示接具体原因。
- **[x] ② 已加自动化测试** — `packages/fushi_engine/test/srs/srs_fushi_card_native_fallback_test.dart`（f5ab1a649d 旧版素材走原生、旧版调序、各道原因、renderCard、apkg 导入本版 / 旧版包）；`packages/fushi_anki/test/fushi_card_template_history_guard_test.dart`（当前版本必须登记、登记表只追加）；`packages/fushi_anki/test/fushi_card_blocks_test.dart`「自证骨架标记」组；`fushi/test/srs/srs_card_face_route_test.dart`（路线判据 + 页面不得绕过统一判据的守卫）；`fushi/test/srs/srs_review_web_fallback_diagnostic_test.dart`（复习页回退记诊断且只记一次）。
- **备注**：远程复习 wire 的回退原因键 `nfb` 未做（排在 PR #3045 合入之后，并入它的回包统一校验与 parity 守卫）；在那之前远程卡没带原因时客户端记 `remoteUnknown`。样式还没有自证标记：旧代码读到未来版本改过的内置样式仍按 cssModified 回退（带原因）。
