## BUG-2243 · 浏览器字幕列表打开落在顶部而非当前时间附近
- **报告**：2026-09-07（用户：字幕列表打开时默认定位到当前时间附近）
- **真实性**：✅ 真 bug。`tools/browser-extension/side-panel.js:829` 的 updateCurrent 原先只在命中字幕区间时滚动，间隙返回 -1 与初始下标相同直接退出，打开列表停在顶部。
- **[x] ① 已修复** — 高亮与定位分离：首次即时居中当前句或最近句，未知播放时间等待有效值，延迟字幕加载使用最新时间。手动滚轮/触摸停止跟随，跟随按钮可恢复。提交见本文件所在提交。
- **[x] ② 已加自动化测试** — `tools/browser-extension/side-panel-position.test.js` 六项行为测试覆盖句内/间隙/片头片尾、时间和字幕延迟、手动滚动及恢复。
- **备注**：扩展 Node 475 项通过，镜像一致。IAB 后端不可连接，实际浏览器视觉复测未完成。
