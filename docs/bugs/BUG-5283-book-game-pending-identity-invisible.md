## BUG-5283 · book-game-pending-identity-invisible
- **报告**：2026-11-23（用户：书 / 漫画、游戏没认出来的条目哪里都看不到，要求和视频统一成一套待确认机制）
- **真实性**：✅ 真 bug。AI 库管家刮书 / 游戏认不出时只把条目记进运行记录的 `pendingItems`（`packages/fushi_engine/lib/media/library_curate/library_curator.dart` `_scrapeBooks` 的 `book_scrape_pending`、`_scrapeGames` 的 `game_scrape_pending`），运行记录只存在设备本地偏好 `library_curate_state` 里，只有 ctl 路由 `library.curate.pending` 读它；书架（`reader_fushi_history_page.dart`）、游戏库（`games_library_page.dart`）没有任何提醒，手动整理结果弹窗的「查看待确认」打开的是整理历史页，里面没有刮削条目。视频则有完整的提醒条 + 带原因的待确认清单 + 忽略（`home_video_page.dart` / `video_source_scrape_dialog.dart`），三种媒体是两套各管各的。
- **[x] ① 已修复** — 统一成一套与媒体无关的待确认身份机制：引擎 `media/identity/pending_identity.dart`（条目 / 原因 / AI 结论 / 忽略域，视频的 `VideoScrapePendingCause` / `VideoScrapeAiOutcome` 改成它的别名、落库值不变；忽略按域存偏好，视频沿用 `video_scrape_ignored_works`，新增 `book_scrape_ignored_works` / `game_scrape_ignored_works`，均设备本地）。数据源：视频适配既有补刮调度（`video_pending_identity.dart`，行为不变，只多带「上次尝试」时刻）；书 / 漫画与游戏从库管家运行记录 + `seen` 派生，并用库管家自己的事实（`bookScrapeUnits` / `gameScrapeUnits`，全量）复核当前状态，已修好的条目自动消失（`curator_pending_identity.dart`）。库管家待确认项多记候选数与 AI 结论；忽略的书 / 游戏不再被整趟自动去查；新增单条重试 `LibraryCurator.retryScrape`（只跑这一阶段、只看这一条、不推进水位、照常记一趟可整趟撤销）与操作 `library.curate.scrape.retry`。界面：提醒条与待确认清单抽成共享组件（`fushi/lib/src/media/identity/pending_identity_widgets.dart`），视频页提醒条与刮削任务面板的「待确认」tab 改用它（key 与行为不变），书架 / 漫画书架 / 游戏库（仅本机游戏库形态）各挂一条只数本媒体的提醒条，「去确认」打开同一个待确认弹窗：原因 + 上次尝试、手动搜索（书 = 书卡的在线刮削弹窗，游戏 = 游戏的刮削资料弹窗）、让 AI 重试（AI 模块门 + 发送同意）、忽略 / 撤销。
- **[x] ② 已加自动化测试** — `packages/fushi_engine/test/media/identity/pending_identity_test.dart`（落库值冻结、忽略域与旧键兼容、书 / 游戏数据源：最近原因、已修好消失、没试过不列、系列按卷键对号、漫画归类、忽略往返）；`library_curator_test.dart` 新增 4 条（待确认项带候选数 / AI 结论、忽略的单元不再查、单条重试书 / 游戏）；`fushi/test/media/identity/pending_identity_widgets_test.dart`（提醒条显隐 / 计数 / 宿主重算、待确认弹窗原因 / 动作 / 忽略往返 / 无 AI 不画重试、重试结论文案）；`ctl_library_curate_routes_test.dart` 新增 `scrape/retry`；`ai_module_gate_guard_test.dart` 新增「让 AI 重试」入口。
- **备注**：系列单元的「手动搜索」一次处理一卷（第一本还缺资料的），写回后清单重读，其余卷仍留在该条目里。视频提醒条图标从 `Icons.rule_folder_outlined` 换成语义图标 `FushiIcons.manageSearch`（新文件不许直接用 `Icons.*`）。
