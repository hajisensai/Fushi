## BUG-4706 · 书库导入页点左上角「书架」回不去，仍停在导入页
- **报告**：2026-11-16（用户：维护者应用内反馈 3cmGrH7EoA，Windows 3.3.0-debug.27417）
- **真实性**：✅ 真 bug。`fushi/lib/src/pages/implementations/media_library_shell.dart:573`（修复前）停在导入页时为了高亮「我的」组，把一级页签的 `selected` 设成组值（书架）——「视觉高亮」和「当前视图」共用同一个 `selected`。页签组件把「点中 selected」当重复点击丢掉：页头大字一级切换 `fushi/lib/src/utils/components/fushi_page_masthead.dart:635`（`if (tabs[i].value != selected) onChanged(...)`），二级连体按钮组同理（同文件 774），焦点外壳 `FushiAdjustableSegmented`（`fushi/lib/src/utils/components/settings_shared.dart:3114`，`if (value != selected)`）从首段按左方向键被夹回原地同样被丢，Apple 非页头大字形态的分段控件（`FushiSegmentedButton` / `FushiAppleSegmentedControl`）点已选段也不回调。于是导入页的「书架」看着是选中的，点 / 按都到不了 `_select`。
- 同根因的另外三个宿主：视频库导入页（`video_library_shell.dart:380`，`currentGroup == null` 时高亮「媒体库」组）、游戏导入页（`game_shared.dart:365`，高亮「游戏库」组）、游戏诊断页（`game_shared.dart:301`，诊断不是页签，一级 / 二级都高亮「工作台」）——点高亮项同样回不去。
- **[x] ① 已修复** — 把「高亮锚点」与「当前视图」拆开：`LibrarySectionTabs` 新增 `selectedIsCurrent`（默认 true），书 / 漫画库壳与视频库壳在导入页传 false，`GameSectionTabs` 在导入页（一级）与诊断页（一级 / 二级）传 false；页头大字一级 / 二级、`FushiAdjustableSegmented` 与 Apple 分段控件（`FushiSegmentedButton.notifyReselect`，连同 `FushiAppleSegmentedControl` / `FushiConnectedButtonGroup`）在 `selectedIsCurrent == false` 时点中 / 方向键落到高亮项照常回调。宿主的切换入口本身幂等。
- **[x] ② 已加自动化测试** — `fushi/test/pages/media_library_shell_test.dart`：导入页真实指针点「书架」回到书架；导入页键盘左方向键回到书架。`fushi/test/pages/home_game_page_test.dart`：游戏导入页点「游戏库」回到游戏库；诊断页点二级「工作台」回到捕获工作台。`fushi/test/pages/library_section_tabs_reselect_test.dart`：页头大字一级 / 二级、Apple 页头大字、Apple 非页头大字分段控件、MD3 TabBar 五种画法下高亮只是锚点时点它照常回调，默认（高亮即当前视图）时点当前项仍不回调。
- **备注**：视频库壳没有壳级真实点击测试——导入页 `MediaSourcesPage` 在 initState 里读 `appProvider` 并查库，widget 测试搭不起来；它与书库壳同一个判据（`selectedIsCurrent: currentGroup != null`），由组件级测试覆盖各画法。MD3 非页头大字形态（墨水屏）的 `FushiSectionTabBar` 走 TabBar `onTap`，本就逐次回调。真机未复测。
