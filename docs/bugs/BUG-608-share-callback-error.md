## BUG-608 · 分享图片PlatformException share-sheet未回调重入
- **报告**：2026-07-08（用户：）· TODO-1318
- **真实性**：✅ 真 bug。根因在 share_plus 7.2.2 的**结果型**文件分享变体：`Share.shareXFiles` → platform interface `shareFilesWithResult` 方法通道 → Android `ShareSuccessManager.setCallback`（`share_plus-7.2.2/android/.../ShareSuccessManager.kt:23-33`）用原子标志 `isCalledBack` 的 `compareAndSet(true,false)` 串联「面板关闭」回调；若上一次结果型分享的 `onActivityResult` 没回调（面板被系统方式关闭 / Activity 因内存或旋转重建 / 目标 App 未回传结果），标志**永久卡 false**，之后每次 `shareXFiles` 都抛 `PlatformException(Share callback error, prior share-sheet did not call back, did you await it? Maybe use non-result variant, null, null)`；快速连点分享按钮的重入也命中同一分支。App 侧图片分享调用点：`hibiki/lib/src/pages/implementations/illustrations_viewer_page.dart:287`、`hibiki/lib/src/pages/implementations/reader_hibiki/chrome.part.dart:527`（另有 crash_dump / log / backup / collection / audiobook / video-clip 共 11 处 `shareXFiles` 同源风险）。
- **[x] ① 已修复** — 新增统一入口 `hibiki/lib/src/utils/misc/hibiki_share.dart`（`HibikiShare.shareFiles`）：本 App 从不读取 `ShareResult`，故改用 share_plus **非结果变体** `Share.shareFiles`（`isWithResult=false`，从根上绕开 `ShareSuccessManager` 回调状态机——错误唯一来源），并加进程内**防重入**串行化（`_sharing` 门，避免面板呈现瞬间重复触发）；内存型 `XFile.fromData`（日志页）先落盘临时文件再分享，缺 mimeType 回退 `*/*`（不收窄可分享目标）。全部 11 处 `Share.shareXFiles` 调用点改走该入口（`illustrations_viewer_page` / `reader_hibiki/{chrome,audiobook}.part` / `video_hibiki/clip_export.part` ×2 / `crash_dump_page` / `debug_log_page` / `error_log_page` / `sync_settings_schema/backup.part` / `collection_exporter` / `log_exporter`）。提交见本轮 TODO-1318 提交。
- **[x] ② 已加自动化测试** — `hibiki/test/utils/hibiki_share_reentrancy_test.dart`（方法通道层拦截 `dev.fluttercommunity.plus/share`：断言只发 `shareFiles` 非结果方法、绝不发 `shareFilesWithResult`；面板在途时重入调用被丢弃、门复位后恢复；缺 mimeType 回退 `*/*`；空列表短路）。另更新 4 个源码守卫（`crash_dump_settings_windows_only_guard_test` / `collection_exporter_platform_guard_test` / `illustrations_viewer_actions_guard_static_test` / `reader_image_actions_guard_static_test`）改断言移动分支走 `HibikiShare.shareFiles`。
- **备注**：真机验收（Android 分享图片不再 PlatformException、连点不崩、目标 App 正常收图）交用户。`Share.share(text)`（文本分享）是非结果 `share` 通道、不触 `ShareSuccessManager`，本轮不改。
