## BUG-2608 · 媒体服务器搜索把服务器的模糊命中原样铺出来，精确命中被埋
- **报告**：2026-09-20（用户：Windows 开发版接 `https://v1.uhdnow.com`（UHD Media Server 兼容层，伪装 Emby 4.9.3），媒体服务器搜索页搜「怪奇物语」，整屏是「怪奇收割 / 尘兔 / 绿毛怪格林奇 / 怪形 / The Thing / BLACK JACK…」只沾一个字甚至一个字都不沾的电影，真正的剧集《怪奇物语》第一屏根本看不到）
- **真实性**：✅ 真 bug。沿真实代码路径取证（`fushi/test/sync/media_server_live_search_probe_test.dart` 打用户那台服务器）：`/Users/{uid}/Items?SearchTerm=怪奇物语&Recursive=true&IncludeItemTypes=Movie` 回 **121** 行、`Series` 回 **68** 行，服务器按字模糊 + 相关度打分（原版 Emby 4.10 本地 docker 同一查询只回精确 1 行：它是「按空格分词 + 词首前缀 + 多词 AND」；Jellyfin 是 `CleanName` 子串）。根因两条：
  1. `fushi/lib/src/sync/jellyfin_video_client.dart:2098`（上游 `search()`）把服务器回的行**原样**投影成命中（`:2128` `items.addAll(mediaServerItemsFrom(...))`），没有任何「结果真含查询词」的把关——客户端默认了服务器 `SearchTerm` 是子串/前缀语义，兼容层不是。
  2. `:2095` `kSearchRounds = ['Movie', 'Series']` 的「电影轮在前、剧轮在后」拼接分页：兼容层 121 部沾边电影先铺满两页，精确命中的剧被压到第 3 页之后；`:675` 又固定 `SortBy=SortName`，即便服务器有相关度排序也被覆盖。
- **[x] ① 已修复** — `feat/fix(media-server)`（本 PR）：新增 `fushi/lib/src/media/video/media_server/media_server_search_match.dart`（`mediaServerSearchTokens` / `mediaServerSearchMatches` / `rankMediaServerSearchHits`，纯函数）；`JellyfinVideoClient.search` 改成「向服务器按 100 行一页扫、每行过把关（查询每个空白分隔词都是归一化标题**或**原名的子串，与库页 `matchesMediaSearch` 同口径）、凑够 `limit` 条命中或扫满 `kSearchScanLimit=500` 行才停、两轮合并后精确同名 > 以查询开头 > 其余置顶」，`nextStartIndex` 仍是服务器行偏移、`totalCount` 是服务器总数上界；`Fields` 加 `OriginalTitle`（Emby 要显式要）并把 `originalTitle` 接到 `JellyfinItem` / `MediaServerItem`。网格 `media_server_grid_view.dart` 的 `_loadMore` 成功后也 post-frame 补一次 `_onScroll`：把关后一页可以只剩 0 条而 `hasMore` 仍 true，没有滚动事件就得主动接着翻。对 Jellyfin 子串命中 / Emby 词首前缀命中无损（它们本来就满足把关条件，本地 docker Emby 4.10 实测 1 → 1）；用户服务器实测 189 行 → 3 条（怪奇物语 / 怪奇物语：1985故事集 / 最后的冒险：《怪奇物语》第五季幕后），精确命中置顶。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/media_server/media_server_search_match_test.dart`（三家命中形态都过、按字模糊过不了、原名命中、归一化口径、分层排序）；`fushi/test/media/video/media_server/jellyfin_media_server_test.dart` `search › 把关（BUG-2608）` 组（121 沾边 + 3 剧的假服务器：滤掉/置顶/请求序列 `Movie@0, Movie@100, Series@0`；原名搜；900 行扫满 `kSearchScanLimit` 先返回、下一页接着扫）；`fushi/test/sync/media_server_live_search_probe_test.dart` 真服务器探针（默认 skip，`--dart-define` 三参）。
- **备注**：刻意不折叠变音符（Jellyfin `CleanName` 把 é 当 e，我们的 `normalizeMediaSearchText` 不折），与本仓三个库页搜索既有口径一致；真有 Jellyfin 用户按无变音符拼写搜带变音符标题的反馈再统一升级归一化。兼容层若按简介 / 演员匹配到的条目，标题和原名不含查询词会被挡掉——这是有意的：用户看不出它为什么出现在结果里。
