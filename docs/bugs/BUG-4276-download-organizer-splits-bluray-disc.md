## BUG-4276 · 下载整理器拆散蓝光原盘：最大 m2ts 被改名成正片、其余进 Extras、盘文件留在原地
- **报告**：2026-11-10（用户：库里「特別編 響け！ユーフォニアム～アンサンブルコンテスト～ (2023)」原盘被拆成两半，原盘菜单 / `fushi_cli disc` 无法使用；另有 4 个 BDMV 种子在队列里会走同一条路径）
- **真实性**：✅ 真 bug，已在用户真实数据上复现（维护者手工按 CLIPINF `number_of_source_packets × 192` 对上 `00001.m2ts` 拼回）。根因（develop `e20277dc5d` 行号）：
  1. `packages/fushi_engine/lib/media/video/download/video_download_organizer.dart:192` `plan()` 只取 `_isVideo` 扩展名的文件（`.m2ts` 在白名单 `:715`），盘的 `index.bdmv` / `MovieObject.bdmv` / `PLAYLIST/*.mpls` / `CLIPINF/*.clpi` / `META/` / `CERTIFICATE/` / `BACKUP/` 根本不进计划，`moveStorage` 后留在原相对路径（只剩菜单骨架的 `『…』/BD/BDMV`）；
  2. 同文件 `:215-:245` 电影形态取最大视频当正片，`:396-:400` 把 `BDMV/STREAM/00001.m2ts` 改名成 `<作品> (年份).m2ts`；`:421-:430` 其余 m2ts 镜像进 `Extras/BD/BDMV/STREAM/`；
  3. 下游 `video_download_pipeline_service.dart:3524`（`_persistOrganizationIntent`）只有 `video` / `extra` 两类，`_importMedia`（`:4358`）把每个 `video` 行当一集视频入库——整条流水线没有「原盘」这一类，而来源库扫描器（`source_library_scanner.dart` `planScanFromFileList` / `_importBlurayDiscs`）早就按 `BDMV/PLAYLIST/*.mpls` 认盘、整盘入库成盘合集。
- **[x] ① 已修复** — 整理器先认盘（`<盘根>/BDMV/index.bdmv|MovieObject.bdmv` 或 `<盘根>/BDMV/PLAYLIST/*.mpls`，与扫描器同形状），盘成员整棵原样落到 `<作品>/<盘目录（剥共享发布根后的镜像路径）>/…`，盘在种子根时作品目录即盘根；新字段 `VideoOrganizationFilePlan.blurayDiscRoot`，文件行记 `kind: 'other'`（kind 有 CHECK 约束，不另立值，盘形状本身就是证据）。导入阶段用扫描器同一个 `planBlurayDiscRoots` 从落位路径认盘，经新抽出的引擎共用实现 `BlurayDiscLibraryImporter`（`bluray/bluray_disc_library_import.dart`，扫描器 `_importBlurayDiscs` 改为调用它）整盘入库成盘合集；纯原盘任务入库后直接完成，盘外散装视频照旧走剧集 / 电影 / Extras 规则。提交见 PR。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/download/video_download_organizer_bluray_test.dart`（单盘、多卷含同名盘目录、种子根即 BDMV、盘与普通 mkv 混装、电影形态、反斜杠路径、无清单的散 STREAM 不算盘、共享发布根）；`fushi/test/media/video/download/video_download_pipeline_service_test.dart` 组「蓝光原盘种子」（真盘 fixture + 真磁盘改名：纯原盘任务落位并入库成一个盘合集、无 m2ts 行；多卷盘 + 分集混装；导入侧 `videoDownloadBlurayDiscRoots` 识别）。
- **备注**：纯原盘任务不进刮削阶段（任务身份没有逐集文件可映射），盘的规范身份交给媒体库原盘识别（来源索引器）；盘面图仍由下一次来源扫描补（`_applyBlurayDiscArtwork` 依赖 app 层封面服务）。未在真机 / 真实 BD 种子上端到端复测（下载需真实种子），已用字节级合成 MPLS/CLPI 盘走完整 organize → import。
