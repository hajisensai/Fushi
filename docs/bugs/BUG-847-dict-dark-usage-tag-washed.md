## BUG-847 · ダークモードで辞書の使い方タグがライト背景のまま浮く
- **报告**：2026-07-16（用户：截图 明鏡「以前」ダークモード「使い方」タグ）
- **真实性**：✅ 真 bug。根因 `hibiki/assets/popup/popup.js` `setStructuredContentElementStyle`（~L655）。明鏡の「使い方」用法タグは辞書（Yomitan structured content）が持つ inline `background-color`（白ページ想定の淡いパステル）で来る。`setStructuredContentElementStyle` は `float`/`position` だけ落として `background`/`color` を `element.style` に**素通し**。`popup.css` のダークテーマは CSS 変数の再定義のみで、辞書 inline 色の中和ルールが皆無（`html[data-theme="dark"]` 配下の structured-content 向け override は画像 invert 1 箇所だけ）。結果、ダークの黒面に淡ピンクのチップが浮き、継承した明色本文テキストが低コントラストで読めない。
- **[x] ① 已修复** — `popup.css` にダーク限定ルール追加：`html[data-theme="dark"] :where(.glossary-group, .glossary-content) [class^="gloss-sc-"][style*="background"] { background-color: rgba(128,128,128,0.2) !important; color: var(--text-color) !important; }`。辞書 inline のライト背景をアプリ既存 glossary-tag と同じ控えめチップ＋可読文字色に中和。`[class^="gloss-sc-"]` スコープで**テキスト系のみ**狙い、画像マスク `.gloss-image-background`（同じく inline `background-color:currentColor`）は不干渉。inline に勝つため `!important`。ライトモードは白面で辞書パステルが正常に読めるため対象外。三镜像同步 + `content.css` 再生成（生成器が `html[data-theme="dark"]`→`:where(#entries-container)[data-theme="dark"]` に再root）。提交 `fbe6fd4bf`。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/popup_glossary_dark_inline_bg_guard_test.dart`（新規）：ダーク限定ルールの存在（`!important` の background + color）、画像マスク非該当（`gloss-image` を含まない）、再root ルールが両 `content.css` ミラーに到達。
- **备注**：CI グリーン。色相（赤＝使い方）は失い控えめグレーチップになる意図的トレードオフ（可読性・ダークネイティブ優先）。色相保持（smart-invert）を望むなら差し替え可能。実機でダーク「以前」の「使い方」タグ可読性を目視要確認。参照「Hoshi popup.css」実体なし＝自前根治。
