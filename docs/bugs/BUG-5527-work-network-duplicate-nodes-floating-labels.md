## BUG-5527 · 关系网：单视频合集与其唯一那集画成两个重复节点、建议边标签飘离连线、标题截断分不清前後編
- **报告**：2026-11-26（用户：截图，MyGO 剧场版的关系网「设计的什么垃圾东西」）
- **真实性**：✅ 真 bug，本机库实测（合集 135 / 136 各只装一部剧场版，用户来源、无刮削身份）。三处根因：
  1. `packages/fushi_engine/lib/media/links/work_graph_loader.dart` `isWorkSeriesCollection` 的 `user` 分支：只装一个视频的用户合集不算系列，合集端点与它唯一那集成了两个互不相干的条目——关系网画成两个一模一样的节点，AI 还给它俩补了「同一作品」连接（`video_collection 135 ⇄ video_episode 00000 (11)`）。
  2. `fushi/lib/src/media/links/work_network_layout.dart` 标签放置：建议边标签 200 宽而栏缝只有 136，放在曲线中点必压节点，原逻辑只会「往下挪 8px 直到不重叠」，一路挪到整张图底下，两个「外传 ✓ ✗」浮在空白处、看不出属于哪条边。
  3. 节点 136 宽、标题两行：前編 / 後編的区别在标题末尾，全被省略号吃掉。
- **[x] ① 已修复** — 只装一个视频的用户合集算系列合集（合集是那个视频的外壳，不可能连起不相干的东西），合集与那集折成一个节点、取合集名；标签改为沿自己的曲线找位置（中点起前后找、上下小幅错开，标签框必含一个曲线点），栏缝放宽到 220 容得下建议标签，同栏弧鼓出 120 让标签落在栏缝；节点 160 宽、标题三行。
- **[x] ② 已加自动化测试** — `fushi/test/media/links/work_graph_test.dart`（单视频 / 双视频用户合集的系列判定）、`fushi/test/media/links/work_network_series_test.dart`（截图形状的布局：每个标签压在自己的边上、不压节点、不互压）。
- **备注**：未在真机复看关系网页像素（布局为纯函数，已由测试咬住几何不变量）。
