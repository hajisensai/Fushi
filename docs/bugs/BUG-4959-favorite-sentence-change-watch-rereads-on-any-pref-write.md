## BUG-4959 · 收藏句变更通知靠偏好表整表更新流，任何偏好写入都让播放页重读整串收藏
- **报告**：2026-11-21（拍板台 design-nmv-fyi-tail ④「根本性做完」；来源 #3831 c51 遗留取舍，代码审读，无用户报告）
- **真实性**：✅ 真问题（性能结构问题，无错误结果）。收藏句整份存在 `preferences` 表的一个键 `favorite_sentences`（JSON 列表，`packages/fushi_audio/lib/src/audiobook/favorite_sentence_repository.dart` `_key`）。`FavoriteSentenceRepository.watchChanges()` 委托 `FushiDatabase.watchPrefChanged`（`packages/fushi_core/lib/src/database/database_prefs_media.part.dart:23`），它订阅的是 `tableUpdates(preferences)` 整表：任何偏好写入（含播放进度定期保存等高频写）都会触发一次 `getPref('favorite_sentences')` 读出整串 JSON 再比较。收藏多时每次偏好写入都白读一遍大字符串。增删一条也是整串读出、解码、重写（`add` / `removeById` / `removeByContent` …）。
- **[x] ① 已修复**（PR #3946，合并提交 0b32d92b1b，拍板台 design-nmv-stats-main-isolate 顺带做掉；2026-11-23 巡检核对后补记）— 收藏句搬进独立表 `favorite_sentences`（schema v166，迁移 `_migrateFavoriteSentencesPrefToTable` 把偏好 JSON 搬成行后删偏好行：撞 id 改名保留、坏条目跳过、坏 JSON 不动偏好、重跑幂等），`FavoriteSentenceRepository.watchChanges()` 改订 `watchFavoriteSentencesChanged`（`packages/fushi_core/lib/src/database/database_favorite_sentences.part.dart`，`tableUpdates(onTable(favoriteSentences))`），写别的偏好不再触发重读；同步（`aggregate_sync_service.dart`，wire 不变）、备份合并（`backup_merge_engine.dart` `_mergeFavoriteSentences` 读源库表）、备份导出 / 恢复、音乐别名改写都改走表。后续 v167（BUG-5140）在同表上加了颜色时钟列。
- **[x] ② 已加自动化测试** — `fushi/test/database/migration_v166_favorite_sentences_test.dart`（搬表字段一致 / 撞 id / 重跑幂等 / 坏 JSON / 无旧偏好）、`fushi/test/media/audiobook/favorite_sentence_change_stream_test.dart`（写别的偏好、内容相同的整表重写都不发）、`fushi/test/sync/favorite_sentence_merge_import_test.dart`、`fushi/test/sync/favorite_sentence_recolor_sync_test.dart`。
