## BUG-676 · 网飞制卡缺少视频名（documentTitle）
- **报告**：2026-07-09（用户：网飞制卡少了视频名标签 / TODO-1361 ③）
- **真实性**：✅ 真 bug（功能差异）。根因：浏览器扩展的网飞 `mineClip` 请求**从不发 `documentTitle`**——`tools/browser-extension/background.js` 的 `mineClip` 分支 body 只有 `{fields,sentence,clipBase64,clipDurationMs}`。服务端 `hibiki/lib/src/mining/immersion_capture_channel.dart:90` `buildImmersionRequest` 用 `p.documentTitle ?? 'Netflix'` → payload 无 documentTitle 时回落**字面「Netflix」**，经 `ImmersionMiningEngine`（`immersion_mining_engine.dart:210` `documentTitle: req.documentTitle`）落到 `AnkiMiningContext.documentTitle` → Anki `{document-title}` 字段（`packages/hibiki_anki/lib/src/anki_models.dart:459`）→ 网飞卡视频名恒为「Netflix」。对比 YouTube：`app_model.dart:4610` `documentTitle: yt.documentTitle ?? 'YouTube'`，`yt.documentTitle` 由服务端 `youtube_clip_miner.dart:73` `?? src.title`（resolveYoutubeSource 真实标题）→ YouTube 卡有真剧名。二者不一致 = 用户报网飞「少了视频名」。
- **[x] ① 根因修复** — 提交 `<PENDING>`（服务端映射链已就绪，仅补扩展侧发送 documentTitle，无 Dart 改动）：
  - `tools/browser-extension/subtitle-adapters.js`（镜像 assets/，字节一致）新增 `netflixDocumentTitle(doc)`：从播放器标题栏 `[data-uia="video-title"]` 抽「系列名(h4) - 集信息(span)」（语言无关、去重），回落 `document.title` 去尾部「- Netflix」；导出供 node 测试。
  - `tools/browser-extension/content.js`（镜像 assets/）：`hibikiEnqueue` 入队即抓当前剧名（此刻在正确剧集页）存进 `item.documentTitle` 持久化；`hibikiRunNetflixBatch` 的 `mineClip` 消息带 `documentTitle: q.documentTitle || 录制时现抓`（旧队列项回落）。
  - `tools/browser-extension/background.js`（镜像 assets/）：`mineClip` POST body 条件带 `documentTitle`（空串不发→保持旧「Netflix」回落，向后兼容）。
  - 服务端 `ImmersionMinePayload.fromJson` 已解析 `json['documentTitle']` → `payload.documentTitle` → `buildImmersionRequest(p.documentTitle ?? 'Netflix')`，**无需改**。
- **[x] ② 已加自动化测试** — `tools/browser-extension/subtitle-adapters.test.js`（node，直接跑真函数）5 例：系列+集拼接 / 电影仅系列名 / 重复 span 去重 / 回落 document.title 去 Netflix 后缀（`-`/`|`）/ null·空 → 空串。`hibiki/test/mining/netflix_todo1361_fixes_guard_test.dart` 两镜像守：subtitle-adapters.js 含 `netflixDocumentTitle` + `[data-uia="video-title"]`；content.js 持久化 documentTitle + mineClip 发送（带 live 回落）；background.js `mineClip` 转发 `msg.documentTitle`。
