- **备注**：与旧内存队列的两处**有意**语义差异：① 自动重试不再区分「瞬时网络错误才重试」——mokuro 卷与在线章节共用服务的退避重试（任何失败 `attempt_count < 3` 退避 2s/8s/20s 后重跑，`.part` 续传照旧），坏 zip 这类本地错误也会多试两次再落 `failed`，代价是最多 ~30s 空转，换来一套重试语义、一张表；② 同卷重复入队是同一 `job_id`（幂等，done 后再入队 = 同行复位 queued 重跑，由下载器的 `DuplicatePolicy.skip()` 判已在库），不再有「重复下载得到两条不同 taskId」。退避期间 worker 阻塞（旧队列退避不占执行位）——单跑道语义与在线章节一致，mokuro.moe 是社区小站本就不做并发。「识别本章」的引擎解析走向导口径（Lens 可选，先过同意闸门），后台钩子仍永不落到 Lens。
