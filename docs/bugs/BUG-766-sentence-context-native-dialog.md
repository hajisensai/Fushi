## BUG-766 · 制卡「选择句子上下文」应为 app 原生顶层对话框（不是画在查词弹窗内）
- **报告**：2026-07-13（用户：qqbotxiaoxiao，原话「我句子和句子之间是重叠的，有层透明，做成这样」「这个是要顶层弹窗，不是查词弹窗内」）

- **[x] ① 已修复** — 改为**真正的 Flutter 顶层对话框**：新增 `hibiki/lib/src/pages/implementations/sentence_context_dialog.dart`（`SentenceContextDialog`，`showAppDialog` 弹出，主题/焦点与 app 一致，句子框不再受弹窗表面约束）。接线：popup.js 词条「调整上下文」按钮改 `callHandler('openSentenceContextModal', {entryIndex, matched})`（entryIndex 用点击时稳定 DOM 序 `:scope > .entry`）；`dictionary_popup_webview` 新增 handler `openSentenceContextModal` + 字段 `onOpenSentenceContextModal` + 方法 `mineEntryByIndex`（确认制卡回 WebView 精确点中该词条 `hoshiPopupMineEntryByIndex`，复用全部制卡/查重/覆写逻辑）；经 `dictionary_popup_layer` 透传到 `base_source_page`（reader 车道）/`dictionary_page_mixin`（video 车道）弹对话框。**宿主后端回调（`onSetSentenceContextToDraft`/`onSentenceContextPreview*`/`_miningDraft`）零改动**——对话框直接复用。旧 WebView HTML 模态（popup.js 模态构建器 + popup.css `.scm-*`）**彻底删除**，三镜像同步 + `generate-content-css.mjs` 重生成 content.css。提交：<待填>
