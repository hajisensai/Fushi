## BUG-5533 · Apple 宽窗侧栏外壳切 tab 后紧跟一帧：所有访问过的保活库页（含藏起的）整页重建
- **报告**：2026-11-26（用户：「cupertino模块切换卡顿，无论是移动端还是pc」）
- **真实性**：✅ 真 bug（宽窗侧栏形态：PC / iPad 横屏）。用探针 `fushi/integration_test/home_tab_switch_perf_itest.dart` 实测：Windows profile，数据根为安装版真实库拷贝 `D:/hibiki-dev-data-perf2`，3840×2160 @2x / 144 Hz，`FUSHI_PERF_DESIGN=glass|material` 两套对照；同一探针也在 macOS profile 上跑过（空库）。glass 下每次切到库页 / 浏览 / 浏览器，切换帧之后约 30 ms 还会再出一帧 13～25 ms 的 UI 帧（例如 games：先 `b24.1`，接着 `b14.5`；browse：先 `b23.0`，接着 `b13.7`），material 只有切换那一帧。macOS 上是同一个「连续两帧」形态（玻璃 build 13～21 ms，Material 4～13 ms）。timeline 拆开第二帧，BUILD 里的脏根正是各保活 tab 的 `AppleLibraryLayout<GameSection / MediaLibraryViewKind×2 / VideoLibrarySection / MusicLibrarySection>` 与 `BrowsePage`，即访问过的所有库页（包括藏着的）各自整页重建了一次。
  - 根因：`fushi/lib/src/utils/adaptive/apple_sidebar_library_host.dart:172-193`（修前行号）中，`AppleSidebarLibraryScope` 是 `InheritedNotifier<AppleSidebarLibraryHost>`，notifier 就是宿主本身。库页布局（`apple_library_layout.dart:134`、`apple_browse_layout.part.dart:81`、`tag_filter_bar.dart:187`、`library_filter_dropdown.dart:494`）都用 `maybeOf` 依赖它，读的却只有 `sidebarMode`。切 tab 时新可见的库页 `publish` 分区行、旧的撤回，`_scheduleNotify` 在帧末 `notifyListeners()`。这一次通知除了送到真正要画这些行的侧栏外壳（`apple_sidebar_tabs.part.dart:144` 直接 `addListener`），还经 InheritedNotifier 送到了全部依赖者，于是每个访问过的保活库页都被标脏、整页重建。代价随访问过的 tab 数增长。这与 MD3 的 BUG-4851 / BUG-4848 同类（共同祖先上的共享状态通知到隐藏保活页），但只出在 Apple 侧栏这条路径上，当时只量了 MD3，所以没覆盖到。
- **[x] ① 已修复** — `apple_sidebar_library_host.dart`：宿主把两路通知分开。`sidebarModeListenable` 只在侧栏形态变化时通知（帧末），`AppleSidebarLibraryScope` 改为 `InheritedNotifier<Listenable>`，notifier 用它，宿主作为字段下发。分区行 / 标签节的登记只通知宿主自己的监听者（侧栏外壳）。`maybeOf` / `peek` 的签名不变，调用方不用改。
- **[x] ② 已加自动化测试** — `fushi/test/utils/adaptive/apple_sidebar_library_scope_test.dart`：在 scope 下挂一个计重建次数的依赖者，模拟切 tab（新 owner 登记、旧 owner 撤回、加一节标签），断言宿主监听者收到通知、`rows` 正确，而依赖者不重建；切侧栏形态时依赖者照常重建。修前旧代码上红。
- **备注**：
  - 手机（iOS / Android 竖屏，底栏外壳）不挂这个 scope，本条解释不了手机端的卡顿。同轮测量里手机路径的情况见 PR 描述：glass 每帧 raster 约为 material 的 2～3 倍（iOS 模拟器只能跑 debug，只能比相对值），首次挂载 UI 线程慢 1.5～2.7 倍。这两条要在真机 profile 下量，不在本条范围。
  - 同轮还看到 Windows glass 首页静止帧 raster 稳定在 12～15 ms（material 低得多，4K @144 Hz 下 glass 首页掉帧），属于玻璃材质的绘制成本，同样不在本条范围。
