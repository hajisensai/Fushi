## BUG-696 · 导航跳转落章节开头而非目标文字
- **报告**：2026-07-10（用户：TODO-1308 复诉「还是没跳转到对应的文字位置，只在章节开头」。竖排 vertical-rl 连续模式，从书内收藏/搜索跳转进阅读器落点是章节开头。此前 BUG-459/TODO-974/TODO-1309 已修过部分跳转入口，用户仍复现）。
- **真实性**：✅ **真 bug（沿真实代码路径三根因定位）**。**根因①（单位契约·主根因）** `hibiki/lib/src/pages/implementations/reader_hibiki/chrome.part.dart` 的 `onJumpToFavorite`：`fav.normCharOffset` 是写入端（`lookup.part.dart:271` / `mining.part.dart:368` 的 `sentenceNormalizedOffset` = JS `reader_selection_scripts.dart:1287 getNormalizedOffset`）产的**章内绝对可匹配字符索引**（0..数千），书内收藏面板跳转却把它 `/ 10000.0` 当 0-10000 进度分数还原 → 目标越深、`/10000` 越趋近 0 → 恒落章节开头。BUG-459 只修了**收藏页冷启动**入口（`reader_hibiki_page.dart:1606` charAnchor 绝对锚），书内收藏面板这条从未修到；TODO-1309 重写 handler 时又原样保留了 `/10000`。**根因②（Range DOM 手术）** `reader_pagination_scripts.dart` 的 `scrollToSearchMatch` 在连续模式（无 `scrollToRange` 时）兜底用 `range.surroundContents(span)`——在 rb/rtc 形态书（JIS mono-ruby，问题①同款 DOM）上命中词跨相邻 `<rb>` 基字时 Range 部分包含元素节点 → 抛 `InvalidStateError` → 滚动被跳过，跨章搜索经 `_applyPendingPreciseLocate`（catch 后仅记日志）确定性停章首。**根因③（竖排死分支）** `scrollToCharOffset`（连续）的 TODO-1229 章首区保位判据 `hintScroll > 0`：连续滚动位竖排是 `window.scrollX`（vertical-rl 滚离章顶后为**负**，见 `_readContinuousScroll` / `scrollToChapterEnd` 的 `-1e9`），`> 0` 在竖排永假 → 「保住当前滚动位」在竖排是死代码，任何重锚（setChromeInsets/缩放/换样式）把 fvco 采成 0 就把竖排用户钉回章首。
- **[x] ① 已修复** — 根因①：`chrome.part.dart` 把收藏跳转闭包抽成 `_jumpToFavoriteSentence` 方法（quick settings sheet 的 onJumpToFavorite 与新 `debugJumpToFavorite` 测试钩子共用唯一真实路径），改走与冷启动同构的绝对字符锚链：跨章把 `charOffset`（+句尾锚 `charOffsetEnd`，BUG-461 整句对齐）烘进 `_navigateToChapterAndWait`；同章直接 `restoreToCharOffset`（与 restoreProgress 同族恢复入口，notifyRestoreComplete 副作用形状一致）。为此 `navigation.part.dart` 给 `_navigateToChapterAndWait` / `_navigateToChapter` / `_beginNavigation` 加 `charOffset`/`charOffsetEnd` 运输参数，`_beginNavigation` 拥有并每次导航复位 `_initialCharOffsetEnd`（防冷启动收藏跳转设过的句尾锚泄漏进后续无关导航）。书签（onJumpToBookmark）的 normCharOffset 才是真分数，`/10000` 保持不变。根因②：搜索兜底改 `this.scrollToTarget(range)`（getRect 走 getClientRects，Range 原生支持，零 DOM 手术，不再切文本节点/残留 span/作废 nodeStartOffsets）。根因③：判据轴向归一 `Math.abs(hintScroll) > 0`（两轴章顶都是 0，非零即已滚离章顶）。
- **[x] ② 已加自动化测试** — 源码守卫 `hibiki/test/reader/favorite_jump_char_anchor_inbook_guard_test.dart`（根因①：收藏跳转方法不得 `/10000`、不得 restoreProgress、必须烘 charOffset + restoreToCharOffset；书签 `/10000` 保留；导航链带 charOffset/charOffsetEnd 运输 + `_initialCharOffsetEnd` 复位；根因②：搜索兜底剥注释后不得含 surroundContents、必须 scrollToTarget(range)）。`hibiki/test/reader/chapter_start_illustration_charoffset_guard_test.dart` 扩展根因③守卫（保位判据必须 `Math.abs(hintScroll)`，不得回退裸 `hintScroll > 0`）。真机层 `hibiki/integration_test/reader_favorite_jump_itest.dart`（竖排连续，`debugJumpToFavorite` 走真实 `_jumpToFavoriteSentence`，同章 + 重置后再跳两次量测 getFirstVisibleCharOffset 落点近目标句、非章首）。TODO-1309 原子链守卫 `test/pages/chapter_jump_double_jump_atomic_chain_test.dart` 同步更新（收藏由烘分数升级为烘绝对字符锚，原子链语义不变）。`test/reader/` + `test/pages/` 2733 全绿、`flutter analyze` 0。
