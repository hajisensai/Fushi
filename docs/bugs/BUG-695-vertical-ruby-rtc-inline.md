## BUG-695 · 竖排rtc形态振假名内联占字符格挤开基字
- **报告**：2026-07-10（用户：TODO-1308 复诉，附截图——竖排「貫禄」的振假名「かん」以整字格内联在貫和禄之间（占一个字符格、带独立高亮块），「ろ」「く」散落在右侧注音道；同书经 BUG-611 display 接管 + BUG-666 ruby-position:over 修复后仍复现）。
- **真实性**：✅ **真 bug（Windows WebView2 真机量测复现）**。根因 `hibiki/lib/src/reader/reader_content_styles.dart`（`_furiganaCss` 的裸 `rt { display: ruby-text !important }` 规则 + 主 CSS ruby 块只接管了 ruby/rt/rp，未接管 `<rb>`/`<rtc>`）。机理：W3C ruby extensions / JIS mono-ruby 形态的书用 `<ruby><rb>貫</rb><rtc><rt>かん</rt></rtc><rb>禄</rb><rtc><rt>ろく</rt></rtc></ruby>` 标注；Blink **不支持 rb/rtc**（真机 `CSS.supports('display','ruby-base')` 与 `('display','ruby-text-container')` 均为 false，两元素默认 display:inline），于是 rtc 里的 `<rt>` 被我们的裸 rt 规则强制成 ruby-text 后、因父级是普通 inline 而被包进**匿名 ruby**，落在正文流原位——注音变成基字列里的独立字符格：かん 挤进貫/禄之间把禄向下推一格（真机量测：かん cy=98 落在两基字间隙、禄被推开约一整字），ろく 掉到词下方（cy=140）。`reader_vertical_ruby_forms_itest.dart` 枚举 13 种真实 ruby DOM 形态量测，`rtc_per`（每基字一个 rtc）与 `loose_rt`（rt 无 ruby 包裹）精确复现用户截图签名；`rb_rtc`（单 rtc 收尾）注音整体掉到词后。
- **[x] ① 已修复** — `reader_content_styles.dart`：阅读器接管**所有 ruby 后代**的布局角色，消除按标签逐个补丁的特殊情况：主 CSS `ruby rb { display: inline !important }`（基字内容归位）、`ruby rp { display: none !important }`（由子代改后代选择器，覆盖 rtc/rb 嵌套里的 rp）、user-select 规则同步改后代选择器；`_furiganaCss` 显示态（show/partial/toggle）新增 `_rtcAnnotationCss`：`rtc { display: ruby-text !important; font-size: 0.45em; }`（rtc 整个映射为单一注音级）+ `rtc > rt { display: inline !important; font-size: 1em; }`（rtc 里的 rt 归位为注音内普通文本，不再被裸 rt 规则包成匿名 ruby）；hide 模式改为 `rt, rtc { display: none !important; }` 且**不发出** rtc>rt 规则（它比裸 rt 特异，若在 hide 模式存在会压过 display:none 把振假名放出来）。修后真机量测：`rtc_per` 恢复正确 mono 配对（かん cy=77 对齐貫、ろく cy=99 对齐禄，与标准 mono ruby 完全一致）；`rb_rtc` 退化为标准 group ruby（注音回到词域内注音道）；书本 CSS `rb/rtc/rt` display 覆盖下同样成立（reader 样式注入在 `</head>` 前最后，!important 级联胜出）；原有正确形态（mono/sep/group/rb 交错/嵌套/span_rt）几何零变化。
- **[x] ② 已加自动化测试** — 真机层 `hibiki/integration_test/reader_vertical_ruby_forms_itest.dart`（13 种 ruby DOM 形态 × 有/无书本 CSS 覆盖，真 WebView2 getBoundingClientRect 量测；违规判定=基字被注音挤开（>0.5 字）/注音纵向出词域/注音 x 侵入基字列（>0.6）/注音落错侧——修复前 rtc_per/rb_rtc 违规、修复后 violations=0，证据 `.codex-test/windows-itest/win-itest-20260710-072321-92c2f3ba/`）。CI 层 `hibiki/test/reader/vertical_ruby_display_context_guard_test.dart` 新增守卫：显示态必发 rtc→ruby-text 与 rtc>rt→inline 两条接管规则、hide 模式必须 rt,rtc 一起隐藏且不得发出 rtc>rt 规则、所有布局必发 ruby rb→inline；`test/reader/` 981 项全绿。
