## BUG-2261 · 阅读器视觉小说视图下纯CSS外观设置不实时生效
- **报告**：2026-09-08（用户：「小说很多外观设置不能点完立马生效，要退出重新进才刷新」）
- **真实性**：✅ 真 bug。根因 `fushi/lib/src/reader/reader_visual_novel_scripts.dart:3051`（host-compat shim 没实现 `beginStyleReanchor` / `commitStyleReanchor`）+ `fushi/lib/src/reader/reader_pagination_scripts.dart:824`（`beginStyleReanchorInvocation` 的 `:-1` 兜底裸返、不换 CSS）。`_applyStylesLive`（`reader_fushi_page.dart:3426`）只在「重锚不会跑」（gate 关 / 无 `window.fushiReader`）时裸换 CSS，gate 开时把换 CSS 全托付给 `beginStyleReanchor`；VN 有 `window.fushiReader` 但缺这对方法 → typeof 门恒假 → 两边都没换 → 字号/行距/边距/主题/明暗/振假名/两端对齐等纯 CSS 设置在 VN 下静默丢弃，退出重进重烤 `_buildStyleTag` 才生效。结构性设置（竖排/视图模式/列数/展开）走整章重载，不受影响。这是 BUG-849（分页 shell 缺席）同一契约漏洞的第三次复发；守卫 `reader_style_reanchor_both_shells_guard_test` 当时两轮循环都读分页脚本，连续 shell 从未被断言，VN 也不在清单。
- **[x] ① 已修复** — 两层：① 契约层根治——`beginStyleReanchorInvocation` 的无方法兜底自己换 CSS + 失效 `paginationMetrics` 再返 -1，任何 shell 再缺方法也只丢「保位」不丢「样式」；② VN shim 补 `beginStyleReanchor`（同步换 CSS + 记当前屏首字符偏移）/ `commitStyleReanchor`（Dart postFrame settle 后按新 CSS 重切屏、落到同一偏移），`refitScreensToCurrentViewport` 加可选锚参数复用同一重切原语（无参路径 = `updatePageSize`/`setChromeInsets` 行为不变）。
- **[x] ② 已加自动化测试** — `fushi/test/reader/vn_style_reanchor_behavior_test.dart` + `.js`（shim 原文进 node 真跑：begin 换 CSS/返偏移、commit 按新屏表落位、屏未就绪仍换 CSS、锚查无退进度、无参 refit 不变）；`fushi/test/reader/reader_style_reanchor_both_shells_guard_test.dart` 改为三个 shell 各读各的脚本 + 三脚本互异断言 + invocation 兜底换 CSS 顺序断言。
- **备注**：分页/连续模式的实时链路本身完好（BUG-849/866 已修）；若用户在分页模式仍复现，属另一条时序问题，需真机复测。
