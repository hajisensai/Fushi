## BUG-4101 · Windows WebView2 创建失败时 sentinel 恢复链因控制器类型错 TypeError，PlatformException 再作为未捕获异常冒两次
- **报告**：2026-11-04（应用内反馈 `bsDs3AQsy0`：Windows 10 Pro 19045，3.2.0-debug.22671，`PlatformException(0, Cannot create the InAppWebView instance!)` × 多次 + `type 'WindowsInAppWebViewController' is not a subtype of type 'InAppWebViewController'`）。
- **真实性**：✅ 真 bug，两处：
  1. `packages/flutter_inappwebview_windows/lib/src/in_app_webview/in_app_webview.dart:384`（旧）`_onCreationError` 把平台控制器 `_controller ?? WindowsInAppWebViewController.static()` 直接交给 `params.onReceivedError`，没像同文件 `onWebViewCreated`（`:356`）和 `in_app_webview_controller.dart:165` 的 `_controllerFromPlatform` 那样先经 `params.controllerFromPlatform` 转换。app-facing 包装层（`flutter_inappwebview-6.1.5/lib/src/in_app_webview/in_app_webview.dart:329-331`）的回调把 dynamic 隐式转成 `InAppWebViewController` → TypeError，TODO-904 / BUG-440 设计的 sentinel 恢复（reader toast + 退回书架）在真实路径上永远到不了。旧测试只用假 channel 测到 `CustomPlatformViewController`，没经过包装层的类型转换。
  2. `packages/flutter_inappwebview_windows/lib/src/in_app_webview/custom_platform_view.dart:783/858`（旧）`_reportSurfaceSize` / `_reportWidgetPosition` 是 `void async`，直接 `await _controller.ready`；创建失败时 completer `completeError`，同一个 PlatformException 已经经 `initialize` rethrow → `onCreationError` 上报，这两个等待者又各把它作为未捕获异常抛进 zone 一次——反馈里「× 多次」的来源。
- **[x] ① 已修复** — `_onCreationError` 用 `params.controllerFromPlatform?.call(platformController) ?? platformController` 转换后再回调；`CustomPlatformViewController` 新增 `Future<bool> created`（构造时即挂监听，成功 true / 失败 false），尺寸 / 位置上报改为 `if (!await _controller.created) return;`。创建失败只经 `onCreationError` 一条路径上报一次。
- **[x] ② 已加自动化测试** — `packages/flutter_inappwebview_windows/test/creation_error_controller_from_platform_test.dart`：真实 `WindowsInAppWebViewWidget` + 假 manager channel 让 `createInAppWebView` 抛 PlatformException，`controllerFromPlatform` / `onReceivedError` 按 app-facing 包装层同形（dynamic → 非平台控制器类型隐式转型）注入；断言 `takeException()` 为 null、`onReceivedError` 恰收到一次经转换的控制器且描述以 sentinel 开头。修复前红（先是 `_TypeError: type 'WindowsInAppWebViewController' is not a subtype of type '_AppFacingController'`；只修第 1 处时仍红在未捕获的 `PlatformException`）；两处都修后与 `custom_platform_view_dispose_test.dart` 合跑 5 例全绿。
- **备注**：同一反馈里进程随后消失（pid 85696 再无日志、无 Windows 崩溃摘要）是否由 WebView2 宿主崩溃带走主进程，证据不足，未在此处理（归入 Windows 无证据退出簇，等 WER 采集）。未做真机验证。
