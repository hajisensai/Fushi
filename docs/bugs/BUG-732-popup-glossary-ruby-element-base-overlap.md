## BUG-732 · 词典弹窗释义正文元素基字 ruby 注音塌到基字上
- **报告**：2026-07-11（用户：截图 明鏡国語辞典 释义正文，みぜんけい/どうし 等振假名压在 未然形/動詞 等基字上）
- **真实性**：✅ **真 bug**。根因 `hibiki/assets/popup/popup.js` 的 `postProcessRuby`（约 :2812-2846）只包裹 `<ruby>` 的**裸文本节点**基字（`node.nodeType !== Node.TEXT_NODE → continue`）。明鏡等单语词典把释义正文的 ruby 基字写成**元素节点**（`<ruby><rb>未然形</rb><rt>みぜんけい</rt></ruby>`，或 `<span>` / 嵌套 structured-content），这些元素基字被跳过 → 不生成 `.ruby-unit` → `popup.css` 的 `:where(.glossary-group,.glossary-content) rt{position:absolute; top:0}` 只能锚到裸 `<ruby>`（`line-height:1`、**无 padding-top 预留**）→ 振假名塌到基字正上方与基字重叠。
  - **回归引入点**：BUG-363（`todo-643-popup-ruby-zoom`）把释义体 ruby 的纵向预留从 `ruby{line-height:2}`（**所有** `<ruby>` 天然都有）迁到 `.ruby-unit{padding-top}`（**只有裸文本基字才被 postProcessRuby 生成**）。此后元素基字 ruby 失去纵向预留。BUG-722 又把 rt 从 `bottom:100%` 改锚到 `.ruby-unit` 的 `top:0`，进一步坐实「无 unit 即无预留」。二者叠加使元素基字 ruby 压字。
  - **判据/复现**：用真实 popup.js 的 `renderStructuredContent`+`postProcessRuby` 跑三种基字（node 复现，见测试）：裸文本基字 → `.ruby-unit`=1、rt 进 unit；`<rb>`/`<span>` 元素基字 → `.ruby-unit`=0、rt 仍直挂 `<ruby>`（= 压字签名）。
- **[x] ① 已修复** — 分支 `worktree-bug-ruby-element-base`，提交见末尾。`postProcessRuby` 改为**对任意基字（裸文本节点 *或* 元素节点）都生成 `.ruby-unit`**：把「base = 非 `<rt>`/`<rp>`/空白 的任意子节点」统一包进定位 unit——裸文本沿用原地 `textContent`（保住划词选区 BUG-110/123/125/129），元素基字则**整体移入** unit（内部文本节点仍活、可选中），再把其后的 `<rt>` 移进 unit。消除「基字是不是裸文本」这个特殊情况，纵向预留对所有 ruby 一致成立。三份镜像（`assets/popup/popup.js` + `assets/browser_extension/vendor/popup.js` + `tools/browser-extension/vendor/popup.js`，字节相同）同步改，parity 守卫不回退。纯 JS，不动 popup.css，BUG-722/345/363 契约保留。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/popup_glossary_ruby_element_base_test.js`（node 行为级，用真实 popup.js 执行 `renderStructuredContent`+`postProcessRuby`）+ `hibiki/test/pages/popup_glossary_ruby_element_base_test.dart`（flutter 包装 + 源码守卫）。断言：① `<rb>`/`<span>`/嵌套 structured-content 元素基字的 `<rt>` 落进 `.ruby-unit`、不再直挂 `<ruby>`；② 裸文本基字仍正常（回归）；③ 多汉字词 `将<rt>しょう</rt>棋<rt>ぎ</rt>` 每个 rt 各自入 unit（BUG-722 不回退）；④ 源码守卫：`postProcessRuby` 不再用 `nodeType !== TEXT_NODE → continue` 单一判据。
- **备注**：视觉压字为像素级，需真机/离屏复测原始失败路径（明鏡释义正文）留证据后再销号。相关：BUG-722（多基字叠印）、BUG-363（zoom 预留迁移）、BUG-345（横向紧凑）。
