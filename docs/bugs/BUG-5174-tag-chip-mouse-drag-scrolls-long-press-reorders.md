## BUG-5174 · 标签 chip 上鼠标按住拖只能重排、不能横滚标签条（鼠标也应长按才重排）
- **报告**：2026-11-22（应用内反馈 tJxhjzEQbi，开发者本人：「#3995 改变了鼠标操作：删掉拖动柄后，鼠标在 chip 上按住拖是重排标签，不再是横滚标签条。长按是重排啊，短按是点击或者滚动不就行了」）
- **真实性**：✅ 真问题（BUG-5066 修法的已知代价，开发者不接受）。沿代码定位：#3995（BUG-5066）在 `fushi/lib/src/media/tags/tag_chip_draggable.dart:60`（修复前）给鼠标 / 触控板套了即时 `Draggable`，`:92` 用 `ImmediateMultiDragGestureRecognizer(supportedDevices: {mouse, trackpad})`——越过 hit slop 的同一帧就认领，比外层 `HorizontalDragScrollable` 的横拖更深、先赢，所以鼠标在 chip 上一拖就是重排，标签条横滚不了。即时拖本身是对 BUG-4899 的绕行：真正的根因是 Flutter 的 `computeHitSlop`（`gestures/events.dart`）对鼠标固定返回 `kPrecisePointerHitSlop`（1 px，无视 `DeviceGestureSettings`），`DelayedMultiDragGestureRecognizer` 长按计时里位移超 1 px 就自行认输、`Scrollable` 的 `HorizontalDragGestureRecognizer` 也是超 1 px 就认领，于是鼠标长按必然输给手抖。
- **[x] ① 已修复** — 不再绕行，直接给鼠标一个容忍手抖、且长按与横滚**共用**的门槛：
  - `fushi/lib/src/utils/misc/platform_utils.dart:167` 新增 `longPressTolerantHitSlop`（鼠标取 `kTouchSlop`，其余指针沿用 `computeHitSlop`）。`HorizontalDragScrollable` 加可选 `mouseDragController`：传了就把鼠标从 `Scrollable` 的 `dragDevices` 里摘掉，改由只认鼠标的 `_LongPressTolerantHorizontalDragRecognizer`（`:175`，覆写 `hasSufficientGlobalDistanceToAccept` 用同一门槛，`DragStartBehavior.down` 让门槛内位移起滚时补上、内容跟手）经 `ScrollPosition.hold` / `drag` 驱动该控制器，与 `Scrollable` 自己的拖动处理同一套。不传时行为与原来完全一致。
  - `fushi/lib/src/media/tags/tag_chip_draggable.dart:23` `FushiTagChipDraggable` 改成所有指针都走 `LongPressDraggable`，识别器的 pointer state（`:66`，与 Flutter `_DelayedPointerState` 同构）把认输门槛换成 `longPressTolerantHitSlop`。删掉即时拖与按设备分流。
  - `fushi/lib/src/pages/implementations/tag_filter_bar.dart:262` 标签条持有 `ScrollController`，传给 `HorizontalDragScrollable(mouseDragController:)` 与 `ListView`。
  - 结果：鼠标与触屏一致——按下就拖（位移先超门槛）= 横滚标签条；按住不动（门槛内手抖）满长按时长后拖 = 重排；不动松开 = 单击筛选。没有拖动柄（BUG-5066 的诉求保留），鼠标长按不再输给手抖（BUG-4899 不复发）。
- **[x] ② 已加自动化测试** — `fushi/test/media/tags/tag_chip_draggable_test.dart`：保留根因复现（原生长按拖 + 鼠标 2 px 抖动 → 认输、被横滚）；新增「鼠标长按（计时内抖 2 px）后拖 → 重排、标签条不滚」「鼠标按下就拖 → 横滚且跟手（位移 40 → offset 40）、不起拖不点选」；鼠标单击 / 触屏短滑 / 触屏长按用例保留。`fushi/test/pages/tag_filter_bar_chip_drag_test.dart`（接入层，限宽让标签条可滚）：鼠标长按（抖 3 px）拖到另一枚 → `onReorder(0, 1)` 且标签条不滚；鼠标在 chip 上按下就拖 → 标签条横滚、不重排不筛选；单击筛选、触屏长按重排保留。`shared_tag_filter_bar_guard_test.dart` 守卫改为钉「长按起拖、不得用 `ImmediateMultiDragGestureRecognizer`、标签条传 `mouseDragController`」。变异实测：把鼠标门槛改回 `kPrecisePointerHitSlop` → 两个鼠标长按用例红；标签条不传 `mouseDragController` → 接入层鼠标长按用例红；恢复后全绿。
- **备注**：未在 Windows 真机用鼠标复测（按仓库现行约定真机验证不做），手势行为由上面的 widget 测试按真实竞技场覆盖。鼠标横滚的起滚门槛从 1 px 变为 `kTouchSlop`（18 逻辑像素），起滚时补上门槛内位移，所以内容仍跟手。
