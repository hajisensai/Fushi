## BUG-1042 · 扩展自更新reload孤立已开页content script需手动刷新
- **报告**：2026-07-24（用户：hibiki 重启时扩展好像会断掉，需要重新刷新浏览器）
- **真实性**：✅ **真 bug（沿真实代码路径定位）**。关键判据：症状「刷新浏览器页面即恢复」→ 死掉的是**注入网页的 content script**（单纯 server 重启不会让 content script 失效，只有扩展被 reload/更新才会）。链路：app 每次启动 `refreshBundledBrowserExtensionIfStale`（`hibiki/lib/src/lookup/browser_extension_installer.dart:180`）在内置扩展指纹变化时整目录重解压磁盘副本 + 写新 `build`；扩展 `tools/browser-extension/background.js`（镜像 `hibiki/assets/browser_extension/background.js`）`maybeSelfReload`（旧 `:76`）在查词/心跳/SW 冷启动比对本地 `HIBIKI_DEFAULTS.build` 与 server `extensionBuild`，不一致即 `chrome.runtime.reload()` 从磁盘拉新（BUG-726 自更新）。`chrome.runtime.reload()` 会**让所有已打开标签页里注入的 content script 上下文当场失效**（"Extension context invalidated"），这些页在用户手动刷新前扩展就是死的。因用户频繁更新 app，几乎每次「app 重启（版本变过）后第一次查词」都触发一次 reload → 当前网页 content script 失效 → 被迫刷新浏览器。
- **[x] ① 已修复** — 根因修（reload 不可省——要加载磁盘上的新扩展代码/配置；消除的是「reload 后已开页变死尸、要手动刷新」）。`background.js` 两镜像：`maybeSelfReload` 在 `chrome.runtime.reload()` **之前**置 `hibikiReinjectPending: true`；新 SW 顶层跑 `maybeReinjectAfterReload()`——读到该标记即清除并调 `reinjectOpenTabs()`：遍历所有 http/https tab，先 `chrome.scripting.executeScript` 探测 `window.__hibikiExtension`（content.js 注入后置真、隔离世界随 reload 被拆即丢）跳过仍存活的页，否则按 `getManifest().content_scripts` 的 `<all_urls>` 组重新 `insertCSS` + `executeScript` 补回 content script（逐 tab try/catch 忽略受限页）。`manifest.json` 两镜像加 `scripting` 权限、`host_permissions` 由 loopback-only 放宽到 `http://*/*`+`https://*/*`（executeScript 进任意已开 tab 需 host 访问；因 content_scripts 已声明 `<all_urls>`，警告集不扩大、不触发停用待批）。效果：自更新 reload 后已打开网页无感恢复，不再需要手动刷新浏览器。提交：<PENDING>
- **[x] ② 已加自动化测试** — `hibiki/test/build/browser_extension_connection_heartbeat_guard_test.dart`（BUG-1042 组）：两镜像 `manifest.json` 含 `scripting`/`http://*/*`/`https://*/*`；`background.js` 在 `chrome.runtime.reload()` 前置 `hibikiReinjectPending: true`（顺序断言）、定义 `reinjectOpenTabs()`、顶层调 `maybeReinjectAfterReload()`、用 `chrome.scripting.executeScript` + 探测 `window.__hibikiExtension` + 只对 `hibikiReinjectPending` 标记生效。两镜像字节一致由既有 `browser_extension_dict_media_mirror_guard_test.dart` 守卫。提交：<PENDING>
- **备注**：浏览器扩展连接生命周期类，与 [BUG-1041](BUG-1041-ext-connection-heartbeat.md)（app 内存 last-seen 无心跳）同批修。心跳（BUG-1041）每 60s 复用同一 `checkVersionOnStartup`，故 app 更新后 ≤60s 自动 reload+重注入，自更新更及时且无感。**真机复测原始失败路径待用户**（桌面 Chrome/Edge）：打开若干网页 → 升级并重启 hibiki（改内置扩展指纹）→ 在某页划词触发自更新 → 其它已打开网页应仍能直接划词查词，**无需手动刷新浏览器**（chrome://、扩展页、file:// 等受限页仍需刷新，符合平台限制）。
