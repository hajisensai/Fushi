## BUG-1489 · 本地视频/书籍页首屏慢：封面全分辨率解码+合集N+1查询+首帧同步stat
- **报告**：2026-07-21（用户：桌面端打开「视频」页，合集与封面要等半天；书籍/有声书页同理）
- **真实性**：✅ 真 bug。桌面本地媒体库首屏三条慢路径（均在 origin/develop `f045b1201` 上验真，主 checkout 落后 683 提交故不可信）：
  - **合集 N+1**：视频页 `hibiki/lib/src/pages/implementations/home_video_page.dart:275-282`（`_loadLibraryMaps` 对每个合集各跑一次 `getCollectionItems`）；书籍页 `hibiki/lib/src/pages/implementations/reader_hibiki_history_page.dart:533-540`（`_loadShelfMaps` 同款）。合集横排行渲染被这条串行 N 查询 gate，合集越多越慢——归属映射早已用单条 `GROUP BY MIN` 聚合（`packages/hibiki_core/lib/src/database/database.dart:2648` `getPrimaryCollectionIdByEntry`）拿到，组内 sortIndex 却退回逐合集查。
  - **封面全分辨率解码**：封面 JPEG/PNG 是视频原生分辨率（ffmpeg 抽帧无 `scale=`，`hibiki/lib/src/media/desktop_audio_clipper.dart:682`）或 EPUB 原始封面（常 1600×2400，导入不缩略）；显示端 `Image.file`/`FileImage` 全无 `cacheWidth/cacheHeight/ResizeImage`（视频 `home_video_page.dart:2822`；书籍 6 处：`media_source.dart:381/477`、`reader_history/card_widgets.part.dart:167`、`reader_history/remote.part.dart:298`、`sync/remote_cover_image.dart:79`、`media/audiobook/now_listening_mini_bar.dart:178`）。卡槽仅约 200px 宽却整帧解码进 Flutter ImageCache（默认 100MB/1000 张），十几张 1080p 或 3 张 4K 即撑爆 → LRU 抖动反复重解码 → 持续卡顿 + 高内存。
  - **首帧同步磁盘 stat**：视频 `hibiki/lib/src/media/video/video_book_repository.dart:255`（`_repairMovedCoverPaths` 每次 `listForShelf` 对全库同步 `existsSync`，冻结 UI isolate）；build() 内每卡同步 stat（视频 `home_video_page.dart:2824`；书籍 `card_widgets.part.dart:137`、`remote.part.dart:292`、`media_source.dart:473`、`now_listening_mini_bar.dart:177`）。
- **[x] ① 已修复** — 根因修复（commit `387eab0cb`）：
  - (a) **合集 N+1**：DB 新增 `getAllCollectionItems()` 一次查全部成员（`packages/hibiki_core/lib/src/database/database.dart`），视频页 `_loadLibraryMaps`（`home_video_page.dart`）与书架页 `_loadShelfMaps`（`reader_hibiki_history_page.dart`）改内存分组（判据 `primaryMap[key] == m.collectionId`，与旧逐合集 `== c.id` 等价）。
  - (b) **封面降采样**：新增共享 `hibiki/lib/src/utils/cover_image.dart`（`kLocalCoverDecodePixelWidth=720` / `kMiniCoverDecodePixelWidth=144` / `resizedFileImage()`=`ResizeImage(FileImage, allowUpscaling:false)`）。视频 `_buildCover` 加 `cacheWidth`；书籍封面 `media_source.dart:381/477`、`card_widgets.part.dart`、`remote.part.dart` 改 `resizedFileImage`；有声书迷你条 `now_listening_mini_bar.dart` 加 `cacheWidth`。
  - (c) **build 内 stat 保守保留**：所有 build 内 `existsSync` 短路守卫**保留**（视频 `_buildCover`、迷你条 `_cover`、书籍卡「封面源选择」语义处 `media_source.dart:473`/`card_widgets` `_existingCoverFilePath`/`remote.part` 回落 coverUrl）——它们避免对已知不存在的封面发起无谓异步解码，单卡一次 stat 成本极小、不影响首屏主开销。曾尝试把 `_repairMovedCoverPaths` 全库 stat 改异步 `exists()`，但会让 shelf 刷新路径的 widget 测试（`home_video_page_menu_test.dart`）`pumpAndSettle` 超时（真实异步文件 IO），且收益边际，故**回退**保持 baseline 同步版。首屏真正开销由 (a) 合集 N+1 与 (b) 封面降采样解决。
- **[x] ② 已加自动化测试** — 提交 `387eab0cb`：
  - DB 等价性单测 `hibiki/test/database/media_collections_dao_test.dart`（新增 2 例）：`getAllCollectionItems` 按 collectionId 分组逐组等于 `getCollectionItems`；内存分组 `memberSortIndex` 与旧逐合集逻辑逐键等价。
  - 源码守卫 `hibiki/test/tools/local_media_cover_perf_guard_test.dart`（7 例）：DB 有 `getAllCollectionItems`、视频/书架分组不再逐合集查、`_buildCover`/迷你条封面 `cacheWidth` 降采样、书籍封面走 `resizedFileImage`。
  - 全量 `flutter test` 12250 通过（含上面被异步改动回归、现已修复的 3 例删除回收测试）。
