## BUG-2648 · 兼容层 Emby 内嵌文本字幕走 libmpv 自绘：不可查词、字幕列表为空
- **报告**：2026-09-25（用户：「emby 字幕加载不全而且没法点击查词」）
- **真实性**：✅ 真 bug。用户服务器仍是 `https://v1.uhdnow.com`（UHD Media Server 兼容层，无字幕抽取端点）；持久化选择 `embedded:4`（英文内嵌 subrip，`SupportsExternalStream=false`）。BUG-2590 的回落 `_showRemoteEmbeddedTrackViaPlayer`（`fushi/lib/src/pages/implementations/video_fushi/subtitle.part.dart`）调 `selectEmbeddedGraphicTrack`——把文本轨当图形轨交给 libmpv **自绘**：字画进画面、`setCues([])` 清空 cue，所以 Flutter overlay 无字可点、字幕列表为空（「加载不全」）。同条目的外挂 srt 端点实测 200、完整，问题只在内嵌轨。
- **[x] ① 已修复** — libmpv 改为**只解码不画**：新 `VideoPlayerController.selectEmbeddedTextTrackViaPlayer` 选轨后保持 `sub-visibility=no`，订阅 media_kit `stream.subtitle`（mpv `sub-text`），每句连同 `sub-start` / `sub-end` 拼成 cue 合进可点 overlay（纯函数 `fushi/lib/src/media/video/player_decoded_subtitle_cues.dart`），边播边累积；`setCues` / `load` / `dispose` 结束回流。零额外流量（仍不做 BUG-2590 否决的 ffmpeg 二次读流）。代价如实写进 OSD：没播到的句子不会预先出现在列表里。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/player_decoded_subtitle_cues_test.dart`（解析 / 构造 / 合并 / 暂定收尾 + 防 UAF 与「只解码不画」源码守卫）；`fushi/test/pages/video_remote_embedded_subtitle_player_fallback_guard_test.dart` 改钉新通路、禁止文本轨再走图形自绘；真服务器 itest `fushi/integration_test/media_server_emby_embedded_subtitle_itest.dart` 断言回流模式且 cue>0。
- **备注**：python-mpv 加载随包 libmpv 对 uhdnow 真流实测：`sub-visibility=no` 下 `sub-text` 照常逐句上报，`sub-start/sub-end` 精确（seek 到 1200s 立刻拿到 1198.198–1200.075 那句）。
