## BUG-3309 · iOS 上 MD3 设计系统的 .adaptive 控件仍渲染 Cupertino 外观（来源顺序对话框绿开关）
- **报告**：2026-10-13（用户：iOS 截图，设置 › 查词 › 词条内容 ›「来源顺序」对话框「没有遵循 M3E」）
- **真实性**：✅ 真 bug。`auto` 下五平台统一 MD3（M3E），但 Fushi 包装层的 `.adaptive` 构造器直通 SDK 的 `X.adaptive`，后者按 `ThemeData.platform`（主题不覆盖 platform，iOS 上即 iOS）选外观：
  - `fushi/lib/src/utils/components/glass/fushi_glass_toggles.dart:519`（`FushiSwitch`）`if (_adaptive) return Switch.adaptive(...)` → iOS 上走 `_SwitchThemeAdaptation`，画 `CupertinoColors.systemGreen` 轨道、不跟主题色（截图里的绿开关）；同文件 Slider / Checkbox / Radio / CheckboxListTile / RadioListTile / SwitchListTile 同形；
  - `fushi_glass_overlays.dart:609`（`FushiAlertDialog.adaptive` → iOS 上 `CupertinoAlertDialog`）；
  - `fushi_glass_feedback.dart:557`（`FushiCircularProgressIndicator.adaptive` 自己读 platform，iOS / macOS 出菊花）。
  另外「来源顺序」对话框本身（`fushi/lib/src/pages/implementations/local_audio_sources_dialog.dart`）每行常驻两枚裸 ^ / v 箭头（首行上移只是变灰）、定高滚动区底部硬切无渐隐。
- **[x] ① 已修复** — 判据收到一处：`adaptive_platform.dart` 新增 `useCupertinoAdaptiveControls(context)`（= 设计系统是隐藏的 `FushiDesignSystem.cupertino`），三个包装文件的 9 处 `.adaptive` 分派都经它，MD3 下一律渲染 Material 控件；隐藏的 `FushiDesignSystem.cupertino` 与玻璃（Apple）分支行为不变。注意：这里的「Cupertino」不是用户可见的「Cupertino」——后者是玻璃设计，走 `isGlassDesign` 分支，不受此判据影响。另一处行为变化：显式选隐藏的 `FushiDesignSystem.macos` 时，`.adaptive` 控件也从 Cupertino（macOS 上的绿开关 / 菊花 / Cupertino 对话框）变成 Material（`isCupertinoPlatform` 对 macos 恒为 false）。对话框：行尾换成 M3E 拖拽把手（`FushiDragHandle`，Apple 下三横线），把手是可聚焦菜单按钮，「上移 / 下移」作为键盘 / 手柄 / 读屏重排路径；滚动区加上下端渐隐（`FushiHorizontalEdgeFade` 增加 `axis`）。提交 be2a7be797（cc/fb-ios-m3e-leaks）。
- **[x] ② 已加自动化测试** — `fushi/test/widgets/glass/md3_adaptive_controls_no_cupertino_test.dart`（iOS 平台 MD3 主题下开关不画 iOS 绿 / 进度是 M3E 波浪环 / 对话框是 Material，正对照裸 `Switch.adaptive` 画绿；隐藏的 `FushiDesignSystem.cupertino` 保持平台分派；隐藏的 `FushiDesignSystem.macos` 渲染 Material；源码守卫：SDK `.adaptive(` 只许在包装层且每处经判据，计数前用 `helpers/source_guard.dart` 的 `maskComments` 整文件遮注释，并带块注释 / 行尾注释判据的自检用例）；`fushi/test/pages/local_audio_sources_dialog_test.dart`（把手菜单重排、无裸箭头、有渐隐、把手命中区 ≥48dp 且视觉尺寸不变）。
- **备注**：同批核查 #LZDKhmJFpM「ios 查词框没有上 m3e 着色」：对照截图取色，频率标签 `#6d391e`/字 `#ffdbcc`、音调来源 `#900038` 与同屏 app 迷你播放器 `#900038` 一致，即 M3 深色 tertiaryContainer / primaryContainer（`popup.css` `html.fushi-m3e` 段，变量由 `popup_theme_css.dart` 从 ColorScheme 注入），iOS 弹窗已走 M3E 主题色，不是固定色；该条用户自带截图里弹窗内容为空是另一条（反馈截图抓不到 WebView，#_uvuiSpjZ7）。
