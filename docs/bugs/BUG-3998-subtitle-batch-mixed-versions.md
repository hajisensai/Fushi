## BUG-3998 · 合集批量下载字幕逐集混排不同版本
- **报告**：2026-11-02（用户：同一合集整季批量下载字幕，第 1 集是 Nekomoe 的 `.ass`，第 2 集起是 Netflix `ja[cc].srt`）
- **真实性**：✅ 真 bug。Jimaku 条目 12217（Grow Up Show）实测：Nekomoe 只有第 1 集（`[JPN]` 认作 ja），Netflix ja[cc] 有 1–13 集，shincaps / NanakoRaws 的 ass/srt 文件名不带语言标记（认作未知语言）。根因在 `fushi/lib/src/media/video/subtitle/subtitle_episode_matching.dart` `chooseSubtitleForEpisode`：每集**独立**按「语言权重 → 文件名字母序」取首个，整批没有版本一致性约束；第 1 集 `[Nekomoe…` 字母序先于 `グロウ…` 赢了，其余集只剩 Netflix 是 ja → 同季混排。番剧下载落位 `matchJimakuFilesToVideoNames`（`fushi/lib/src/media/torrent/anime_download_matching.dart`）同形。
- **[x] ① 已修复** — ⑴ 新增 `SubtitleEpisodeIndex.preferConsistentVersion`：按整批目标集给版本排名（语言 → 覆盖目标集数 → ASS/SSA 先于 SRT → 稳定序），每集按版本排名重排，判据不变；首选版本缺的集由次选版本补。⑵ 文件名不带语言的版本不再按「未知」垫底：`probeUnlabeledVersionLanguages`（`subtitle_version_language_probe.dart`）每个这样的版本下一个代表文件，用既有正文检测 `detectSubtitleContentLanguage` 判语言再参与排名；下过的字节缓存复用，选中时不重下。⑶ 正文检测把半角片假名（U+FF66–FF9D）算作假名，纯半角片假名的广播 CC 不再被汉字计数判成中文。合集批量 `runSubtitleBatch` 与番剧下载 `JimakuPlanSubtitleResolver` → `matchJimakuFilesToVideoNames` 两条路径都接上。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/subtitle_batch_test.dart`「整批版本一致（Jimaku 12217 实测形状）」6 条（含正文日语的未标语言 ASS 拿下整季且不重下、正文中文不压过 ja）；`fushi/test/torrent/anime_download_matching_test.dart` 2 条；`fushi/test/media/video/subtitle_content_language_test.dart` 半角片假名 1 条。
- **备注**：实测本机已下的 shincaps / NanakoRaws Grow Up Show 第 2 集 .ass 正文全角假名 2891 个，正文探测判日语 → 本例整季落在 ASS。`[CHS, JPN]` 逗号列表括号的文件名语言识别未改（正文探测已覆盖批量选择）。
- **跟进（同 PR）**：合集面板顶部「来源」chip + 「偏好版本」下拉合并为聚合版本列表（来源 → 版本行：组名/发行平台 · 容器 · 语言（未标语言的标「正文：…」）· 覆盖本合集几集），每行可直接点选，首行「自动：整季统一版本」写明会用哪个版本，列表顺序与批量判据同源（`rankSubtitleCollectionVersions` → `SubtitleEpisodeIndex.rankVersions`）；成员行显示该集实际会用的版本。无组名的官方抽轨按发行平台 token 区分版本（`subtitleVersionTag`：Netflix / Amazon …）。批量探测不再动有下载配额的源（`allowsFreeProbeDownload`）。
- **审查跟进（同 PR）**：⑴ 版本键名字段改成 `subtitleVersionTag` 后，合集列 `subtitleReleaseGroup` 里旧下拉存的键（无组名平台抽轨末段为空串）对不上新键会静默退回「自动」——`resolvePinnedSubtitleVersion` 先按新键命中，命不中再按 `legacySubtitleVersionKeyOf` 找并把列一次性改写成新键。⑵ 代表文件只从集号落在目标集里的文件挑，一集都不覆盖的未标语言版本不下载；合集面板改用同一共享函数，不再另写一份挑法。⑶ 面板持有唯一的候选下载缓存，作为 `download` 传给 `runSubtitleBatch`；探过但判不出的版本也记下（值 null），批量不再重探。⑷ 面板派生状态（集号 / 版本排名 / 点名版本 / 各集计划）在输入变化处由 `_rederive` 显式重算，build 只读字段。测试：`subtitle_batch_test.dart`（不覆盖目标集的版本不探、共用下载缓存不重下、判不出的版本不重探）、`subtitle_collection_panel_test.dart`（旧键迁到 Netflix 版本）。
