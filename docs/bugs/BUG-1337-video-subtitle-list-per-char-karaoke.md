## BUG-1337 · 字幕列表把 OP 逐字卡拉OK 列成整屏单字

- **报告**：2026-08-01（用户：「这个渐出现，渐消失的，都是单字。看看能不能修。不能就算了」）
- **真实性**：⚠️ **不是渲染 bug，是列表可读性缺陷**——片源本身就是每字一条事件，列表按事件
  1:1 列行属实现如实反映；但由此导致「读不出句子 + 逐字行只能查/制一个字」，作为改善处理。

### 片源真值

`[Nekomoe kissaten&VCB-Studio] Tensei Oujo to Tensai Reijou no Mahou Kakumei`，
`PlayResX 1280 / PlayResY 720`，**每集 175 条**这样的事件：

```
Dialogue: 0,0:00:41.35,0:00:44.48,OP_JP,,0,0,0,,{\an7\pos(461,672)\fad(250,250)\blur2}手
Dialogue: 0,0:00:41.40,0:00:44.52,OP_JP,,0,0,0,,{\an7\pos(491,672)\fad(250,250)\blur2}を
Dialogue: 0,0:00:41.44,0:00:44.57,OP_JP,,0,0,0,,{\an7\pos(521,672)\fad(250,250)\blur2}伸
```

一句歌词被拆成每字一条独立 `Dialogue`，各带自己的 `\pos`，靠坐标在画面上拼成一行
（libass 如此渲染才看着像一句）。用户截图里同一个 `1:03` 时间戳连出 9 行单字即此。

### 修复

- **[x] ① 已修复** — commit `（见下方补记）`
  - 新增纯函数 `mergePerCharacterCueGroups()`（`video_subtitle_jump_panel.dart`）：把逐字
    事件合并回整句，返回 `byRep`（代表行 → 合成 cue）与 `repByRaw`（成员 → 代表行）。
  - **合并只作用于字幕列表**：渲染层必须保留逐字事件（每字有各自的 `\pos` 与淡入淡出
    时刻），两者消费同一份 cue 的不同视图。
  - 判据刻意收窄，**宁可漏合也不错合**（错合会把正常双语/多行字幕并成一行）：每条都带
    `\pos`、文本是单个 grapheme、同一行（`\pos` 的 y 分数相等）、同 ASS Layer、与本组已
    累积区间时间重叠、组内至少 2 条。组内按 `\pos` 的 x 升序拼接（复现画面横向顺序，
    而非文件顺序）。
  - 复用**既有代表行机制**：`repByRaw` 与 BUG-841 的 `(startMs, 文本)` 折叠共用同一张表，
    故「当前播放句落在任一单字事件上 → 高亮/自动滚动定位回那唯一的整句行」零改动即成立。
  - 合成 cue 是**真 `AudioCue` 对象**而非显示层字符串，因此列表的查词、收藏、制卡、搜索
    全部自动作用于整句——收藏判据是 `(text, startMs)` 值语义、不依赖对象身份
    （`lookup_favorite.part.dart:182`）。
  - 列表内一切「这一行是什么」的读取收敛到单一入口 `_rowCue()`（行文本、行高测量、点击
    跳转、逐字查词、收藏 toggle、制卡选择、计数与筛选共 8 处）。**这是关键**：漏改任何一处
    就会出现「列表显示整句、制卡只拿到一个字」的割裂。

- **[x] ② 已加自动化测试** — `hibiki/test/media/video/video_subtitle_list_per_char_merge_test.dart`
  - 16 条：6 正向（含片源真值 6 字合并、时间跨度、成员映射、按 x 排序、上下两行不混、
    连唱两句断组）+ 7 负向（无 `\pos` / 多字事件 / 孤立单字 / 不同 Layer / 纯 SRT / 空列表）
    + 2 下游契约 + 2 源码守卫。
  - **变异实测抓到一个自造的假绿用例**：「多字事件不被合并」首版把两条数据放在**不同 y**
    上，靠「同行」判据就挡掉了，根本没考验到「单字」判据——去掉单字判据后它照样绿。
    改成同 y、时间重叠（让单字判据成为唯一防线）后，该变异立刻变红。另一次变异（去掉
    时间断组判据）被「连唱两句不粘」用例抓到。均反向替换还原，未用 `git checkout --`。
  - 回归：`test/media/video` **2022 条**全绿；全量 `flutter analyze` 干净。
  - `test/pages` 全量在本机并发下 flaky（两次失败点漂移：`popup_tap_outside_layer_test` →
    `audio_sources_dialog_page_test` 的 loading 错误；两文件与字幕列表零关联，单独跑 21/21
    全绿；干净 develop 亦曾全绿）。本机同时有 8 个 dart 进程互抢，属已知环境竞争，交 CI 兜底。
