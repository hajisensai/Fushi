## BUG-3818 · 媒体服务器：继续观看卡要能去详情，非续播集播放前要能选版本
- **报告**：2026-10-26（应用内反馈 a-XEzglLaq「Emby 点继续播放不要直接播放，想去详情看同一部其它集」、mxYhpVcwOX「点集数直接播了，没法在非当前集播放前选版本」；Windows 3.0.1-debug.21417。设计由所有者 2026-10-27 按分诊第五节第 3 项推荐方案批准）
- **真实性**：✅ 真问题。① 继续观看卡长按 / 右键其实早就直接跳详情（`fushi/lib/src/pages/implementations/media_server/media_server_home_view.dart` `_continueRow` 的 `onLongPress: openMediaServerItemDetail`），但没有任何可见入口，用户不知道；点按走 `resumeMediaServerItem` 直接续播（`media_server_routes.dart`）。② 版本只给续播那一集取（`media_server_detail_view.dart` `_loadEpisodeVersions` 用 `_continueIndex`），集卡 `onTap` / `ActivateIntent` 直接 `_playEpisode`，其它集在播放前没有任何选版本的机会；清单又不带 MediaSources（BUG-1891），集卡上看不出哪集有多版本。
- **[x] ① 已修复** — 继续观看卡点按仍续播，长按 / 右键改出设计系统菜单（`showMediaServerContinueMenu`，`showFushiMenu`：「继续播放 / 打开详情」）。契约加可选能力 `MediaServerItemVersions.listItemVersions`（Jellyfin / Emby 实现为单条目详情的 `MediaSources[]`；Plex v1 不实现 → 点集直接播）、`MediaServerItem.versionCount`（`/Shows/{id}/Episodes` 点名 `Fields=MediaSourceCount`，只是计数，不是 MediaSources 重字段）、`matchRememberedMediaServerVersion`（本集记忆 > 同剧同名 > 同剧同规格，对不上返回 null）。详情页点集 / Enter / 「播放」先过 `decideMediaServerVersionBeforePlay`（`media_server_version_picker.dart`）：多版本且记忆对不上 → 弹 `showFushiChoiceDialog` 版本选择（M3E / Apple 两套，对话框路由动效），选中即记住（本集 + 同剧）、取消不播；对得上直接播（取流时客户端按记忆带 MediaSourceId）。集卡长按 / 右键强制重选。查过 / 清单报过的多版本集在集卡副行标「N 个版本」。
- **[x] ② 已加自动化测试** — `fushi/test/pages/media_server/media_server_episode_versions_test.dart`（6 条：非续播集先问版本、选后同剧其它集按同名直接播、记忆对不上再问、取消不播、单版本直接播 + 清单计数标卡、长按强制重选、不支持能力的服务器直接播）；`fushi/test/pages/media_server/media_server_home_view_test.dart`「a-XEzglLaq：继续观看卡点按续播，长按 / 右键出菜单」；`fushi/test/media/video/media_server/jellyfin_media_server_test.dart` listEpisodes 用例改钉 `Fields=ProductionYear,MediaSourceCount` 并断言 `versionCount` 解析。
- **备注**：没有多版本 Emby 服务器，未真机复测；Emby 是否在 `/Shows/{id}/Episodes` 上回 `MediaSourceCount` 未实测（不回只是集卡不预先标数，点集时仍按单条目详情判定，功能不受影响）。Plex 的多 `Media` 版本仍未接（v1 只 direct play 服务器默认那条），按契约退化为直接播。
