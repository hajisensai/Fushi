- **报告**：2026-07-07（用户：）· TODO-1289
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/reader/reader_pagination_scripts.dart:1432`（`_sharedInitImages` 的 `_hoshiBlurImage` 无条件给所有 `block-img` 加 `blurred` class）。揭开只在 WebView 内删 DOM class（`webview.part.dart:_hoshiRevealBlurredImage` / `reader_caret_scripts.dart` caret 揭开），未在任何跨文档存活处持久；任何章节 (重)载都重跑 `initialize()`→`_sharedInitImages` 把 `blurred` 加回。触发重载的常见路径：布局设置切换（writing mode / 分栏 / view mode / spread / prioritize / blur 开关，均经 `chrome.part.dart:_reloadWithCurrentSettings`→`_loadChapterDirectly`）、章节导航、重开书。`domStorageEnabled:false`（`webview.part.dart:1189`）故 JS 侧 localStorage 不可用。
