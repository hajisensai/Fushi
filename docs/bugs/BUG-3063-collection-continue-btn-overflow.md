## BUG-3063 · 合集详情 hero「继续」按钮图标溢出左边缘、内边距不对称
- **报告**：2026-10-07（用户：iPhone 截图，书的合集「無職転生」共 5 项，hero 卡片里「继续 · [23卷] 無職転生 ~異世界行ったら…」按钮左侧播放图标压在按钮左缘外、文字顶到右缘才省略，左右内边距不对称；同卡片「编辑标签」tonal 按钮正常）
- **真实性**：✅ 真 bug。根因 `fushi/lib/src/media/collections/collection_detail_hero.dart:282`（修前 `_ContinueButton` 的 MD3 分支）用 `FushiFab` 扩展 FAB 当整宽主按钮：Flutter `FloatingActionButton.extended` 把「左 16 + 图标 28 + 间距 12 + 文字 + 右 16」包进 `_ChildOverflowBox`（`floating_action_button.dart:564/681`），子 Row 以**无界宽度**排版后在按钮里居中，按钮本身被父约束夹到卡片内容宽；文字又被写死 `maxWidth: 320`，于是 Row 自然宽 ≈ 392dp > 手机卡片内容宽（390 屏 ≈ 334dp），超出部分从两侧等量溢出——左侧播放图标被挤到按钮左缘外，右侧文字贴边截断。书 / 漫画 / 游戏三域合集详情（`media_collection_grid_detail_page.dart:738` 唯一调用点）共用这一个 hero，三域同病；视频合集不走这个 hero。修前 widget 测试在 390 / 360dp 深浅主题下实测图标 left = 0、按钮 left = 32。
- **[x] ① 已修复** — `_ContinueButton` 改用共享 M3E 尺寸档按钮 `FushiFilledButton.icon(size: FushiButtonSize.m)`（56 高、左右 24 留白、按压形变，token 来自 `FushiButtonMetrics`），文字由 `FilledButton.icon` 的 Flexible 收缩 + 省略号；Apple 设计系统同一调用走玻璃填充胶囊，不再分两套实现。提交见 git log（`fix(collections): keep hero continue button content inside (BUG-3063)`）。
- **[x] ② 已加自动化测试** — `fushi/test/widgets/collection_detail_hero_continue_button_test.dart`：390 / 360dp × 深 / 浅主题，长条目名下按钮在卡片内、图标与文字完整落在按钮内、左右内边距相等（≥16）、文字 `didExceedMaxLines` 为真；短标题按钮贴合内容且居中。修前 4 条长标题用例全红（图标 left 0 < 按钮 left 32），修后全绿。
- **备注**：真实像素修前 / 修后对比图在 `.codex-test/collection-continue-btn/`（不入库）。
