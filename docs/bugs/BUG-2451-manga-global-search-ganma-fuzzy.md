## BUG-2451 · 全局搜索里 GANMA! 返回与关键词无关的作品（未复现为本仓 bug：源站服务端分词模糊匹配）
- **报告**：2026-09-11（用户：截图「搜索全部来源」搜 `週に一度クラスメイトを買う話`，其它日文源报「没有找到漫画」，GANMA! 却回一排无关热门作品；原话「扩展搜索和未搜索结果不一样」）
- **真实性**：❌ 非本仓 bug。沿链路核到底：搜索框 `manga_global_search_page.dart:104-127` trim 后经 `manga_global_search_runner.dart:120-136` → `mihon_bridge_runtime.dart:103-127`（method `getSearchManga`，`filterList: []`）→ `desktop_mihon_runtime.dart:708-746`（POST `/dalvik`，`charset=utf-8`）→ sidecar `MihonInvoker.kt:67` → `:218-231` `source.getSearchManga(page, search, filters)`。Dart 层、Kotlin overlay、sidecar upstream 都没有 search→popular/latest 的降级分支（`MihonInvoker.kt:57-88` 纯字典分发，异常只走 `errorResponse`）；空 `filterList` 经 `convertFilterList`（`MihonInvoker.kt:786-871`）后等价于源默认筛选，与单源浏览页下发参数一致。扩展侧（keiyoushi `src/ja/ganma/Ganma.kt`）关键词非空时走 GraphQL 持久化查询 `magazinesByKeywordSearch`，确实带了关键词。**直接向 `https://ganma.jp/api/graphql` POST 同一条持久化查询**（hash `55c7ca6c…`，variables `{keyword: 週に一度クラスメイトを買う話, after: null}`）：返回 20 条、`hasNextPage: true`，标题与截图逐条一致（含「さやは2度死ぬ」「一匹狼な女の子が気になる話」——按「度」「話」等分词 OR 命中）；换随机乱码关键词返回 0 条。所以是 ganma.jp 服务端全文模糊匹配的行为，Hibiki 如实渲染。
- **[ ] ① 未修复** — 不修：本仓没有错误路径。可选改进（不属本 bug）：单源浏览页的分段按钮只有 popular/latest 两档（`mihon_source_browse_page.dart:265-279`），search 态被回显成 popular，用户分不清当前网格是搜索结果还是浏览列表；「没有找到漫画」与「响应解析成空」在 UI 上不可区分（`mihon_models.dart:196` 缺字段兜成空列表）。
- **[ ] ② 未加自动化测试** — 不适用。
- **备注**：GANMA! 上本就没有这部作品（它是 ComicWalker/角川系连载），源站返回的是模糊候选；全局搜索若要「只显示精确命中」，只能在客户端按标题归一化再过滤，那是产品决策不是修复。
