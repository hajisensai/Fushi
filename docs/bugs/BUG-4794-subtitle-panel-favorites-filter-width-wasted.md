- **报告**：2026-11-17（PR #3646 / BUG-4781 合入后的独立复审）
- **真实性**：✅ 真问题（BUG-4781 的修法引入）。`fushi/lib/src/media/video/video_subtitle_jump_panel.dart:2013`（筛选可滚区 `Flexible`）与 `:2081`（收藏计数 `Flexible`）同为 flex 1 的松弛 Flexible：Row 把开关 / 导出钮之外的剩余宽度 R 对半分配上限，计数实际只用 min(自身宽度, R/2)，用不满的部分不回补给筛选区，筛选区被截到 R/2。这正是 m3e 版式 BUG-4249（`:2765` 注释）修掉的「对半分」写法。widget 探针实测（收藏档，经典版式，分段内容宽 en 276px / zh 94px；修前数值的视口里还含开关 ~44px）：
