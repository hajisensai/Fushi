## BUG-1480 · 穿透态点不了文字查词：整窗 WS_EX_TRANSPARENT 让字和背景一视同仁
- **报告**：2026-08-09（用户：冷盈閑酔；用户本人拍板「穿透态支持点击文字查词」）
- **真实性**：✅ 真 bug（能力缺口，不是回归）。[[BUG-951]] 的双窗方案完整在位、无回退。
  - 穿透 = 整窗 `WS_EX_TRANSPARENT`（`floating_lyric_window.cpp` 的
    `SetBodyExTransparent`，唯一写点）。这是**窗口级**开关：OS 连 `WM_LBUTTONDOWN`
    都不投给我们，字和背景一视同仁。链路断在第一环，代码注释自己写着
    「while it is set this handler is not called at all, which is exactly the point」。
  - 之外还有三道显式软闸主动堵死查词：悬停查词早退、滚轮早退、正文内工具条不绘制。
  - 从用户视角这是**退化**：BUG-951 的文档自述旧行为「只在背景不透明度=0 时看起来能用，
    那是层窗口逐像素命中测试的功劳」。
- **[x] ① 已修复** — 把两个互斥需求变成**同一条规则**，而不是再加一套机制：
  - 这个窗口是 `UpdateLayeredWindow` 的**逐像素 alpha** 窗。仓库里已经记着这条事实
    （`kHookTextMinCatchAlpha` 那段注释）：**alpha-0 像素本来就会把点击透给下面的窗口，
    跨进程有效，且与 `WM_NCHITTEST` 无关**。所以只要背景是真 alpha 0，OS 自己就给出了
    我们要的两分：**背景像素 → 游戏，字形像素 → 我们**。
  - 于是穿透态改成：① `Render` 里**无条件**把 body 填充 alpha 清零
    （`body_bg &= 0x00FFFFFF`）；② `ApplyPassThroughExStyle` **不再**设
    `WS_EX_TRANSPARENT`。
  - ⚠️ 强制清零是关键：老「逐像素」实现唯一的真缺陷就是「只在你碰巧把背景不透明度
    设成 0 时才成立」——用户设了可见底色，整块 rect 变不透明，OS 把每一次点击都给我们、
    游戏什么都收不到。由代码强制，而不是写进文档让用户自己避开。
  - 悬停查词在穿透态**放行但收窄到必须按住 Shift**：穿透的用途是把鼠标让给游戏，
    纯移动就弹卡片会不停打断游玩；Shift 是显式意图。点击查词不受此限
    （点在字上本来就到不了游戏）。
  - **与两次历史事故的区别必须说清**，别被当成"又回到老路"：BUG-951 修掉的是
    `HTTRANSPARENT` —— 那个只在**同线程**窗口间走，永远到不了另一个进程的游戏，
    所以点击是被**吞掉**的；PR#460（已 revert）错在**定时器翻转可交互性**的竞态。
    逐像素 alpha 既不是前者也不是后者：它是 OS 在合成阶段就判定「这个窗口在这个像素上
    不存在」，且本修复**不含任何定时器**、不写 `GWL_EXSTYLE`。
- **[x] ② 已加自动化测试** — 既有守卫按新契约重写（契约变更的证据点）：
  - `gal_overlay_passthrough_dual_window_guard_test.dart`：原「Show() 必须排在
    `SetBodyExTransparent(true)` 之前」的顺序断言失去被守对象（正文不再整体停止接收
    点击），重述为「建不出逃生工具条就必须取消穿透」+ 新增「穿透态必须强制背景 alpha 0」。
    逃生工具条**仍是必需的**，理由换了：穿透态正文内工具条不绘制，关掉穿透的唯一入口
    就只剩那个独立小窗。
  - `gal_overlay_shift_hover_pin_guard_test.dart`：原「穿透态不查词」改为
    「穿透态悬停查词必须按住 Shift」。
  - `test/tools/` + `test/lookup/` 879 tests PASSED；`flutter build windows --debug` exit 0。
- **备注**：⚠️ **真机未复验**（本轮真机验证已取消）。这条改的是输入路由，
  且这块区域历史上 revert 过一次（PR#460），真机需要复验的点：
  ① 穿透态点背景，游戏确实收到点击（推进台词）；
  ② 穿透态点字，出查词卡且**游戏没有**同时推进；
  ③ 用户把浮窗背景不透明度调到可见后，①②仍成立（这条是本次强制清零要保住的不变式）；
  ④ 关掉穿透后正文恢复拖拽与整块可点。
