## BUG-4820 · 视频「搬家」判定只凭同名 + 旧文件不在，删旧剧再放进同名新文件会把旧行错绑到新文件
- **报告**：2026-11-17（nmv 优化清单 gap-scanner-1，代码路径复核时发现，非用户实报）
- **真实性**：✅ 真 bug（代码路径逐行走通，未在真机复现）。BUG-2979 引入的 `isVideoRowMovedTo`（修前 `fushi/lib/src/media/source_library/source_library_scanner.dart:2967-2982`）全部判据是反证：不是清单 / 流、不是 URL、路径不同、basename 相同、旧盘在线、旧文件不存在——没有任何一条说明「新文件就是旧文件」。而视频 uid 只由文件名派生（`packages/fushi_engine/lib/media/video/video_library_import.dart:39-42`，刻意的跨设备身份），app 内扫描又有意不回收已删文件的行（BUG-4055 选 B），所以「同名旧行的文件不在了」是常态：
  - `A/01.mkv` 入库 → 库外删掉 → 放进 `B/01.mkv` → 扫描：`rowByUid['video/01']`（修前 `:2479-2481`）取到 A 行，判成搬家，A 行被改指到 B 的文件（修前 `:2484-2499`），进度 / 看完 / cue / 合集全带过去；
  - A、B 的 `01.mkv` 都在库（B 是 `video/01 (2)`）→ 库外删 A → 重扫：A 的进度 / 看完 / 标签 / 合集被并进 B 行，A 行被删（修前 `:2501-2510`、`:2617-2660`）。
- **[x] ① 根因修复** — `1f9ad3f6a23`：搬家要**正证据**（`videoRowMoveEvidence`，取代 `isVideoRowMovedTo`）。规格缓存 `video_file_specs` 里探过旧路径时只比字节数（相等 = 搬家，不等 = 另一个文件）；没探过时比目录尾段：从最近一层起连着对上至少两层（或两边的目录整条都对上），且对上的名字不全是通用目录名（`isGenericVideoDirectoryName`：`Season 01` / `S1` / `Disc 1` / `Specials` / `BDMV` 一类）才算（`VideoMoveEvidence.directoryChain`）。改指与合并删行用同一道门槛——改指错了同样是把 A 剧的进度绑到 B 剧的文件上。证据不够时新文件照常新建一行、旧行原样不动。（首版 `1f9ad3f6a23` 的改指只要求父目录名一致，`剧A/Season 01/01.mkv` 删掉后放进 `剧B/Season 01/01.mkv` 仍会错绑，审查后在同一 PR 收紧。）
- **[x] ② 自动化测试** — `fushi/test/media/source_library/source_scan_integrity_test.dart`「视频搬家判定要正证据」组（真实临时目录 + 内存库跑整条 `SourceLibraryScanner.scan`）：整棵目录挪位置后只剩一行且进度保留（BUG-2979 ② 欠的那条）；不同目录同名文件新建一行、旧行不动；规格大小不等不认、相等即认；同名集都在库时删一部不合并；删掉 A 剧再放进 B 剧、父目录都叫 `Season 01` 时 A 行不被改指；两层都对上但全是通用名（`Season 01/Extras`）同样不认；两层尾段一致的 `X (2)` 残留并回一行；通用目录名判据的纯函数用例。
- **备注**：比计划原文（「没有规格行时比父目录名」）更严，代价是漏判：没探过规格、且只有一层目录对得上（`D:/下载/Show/01.mkv` → `E:/动漫/Show/01.mkv`）或目录名改了的真搬家不再被认出，回到另建 `X (2)`（旧行与进度都还在，不丢数据）。通用目录名是一张名单，名单外的通用名连着两层都撞上时仍可能误判。根治要给视频记内容指纹（清单 gap-scanner-6）——已做（拍板台 design-nmv-video-move-fingerprint）：schema v165 设备本地表 `video_content_fingerprints`（book_uid → 大小 / 修改时刻 / OpenSubtitles 哈希或小文件 SHA-256），扫描入库 / 改指时当场记、扫描末尾与视频书架后台补算存量行；旧行有指纹时 `videoRowMoveEvidence` 只看内容（`VideoMoveEvidence.sameContent`，内容不同即不是搬家，目录名不论），没有指纹的行才退回规格大小 / 目录链。待真机：桌面用真实视频库验一次「整部剧挪目录后重扫」不出重复卡。
