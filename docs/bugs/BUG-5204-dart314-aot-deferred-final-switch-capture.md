## BUG-5204 · Dart 3.14.0 AOT 编译推迟 final + switch 赋值 + 闭包捕获时崩溃（全平台 release 红）
- **报告**：2026-11-15（用户：Flutter 3.50 升级 PR #3400 接手，Windows release 构建在 gen_snapshot 挂）
- **真实性**：✅ 真 bug（上游 dart-lang/sdk#64917，Dart 3.14.0 回归）。`fushi/lib/src/pages/implementations/home_page.dart:3193`（`_openRemoteAiVideoAcquisition`）的 `final HostAssistantTarget target;` 在 sealed `switch (outcome)` 的一个 case 里赋值、另一个 case `return`，之后被 `MaterialPageRoute(builder: (_) => ... target.label)` 闭包捕获；`gen_snapshot --trace_compiler` 最后编的就是这个函数，随即 `linearscan.cc: 3013: error: unreachable code`。CFE 把穷尽 pattern switch 降成不带 else 的 `if` 链（dart-lang/sdk#64923），唯一一次初始化写入不支配后面的读，`LoadFieldInstr::Canonicalize` 仍把写入值转发给 Context 读，生成非法 IL。debug / analyze / test 全绿，只有 release AOT 崩。
- **[x] ① 已修复** — 把每个 case 的后续工作挪进 case（抽成 `_openRemoteAiVideoAcquisitionOn` / `_openRemoteAiAgentOn` / `_hitCard`），或改成 switch 表达式在声明处取值：`home_page.dart`、`ai_agent_page.dart`（同形状、暂无闭包，一起改）、`media/manga/manga_global_search_page.dart`（单 case 穷尽 switch + 卡片闭包，同样中招形状）、`media_collection_grid_detail_page.dart`（两处赋值、setState 闭包捕获，按同规则改）。全仓用 analyzer AST 扫过 `fushi/lib`、`packages`、`third_party`、`integration_test`（推迟 final + switch / if-case 赋值 + 闭包引用），改后 0 命中。上游修复 dart-lang/sdk@7848cfe821d（2026-11-13 进 main），截至 2026-11-15 无含它的 Dart 3.14.x / Flutter 3.50.x 补丁版；升到含修复的补丁版后守卫可删，已改写代码不必还原。
- **[x] ② 已加自动化测试** — `fushi/test/build/aot_deferred_final_switch_capture_guard_test.dart`：扫描 `fushi/lib` 与 `packages/*/lib`，禁止「推迟赋值 final 在 switch 语句里赋值 + 之后被闭包捕获」；附上游 repro 形状的扫描器自检。
- **备注**：同一次 AOT 失败还叠着 slang flat map 巨型 string switch 在 Windows 1 MB 主线程栈上的栈溢出（BUG-1589 老问题，由另一个 PR 关 flat map 处理）。
