## BUG-2461 · 阅读器内 OCR 入口（整卷按钮/点击即识别/框选重识别）移除，OCR 只在阅读器外触发
- **报告**：2026-09-12（用户：产品决策，OCR 只能在阅读器**外**触发；阅读器只保留「观察外部任务进度的 HUD + 逐页热替换 + 取消按钮」）
- **真实性**：产品决策，非 bug；本条记录删除面与守卫。删除面（基于 develop `03883986b9`）：
  - `fushi/lib/src/media/manga/reader/manga_fushi_page.dart`：顶栏整卷 OCR 按钮（`manga_full_ocr_button`、`_openWholeVolumeOcr`、`_buildOnlineOcrJob`、`_attachWholeVolumeOcrJob`）、点击即识别（`_onTapEmpty`/`_startTapOcr`/`_showTapOcrNotice`/`_replayPendingTapLookup`/`_MangaTapLookup`）、框选重识别 + 撤销（`manga_rescan_button`、`_setRescanMode`、`_onMangaBoxSelected`、`_reocrRegion`、`_offerRegionRescanUndo`、`_undoRegionRescan`、`onMangaBoxSelected` JS handler）。保留：注册表观察（`_reattachRunningOcrJob`/`_observeWholeVolumeOcrJob`/`_handleWholeVolumeOcrEvent`）、`_replacePageOcrOverlay`、`_finishWholeVolumeOcr`、`_cancelWholeVolumeOcr`、HUD 进度文本；新增独立取消按钮 `manga_ocr_cancel_button`（只在 `_wholeVolumeOcrRunning` 时显示）。
  - `fushi/lib/src/media/manga/manga_overlay_html.dart`：RESCAN 模式 / `__mangaSetRescanMode` / `_pageAt` / `__mangaTapLookupAt` 删除；`onTapEmpty` 回到无 payload。`__mangaReplaceOcr` 与 `.ocr-box` 保留（外部任务热替换面）。
  - 整文件删除：`ocr/manga_region_rescan.dart`、`ocr/manga_region_ocr.dart`、`ocr/manga_ocr_auto_start.dart`、`mihon/mihon_online_ocr.dart`；`manga_json_writeback.dart` 删 `MangaRegionReplaceResult`/`replaceMangaBlocksInRegion`/`restoreMangaPage`（`runExclusiveOnMangaJson`/`writeMangaJsonAtomically`/`estimateMangaBlockFontSize` 保留，后者仍被 `system_ocr_manga_service.dart` 使用）。
  - 偏好：`manga_tap_to_ocr` / `manga_tap_to_ocr_notice_shown` 键、repo getter/setter、`AppModel` 转发、`settings_schema_manga_ocr.dart` 的 `manga.tap_to_ocr` 开关删除（旧库里残留的键值只是死数据，不做迁移）。
  - i18n：删 15 个 `manga_rescan_*` / `manga_tap_ocr_*` / `manga_tap_to_ocr*` key（`i18n_sync --remove`）。
  - 保留 `MangaModule.openBookOcr` 与 `MangaOcrWizardDialog` 的 `launchInBackground`/`existingBook`/`startPage`：下一阶段作品页/书架的「整卷 OCR」外部入口要用它们拿 job 再 `registry.start`。
