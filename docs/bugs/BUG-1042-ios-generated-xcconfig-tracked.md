## BUG-1042 · iOS Flutter 生成文件误入库导致 Mac 上 pod install 失败
- **报告**：2026-07-24（用户：qqbotxiaoxiao，mac/iOS 全平台验证任务中发现）
- **真实性**：✅ 真 bug。`hibiki/ios/Flutter/Generated.xcconfig` 等 6 个 Flutter 机器生成文件被强行 add 入库（`67ca389ce` "chore: add local build helpers" 等），xcconfig 内烧死 Windows 机器路径 `FLUTTER_ROOT=D:\flutter_sdk\flutter_extracted\flutter`。Mac checkout 后 `pod install` 沿 `hibiki/ios/Podfile:26` 的 `require .../podhelper` 解析到 `D:\...` 路径直接失败：`cannot load such file -- .../D:\flutter_sdk\...\podhelper`。这些文件本就在 `hibiki/ios/.gitignore:19-28` 声明忽略（`Flutter/Generated.xcconfig`、`Flutter/ephemeral/`、`Flutter/flutter_export_environment.sh`、`Runner/GeneratedPluginRegistrant.*`），必须由每台机器的 flutter 工具自行生成。
- **[x] ① 已修复** — `git rm --cached` 移出 6 个文件的跟踪（`ios/Flutter/Generated.xcconfig`、`ios/Flutter/flutter_export_environment.sh`、`ios/Flutter/ephemeral/flutter_lldb_helper.py`、`ios/Flutter/ephemeral/flutter_lldbinit`、`ios/Runner/GeneratedPluginRegistrant.h/.m`），本机由 `flutter build ios --config-only` 重新生成后 iOS `pod install` 通过。提交：见本 bug 落地提交。
- **[x] ② 已加自动化测试** — `hibiki/test/ios/generated_platform_files_not_tracked_guard_test.dart`：用 `git ls-files -i -c --exclude-standard` 扫 `hibiki/ios` + `hibiki/macos` 下「已跟踪但被 .gitignore 忽略」的文件，除有意跟踪的 `Assets.xcassets`（被 golden-diff `*.png` 规则连带匹配）外必须为空。
- **备注**：同批发现并修复：`hibiki/macos/Podfile.lock` 与 `hibiki/ios/Podfile.lock` 落后于 pubspec（缺 `macos_ui`/`macos_window_utils`/`appkit_ui_element_colors`/`pdfium_flutter`，iOS 侧还残留已删除的 `document_file_save_plus`/`flutter_image_compress`），已由 `pod install` 再生成入库。
