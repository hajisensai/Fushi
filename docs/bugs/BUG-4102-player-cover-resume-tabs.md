## BUG-4102 · 播放页退出后浏览器标签页不续播；有声书 / 音乐播放页盖住浏览器不按住网页
- **报告**：2026-11-05（用户审 BUG-4084 / #2837 后拍板「改」：播放页盖住浏览器时把已加载标签页都按住，① 按住前在播的标签页，播放页退出后要恢复播放——只恢复原本在播的，不是一律续播；② 有声书播放页与音乐播放页也要算「播放页」）
- **真实性**：✅ 真缺口，沿 #2837 合入后的代码确认：
  - ① 露出时只跑 `kWebBrowserReleaseMediaScript`（`fushi/lib/src/web_browser/features/page_visibility/web_browser_page_visibility_feature.dart:217`，develop `df8bddcd16`），它只摘 `play` 拦截监听，不记也不恢复按住前的播放态；按住脚本 `kWebBrowserHoldMediaScript`（`fushi/lib/src/web_browser/features/play_in_fushi/play_in_fushi_feature.dart:33`）暂停后没留下「谁原本在播」。播放页退出后原本在播的网页视频 / 音频一直停着。
  - ② 播放页登记 `PlaybackRouteMarks`（`fushi/lib/src/media/playback_route_marks.dart`）只有 `VideoFushiPage`、`WebVideoFushiPage` 两个登记者；有声书播放页（阅读器歌词模式覆盖层 `ReaderLyricsPlayerOverlay`）、音乐播放页（`MusicLyricsPage`）、MV / 卡拉 OK 舞台（`MusicKaraokeStagePage`）没登记，盖住浏览器时网页照样和它们一起出声。
- **[x] ① 已修复** —
  - 续播：`web_browser_page_visibility_feature.dart` 新增 `kWebBrowserCoverHoldMediaScript`（先把此刻在播的媒体记进 `window.__fushiCoverResume`，再跑共用按住脚本）与 `kWebBrowserCoverReleaseMediaScript`（先解除按住，再只续播记下的、仍在文档里且仍暂停的元素，`play()` 的拒绝吞在页面里）。按住状态机加 `_PageState.reloadedWhileHidden`：盖住期间整页换了文档只重新按住、不记续播（此刻在播的是盖住后自动开播的预告片）。「用 Fushi 播放」交接那对脚本不变、不续播：交接先暂停页面媒体，之后的盖住按住记不到它。
  - 登记：`ReaderLyricsPlayerOverlay`（登记所在阅读器路由，只在歌词模式挂着时算，纯读书不算）、`MusicLyricsPage`、`MusicKaraokeStagePage` 各加一个 `PlaybackRouteMark`（`didChangeDependencies` attach / `dispose` 撤），登记者清单写进 `PlaybackRouteMarks` 文档。判据仍只有 `PlaybackRouteMarks` 一处，浏览页（消费端）不改。
- **[x] ② 已加自动化测试** — `fushi/test/web_browser/features/page_visibility/cover_media_resume_js_test.dart`（node 在假 DOM 上真执行四段脚本：在播的续播且只续一次、原本暂停的与盖住期间才想开播的不动、站点已自行续上 / 元素已移出不重复播、交接按住不续播、换文档后不续播、`play()` 被拒不留未处理拒绝）；`web_browser_page_visibility_feature_test.dart`（盖住用记录版按住、露出用续播版解除；换文档重按用不记录的按住且失败重做仍不记录）；`fushi/test/media/audiobook/lyrics_player_overlay_test.dart`（覆盖层挂着时所在路由是播放页、撤掉即撤）；`fushi/test/pages/music_lyrics_page_test.dart`（音乐播放页登记 / 关掉撤登记）；`fushi/test/media/playback_route_marks_test.dart`（五个登记者源码守卫 + 文档清单）。
- **备注**：真 WebView 上的续播（站点自动播放策略、WebView2 `TrySuspend` 恢复后的 `play()`）与真机复测本轮未做；MV 舞台起 media_kit 播放器，只有源码守卫没起整页。
