## BUG-2700 · 制卡「紧凑释义」开关不生效
- **报告**：2026-09-26（用户：上游 issue hajisensai/hibiki#1432——Anki 设置里「Compact glossaries」开着，发往 Anki 的释义仍不紧凑；对照 Yomitan 的 Compact Popup and Anki）
- **真实性**：✅ 真 bug。`AnkiSettings.compactGlossaries`（`packages/fushi_anki/lib/src/anki_models.dart:309`）只被写入（`fushi/lib/src/anki/anki_view_model.dart:207`）和在设置页显示（`fushi/lib/src/pages/implementations/anki_settings_page.dart:275`），制卡链路从不读它。导出释义 HTML 由 `fushi/assets/popup/popup.js` 的 `constructSingleGlossaryHtml` / `constructGlossaryHtml` 生成，二者判断的是 `window.compactGlossariesAnki`（原 `popup.js:1451`、`:1596`），而生产代码没有任何地方给这个全局赋值（只有测试夹具写 `false`）→ 分支永远不走，开关是死的。弹窗侧另有独立开关 `lookup.compact_glossaries`（BUG-2284，`window.compactGlossaries`），与本条无关、不改。
- **[x] ① 已修复** — 弹窗 JS 看不见 Anki 设置，真正握着 `AnkiSettings` 的是各后端组装字段那一步，所以样式改在 Dart 侧注入：新增 `packages/fushi_anki/lib/src/anki_compact_glossaries.dart`（`kCompactGlossariesAnkiCss` 由 popup.js 原 `COMPACT_GLOSSARIES_ANKI` 原样挪来；`compactAnkiGlossaryHtml` / `compactAnkiGlossaryMap` 把 `<style>` 插在 `.yomitan-glossary` 容器收尾 `</div>` 之前，与原 JS 分支产物同形；关闭时原样返回、逐字节不变；空串不注入、已注入不重复）。接线点是重建 `AnkiMiningPayload` 的两处：`BaseAnkiRepository.renderMediaPayload`（`packages/fushi_anki/lib/src/base_anki_repository.dart`，AnkiConnect / AnkiDroid 的制卡与覆盖更新都经此）和 `AnkiMobileRepository` 的字段组装（`fushi/lib/src/anki/ankimobile_repository.dart`）；`glossary` / `glossaryFirst` / `singleGlossaries` 三份一起处理，于是 `{glossary}`、`{glossary-first}`（含长按选中词典）、`{glossary-first-N}` 全覆盖。扩展 `/api/mine`、互联转发制卡最终都落在上述后端。同时删掉三份 popup.js（`fushi/assets/popup/`、`fushi/assets/browser_extension/vendor/`、`tools/browser-extension/vendor/`）里无人赋值的 `compactGlossariesAnki` 死分支与常量，以及测试夹具里对它的赋值。
- **[x] ② 已加自动化测试** — `packages/fushi_anki/test/compact_glossaries_mining_test.dart`（走真实 `renderMediaPayload → buildMinedFields`：关 = 释义字段不含紧凑样式；开 = `{glossary}` / `{glossary-first}` / `{glossary-first-2}` / 选中词典都带样式且其余字节与关闭时一致；helper 关闭原样、空串、幂等）；`fushi/test/anki/anki_compact_glossaries_guard_test.dart`（源码守卫：三份 popup.js 不得再出现 `compactGlossariesAnki` / `COMPACT_GLOSSARIES_ANKI`；`fushi/lib` 与 `packages/fushi_anki/lib` 里不得原样透传 `payload.glossary*` 释义字段；两处后端都取 `settings.compactGlossaries` 经 helper）。
- **备注**：未在真 Anki（桌面 / AnkiDroid / AnkiMobile）上目视卡面效果；样式与 Yomitan 同语义（义项行内 + 灰色 ` | ` 分隔），但部分笔记类型自带的释义 CSS 可能与之叠加。互联转发制卡时生效的是 host 端的 Anki 设置（与字段映射同源）。
