## BUG-2549 · 英语短语动词的变形查不到原形（gave up / picked it up 还原不到 give up / pick up）
- **报告**：2026-09-15（用户：「give up → gave up → given up 这个短语动词有过去时查不到，参照一下 hoshi reader Android 英语这块怎么实现的，补齐一下短板」）
- **真实性**：✅ 真 bug。参照物核实：Hoshi Reader Android 本身没有任何英语变形逻辑（只调子模块 `Manhhao/hoshidicts`，上游仓库里连 transforms JSON 都没有；iOS 版同样没有），真正的来源是 en.json 所移植的 Yomitan `english-transforms.js`——它有一套短语动词规则（`createPhrasalVerbInflection`：动词头 + 小品词/介词；`phrasalVerbInterposedObjectRule`：`picked it up`），全是正则型 `other` 规则，移植成 JSON 时被整体丢掉。结果是 `fushi/assets/transforms/en.json` 里 `v_phr` 条件存在但零条规则用到它，而引擎 `native/fushidicts/fushidicts_src/deinflector.cpp` 的 `deinflect_recursive` 只把 suffix / prefix / wholeWord 规则套在**整个候选串**上：`gave up` 的后缀是 `up`、wholeWord `gave→go` 要求整串相等，两边都碰不上，`gave up` / `given up` / `gives up` / `walked away` / `picked it up` 一律只命中同形词条本身。
- **[x] ① 已修复** — 引擎：`Deinflector::deinflect_phrasal`（`deinflector.cpp`）按 Yomitan 语义补两条机制——动词头变形（第一个空格前的动词头单独过一遍打了 `phrasalVerb` 标记的 suffix/wholeWord 规则，小品词原样接回，输出条件 `phrasalVerbs.condition`）与宾语插入（动词头之后、第一个小品词之前夹着不含短语动词用词的宾语则抠掉，再链到动词头变形）；两处刻意差异（小品词按整 token 匹配、动词头不走 prefix 规则）在函数注释里。数据：`en.json` 顶层新增 `phrasalVerbs`（Yomitan 的 particles / prepositions 两张表逐字）、`past` / `ing` / `3rd pers. sing. pres` 打 `phrasalVerb: true`、新增 `interposed object` 组（规则类型 `phrasalVerbInterposedObject`）；`en_irregular.json` 的四个动词组打标记，所以 `gave up → give up` 这类替补形也能还原。`assets/transforms/i18n/zh-CN.json` 补新组译文。提交 `0814556b9f`（feat(dict): phrasal-verb deinflection）。
- **[x] ② 已加自动化测试** — `native/fushidicts/tests/en_inflection_lookup_test.cpp` D 组（13 条：动词头四种变形、大写、宾语插入单词/多词、未变形头 + 宾语插入、尾随介词、小品词整 token、不丢小品词、宾语含小品词不算插入）+ C5/C6（`v_phr` 经 `filter_by_pos`：rules `v` 接住、rules `n` 挡掉）；`fushi/test/dictionary/en_phrasal_verbs_guard_test.dart`（词表/条件/标记组/宾语插入规则的数据形状）；既有 `transform_description_i18n_test` 守卫新组译文。
- **备注**：`*` 通配词典（MDX 转换）与无词性 Yomitan 词典（OALDPE10）因 BUG-2543 的 sidecar 才能吃到这些还原，两条修复互为前提。Yomitan 不含不规则动词，所以它自己也查不到 `gave up`；本仓因 en_irregular.json 而超出参照物。
