## BUG-812 · 互联开启后手机上有声书不进合集(host listBooks 只用 epub|bookKey 查归属，漏 srt-backed 有声书的 srt|uid 成员键)
- **报告**：2026-07-14（用户：手机上有声书没进到合集里面，开启了 Hibiki 互联）
- **真实性**：✅ 真 bug。根因：srt-backed 有声书（既有 EpubBooks 又有 SrtBooks 行）加入合集时以 **`srt|<uid>`** 存进 `media_collection_items`（本地书架把它当 SRT 卡渲染、经 `srt|uid` 折叠——参考实现 `reader_hibiki_history_page.dart:949-958` 把 srt-backed bookKey 从 epub 列表剔除、当 srt 卡）。但 host `app_model_library_host_service.dart:334`（`listBooks` 只 `membership['epub|${r.bookKey}']`）对同一本书查 `epub|bookKey` → 必 miss（该书无 epub 成员，只有 srt 成员）。互联 client 把 srt-backed 有声书作为 EPUB 占位卡收下（`remoteState.books`），其 `RemoteBookInfo.collection` 为 null → 书架注入循环 `reader_hibiki_history_page.dart:1060` 判散卡 → 不折进合集。DB 实证：合集「安達としまむら」含 10 epub 成员 + 4 srt 成员（`srt|srtbook_epub_安達としまむら[N]`），6 个有声书全 srt-backed，成员表无 audiobook 类型。
- **[x] ① 已修复** — `app_model_library_host_service.dart` `listBooks` 建一趟 `bookKey→srtUid` 映射（`getAllSrtBooks` 里 bookKey 非空者），归属查改为 `membership['epub|bookKey'] ?? membership['srt|uid']`，使 srt-backed 有声书 EPUB 占位卡也携带 `collection` → client 经现有注入循环折进合集，与本地书架对称、不依赖后台 sweep。
- **[x] ② 已加自动化测试** — `test/sync/hibiki_library_collections_test.dart`：EpubBook+SrtBook(bookKey) 同 bookKey、合集加 `srt|uid` 成员 → listBooks 返回该书 collection 非空且 name/type/sortIndex 正确；对照散卡（无 srt 成员）归属为 null。
- **备注**：standalone 纯 SRT 有声书（bookKey 空、走 remoteSrtBooks）的即时折叠是另一未覆盖缺口（`RemoteAudiobookInfo` 无 collection 字段 + 书架不注入 remoteSrt），本库无此类数据，列为 follow-up。取 812 避让 origin 808-810。
