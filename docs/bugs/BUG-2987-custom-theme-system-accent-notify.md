## BUG-2987 · 自定义主题跟随系统强调色后不通知界面
- **报告**：2026-10-06（样式改版审查）
- **真实性**：真实状态通知缺陷；公共历史基线已存在，不归因为本次样式重设计新增。
- **根因**：`fushi/lib/src/models/theme_notifier.dart:856` 刷新系统颜色后原先仅在 `appThemeKey == 'system-theme'` 时通知；活跃自定义主题的 `followSystemAccent` 同样消费系统色，却不会收到通知，界面直到其他重建才更新。
- **[x] ① 已实现修复** — 活跃且跟随系统色的自定义主题也触发通知，保留同色早退及不跟随主题静默行为。提交见本文件所在修复提交。
- **[x] ② 已增加自动化测试** — `fushi/test/models/custom_theme_system_accent_refresh_test.dart`，覆盖派生/钉死主色、同色静默、系统色消失回退及不跟随主题。
- **验证结果**：见 [审查报告 HBK-AUDIT-006 及最终验证记录](../reviews/2026-10-06-project-review.md)。
- **备注**：未在真实操作系统设置中切换强调色验收，不宣称平台端到端通过。
