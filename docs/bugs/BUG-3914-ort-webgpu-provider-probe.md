## BUG-3914 · ort-webgpu-provider-probe
- **报告**：2026-10-28（应用内反馈 eEnV5gBn1K，OnePlus CPH2747 / Android 16，3.0.1-debug.21889：转录面板「GPU 探测失败，按 CPU 规划：Invalid argument(s): Provider WEBGPU is not a valid OrtProvider.」）
- **真实性**：✅ 真 bug。根因 `third_party/flutter_onnxruntime/lib/src/onnxruntime.dart` `OnnxRuntime.getAvailableProviders`（修前 `:139`）：按 Dart `OrtProvider` 枚举名精确匹配 native 回报的名字，匹配不上就抛 `ArgumentError`。Android ORT 1.28.0 aar 的 Java 枚举名是 `WEBGPU`（Dart 侧叫 `WEB_GPU`），于是整份 EP 列表探测失败；`asr_transcribe_sheet.dart` `_appendProbeHint` 再把异常原文直接拼进面板文案。
- **[x] ① 已修复** — `22fa6a8bd3`（PR #2695）：新增 `ortProviderFromNativeName`（`third_party/flutter_onnxruntime/lib/src/ort_provider.dart`，Java 枚举名 / Windows·Linux 映射表 / ORT C 名三套别名表），`getAvailableProviders`（现 `onnxruntime.dart:148`）对本 API 表达不了的 EP 丢弃并记 `flutter_onnxruntime` 日志而不是抛错（表达不了的 EP 本来也无法经 `OrtSessionOptions.providers` 请求）；转录面板只显示可读说明 `audiobook_transcribe_probe_failed_hint`，异常原文进日志。vendored 改动记录 `third_party/flutter_onnxruntime/PATCHES.md` #15。（同题的 PR #2681 已关闭未合，其 BUG-3892 记录随之未入库，故在此补建。）
- **[x] ② 已加自动化测试** — `fushi/test/onnx/onnxruntime_provider_names_test.dart`（走真实 `flutter_onnxruntime` method channel，mock native 回包：Android 1.28.0 的 `WEBGPU`、Java 枚举里 Dart 枚举没有的名字、Windows/Linux 的 `MIGRAPHX` 与 ORT C 名、本 API 无法表示的 EP 被排除且其余照常回报、Android / Windows 加速探测不再抛错）；面板文案断言在 `fushi/test/media/audiobook/asr_transcribe_sheet_test.dart`。
- **备注**：Android 加速 EP 选择本来只认 CUDA / DML / CoreML，实际仍走 CPU；修的是探测整体失败带来的误报与降级说明。未在 Android 真机复看探测文案。
