## BUG-5371 · anidb-tag-tree-backtick
- **报告**：2026-11-24（用户：开发者本人，应用内反馈 hUnujr-N2h「这刮削的什么玩意」，截图是 BanG Dream! It's MyGO!!!!!（AniDB 17981）视频详情页）
- **真实性**：✅ 真 bug。实拉 AniDB HTTP `anime aid=17981` 对照截图：① 标签行「musical band · dynamic · themes · setting · elements · time · place · present · Earth · Japan …」——`<tags>` 是 AniDB 标签树按 id 平铺，每个具体标签的全部祖先（`dynamic` / `themes` / `setting` / `elements` / `time` / `place` / `cast` / `origin` 等分类节点和 `Earth` → `Asia` 中间层）都一起下发、用 `parentid` 串树，旧代码 `packages/fushi_engine/lib/media/video/metadata/anidb_video_metadata_provider.dart:675`（`_parseAnime` 的 `tags`）不看 `parentid` / `weight` / 剧透标记，逐条收下；② 标题「BanG Dream! It\`s MyGO!!!!!」、集简介「Rāna\`s」——AniDB 全站把撇号存成反引号（HTTP XML、每日标题目录、UDP 应答同样），`_text`（同文件 `:1354`）、`AniDbTitle`（`anidb_title_catalog.dart:37`）、相关作品名（`video_related_works.dart:195`）、UDP `EPISODE` 集名（`anidb_udp_file_client.dart:667`）都原样入库。
- **[x] ① 已修复** — 新增 `packages/fushi_engine/lib/media/video/metadata/anidb_text.dart`：`aniDbLeafTagNames` 按结构只留叶子标签（被同文档别的标签当 `parentid` 的一律是祖先，含义已由子标签表达）、去掉 `localspoiler` / `globalspoiler` 剧透标签、按 AniDB 权重降序（同权重保持文档顺序）；`aniDbDisplayText` 把反引号换回 ASCII 撇号，接在 `AniDbTitle` 两个构造器、provider 的简介 / 集简介 / 人名 / 角色名（`_prose`）、相关作品名与 UDP 三语集名上。已刮过的作品要重新刮削（或 AniDB XML 24h 缓存过期后刷新）才会换成新结果。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/metadata/anidb_video_metadata_provider_test.dart`「flattens the AniDB tag tree to leaf tags and decodes backtick apostrophes」：用 17981 真实 XML 的标签子集（id / parentid / weight 照抄，外加一条剧透标签）走 `fetchWork` / `fetchEpisodes`，断言标签只剩叶子且按权重排、剧透标签不出、标题 / 原名 / 简介 / 工作室 / 集名 / 集简介 / 别名 / 人名无反引号。
