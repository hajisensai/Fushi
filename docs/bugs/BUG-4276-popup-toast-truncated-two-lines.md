## BUG-4276 · 「保存到」退回主机默认的提示被截断 / 被结果提示顶掉
- **报告**：2026-11-08（服务端 Fushi 复习端到端测试：「保存到」退回主机默认的提示在查词弹窗里只显示到「Cards now go to …」）
- **真实性**：✅ 真 bug，两层。
  - 根因一（截断）：`fushi/lib/popup_main.dart` 的查词弹窗进程从没给 `FushiToast.navigatorKey` 装 key（只有 `main.dart:1227` 装了），`FushiToast.show`（`fushi/lib/src/utils/misc/fushi_toast.dart` 的 `overlay == null` 分支）在弹窗里一律退回原生 Fluttertoast，Android 12+ 的系统文字 toast 最多两行。不是文案问题。
  - 根因二（被顶掉）：这句提示是 `anki_view_model.dart`（修复前 `:762`）在 `onTargetUnavailable` 回调里单独弹的一条 toast，紧接着制卡结果 toast 到来；应用自绘通知只有一个槽位，后到的顶掉先到的。主 app 里一直如此（提示一闪即没），弹窗改用自绘通知后同样。原生 toast 排队，所以之前在弹窗里还能看到被截断的版本。
- **[x] ① 已修复**
  - 弹窗词卡页的 `MaterialApp` 挂一把只给 toast 用的 navigator key（`popup_main.dart:98`、`:238`，`initState` 里交给 `FushiToast`，`:104`），弹窗内提示画成应用自己的通知胶囊（不限行）。不复用 `AppModel.navigatorKey`：那把挂着主 app 的全局弹窗入口。
  - 提示改跟制卡结果走同一条通知：`MineOutcome.success` 加 `notice`（`packages/fushi_anki/lib/src/anki_models.dart`），`RemoteMiningAnkiRepository` 在主机回 `targetUnavailable` 时填上注入的本地化文案（`remote_mining_anki_repository.dart:148`，本类仍无 Flutter 依赖），`describeMineOutcome` 把它接在结果后面并按 `addedWithWarning` 弹（`error_log_service.dart:701-705`；关掉「制卡成功提示」也照样弹）。「保存到」退回默认仍由 `AppModel.createRemoteMiningClient` 做。
- **[x] ② 已加自动化测试** — `fushi/test/utils/misc/fushi_toast_popup_overlay_test.dart`（自绘胶囊在手机宽度下完整画出三行以上的长句；源码守卫钉住弹窗入口装 key）；`fushi/test/anki/remote_mining_anki_repository_test.dart`「BUG-4276: a reset save location rides on the success outcome…」（含旧主机本地牌组名降级路径）；`fushi/test/anki/describe_mine_outcome_test.dart`「BUG-4276 success + notice」。
- **跟进（审查 #3093 发现的回归）**：提示从客户端级 toast 挪到 `MineOutcome.notice` 后，只有走 `describeMineOutcome` 的单张制卡路径会显示；不看逐张结果的批量 / 后台路径就此静默——待发队列补发（回前台自动补发与「全部发送」）、视频暂存队列（对话框 / OSD / 退出后后台写入）、ctl 路由、收藏夹批量制卡。修复：`PendingFlushReport.notice` / `VideoMineCommitSummary.notice` 收第一条提示并随汇总提示一起显示（自动补发单独弹一条），ctl JSON 带 `notice` 字段，收藏夹批量制卡把它附在该行的结果说明里（`favorite_batch_mining_runner.dart` 的 `favoriteBatchAddedMessage`）。测试：`pending_mining_anki_repository_test.dart`、`video_mine_queue_test.dart`、`anki_mining_error_messages_test.dart`、`favorite_batch_added_message_test.dart`。
- **跟进二（再审 #3093）**：app 外浮窗（全局查词 / 剪贴板面板 / 截屏识字，`fushi/lib/src/lookup/overlay_bridge_handlers.dart` 的 `_mineEntry`）成功时宿主不弹结果 toast，回包也只在失败时带 `message`，提示同样静默；galgame ctl 路由（`ctl_game_routes.dart`）的 JSON 也没带 `notice`。修复：回包抽成 `overlayMineReply`，成功且有 `notice` 时把它放进 `message`，`popup.js` 成功分支就地 `showInlineHint`（应用内表面成功回包不带 `message`，不会与宿主 toast 重复）；ctl game 路由补 `notice` 字段。测试：`fushi/test/lookup/overlay_mine_reply_notice_test.dart`。
- **备注**：模拟器复测：选「保存到 · E2E」，在手机上把 E2E 改名并同步到服务端，弹窗里制卡，结果通知完整显示「Card exported to 『Default』. The paired device no longer offers your chosen save location. Cards now go to its default.」（三行、警示色），「保存到」退回主机默认。已知取舍：自绘提示画在弹窗窗口里，提示消失前关掉弹窗会一起消失。结果为重复 / 失败时不附这句（「保存到」照样退回，设置行可见）。
