## BUG-901 · 字幕点击与进度条点击命中区重叠误触
- **报告**：2026-07-19（用户：字幕点击和进度条点击挨得太近了，让他们远一点或者点击更远一点，不然点击太容易点错了）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/media/video/video_subtitle_style.dart:66`（`videoSubtitleControlsReserve` 移动分支只让**可见轨道高**）+ `hibiki/lib/src/pages/implementations/video_hibiki_page.dart:4918`（`_subtitleControlsBottomReserve` 传 `_videoSeekBarTrackHeight`）。
  - 几何账（移动端、界面缩放 1.0、沉浸态系统 inset 0，离视频底边坐标）：进度条**触摸热区容器** 40px 高（`_videoSeekBarContainerHeightBase`），可见轨道只占底部 5px（`_videoSeekBarTrackHeightBase`），容器上方约 35px 是**透明但可点**的 seek 命中区；热区底缘 72、上缘 **112**。字幕避让 reserve 只算到「可见轨道上缘 77 + 呼吸 8 = **85**」，字幕逐字符命中区（含 BUG-825 后的兜底扩边）下缘≈85。
  - 于是字幕命中区（85↑）与进度条透明热区（72–112）在 **85–112px 完全重叠**。字幕的 `_SubtitleCharTapRecognizer` 与 media_kit 进度条 Slider 在**同一手势竞技场**竞逐（`video_subtitle_overlay.dart` 逐字符命中门控 → 命中字符才进 arena，否则放行 seek）：落在重叠带的一次点击，手指差几像素就把字幕点误判成 seek、seek 误判成字幕 = 用户报的「太容易点错」。
  - 直接诱因：TODO-568 当初为消「字幕顶飞」把移动 reserve 从触摸热区全高改成可见轨道高 + 呼吸，字幕落回了进度条那段透明热区里。用户现在明确要「远一点」，正该让字幕避让**整个触摸热区**。
- **[x] ① 已修复** — 移动 reserve 改用**触摸热区全高** `_videoSeekBarContainerHeight`（进度条真正可点目标，含轨道上方透明 seek 区）+ 呼吸间距，字幕命中区整体清出进度条整段 seek 命中区、零重叠。改后 reserve = 8+0+56+8+40+8 = **120**，字幕命中区下缘≈120 清过热区上缘 112 有 8px 呼吸。代价是控制条可见时字幕比可见轨道高约一个热区高（用户明确要的分隔；控制条自动隐藏后字幕落回用户基线）。改动：`video_subtitle_style.dart`（`videoSubtitleControlsReserve` 参数 `seekBarTrackHeight`→`seekBarContainerHeight` + 移动分支 + 文档）、`video_hibiki_page.dart:4918`（`_subtitleControlsBottomReserve` 传 `_videoSeekBarContainerHeight`）。提交：932a2b8c4
- **[x] ② 已加自动化测试** — 纯函数几何守卫：`hibiki/test/media/video/video_subtitle_style_test.dart` 的 `videoSubtitleControlsReserve` 组重写为断言「移动 reserve ≥ 进度条触摸热区上缘（清出 seek 命中区）、差值 = 呼吸间距、且 > 只让可见轨道高的旧值 101」，缩放下同守；源码守卫：`hibiki/test/pages/video_subtitle_push_up_guard_test.dart` 翻转为「reserve 必须含 `_videoSeekBarContainerHeight`、不得只用 `_videoSeekBarTrackHeight`」。提交：932a2b8c4
- **备注**：本 worktree 取号 BUG-901，与本会话其它并发 worktree（PR#230/233/234）撞号；集成时按惯例改号 + `dart run tool/bug.dart reindex`。overlay 侧 `max(bottomPadding, reserve)` 落回逻辑与 `kVideoControlsBottomReserve`(56) 常量未动。若真机上分隔过大，收窄 `_videoSeekBarContainerHeight` 或呼吸间距即可，但不能退回只让可见轨道高（本 bug 根因）。真机复测项：控制条弹出时点字幕查词/点进度条 seek 各自命中、不再互相误触。
