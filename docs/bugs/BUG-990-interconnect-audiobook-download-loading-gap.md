## BUG-990 · 互联下载有声书两阶段之间露出「无转圈的普通书」(空窗期本地卡缺加载指示)
- **报告**：2026-07-14（用户：点有声书下载，转圈完先显示成 epub，才显示下载了有声书，中间应该有转圈提醒）
- **真实性**：✅ 真 bug（UX）。根因：远端有声书下载走两阶段(`reader_history/remote.part.dart` `_downloadRemoteBook`→`_downloadRemoteAudiobook`)，转圈徽章只画在**远端占位卡**(`_downloadingBooks[book.title]`→`RemoteDownloadProgressBadge`)。EPUB 一落库，`hibikiBooksProvider`/`srtBooksProvider`(监听 DB 变化的流,`reader_hibiki_source.dart:44/53`,BUG-793)**自动刷新书架** → 远端占位卡被去重顶替成**本地卡**;此刻有声书 srt_book 还没落库,本地卡无任何加载指示 → 露出「无转圈的普通 EPUB 书」;等有声书落库再刷成有声书卡。用户看到:转圈→普通 EPUB 卡(无转圈)→有声书卡,中间空窗缺提示。非本轮新代码引入(两阶段下载=b76345790,自动刷新=BUG-793)。
- **[x] ① 已修复** — 新增 `Set<String> _downloadingAudiobookKeys`(按导入后本地 bookKey)。`_downloadRemoteBook` 在 EPUB 落库、`_downloadRemoteBookProgress` 之后、`_downloadRemoteAudiobook` 之前,若 `book.hasAudiobook` 则标记 localBookKey(记入 try 外 `markedAudiobookKey` 供 finally 清理);单点 `finally` 清除(覆盖成功+`_RemoteAudiobookException`+通用 catch 所有 return 出口)。`_bookCardLayout`(`card_widgets.part.dart`)新增居中全幅 `loadingOverlay` 槽(不抢占 coverBadge/leadingBadge/tagLabels);本地 EPUB 卡(`buildMediaItemContent`)与 SRT 卡(`books.part.dart _buildSrtCard`)在各自 bookKey 命中集合时叠 `_audiobookDownloadingOverlay`(复用 `RemoteDownloadProgressBadge(progress:null)` 转圈)。
- **[x] ② 已加自动化测试** — `test/pages/reader_remote_interconnect_test.dart`:本地 SRT 卡(bookKey=local-book-key)+ Completer 闸门卡住有声书下载 → 点远端下载 → 断言本地卡出现 `audiobook_downloading_local-book-key` 覆盖层 → 放行 → 覆盖层清除。
