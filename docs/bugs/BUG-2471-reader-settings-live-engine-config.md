## BUG-2471 · 阅读器边距等设置改完不实时生效
- **报告**：2026-09-12（用户：「阅读设置的各项设置不能实时变化」；上一轮也提过「调上下边距没用」）
- **真实性**：✅ 真 bug（BUG-866 的边距一半在 2026-08-24 `9eaf2023df`（BUG-1812）之后重新失效）。根因 `fushi/lib/src/pages/implementations/reader_fushi/webview.part.dart` 的引擎 install：`window.__fushiApplyReaderMargins` 把 `C.marginTop/Bottom/Left/Right` 物化成 `documentElement` 上的**内联像素变量** `--reader-margin-*`，而 `C`（`ReaderEngineConfig`，`webview.part.dart` `_buildReaderEngineConfig`）只在每次导航 boot 时下发一次；改边距走的是只换 CSS 的 `onSettingsChangedLive` → `_applyStylesLive`（`reader_fushi_page.dart`），新样式表里 `var(--reader-margin-top, Xvh)` 的回退值被停在旧值的内联变量遮住——改完没反应，翻章 / 重开书才见效。同一根因（只在 install 时读 `C`）还有：滑动灵敏度阈值 `C.swipeDistThreshold/swipeFastDistThreshold`、滚轮静默窗 `C.wheelGestureQuietMs`、扫描非日文 `window.scanNonJapaneseText = C.scanNonJapaneseText`（设置项 `lookup.scan_non_japanese` 甚至只 `refresh()` 设置页，不通知阅读器）；另有全局默认内容语言只在开书时解析进 `_contentLanguage`，改了不重算字体族。
  - 其余「不实时」项经查各有通道且工作：字号 / 字重 / 行高 / 缩进 / 段距 / 振假名 / 排版 / 主题 走 CSS 热换，视图 / 书写模式 / 栏数 / 模糊图走整章重载，顶部进度 / 悬浮 / 自动隐藏走 chrome 重建。统计空闲超时与日切时间是 `StudyClock` 建书时读一次，设置页已标「下次打开书生效」，不在本条范围。
- **[x] ① 已修复** — 提交见合并记录。引擎加 `window.__fushiEngine.updateLive(patch)`：把 patch 合并进已 install 的 `window.__fushiReaderConfig`（与 install 闭包里的 `C` 是同一个对象，所有运行时读 `C.*` 的闭包立即看到新值）；边距变了就用 `__fushiApplyReaderMargins` 上一次见到的视口（新记的 `window.__fushiReaderMarginsLast`）重物化 `--reader-margin-*`；`scanNonJapaneseText` 镜像到 window。Dart 侧 `ReaderEngineConfig.liveUpdateInvocation(...)` 编码这份 patch，`_liveEngineConfigJs()`（与 `_buildReaderEngineConfig` 同一套派生）在 `_applyStylesLive` 里**先于换 CSS**、拼进同一次 `evaluateJavascript` 下发；`_applyStylesLive` 同时按 `_explicitContentLanguage` + 新全局默认重解析 `_contentLanguage`；`lookup.scan_non_japanese` 改为 `notifyReaderSettingsChanged`。不重跑 install、不重载章节、导航代数不变。
- **[x] ② 已加自动化测试** — `fushi/test/reader/reader_engine_live_config_test.dart`：patch 只含热更新键（导航 / 视口 / 进度等冻结键不得混入）；引擎源码守卫（`updateLive` 唯一、记视口、按 last 视口重物化、镜像 scan）；`_applyStylesLive` 的 patch 必须在换 CSS 之前且同一次 eval；`_liveEngineConfigJs` 与 install 同一套阈值派生；设置 schema 里四个边距 / 滚轮 / 滑动 / 扫描非日文都打 `notifyReaderSettingsChanged`。行为级：`reader_engine_live_config_behavior_test.js`（node，从 `webview.part.dart` 原样切出 `__fushiApplyReaderMargins` + `updateLive` 执行：install 物化 → 改边距按最近视口重物化并返回 true → resize 后仍按新视口 → 边距未变不重物化返回 false → install 前安全 no-op）。真 app：`fushi/integration_test/reader_live_settings_itest.dart` 段 A——开着书把上边距 +10 个百分点，断言 `--reader-margin-top` 像素 == 视口高 × 新百分比、body padding-top 同步增长、`__fushiReaderConfig.marginTop` 已是新值、导航代数不变；滑动阈值 / 滚轮静默窗 / `window.scanNonJapaneseText` 也随之更新；改回基线复原。
- **备注**：`ReaderQuickSettingsSheet.onPageMarginChanged` 是早先留下的死接线（四个边距键都调它，阅读器从不提供），本次不动它——边距现在与其它设置一样走 `onSettingsChangedLive`。VN 模式的四个 `vn*` 键没有设置项、`blurImages` 走整章重载，都不进 live patch。
