## BUG-791 · 悬停底栏音量/倍速图标误关 push-aside 字幕列表
- **报告**：2026-07-14（用户：桌面端视频播放器打开右侧「字幕列表」，鼠标放到视频右下角控制栏就会把字幕列表弄消失，正常不该消失）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/pages/implementations/video_hibiki/controls_popover.part.dart:301-304`。桌面默认控制布局把 volume + speed 放进 `bottomRight` 槽紧挨 fullscreen（`hibiki/lib/src/media/video/video_control_customization.dart:598-606`）；`_controlPopoverAnchor` 给这些按钮包了 `MouseRegion`，**hover（`onEnter`）** 即调 `_showControlPopover`（`controls_popover.part.dart:35-43`）。而 `_showControlPopover` 内沿用了 `_showVideoSidePanel` 的「开任何浮层就关 push-aside 字幕列表」互斥假设，无条件 `_subtitleListVisible.value = false`。但该前提对轻浮层不成立：音量/倍速轻浮层的落点被 `resolveVideoControlPopoverPlacement` clamp 在 `playerBounds`（字幕列表推开后已窄化的视频列）内，几何上**不与右侧 push-aside 字幕栏重叠**（BUG-371 已确立 push-aside 字幕列表应与不遮挡它的东西共存）。所以鼠标划过右下角音量/倍速图标去够全屏按钮时，hover 就把字幕列表误关了。剧集列表 `_episodeListVisible` 同处右栏但它是控制条门控（开列表时控制条被隐藏、无法 hover 到音量/倍速），故不暴露此症状——只有字幕列表（BUG-371 移除其门控、控制条仍可见可 hover）中招。
- **[x] ① 已根因修复** — `controls_popover.part.dart` 的 `_showControlPopover` 移除对 push-aside 字幕列表的强制关闭（轻浮层与字幕列表几何不冲突，可共存，与 BUG-371 对三处门控的处理一致）。提交见分支 `worktree-fix-subtitle-list-hover-popover`。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/video_subtitle_list_hover_popover_guard_test.dart` 源码守卫：断言 `_showControlPopover` 方法体不含 `_subtitleListVisible.value = false`（hover 触发的轻浮层不得关字幕列表），并反向锚定「点击触发」的 `_showVideoSidePanel` 仍保留互斥关闭（overlay 面板确实遮挡右栏，关闭合理），锁死二者语义差异不被回改。
- **备注**：桌面 hover 行为，真机/离屏验证待用户（打开字幕列表 → 鼠标移到右下角控制栏 → 字幕列表应保持可见）。
