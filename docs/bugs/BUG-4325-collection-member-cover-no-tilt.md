## BUG-4325 · collection-member-cover-no-tilt
- **报告**：2026-11-10（用户：开发者 shishamo 自提，反馈 bsbJ4OVa8o「合集内的书或者视频没有 3d 斜视差，统一一下」）
- **真实性**：✅ 真 bug。合集详情成员卡（书 / 游戏）整张包在 `IgnorePointer` 里，悬停由 `_HoverableMemberCard`（`fushi/lib/src/pages/implementations/media_collection_grid_detail_page.dart:1958`）经 `FushiHoverLiftHost` 代收，但 host 只代收 `hovering` 一位、不代收指针位置（`fushi/lib/src/utils/components/fushi_hover_lift.dart:117`）；卡里 `FushiHoverLift` 的 `_pointer` 只由它自己被挡住的 MouseRegion 写（同文件 `:386-389`），恒为 null，`_syncTilt`（`:234`）发出的倾斜位置恒为 null → 抬升 / 扫光都有，`FushiTilt` 永远是平的。视频合集集卡 `CollectionEpisodeCard`（`fushi/lib/src/media/collections/collection_detail_layout.dart:1307`）整卡 `IgnorePointer` 且根本没有 `FushiHoverLift` 祖先，缩略图的材质封面框里的 `FushiTilt` 拿不到 notifier。原「`FushiTilt` 没收进统一封面组件」的推测不成立：`ShelfCoverFrame` 两条路径（无材质 `shelf_card_widgets.dart:450/486`、材质 `ShelfCoverPile` `shelf_cover_material.dart:861`）都恰好包一层倾斜，缺的是指针位置。
- **[x] ① 已修复** — `FushiHoverLiftHost` 增加 `pointer`（代收的全局指针位置），`FushiHoverLift` 订阅它作为被挡住时的指针来源；新增公共壳 `FushiHoverLiftRelay`（MouseRegion 同时代收悬停与位置）。合集详情成员卡 `_HoverableMemberCard` 与 `CollectionEpisodeCard`（合集详情集卡 + 媒体服务器剧集卡）都改走它，集卡里补一层 `FushiHoverLift(scale: 1)` 让缩略图走库页同一套抬升扫光 + 倾斜 + 镜面高光。墨水屏 / 减弱动态效果仍由 `FushiHoverLift` 统一关掉。
- **[x] ② 已加自动化测试** — `fushi/test/widgets/collection_member_cover_tilt_test.dart`：合集详情书卡（默认网格 / 手动序拖排网格）与视频集卡各恰好一层 `FushiTilt`，悬停右缘朝右转、移出回单位矩阵；库页单本（无材质 / 材质）、叠层（材质扇形 / 无材质）各恰好一层 `FushiTilt`。（本分支未运行，统一在合并后验证。）
- **备注**：只代收鼠标；触屏在这些网格上按住即拖排，不做按压倾斜。集卡整卡不放大（宽卡在 12px 间距网格里按 1.05 放大会压到邻卡）。
