## BUG-683 · 长按左右键无法连续切句/连续翻页
- **报告**：2026-07-09（用户）
- **真实性**：✅ 真 bug（阅读器键盘长按不连发）。根因 `hibiki/lib/src/pages/implementations/reader_hibiki/caret.part.dart:143`（原 103）：阅读器 `_handleKeyEvent` 在解析快捷键前有 `if (event is! KeyDownEvent) return KeyEventResult.ignored;` 闸门，把长按产生的 OS 自动重复 [KeyRepeatEvent] 全部丢弃（仅字符光标在其上另有专门重复分支）。因此按住 Ctrl+←/→（有声书上一句/下一句，默认绑定）或用户改绑成裸 ←/→ 的句子导航，只在按下瞬间触发一次，无法连续切句；裸左右键翻页同理也不连续。对照：视频播放器经 `SingleActivator(includeRepeats: true)`（`video_player_shortcuts.dart:157`）连续切句幕，手柄 D-pad 经 `GamepadFrameProcessor`（`gamepad_service.dart:1038`）连续翻页——唯独阅读器键盘路径缺失长按连发，属键盘/手柄/视频三者不一致。
- **[x] ① 已修复** — `caret.part.dart` 在 KeyDown-only 闸门之前新增 `if (event is KeyRepeatEvent)` 分支：排除字符光标激活态（其重复在上面已处理）与原生手柄键（`GamepadButton.fromKeyEvent`，保持按下沿路由不变），再用抽出的共享解析器 `_resolveReaderKeyboardShortcut`（KeyDown 与 KeyRepeat 两路共用，保证解析一致）解析当前键的动作，仅当命中 `isRepeatableReaderKeyboardShortcut`（白名单：readerPageForward/Backward、audiobookNext/PrevSentence）时执行——离散动作（查词/书签/关词典/播放暂停）仍一次一按。谓词落在纯函数 `hibiki/lib/src/shortcuts/reader_space_override.dart:isRepeatableReaderKeyboardShortcut`。无 app 层节流：OS 重复速率决定连发节奏，与视频播放器 includeRepeats 语义一致。提交于分支 `todo1370-longpress-arrow-sentence`。
- **[x] ② 已加自动化测试** — `hibiki/test/shortcuts/reader_keyboard_repeat_test.dart`：① 纯函数单测锁定白名单（翻页 + 有声书上下句可重复；查词/书签/关词典/播放暂停/打开菜单等离散动作不可重复）；② 源码守卫锁定 `_handleKeyEvent` 存在 KeyRepeat 分支、落在 `is! KeyDownEvent` 闸门之前、调用 `isRepeatableReaderKeyboardShortcut`、并排除原生手柄键与光标激活态。
- **备注**：长按连续切句是阅读器（有声书）键盘路径；视频字幕切句本就连发、不受影响。桌面模拟器真机复测「按住 Ctrl+←/→ 连续切句 / 按住裸方向键连续翻页」待集成验证（见 TODO-1370 看板）。
