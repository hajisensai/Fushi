## BUG-4860 · collage-remote-cover-shadow-mismatch
- **报告**：2026-11-16（用户：哈吉千歳，QQ「阴影和实际不符」——手机漫画库拼贴布局，下载中的远端漫画块：封面斜放带圆角，底下一块不旋转、直角、略大且错位的暗矩形）
- **真实性**：✅ 真 bug。根因 `fushi/lib/src/utils/components/fushi_cover_block.dart:781-785 / 871-874 / 885-888 / 901-905`（修复前行号）：`coverOverlay`（远端下载进行中的 `RemoteDownloadProgressBadge` → `FushiDownloadCoverOverlay`，自身 `SizedBox.expand` 铺满压暗 + 进度环）在四种摆法里都以 `Positioned.fromRect(rect: slot.rect, child: Center(child: coverOverlay))` 挂成封面的**兄弟层**——在 `_posed` 的姿态 `Transform`（位移 / 旋转 / 缩放）和 `_CoverCard` 的 `ShellClip` 圆角裁切之外，于是压暗层画在未变换的槽矩形上：不旋转、直角、与缩放 / 位移后的封面错位。书架远端书 / 纯 SRT 有声书 / 下载中有声书（`reader_history/card_widgets.part.dart` `_shelfCoverBlock(coverOverlay: loadingOverlay)`）与漫画库远端条目（`remote.part.dart` `_buildRemoteBookCard` 同一路径）全都受影响。
- **[x] ① 已修复** — 盖层收进封面卡本身：`_CoverCard` 新增 `overlay`，叠在封面之上、同在 `ShellClip` 里，整张卡由 `_posed` 变换（书封扇形只压最前那张 i == 0；单张竖海报、唱片摆法同理）；横版剧照槽没有 `_CoverCard`，用 `_withCoverOverlay` 把盖层叠进剧照所在的同一个 `_posed`。删掉四处姿态外的 `Positioned.fromRect` 兄弟层。（未提交，按委托不 commit）
- **[x] ② 已加自动化测试** — `fushi/test/utils/components/fushi_cover_block_overlay_test.dart`：书封扇形 / 单本书封 / 单张竖海报 / 唱片 / 横版剧照五种摆法，断言盖层是封面姿态 `Transform` 的后代、与封面共用同一个 `ShellClip`（裁切在变换里），且屏上四角（变换后坐标）与封面重合。
- **备注**：视频库拼贴（`home_video_page.dart`）远端下载态只进副行（`_remoteDownloadMeta`），不传 `coverOverlay`，无此问题；合集详情 `collection_detail_layout.dart` 的 `positionRemoteDownloadBadge` 在自己的封面 Stack 里铺满（不走色块），也无此问题。设备肉眼复测待补。
