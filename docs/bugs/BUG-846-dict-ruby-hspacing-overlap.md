## BUG-846 · 辞書例文の逐字ルビが横方向に重なる
- **报告**：2026-07-16（用户：截图 明鏡「大学」「以前」例文）
- **真实性**：✅ 真 bug。根因 `hibiki/assets/popup/popup.css`（`:where(.glossary-group, .glossary-content) rt`）+ `popup.js` `postProcessRuby`。明鏡式逐字ルビは各漢字が独立の `<ruby>`/`.ruby-unit`。`rt` が `position:absolute; left:0; right:0`（縦 reserve は `.ruby-unit{padding-top:0.55em}` で確保済み）だが、**横方向の reserve が皆無**。`rt{font-size:0.5em}` の 3 拍以上の読み（きょう/けん/きゅう…）は 1em の漢字より広く、`text-align:center` で左右にはみ出して隣の基字の読みと衝突。BUG-345/TODO-620 が「圧縮の代償で数px はみ出す」を許容していたが、逐字ルビでは実質フル重なりになっていた。
- **[x] ① 已修复** — `popup.js` `postProcessRuby`：各 `.ruby-unit` に**零高度・in-flow の読音孪生** `<span class="ruby-reserve">`（`aria-hidden`）を注入。`popup.css` `.ruby-reserve{display:block; width:max-content; height:0; overflow:hidden; font-size:0.5em; visibility:hidden}` で unit の収縮幅を `max(漢字,読み)` に拡張、`.ruby-unit{text-align:center}` で基字を読みの下に居中。零高度で基線不変（BUG-108/363 縦 reserve 温存）、全て font-size 相対＝ズーム免疫。読みが漢字以下の unit は従来の圧縮を維持。三镜像同步 + `content.css` 再生成（`generate-content-css.mjs`）。提交 `fbe6fd4bf`。
- **[x] ② 已加自动化测试** — `hibiki/test/pages/popup_glossary_ruby_hspacing_guard_test.dart` に BUG-846 の 2 テスト追加：popup.css `.ruby-reserve` が `width:max-content`+`height:0`+`font-size:0.5em`、popup.js が `ruby-reserve` を生成・読み text 複製・`aria-hidden`。行為級 `popup_glossary_ruby_element_base_test.js`（node 実行）も reserve 注入後にグリーン（fake DOM に標準 `insertBefore` 追加）。
- **备注**：CI グリーン。実機（Android/Win 離屏）で明鏡「大学」「以前」例文のルビ非重なりを目視要確認。参照元「Hoshi popup.css」はディスク上に実体なし（コメントの私的参照のみ）＝写経不可、自前根治。
