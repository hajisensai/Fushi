## BUG-3194 · 字幕列表行尾动作按钮压住句尾、被压的词点不了查词
- **报告**：2026-10-08（用户：群反馈 otakuDt，例词「チャート」）
- **真实性**：✅ 真 bug。M3E 字幕列表行（`fushi/lib/src/media/video/video_subtitle_jump_panel.dart` `_buildM3eRow`）把「跳到此句 / 复制 / 收藏」三枚动作做成悬停时浮出的叠层：`Positioned(top: 4, right: 6, child: actions)` 叠在 `Stack` 最上层，正文 `Expanded` 占满整行宽（`_rowTextWidth` 不扣动作宽）。桌面鼠标一移到行上动作就浮出，盖住句尾 3 个字左右（渐隐底只是视觉遮挡），点那几个字命中的是动作按钮 / 渐隐底，查不了词。
- **[x] ① 已修复** — 桌面（有悬停）下动作独占行尾一列：行布局在正文之后放一列固定宽（三枚动作的宽度）的动作列，悬停才显形但列宽常驻；`_rowTextWidth` 同步扣掉这一列（行高测量与渲染同源），正文永远不在动作底下。触屏没有悬停（动作走长按菜单），不留列，窄屏不白白少一截正文宽，只在聚焦 / 刚复制时以原叠层短暂浮出。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/video_subtitle_list_row_actions_column_test.dart`：520 与 300 两种面板宽下悬停行，断言正文右缘 ≤ 动作列左缘，且点句尾最后一个字（「ト」）命中查词、下标正确。
