## BUG-866 · 阅读器余白/主题改完不实时生效须退出重进(样式重锚就绪门控静默丢CSS)
- **报告**：2026-07-17（用户：）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/pages/implementations/reader_hibiki_page.dart` `_applyStylesLive`（旧行 2449）+ `_reanchorForStyleChange`（`reader_hibiki/chrome.part.dart:1128`）→ `runUiScaleReanchorOrchestration`（`reader_hibiki_page.dart:675` `if (!gateAllowed) return;`）。
  - 现象：书内设置抽屉调「上下/左右余白」或切「主题/配色」后，**设置菜单即时更新、书正文(WebView)不变**，必须退出书再重进才生效。
  - 链路：余白 `notifyReaderSettingsChanged` / 主题色卡 `setAppThemeKey`+`notifyReaderSettingsChanged`（`settings_actions.dart:392/416`）→ 静态回调 `onSettingsChangedLive`（reader `initState` 绑为 `_applyStylesLive`）。字号/行距/主题/余白**同一条** `_applyStylesLive` 链路。
  - 根因：`hoshiReader` 存在（真实阅读器）时，`_applyStylesLive` 的内联裸换 CSS 只在 `!window.hoshiReader` 时触发；有 `hoshiReader` 时把「换 CSS」全托付给 `_reanchorForStyleChange` → `beginStyleReanchor`（它内部才 `styleEl.textContent = css`）。但 `beginStyleReanchor` 由 `runUiScaleReanchorOrchestration` 经门控 `readerStyleReanchorAllowed = controllerAvailable && readerContentReady && !lyricsMode` 调用，`!gateAllowed` 时编排在 `evalBegin` **之前**就 `return` → `beginStyleReanchor` 从不执行 → **CSS 被静默丢弃**。门控 `readerContentReady` 在切章/重排在飞/内容未就绪窗口内为 false；这些瞬态下改余白/主题，CSS 丢，只能退出重进靠 `_computeStyleTag` 重烤 CSS 到章节 HTML 才见效。
  - 判据：主题是纯颜色 CSS，`<style>.textContent` 一换必重绘——主题改完不生效 ⟺ CSS 根本没换上 ⟺ 门控关掉了 `beginStyleReanchor`（非渲染层问题）。TODO-736 B-1 把裸换 CSS 从「无条件」收进门控后的 `beginStyleReanchor` 引入本回归（此前内联无条件 `el.textContent = css` 不受门控）。
- **[x] ① 已修复** — `reader_hibiki_page.dart` `_applyStylesLive`：把「换 CSS（用户可见效果）」与「样式重锚就绪门控」**解耦**。先算 `reanchorWillRun = readerStyleReanchorAllowed(...)`；内联兜底条件从 `if (!window.hoshiReader)` 改为 `if (!window.hoshiReader || ${!reanchorWillRun})`——重锚**不会**跑（无 hoshiReader / 内容未就绪 / 重排在飞）时就地裸换 CSS 并失效 `paginationMetrics`（让余白几何重新分栏）；重锚**会**跑（gate 开）时不在此换，交给 `beginStyleReanchor` 原子「采锚→换 CSS→置旗」（保翻页保位不裁行）。二者互斥、绝不双换、CSS 永不丢。提交见下。
- **[x] ② 已加自动化测试** — `hibiki/test/reader/reader_live_settings_guard_test.dart` 新增守卫 `applyStylesLive swaps CSS even when reanchor gate is closed (BUG-866)`：源码扫描断言 `_applyStylesLive` 计算 `readerStyleReanchorAllowed(` 门控、且内联兜底换 CSS 覆盖 `!window.hoshiReader || ${!reanchorWillRun}`（退回只 `if (!window.hoshiReader)` 即红）。行为级(真实 WebView)无法 widget 挂载，沿用本文件既有源码扫描守卫模式。
- **备注**：与 BUG-024（面板 live 生效「待用户后补」从未真机确认）同源现象。真机复测：开书→点底栏调整→调上下余白+切主题→正文即时变（不必退出重进）+ 关面板样式仍在。
