## BUG-2331 · iOS 多处页面/模态没有出口，进去就得重启 app
- **报告**：2026-09-09（用户：hajisensai）
- **真实性**：✅ 真 bug。全仓扫描（`lib/src/` 1332 个 dart 文件分五域逐一核过路由/模态/覆盖层）确认 14 处，分四类根因：
  - **① 全局侧滑被拆掉**：`lib/src/models/theme_notifier.dart:1194` 墨水屏分支给 `TargetPlatform.iOS`/`macOS` 注册 `EinkNoPageTransitionsBuilder`（`:303`，`buildTransitions` 直接 `return child`），不经 `CupertinoRouteTransitionMixin.buildPageTransitions`，Flutter 因此不给路由装 `_CupertinoBackGestureDetector`。而 `isCupertinoPlatform`（`lib/src/utils/adaptive/adaptive_platform.dart:84`）在默认 `auto` 设计系统下为 false → iOS 每个页面都是普通 `MaterialPageRoute`，侧滑手势 **100% 挂在这一个 `PageTransitionsTheme` 条目上**，没有任何冗余。墨水屏开关（`lib/src/settings/settings_schema_appearance.dart:131`）没有平台门，iOS 点得到。同文件 `:1206` 的注释早就写明「漏一个平台 iOS/macOS 会因此丢掉 Cupertino 的边缘滑动返回」，eink 分支恰恰犯了这条。
  - **② 出口挂在内容上**：`lib/src/pages/implementations/reader_fushi_page.dart:3169` 的 Scaffold 无 AppBar，返回箭头在 `reader_fushi/chrome.part.dart:2216`，可见条件含 `_hasEverLoaded`——只在 WebView 首屏渲染成功后置位。书打不开（EPUB 损坏 / 解压目录缺失 / WebView 起不来 / 音频槽解析挂住）时整页只剩转圈：`canPop: false` 关掉侧滑、iOS 没有系统返回键、「点空白唤顶栏」在非 Windows 走页内 JS（`hostOwnsWebViewPointerInput`，`lib/src/focus/webview_key_bridge.dart:30`）而 JS 恰恰不存在。三条通道同时落空。网页流媒体页早已为此修过（BUG-2230），阅读器没跟上。
  - **③ 退出绑在一次数据库写入成功上**：小说/漫画/PDF 三页的 `PopScope.onPopInvokedWithResult` 都是 `await onWillPop(); nav.pop();`。`onWillPop`（`lib/src/pages/base_source_page.dart:250`）里是位置 flush + `closeMedia` 两笔 drift 写；一条 `SQLITE_BUSY` 后未 reset 的写语句能让整条连接每次 COMMIT 都抛错（`lib/src/media/video/video_exit_flush.dart:5` 记的 2026-09-04 真机），await 一挂住 `pop()` 永远到不了。小说页更糟：`_popInProgress` 单飞门只在 `finally` 复位，挂住时后续每一次返回都被静默吞掉。视频页 BUG-2119 已改用 `exitAfterPersist`，另外三页没跟上。
  - **④ 进度类模态把唯一出口锁在业务状态后面**：`barrierDismissible: false` + `PopScope(canPop: false)` + 取消按钮被 `busy` / 能力位门控，于是任务不结束就一颗按钮都没有；而这些任务全都没有超时上界（远端 Anki 媒体去重超时 30 分钟、AnkiConnect 逐卡串行、同步 apply 先抢全局互斥锁再逐本传输、批量刮削整库逐项网络请求）。iOS 上 barrier 点不掉、对话框路由没有侧滑、没有系统返回键 → 只能杀进程。
- **[x] ① 已修复** — 一处一处对症，全部保持「出口不随业务状态存亡」这一条口径：
  - `theme_notifier.dart`：新增 `EinkCupertinoPageTransitionsBuilder`，委托 `CupertinoRouteTransitionMixin.buildPageTransitions` 保住手势，无拖动时喂 `kAlwaysCompleteAnimation`/`kAlwaysDismissedAnimation` 保住墨水屏的单帧切换；eink 分支 iOS/macOS 改用它。
  - `reader_fushi_page.dart`：`if (!_hasEverLoaded)` 时无条件挂返回键（key `reader_unloaded_back`）；退出改走 `exitAfterPersist`。`reader_pdf_page.dart` / `manga_fushi_page.dart` 同口径改退出。
  - `home_dictionary_page.dart`：独立查词路由（`showBackButton`）在 Cupertino 档也渲染页头，返回键不再被平台条件藏掉。
  - `dictionary_dialog_page.dart`：删除词典包 try/catch，异常路径照常收掉不可关闭的进度页并弹错误详情。
  - `creator/fields/image_field.dart`：长按预览的全屏 `OverlayEntry` 提升为字段（局部变量在 rebuild 后拿不到旧 entry，遮罩永久残留），补 `onLongPressCancel` 与点击自闭。
  - `video_shader_dialog.dart`：收尾那次 pop 不再受 `mounted` 门控（改用提前捕获的 navigator），`PopScope` 补 `onPopInvokedWithResult` 让返回等价于取消。
  - `scrape_batch.dart` / `anki_media_dedup_dialogs.dart` / `anki_deck_reposition_dialogs.dart` / `sync_compare_dialog.dart` / `anki_mined_card_action_sheet.dart`：任务进行中一律保留一颗出口按钮（新 i18n `dialog_background_close`「关闭（任务继续在后台运行）」），只解绑 UI、不谎称能中止；note viewer 另补关闭键与 `_load` 的 catch（拉字段失败不再永久转圈）。
- **[x] ② 已加自动化测试** —
  - `fushi/test/ios/eink_swipe_back_guard_test.dart`（4 条）：**行为**测试。用真实 `ThemeNotifier` 取墨水屏主题，`debugDefaultTargetPlatformOverride = iOS`，push 第二页后从左边缘 `dragFrom` 拖动，断言回到第一页；反向对照用例把 iOS 项换回 `EinkNoPageTransitionsBuilder` 并断言**滑不回去**（突变验证，证明主用例不恒绿）；另有单帧落位断言与类型级防回退断言。
  - `fushi/test/ios/media_page_exit_affordance_guard_test.dart`（4 条）：源码扫描守卫（带扫描规模哨兵）。全 `lib/` 树禁止 `await onWillPop()`（注释行豁免）、三个自管退出的阅读页必须出现 `exitAfterPersist(`、小说页必须保留 `if (!_hasEverLoaded)` 的 `reader_unloaded_back` 出口。真机坏路径（损坏 EPUB、卡住的 sqlite 连接）widget 测试造不出来，能守住的是代码形状这个契约。
- **备注**：本轮只处理「进得去出不来」。已逐条读过并确认**不是**问题、故意不动的有：视频页（`canPop:false` 自管退出但 `exitAfterPersist` + 常驻 back 控件 + 沉浸锁可唤回，全仓做得最对的一页）、漫画页的 chrome 返回键、`backup_validating_overlay_route`（validating 相位恒有取消）、`desktop_oauth_wait_dialog`（三按钮恒可点且 iOS 不走）、`popup_dictionary_page`（iOS 走带 `closeInApp` 的分支 + 全屏 tap 关闭）、`subtitle_workbench_page`（fullscreenDialog 但 Material 自动渲染 ×）、`onboarding_wizard_page`（显式 `leading: BackButton`）、`aidoku_source_browse_page` / `aidoku_cloudflare_challenge_page`（都有显式 leading）。
