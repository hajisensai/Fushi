## BUG-5456 · 书目还在而正文丢失时同步无法补回原书
- **报告**：2026-11-25。Android 正式版 3.4.0 仍显示原书目及阅读进度，点开漫画报「找不到书籍文件」，实际书目录缺失。电脑有同一书目的完整文件。
- **真实性**：✅ 真 bug。fushi/lib/src/sync/sync_orchestrator.dart:1104 的常规书正文阶段只补上传，手动下载又按书目去重，无法处理本地行仍在、正文目录已丢的状态。
- **[x] ① 已修复** — 提交 1ce54b20c5。云和互联整轮同步检查已有受管书目。通过唯一远端对应关系及删除意图校验后，在原目录补正文，保持原书目的 UID、阅读进度及已有文件。下载失败、取消或对端切换不会提交暂存正文。
- **[x] ② 已加自动化测试** — fushi/test/sync/sync_orchestrator_test.dart 覆盖云端快照及逐目录列举，fushi/test/sync/sync_orchestrator_live_book_test.dart 经真实 HTTP 互联服务验证正文就地恢复、保留本地封面与重复同步幂等。本机运行两组共 31 项通过。
- **备注**：恢复要求远端持有可下载的正文。PDF 原件走互联，EPUB 和单册漫画包也可从云恢复。章节式在线漫画按章缓存，暂无整册包可走这条恢复路径。真机安装版已手工验证文件补回，自动路径以集成回归为证，尚未在真机运行新版本。
