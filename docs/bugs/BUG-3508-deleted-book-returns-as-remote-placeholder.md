## BUG-3508 · deleted-book-returns-as-remote-placeholder
- **报告**：2026-10-17（用户：书架删除《Do Androids Dream of Electric Sheep?》并勾「从所有设备删除」后，书架上仍有这本书，变成带云角标 + 下载按钮的远端占位卡）
- **真实性**：✅ 真 bug。删除只删本地行并写 `book` 类同步删除墓碑（`fushi/lib/src/media/sources/reader_fushi_source.dart` `deleteBook` 的 `writeSyncDeletionTombstone`），墓碑要到下一轮同步才由 `_pushDeletionTombstonesLive` 推给 host 执行删除；在那之前（以及推完后远端清单仍停在 `RemoteLibraryCache` TTL 内时）host 清单里还有这本书。书架远端占位卡的过滤（`fushi/lib/src/pages/implementations/reader_history/remote.part.dart` `_loadRemoteBooks`）只看本地同 key、「仅从本机移除」隐藏表与分架，**从不看本端删除墓碑**——本地行一删 `dedupeRemoteBooks` 就命不中，刚删的书以「云端可下载」卡复活。首页「继续」的远端候选（`home_dashboard_page.dart` → `remoteContinueCandidates`）同一缺口。
- **[x] ① 已修复** — 引擎新增纯函数 `filterOutLocallyDeletedRemoteBooks`（`packages/fushi_engine/lib/sync/fushi_library_host_service.dart`）：按本端 `book` 墓碑剔除远端书，host bookKey 与标题派生键两路都比（墓碑可能写的是别名表里的对端键）；（初版用 host `importedAt > deletedAt` 判重新导入，有跨设备时钟偏差，已在审查跟进中替换，见下）。DB 便捷读法 `getSyncDeletionDeletedAtByKey`（`fushi_core` `database_tags_sync.part.dart`）。书架占位卡与首页「继续」两处接入。
- **[x] ② 已加自动化测试** — `fushi/test/sync/remote_cover_dedup_test.dart` 的 `filterOutLocallyDeletedRemoteBooks` 组（标题键命中 / 对端键命中 / 墓碑后重新导入照常显示 / 无墓碑原样返回）。
- **审查跟进（2026-10-17）**：
  - **时钟偏差**：初版判据「host `importedAt > deletedAt` 视为重新导入」拿 host 时钟比本端时钟，host 时钟超前时刚删的书立刻复活、落后时真正重新导入的书永久被藏。改为只比本端时钟：引擎 `pendingRemoteDeletionKeys`（`packages/fushi_engine/lib/sync/fushi_library_host_service.dart`）——互联 host 会执行墓碑（删行 + 写 host 墓碑，重新导入时清掉 host 墓碑），所以只藏**未送达**的墓碑（`deletedAt > ` 本端互联推送基线 `getDeletionTombstonesPushBaselineMs`）；云盘 / 媒体服务器从不执行墓碑，墓碑在就藏。送达后 host 清单里还有这个键就是 host 删后重新导入的新书。配套两条不变量：① host 删除成功时 `InterconnectSyncBackend.remoteLibraryMutationRevision` 自增，`remoteLibraryCacheProvider` 同步作废互联来源清单缓存；② 调用方先读推送基线、后取清单（`fushi/lib/src/sync/remote_deletion_filter.dart` `loadPendingRemoteDeletionKeys`），保证「基线已推进」时手里的清单是删除后取的。
  - **视频同形缺口已修**：视频库远端占位卡（`home_video_page.dart` `_loadRemoteVideos`）、合集详情的远端成员（`_collectionRemoteContext`）、首页「继续」的远端视频候选（`home_dashboard_page.dart`）都经 `filterOutLocallyDeletedRemoteVideos` 按 `video` 墓碑（bookUid = `RemoteVideoInfo.id`）剔除。
  - 测试：`fushi/test/sync/remote_cover_dedup_test.dart`（判据不看 importedAt、送达前后、云盘恒藏、视频过滤）、`fushi/test/sync/remote_deletion_filter_test.dart`（推送基线读法 + 删除后缓存作废）、`fushi/test/sync/interconnect_delete_push_test.dart`（删除成功才推进 revision）。
