## BUG-936 · 日文IME激活时视频页空格无法播放暂停（BUG-853 修复真机仍失效）
- **报告**：2026-07-20（用户：非沉浸模式下空格播放失效，日文空格还是没办法使用）
- **真实性**：✅ 真 bug —— BUG-853（commit `97fcba434`，已在 develop）早已加了 IME 物理键回退，单测通过但从未真机验证，用户证实真机仍失效。根因在 BUG-853 的**判据太窄**：`hibiki/lib/src/media/video/video_player_shortcuts.dart` 的 `isVideoImeSpacePlayPause` 只认 `logicalKey == LogicalKeyboardKey.process` 这一种 IME 改写值。Windows 日文微软 IME 在不同输入模式 / 引擎下，把物理空格改写成的 `logicalKey` **未必是** `process`（可能是别的非 space 逻辑键），故 `process`-only 判据漏命中 → 视频页两条 `SingleActivator(space)` 路径（media_kit `keyboardShortcuts` + 页级 `_withPageSpaceOverride`）也都匹配不上 `logicalKey` → 按空格无反应。用户报"非沉浸模式"只是测试语境：回退经 `_runWhenImmersiveAllowsShortcuts` 门控，非沉浸下门本就开着，失败纯粹是判据漏命中，与沉浸无关。（排查旁证：media_kit 桌面控件 `CallbackShortcuts` 对未匹配键返回 `KeyEventResult.ignored` 不吞键，`process`/IME 键会正常冒泡到 Hibiki 最外层 `_wrapVideoGamepadControls` 的 `Focus.onKeyEvent`，接线通畅；`Focus(autofocus:true)` 保证窗口与全屏都持焦——故唯一缺口是判据。）
- **[x] ① 已修复** — 把 `isVideoImeSpacePlayPause` 判据从「`logicalKey == process` + `physicalKey == space`」放宽为「`physicalKey == PhysicalKeyboardKey.space`（USB HID 扫描码，IME 绝不改写，是"用户按了物理空格"的唯一稳定信号）+ `logicalKey != LogicalKeyboardKey.space`（即被 IME 改写过）」，仍受无修饰键 + 无文本框 composing 门控。覆盖 `process` 及任意其它 IME 改写值。严格是旧判据的超集：裸空格（`logicalKey == space`）仍走既有 media_kit `SingleActivator(space)` 路径、在冒泡到本回退前就被消费，故绝不双触发（Never break userspace）；即便真机事件不含物理空格或到不了外层 Focus，也不比旧行为更差（无回归）。改点：`video_player_shortcuts.dart` 谓词体 + `video_hibiki_page.dart` 的 `_handleVideoImeSpacePlayPause` 注释。提交：eaa568cd9
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/video_ime_space_playpause_test.dart` 补 BUG-936 守卫用例「IME 改写成**非 process** 的其它逻辑键（`nonConvert`，日文無変換）+ 物理是空格 → 仍命中」，锁住放宽后的语义；原有用例（process 命中 / 裸 space 不命中 / 有修饰不命中 / composing 不命中 / 物理非空格不命中）全部保留仍通过 + 源码守卫（`_handleVideoImeSpacePlayPause` 接入最外层 Focus.onKeyEvent）。提交：eaa568cd9
- **备注**：⚠️ 本修复仍属草稿待真机——放宽判据是当前证据下最可能且严格不劣于旧行为的根因修复，但真机是否彻底解决需在用户实际 IME 环境确认。若真机仍失效，下一步是在最外层 Focus.onKeyEvent 加临时诊断日志抓取用户按空格时的真实 KeyEvent（logicalKey/physicalKey/character/事件类型），精确定位。IME 快捷键教训：任何用 `SingleActivator(logicalKey)` 匹配裸键的桌面路径遇 IME 都因 logicalKey 改写失效，**回退判据必须按 physicalKey**（logicalKey 在 IME 下不可靠，`process` 只是其中一种改写值）。相关 [[project_video_ime_space_pause_bug853_pr180]]。
