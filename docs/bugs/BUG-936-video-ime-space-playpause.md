## BUG-936 · 日文IME激活时视频页空格无法播放暂停（BUG-853 修复真机仍失效）
- **报告**：2026-07-20（用户：非沉浸模式下空格播放失效，日文空格还是没办法使用）
- **真实性**：✅ 真 bug（症状真实，且**用户真机证实** BUG-853 的 `.process` 修复无效——这是本仓唯一一条真机反证），但 ⚠️ **下面这条根因表述与本条自己的修复前提均已于 2026-08-02 被引擎源码证伪，当前真凶待定**——见「根因证伪」栏。以下保留原始记录以存档：BUG-853（commit `97fcba434`，已在 develop）早已加了 IME 物理键回退，单测通过但从未真机验证，用户证实真机仍失效。根因在 BUG-853 的**判据太窄**：`hibiki/lib/src/media/video/video_player_shortcuts.dart` 的 `isVideoImeSpacePlayPause` 只认 `logicalKey == LogicalKeyboardKey.process` 这一种 IME 改写值。Windows 日文微软 IME 在不同输入模式 / 引擎下，把物理空格改写成的 `logicalKey` **未必是** `process`（可能是别的非 space 逻辑键），故 `process`-only 判据漏命中 → 视频页两条 `SingleActivator(space)` 路径（media_kit `keyboardShortcuts` + 页级 `_withPageSpaceOverride`）也都匹配不上 `logicalKey` → 按空格无反应。用户报"非沉浸模式"只是测试语境：回退经 `_runWhenImmersiveAllowsShortcuts` 门控，非沉浸下门本就开着，失败纯粹是判据漏命中，与沉浸无关。（排查旁证：media_kit 桌面控件 `CallbackShortcuts` 对未匹配键返回 `KeyEventResult.ignored` 不吞键，`process`/IME 键会正常冒泡到 Hibiki 最外层 `_wrapVideoGamepadControls` 的 `Focus.onKeyEvent`，接线通畅；`Focus(autofocus:true)` 保证窗口与全屏都持焦——故唯一缺口是判据。）
- **根因证伪（2026-08-02，引擎源码级）**：本条的根因表述「IME 把物理空格改写成**某个**非 space 的 `logicalKey`（`process` 只是其中一种）」**整体不成立**——引擎在被 IME 消费时**根本不发事件**，谈不上"改写成什么"。证据：
  - `LogicalKeyboardKey.process` 是 **Flutter Web 专有**值：裸 keyId `0x0010000070f` 在整棵 engine 树只出现 3 处——web 引擎 `lib/web_ui/lib/src/engine/key_map.g.dart:237`（唯一生产用）+ Android / embedder 两个 **test util**；Windows / Android / iOS / macOS / Linux-GTK 生产键表**全无**（框架侧同理，只在 `keyboard_maps.g.dart` 的 `kWebToLogicalKey`:2398）。
  - Windows 上被 IME 消费的键由 `shell/platform/windows/keyboard_key_embedder_handler.cc:177-183` 在 `VK_PROCESSKEY` 时 `callback(true); return;`（注释原文 "not sent to Flutter"），keyup 也在 `:255-260` 被丢弃 ⇒ **Dart 侧既拿不到 down 也拿不到 up**。
  - 👉 本条**自己那个放宽后的判据同样死在这里**：它要求 `physicalKey == PhysicalKeyboardKey.space`，但被 IME 消费的空格连事件都没有；退一步说，BUG-1239 实测记录 Flutter Windows 对 `VK_PROCESSKEY` 会把 physical/logical 一并降成 0（`hibiki/lib/src/media/video/video_player_shortcuts.dart:254-265` 处的分析）。所以「改判据为物理键」这一步**没有修好任何东西**，只是把死代码从 `== process` 换成了 `physicalKey == space`。
  - 守卫：`hibiki/test/shortcuts/ime_process_key_reachability_guard_test.dart`（BUG-1432）。⚠️ **同族真机确认率 0/3**（BUG-430「真机门禁待验」、BUG-853「待用户验收」、本条本就是前者的真机反证）。
