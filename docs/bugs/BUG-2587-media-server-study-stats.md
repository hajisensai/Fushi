## BUG-2587 · 媒体服务器（Jellyfin / Emby）与互联远端视频不进学习统计
- **报告**：2026-09-18（用户：「媒体库的文件不参与进度统计」，附媒体服务器设置页与 Jellyfin 媒体库浏览页截图）
- **真实性**：✅ 真 bug。`fushi/lib/src/pages/implementations/video_fushi_page.dart` `_ensureWatchTracker` 以 `if (_bookRow != null && _watchTracker == null)` 门控观看统计采集器（`VideoWatchTracker` + `StudyClock`）。媒体服务器条目经 `media_server_browse_page.dart` `_play` → `VideoFushiPage.neutralizedRemote` → `VideoFushiPage.remote` 打开，`_init` 走 `_initRemote()` 提前返回、`_bookRow` 恒 null → 采集器从不建，观看时长 / 字幕字数一秒不写 `study_segments`。互联远端（LAN host 的视频）同路径同症状；旧注释「互联远端媒体归 host 不采集」也不成立——host 端 `fushi_library_host_service.dart` 没有任何替客户端记统计的写入面（`StudyClock` 唯一写入方在本机页面）。
