## BUG-2794 · 发现页搜索资源有时只剩一个源、没有 Nyaa
- **报告**：2026-09-30（用户：「实际去搜索的时候，有时它只能搜到一个源、搜不到 NYAA」「不是 AI，是发现里直接搜」）
- **真实性**：✅ 真 bug。资源 registry 按作品的发现域挑索引器：Nyaa 只进 `anime` 域（`packages/fushi_engine/lib/media/torrent/nyaa_resource_provider.dart:35`、`video_resource_provider.dart:139` `videoResourceProviderApplies`），`tv` / `movie` 域只剩 apibay + Knaben。TMDB 发现条目的域由 `fushi/lib/src/media/video/discovery/video_discovery_adapters.dart` `_mapItem` 判定，旧逻辑只认 genre 16（Animation），**genre 为空**一律落 `tv` / `movie`。TMDB 新建的动画条目常常还没有 genre：2026-09-30 用用户的 TMDB key（zh-CN）实测「死神 千年血战篇 -祸进谭」= tmdb/tv、原语言 ja、产地 JP、`genre_ids: []` → 判成 `tv`。这张卡没被 AniList / MAL 合并成动画时（同次实测 Jikan 每次都 network 失败），详情页「搜索资源」就不打 Nyaa，页面只剩 apibay 一家（Knaben 同次实测多半失败）——即「有时只有一个源、没有 Nyaa」。同一批词按 anime 域搜 Nyaa 每词 56–75 条、零失败，Nyaa 本身没有问题；用户两套数据根都没停用任何资源源、没配 Torznab，排除了停用和跨源去重吞掉 Nyaa 的可能。
- **[x] ① 已修复** — `a759035c222`：新增 `tmdbDiscoveryCategory`（`video_discovery_adapters.dart:1138`）：带 Animation → anime；**genre 整个为空且原语言为 ja** → 也按 anime（这是资料缺失，不代表不是动画）；genre 非空但没有 Animation → 维持 movie / tv（TMDB 明确给出的真人作品，比如日剧《更衣人偶坠入爱河》、真人电影版，不因语言改判）。
- **[x] ② 已加自动化测试** — `fushi/test/media/video/discovery/video_discovery_service_test.dart` 的 `untagged Japanese TMDB entries stay in the anime resource domain`：mock TMDB 返回「空 genre + ja」「空 genre + en」「有 genre 无 Animation + ja」三条，断言域分别为 anime / tv / tv，再把三条都交给真实 `VideoResourceRegistry` + `NyaaVideoResourceProvider`，断言 Nyaa 只被第一条打到一次（`c=1_0`）。去掉修复时这条是红的（Expected anime, Actual tv）。
- **备注**：没有做的事——资源页仍然不会提示「这个域没搜 Nyaa」；日语真人作品（带明确 genre）照旧不进 Nyaa（Nyaa 的 `1_0` 只有动画）。如果以后 TMDB 条目 genre 缺失又不是日语（例如国漫），仍会落 tv 域。
