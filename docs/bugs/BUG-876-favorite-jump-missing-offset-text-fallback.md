## BUG-876 · 书内点收藏「有时」跳不到句子位置（normCharOffset 缺失时静默失败/落章首）
- **报告**：2026-07-18（用户：）。用户补充：点收藏有时能跳到正确位置、有时不能，规律不明。
- **真实性**：✅ 真 bug（数据依赖的间歇失败）。根因 `hibiki/lib/src/pages/implementations/reader_hibiki/chrome.part.dart` `_jumpToFavoriteSentence`（旧行 1963）在 `fav.normCharOffset == null` 时无可用定位锚。
  - 现象：Navigation → 收藏，点某条**有时**跳到该收藏句、**有时**跳不动/落章首；TOC 一直正常（TOC 只走章节 nav 不依赖章内锚）。
  - 链路：收藏写入 `_toggleFavoriteSentence`（`chrome.part.dart:~1947`）`normCharOffset: sentenceRange?.offset`，`sentenceRange = _cachedSentenceRange ?? _cachedSelectionRange`，其 `offset` 来自 JS `getNormalizedOffset`（`_cachedSentenceRange` 设于 `chrome.part.dart:648`，`data.sentenceNormalizedOffset != null` 才非空）。跨 ruby / 复杂节点 / 某些选区 `getNormalizedOffset` 返 null → 该条收藏存 `normCharOffset == null`。跳转 `_jumpToFavoriteSentence`：**同章**分支 `if (normCharOffset != null) restoreToCharOffset(...)` → null 时**静默 no-op**（什么都不动）；**跨章**分支 `_navigateToChapterAndWait(charOffset: null)` → `charOffset ?? -1` → progress 0 → **落章首**。故「能否跳」取决于该条收藏写入时有没有拿到 offset = 用户报的「有时能、有时不能」。
  - 判据：TODO-1308/BUG-686（`e734e505b`）已修「把 normCharOffset 当 0-10000 分数 /10000 误还原→落章首」；本 bug 是其**残留的 null-offset 分支**——offset 存在则跳对（那次修复生效），offset 缺失则无锚可用。收藏条目**总有文本**，却没被用作兜底。
- **[x] ① 已修复** — `chrome.part.dart` `_jumpToFavoriteSentence`：`normCharOffset == null` 时回退到与「搜索跳转」（`onSearchJump`）同一条 **by-text** 定位原语 `ReaderPaginationScripts.scrollToSearchMatchInvocation(fav.text, 0)`——按句文本在章内命中（整句文本在章内通常唯一，hint=0 即命中），不依赖脆弱的持久化 offset：同章直接 `evaluateJavascript`，跨章经 `_navigateToChapterAndWait(preciseLocateJs:)` 排进原子恢复链（settle 后应用，复用 TODO-1309 既有机制）。有效 offset 仍走精确 `restoreToCharOffset` / 字符锚导航（现有正常路径逐字节不变，向后兼容既有可跳收藏，且对**已存的** null-offset 老收藏也生效）。提交：<待填>。
- **[x] ② 已加自动化测试** — `hibiki/test/reader/favorite_jump_text_fallback_bug876_test.dart`：源码守卫断言 `_jumpToFavoriteSentence` 体内含 `scrollToSearchMatchInvocation`（缺 offset 文本回退）、仍含 `restoreToCharOffset`（有效 offset 精确路径）、且门控为 `useOffset = normCharOffset != null`。headless WebView 不可用（State 私有方法 + 章节装载依赖），沿用项目源码扫描守卫范式。
- **备注**：真机复测：收藏一句（正常选区）+ 收藏一句会让 getNormalizedOffset 返 null 的句（如含 ruby / 特殊结构），Navigation→收藏分别点两条都应跳到对应句（不再 no-op / 落章首），跨章收藏亦然。**未覆盖**：offset 非空但因 section 漂移 `charOffsetInRange` 兜回章首的 stale 场景（更罕见，需 JS 层给 restoreToCharOffset 加文本兜底，另行处理）。与 BUG-875（竖排行尾单字翻页）同 PR 但独立根因。
