## BUG-5614 · 视频页里不在本机库的媒体服务器剧没有背景图 / 艺术字
- **报告**：2026-11-28（用户：视频页「继续观看」里，本机库里的剧有斜放海报 + 背景图 + logo 的系列色块，Jellyfin 上还没加入媒体库的剧只有封面取色 + 大字水印；截图在本地，未入库）
- **真实性**：✅ 真 bug，与 BUG-5608 同类（BUG-5608 只修了首页，视频页是另一条取数路径）。视频页把媒体服务器混排成远端占位、按剧名折进合集，色块元数据却只来自本机刮削库：`_videoBlockMeta`（`fushi/lib/src/pages/implementations/home_video_page.dart:13216`，基线 develop + #4604）只读 `_metadataWorkByCollection` / `_mediaImagesByCollection` / `_collectionScrapeMetaById`，纯远端合集这几张表都没有行，结果是空资料，色块退回封面取色。海报倒是从服务器取的（`_membersRemoteSeriesCoverProvider`，`:8940`），背景图 / logo 却从没向服务器要过。根本原因在数据结构：远端占位 `RemoteVideoInfo`（`packages/fushi_engine/lib/sync/fushi_library_host_service.dart:3010`）只带封面 / 剧海报地址，服务器清单里本来就有的作品级背景 / logo（`MediaServerItem.hasBackdrop` / `hasLogo` / `parentBackdropItemId` / `parentLogoItemId`）在 `JellyfinVideoClient._remoteVideoInfoFor` / `PlexVideoClient._remoteVideoInfoFor` 映射时被丢掉。远端散片（服务器上的电影）在系列墙与「继续」里也一样：卡上根本不传元数据。
- **[x] ① 已修复** — 远端占位带上作品级图的**条目 id**：`RemoteVideoInfo.workBackdropItemId` / `workLogoItemId`（只在 client 本地派生、不进互联 wire）。存 id 不存地址：地址带访问令牌、换线路就变，展示时经服务器自己的取图器现拼。取哪个条目的图由新的单一判据 `mediaServerWorkImageItemId`（`media_server_browser.dart`）决定：集先认所属剧的，剧没有才用集自己的；电影 / 剧 / 季先看自己再借上级。服务器页与首页原来的 `_workImageItem` 改走同一判据，新增 `mediaServerWorkArtImage`（按条目 id 出 provider，与服务器页、首页「继续」同一缓存键，同一部剧只取一次）。Jellyfin / Emby / Plex 的映射都填这两个 id；清单落盘（`RemoteVideoListStore`）一并存取，格式版本 1 → 2，旧缓存作废、重新整库枚举一次。视频页：`_videoBlockMeta` 新增 `remoteArt`，本机刮削到的图一律优先，缺的背景 / logo 由服务器补（新 `FushiSeriesMeta.withMissingArt`，只填空位）。接到所有画远端占位的色块：系列墙合集卡与远端散片卡、「继续观看」主卡与行卡（合集与远端散片）、「最近添加」、「已更新未看」。非媒体服务器来源（互联 host、云盘）不拼图，与改动前一致。
- **[x] ② 已加自动化测试** — `fushi/test/pages/home_video_server_series_art_test.dart`（系列墙纯远端剧色块、「继续观看」看到一半的纯远端剧，都画服务器剧的背景图与 logo；互联来源不拼服务器图）；`fushi/test/media/video/media_server/jellyfin_media_server_test.dart`（映射：集取剧的 id，即使集自己有背景；电影取自身；没有图为 null；不进 wire）；`fushi/test/sync/remote_video_list_store_test.dart`（两个 id 落盘往返）；`fushi/test/utils/components/fushi_series_cover_block_test.dart`（`withMissingArt` 只补空位、保留带字背景旗子与其余字段、无可补时返回同一对象）。
- **备注**：已知可读性问题另记，不在本条：logo 代替标题文字是设计意图（`fushi_cover_block.dart:439`），logo 是原语言时用户读不出片名，这一点待拍板，不是 bug。
