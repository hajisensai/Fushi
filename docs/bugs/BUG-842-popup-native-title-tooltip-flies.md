## BUG-842 · Windows查词弹窗调整上下文等按钮原生title提示飞到窗口角落
- **报告**：2026-07-15（用户：截图「文字显示飞了」——视频（BS11）上查词弹窗底栏 tune 按钮的「调整上下文」提示飞到画面右上角）
- **真实性**：✅ 真 bug（结构性）。根因：查词弹窗（`hibiki/assets/popup/popup.js` 内联动作按钮）用 HTML `title` 属性出提示。Windows 桌面下 WebView2 走**离屏合成**（`CreateCoreWebView2CompositionController` → DirectComposition visual `put_RootVisualTarget`，`packages/flutter_inappwebview_windows/windows/in_app_webview/in_app_webview.cpp:105/2021`；再由 Windows Graphics Capture 捕获到 Flutter texture，`windows/custom_platform_view/graphics_context.cc:52-75` / `texture_bridge.cc:54`；父 HWND 是原点(0,0)、不可见的全窗子窗口，`in_app_webview_manager.cpp:135-142`），可见像素还经 `HibikiAppUiScale` 的 `FittedBox` 拉伸（`hibiki/lib/src/pages/base_source_page.dart:149-166`）。原生 `title` 工具提示是 WebView2 生成的**独立 top-level OS 窗口**，按「父 HWND 原点 + WebView 内部未拉伸逻辑坐标」定位，与纹理真正合成的位置（弹窗卡片）两个坐标系乖离 → 提示「飞」到窗口角落。同型的原生右键菜单错位（"跑到很远"）已在 `hibiki/lib/src/pages/implementations/dictionary_popup_webview.dart:961-967` 记录并换 Flutter `showMenu` 规避，但 `title` 无法拦截/重定位。
- **[x] ① 已修复** — `popup.js` 新增内联动作按钮的 **DOM 自绘提示**（`setInlineButtonTip` / `__hoshiShowButtonTip` / `__hoshiHideButtonTip`，`hibiki/assets/popup/popup.js`）：设 `aria-label`、**移除原生 `title`**、悬停/聚焦时在 DOM 内（`__hibikiOverlayParent()`）弹一个按 `getBoundingClientRect` 屏幕坐标定位的 `.hoshi-btn-tip`（随纹理正确合成，不再飞）。按钮行在弹窗顶部故优先置于按钮下方，放不下再翻上方并夹在视口内。`dataset.hoshiTipBound` 保证监听只挂一次（refresh 可反复刷新文案不叠加）。改造三处：`调整上下文`（tune，`ctx-adjust-button`）、`清空已加句子`（`clear-draft-button`，`refreshClearDraftButton`）、无音频反馈（`showNoAudioHint` 原生 title → `aria-label`，本就已有自绘 `.audio-hint`）。CSS：`popup.css` 让 `.hoshi-btn-tip` 与 `.audio-hint` 共用视觉规则。三镜像同步（`assets/browser_extension/vendor/` + `tools/browser-extension/vendor/` 的 `popup.js`/`popup.css` byte-identical）+ `node tools/browser-extension/scripts/generate-content-css.mjs` 重生成 `content.css`。**范围限定**：辞書コンテンツ由来の `title`（图片容器 `popup.js:1070`、结构化内容节点 `element.setAttribute('title', node.title)`）不在本次范围——它们承载词典元数据、悬停在正文行内、改动风险大；若后续用户报同类飞走再统一迁移。提交：7ba4bde45
- **[x] ② 已加自动化测试** — `hibiki/test/dictionary/popup_native_title_tooltip_guard_test.dart`（源码扫描守卫）：断言 popup.js 里 tune / clear-draft 动作按钮不再设原生 `title`、改走 `setInlineButtonTip`；`showNoAudioHint` 不设 `title`；`setInlineButtonTip` 会 `removeAttribute('title')` 并挂 `.hoshi-btn-tip`；popup.css 定义 `.hoshi-btn-tip`。三镜像/`content.css` 完整性由既有 `test/build/browser_extension_popup_parity_guard_test.dart` 覆盖。
- **备注**：真机验证待用户——Windows 桌面在视频/阅读器查词弹窗悬停「调整上下文」/「清空已加句子」按钮，提示应出现在按钮**正下方**而非窗口角落；Android/移动端无 hover，提示走 focus（手柄/键盘）触发，鼠标端不受影响。此为 Windows 离屏 WebView2 结构性问题，模拟器/桌面离屏截图难自动复现原生 OS 提示窗，故留真机目视。
