## BUG-2695 · 漫画阅读器设置里跳过已读/已过滤/重复章节与章节过渡四个开关不生效
- **报告**：2026-09-26（用户：Windows 桌面端读在线（Mihon 扩展）漫画，觉得阅读器比 Mihon 简陋；审计时发现）
- **真实性**：✅ 真 bug。阅读器设置面板（`fushi/lib/src/media/manga/reader/manga_reader_settings_sheet.dart:95-101`，修前）露出 `skipRead` / `skipFiltered` / `skipDuplicate` / `alwaysShowChapterTransition` 四个开关，`MangaReaderPreferences`（`fushi/lib/src/media/manga/manga_reader_preferences.dart`）照常落库，但全仓没有任何读取方：换章 `_onReachedChapterEdge`（`fushi/lib/src/media/manga/reader/manga_fushi_page.dart`，修前 `final int target = _shelfChapterIndex + step;`）只按下标 ±1 走，开关怎么拨都一样。另外 `skipFiltered` 没有可跳的对象（章节列表只有作品页临时的「只看未读」，无汉化组 / 下载 / 书签过滤），`alwaysShowChapterTransition` 没有章节过渡页。
- **[x] ① 已修复** — 换章落点收成纯函数 `resolveAdjacentMangaChapter`（`fushi/lib/src/media/manga/library/manga_adjacent_chapter.dart`，对齐 Mihon：跳过已读章；跳过与当前章同话数的章，下一话多版本时优先同一汉化组），`_onReachedChapterEdge` 经 `_adjacentChapterIndex` 调它；`skipFiltered` / `alwaysShowChapterTransition` 从面板移除（字段保留兼容旧覆盖 JSON），两个失去读取方的 i18n key 一并删除。同批加了「阅读时预下载下一章」（`downloadAhead`，默认开）。提交 `0844769c136`。
- **[x] ② 已加自动化测试** — `fushi/test/media/manga/manga_adjacent_chapter_test.dart`（纯函数：方向、两端、skipRead、skipDuplicate 同组优先 / 未知话数、预下载阈值；源码守卫钉住换章与预下载必须经纯函数）；`fushi/test/media/manga/manga_reader_settings_sheet_test.dart`（面板只露出生效的开关、预下载开关写稀疏覆盖）；`fushi/test/media/manga/manga_reader_preferences_test.dart`（downloadAhead 默认开、旧键往返）。
- **备注**：未真机复测（需要在线源 + 已入书架的作品翻过章节边界）。目标章未下载时走 #1659 恢复的在线直读。预下载只在当前章本身是已下载章时触发（与 Mihon 同口径）：在线直读中不预下载，免得把用户没打算下载的下一话悄悄持久化到磁盘（所有者 2026-09-26 拍板，合并时补的门槛 `_streamingChapter`）。
