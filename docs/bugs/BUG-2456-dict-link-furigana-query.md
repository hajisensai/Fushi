## BUG-2456 · 词典正文链接点击查询词混入振假名，前缀扫描退化成首字汉字
- **报告**：2026-09-11（用户：查词页 明鏡国語辞典 第三版「棒」的 逆引き 惯用句链接，如「足が棒になる」，点击后跳到首字汉字而不是惯用句；「点击惯用句如果开头是汉字会进不去惯用句重定向到汉字」「词典内链接无法跳转」；用户跑的是安装版 `2.4.0-debug.14539`，其 `popup.js` 与修复前 develop 逐字节相同）
- **真实性**：✅ 真 bug（查询词构造层）。根因 `fushi/assets/popup/popup.js`：
  - `handleGlossaryAnchorClick`（MDX 原始 HTML 锚点，修复前 `popup.js:6069`）`const query = (anchor.textContent || '').trim();`
  - `renderStructuredContent` 结构化内容 `<a>` 的 onclick（修复前 `popup.js:2546-2548`）：没有 `?query=` 时以 `element.textContent` 作查询词。
  - 链接文本带 `<ruby>/<rt>` 时（惯用句/交叉引用几乎都带），裸 `textContent` 把读音拼进去；`postProcessRuby` 还会把每个 rt 克隆成 `.ruby-reserve` 插在基字**前面**，真实串是「あし足あしがぼう棒ぼうになる」（jsdom 用真实 明鏡 释义实测）。
  - Dart 侧 `AppModel.searchDictionary` → `FushiDicts.lookup` 是从串首由长到短的**前缀扫描**（`scan_candidates` 只产出前缀），FFI 探针实测：`lookup('足が棒になる')` 首条就是惯用句；`lookup('足あしが棒ぼうになる')` 只剩「足」；`lookup('あし足あしが…')` 只剩「あし」→ 足/脚/肢。这条路径上用户看到的就是首字那个汉字的词条；开头是假名的链接读音跟在后面的汉字后，前缀恰好还能命中更长一段，所以「开头是汉字才进不去」。
  - **但用户报的 明鏡（Yomitan 结构化内容）链接自带 `href="?query=足が棒になる&wildcards=off"`，不走上面两条 textContent 路径。** 真机取证（Windows 离屏 runner，真 WebView2，真实 OS 鼠标 `mouse_event` 点「足」，用户同款 3 本词典 / 3 列 masonry / 折叠 / 字号 21）：DOM 上 pointerdown→click 全落在「足」span，桥收到 `onLinkClick("足が棒になる")`，嵌套弹窗首条即惯用句（证据 `.codex-test/windows-itest/win-itest-20260911-134645-b743658f/`）。**用户原始症状在 develop 上未复现**；用户安装版是 9 月 10 日 15:50 的 debug 通道构建，Dart 侧与 develop 的差异未逐项排除。已请用户补：点击后弹窗的截图、是所有链接都这样还是只某几本词典。
- **[x] ① 已修复** — `dfbf4de4ad`（wip）+ 本轮收尾提交：新增 `linkVisibleBaseText(root)`（只收基字文本节点，跳过 `rt`/`rp`/`.ruby-rt`/`.ruby-reserve`，与 `wrapExpressionInlineKanji` 的 walker 同一过滤集；空白折叠为单空格），两处调用点改用它；`?query=` 仍为权威来源。浏览器扩展两份 vendor 镜像同步（字节锁）。
- **[x] ② 已加自动化测试** — `fushi/test/pages/popup_dict_link_query_furigana_test.dart`（CI 单测门内）：① node 真执行 popup.js 的 renderStructuredContent + postProcessRuby + 链接 onclick / handleGlossaryAnchorClick，断言到达 `onLinkClick` 的查询词为「足が棒になる」，带「裸 textContent 确实被污染」反向对照防空壳（`popup_dict_link_query_furigana_test.js`）；② 源码守卫：两处调用点经 `linkVisibleBaseText`、不再直接拿 textContent，过滤集四项齐全，vendor 镜像带同一 helper。`test/js/dict_glossary_crossref_link.test.mjs`（jsdom）新增 3 条 BUG-2456 用例（原始 ruby / postProcessRuby 之后的 DOM / rp 与空白）。变异实测：把两处退回 textContent → 行为测试与源码守卫双红。
