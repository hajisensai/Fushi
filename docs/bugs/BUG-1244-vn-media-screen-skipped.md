## BUG-1244 · VN独立图片屏被逐句跳转永久略过
- **报告**：2026-07-29（用户）
- **真实性**：✅ 真 bug。纯图片 VN screen 的字符范围为零；有声书逐句跟随按下一 cue 的字符偏移直接选文字 screen，零宽媒体 screen 没有任何 cue 会命中，自动播放时可永远不可见。
- **[x] ① 已修复** — 建屏后、cue 合屏前，把连续零宽媒体屏附到下一句/下一块共同渲染；章尾没有下一句时附到上一屏，保证图片至少随相邻文字出现一次。
- **[x] ② 已加自动化测试** — `vn_shell_smoke_test.dart` 钉住媒体附加发生在 cue 合屏之前、只处理零宽媒体屏，并覆盖前导图片与章尾图片两种归属。
- **备注**：普通文字屏和本来已含文字的图文混排屏不重排。
- **后续**：2026-10-14 [BUG-3395](BUG-3395-vn-merged-image-hides-sentence.md) 取代本条修法——图附到相邻文字同屏时整屏插图把同屏句子挤出屏外；现插图独占一屏，跟随跨过图片屏时按图片暂停开关先停在图上。
