## BUG-2458 · 书架多选态点云书直接下载而非勾选
- **报告**：2026-09-12（用户：截图，书架多选态下点云书「かがみの孤城 [1] PR9原版」没勾选、直接开始下载）
- **真实性**：✅ 真 bug。根因两处：`fushi/lib/src/pages/implementations/reader_fushi_history_page.dart:397`（`_looseSelectionKey` 对远端槽返回 null，注释明写「远端占位卡不可多选」→ 壳 `_bookCardShell` 无 `selectionKey` 时多选态照旧走 `onTap`）+ `reader_history/remote.part.dart:199`（`_buildRemoteBookCard` 的 `onTap` 无条件 `_downloadRemoteBook`，不看 `_selectionMode`）。远端键此前不进选中集的原因是批量栏只有组合/标签/删除三个本地动作，对云书无义——但「不可选」不等于「点了就下载」。
- **[x] ① 已修复** — 远端槽给选择键 `remote_book_<downloadId>` / `remote_srt_<identity>`，两种远端卡走 `_bookCardShell` 的 `selectionKey`（多选态点击=勾选，勾选框占左上角时不画类型徽章）；选中集派生 `_selectedLocalKeys` / `_selectedRemoteKeys`，组合/标签/删除只吃本地键，批量栏新增「下载」按钮（`reader_shelf_batch_download`）对远端键**串行**走既有单本下载链（先退多选、服务不可达只提示一次）；多选态卡内右上角下载按钮与左上类型徽章一并让位；`_pruneStaleSelection` 的存在性集纳入最近一次远端目录。合集行成员远端卡沿用 `selectable: false`。视频库页同款缺口一并根治（用户要求）：那页没有统一卡壳，`handleTap` 多选分发是每张卡各抄一份、远端卡漏抄——收成唯一入口 `_dispatchCardTap(selectionKey, open)`，本地/远端、网格/列表四种散卡全走它；远端视频给 `remote_video_<id>` 键、可见序与剪枝纳入远端目录、批量栏加串行「下载」（`home_video_batch_download`）、本地三动作只吃 `_selectedLocalUids`；源码守卫 `video_tags_menu_source_guard_test.dart` 改钉「`_toggleSelection` 只在分发器一处调用」。
- **[x] ② 已加自动化测试** — `fushi/test/pages/reader_remote_multiselect_test.dart`：多选态点远端卡不触发 `getRemoteBook`、进选中集计数、下载可用/删除与组合禁用、再点取消；勾选两本→批量下载先起第一本、第一本收尾后才起第二本、未勾的不动；多选态卡内下载按钮 `onPressed` 为 null。`test/media/media_selection_controller_test.dart` 补 `hiddenSelectedCountWhere`。 视频侧 `fushi/test/pages/home_video_remote_multiselect_test.dart`（网格 / 列表多选态点远端卡不建流播、批量下载串行只下勾选项）。
