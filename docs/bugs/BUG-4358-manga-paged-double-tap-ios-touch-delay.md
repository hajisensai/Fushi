## BUG-4358 · iOS 漫画分页模式双击缩放几乎总是先弹控制层：WebView 触摸经 Flutter 手势竞技场延后投递
- **报告**：2026-11-06（应用内反馈 P2jQzOBBag，重新提交自 IDF2uWUvlf；录屏 C-y5hM-wnz。iOS 27.2 / iPhone19,2 / 分页模式 / TestFlight 3.3.0 (24555)）。关联 BUG-3682（第二击按下即武装双击）、BUG-4224（只修条漫的缩放锚点滚动）。
- **真实性**：✅ 真 bug（结构性根因由代码路径 + 引擎源码推定，未在 iOS 设备上打时间戳实测）。
  - 双击判据全在页内 JS：空白单击挂 `DBL_MS`=300ms 定时器再发 `onTapEmpty`（→ `_toggleFloatingChrome`），第二击 **pointerdown** 落在窗口内才取消（`fushi/lib/src/media/manga/manga_overlay_html.dart:2784-2858`，按下武装 `:3036`）。判据测的是 **DOM pointer 事件之间**的时间。
  - 漫画正文 WebView（`fushi/lib/src/media/manga/reader/manga_fushi_page.dart` `_buildWebViewSurface`）在 iOS 上走引擎默认的 `eager` 手势阻塞策略：`FlutterTouchInterceptingView` 装 `FlutterDelayingGestureRecognizer`（`delaysTouchesBegan`/`delaysTouchesEnded` = YES，且所有其它识别器 `shouldBeRequiredToFailBy` 它），WKWebView 派发 DOM 触摸事件的识别器要等它失败——即 Flutter 手势竞技场裁决、`acceptGesture` 经平台通道回到原生 `releaseGesture`——才收得到这次触摸。每次触摸序列都要一次异步往返，竞技场到松手才裁决时 pointerdown 与 pointerup 一起到。第二击的 pointerdown 因此晚于挂起单击的定时器，悬浮栏先被切出来；快速三击时第二、三击凑成一对才偶尔放大——与录屏一致。BUG-3682 的「按下即武装」依赖 pointerdown 实时到达，在 iOS 上被这层延迟抵消。
  - 本来有对口开关：flutter_inappwebview 的 `preventGestureDelay`（文档「prevent gesture delay on iOS caused by Flutter's gestures handling between native/platform views」），但 1.1.2 的实现（`InAppWebView.swift` `hitTest`）按类名 `DelayingGestureRecognizer` 找识别器去禁用，引擎早已改名 `FlutterDelayingGestureRecognizer`，是空操作。
- **[x] ① 已修复** — pub-cache 覆盖补丁 `ci/patches/hosted/flutter_inappwebview_ios-1.1.2/lib/src/in_app_webview/in_app_webview.dart`（与既有 BUG-4013 Swift 覆盖同一机制，说明见同目录 `PATCHES.md`）：`preventGestureDelay: true` 映射到 `UiKitView.gestureBlockingPolicy = UiKitViewGestureBlockingPolicy.doNotBlockGesture`（引擎不装延迟识别器，盖在 WebView 上的 Flutter 层仍由同步命中测试拦住），其余 WebView 保持插件默认策略；漫画正文 WebView 传 `preventGestureDelay: kMangaWebViewPreventGestureDelay`。没有拉长 `DBL_MS`。
- **[x] ② 已加自动化测试** — `fushi/test/media/manga/manga_webview_gesture_policy_test.dart`：映射函数、`IOSInAppWebViewWidget.build` 产出的 `UiKitView` 策略、漫画 WebView 构造参数源码守卫、覆盖补丁与锁定版本同号。（测试未在分支上运行，统一在合并后验证。）
- **备注**：未在 iOS 设备上复测原始失败路径（本批次不做真机验证），也未对 JS pointerdown / Flutter 指针事件打时间戳实测投递延迟；待补：iOS 真机分页模式空白处双击 → 只缩放不弹栏、单击 → 300ms 后切栏、查词弹窗打开时点弹窗外仍被 barrier 拦住。附带诉求「quick zoom out 与双击缩回语义重叠」属 UX 取舍，未改，列在 PR 待决策。
