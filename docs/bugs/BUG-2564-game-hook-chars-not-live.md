## BUG-2564 · galgame hook 字数 500 字/60 秒才落库、不经 StudyClock，学习统计翻几行后仍为 0
- **报告**：2026-09-16（用户：VN 里翻了几行，统计中心「Today」卡只有 Lookups 有数，0 characters / 0 min / Sessions 0；问「游戏是不是要按什么按钮才会进学习活动」）
- **真实性**：✅ 真 bug。字数侧：`fushi/lib/src/mining/gal_hook_session_controller.dart` 的 `_recordActivity` 把每行字数记进自家 `GalHookActivityAccumulator`，只有 `shouldFlush`（累计 ≥ 500 字，或行间隔 ≤ 30s 的活跃时长 ≥ 60s，`gal_hook_activity_accumulator.dart:17-18`）或 `stopCapture` / `close` 才 `_flushGameActivity` → `_resolveActivityWriter` 里 `database.upsertStudySegment(StudySegmentsCompanion.insert(uid: newStudySegmentUid(), …, chars: charsDelta))`——每次 flush 一条**新 uid**、`startAt == endAt`，绕开了 v92 统计域唯一写入面 `StudyClock`；翻几行远不到阈值，统计页读到的就是 0。同一写入方的 `dateKey` 用 `FushiTimeFormat.dayKey(now)`（日历日），不是 `FushiDatabase.statDateKeyOf`（统计日重置小时），跨过重置边界的段会落错「今日」。时长侧 0 min / Sessions 0 是既有契约（§3.1）：游玩时长只在游戏退出或停止捕获时由 `GalgamePlayTracker` 结算一行 `galgame_sessions`，且 `kMinSessionSeconds = 60` 以下不入库——不是本条要改的。另：只有解析出 `galgames.id`（游戏在库里，launch 自带 / attach 经 PID→exe 反查）字数才有归属，不在库里的进程按设计不计。
- **[x] ① 已修复** — 字数写入面收敛到 `StudyClock`：`_beginActivitySession` 解析出库内身份且 DB 已接上时建 `StudyClock(mediaKind: game, accrual: explicit, tick: 5min)` 并起表，每行 `addChars` 后去抖 2s `flushNow()` 写穿（同 uid 绝对值 upsert，不等停止监听统计页就能读到），`stopCapture` / `close` / 退出快杀 `await stop()`；删除 `GalHookActivityAccumulator` 与 `GalHookActivityWriter`。`StudyClock` 显式记账模式下 `addChars` / `addPages` 也标记本窗有记账（否则只喂字数的时钟每次 tick / flushNow 都封段、每行一个 uid）。dateKey 随 `StudyClock` 走 `statDateKeyOf`。守卫 ② 收紧为「`upsertStudySegment` 只有 `StudyClock` 一个写入方」。提交 `39c741bc5bd`。
- **[x] ② 已加自动化测试** — `fushi/test/mining/gal_hook_session_controller_test.dart`「BUG-2564：hook 台词字数经 StudyClock 落 game 段，去抖后不等停止监听即可见」（attach 经 PID→exe 反查库内身份；两行 5+6 字在 stopCapture **之前**就读到同一 uid 的 11 字段；durationMs 0；重置小时 4、02:30 的段 dateKey 落「昨日」；stopCapture 后仍是同 uid 同值）；两条 BUG-1085 计数用例改为断言真 DB 的段；`fushi/test/media/audiobook/study_clock_test.dart`「显式记账模式：只喂字数的时钟不因无 addActiveMs 而每窗封段」；源码守卫 `fushi/test/tools/statistics_write_convergence_guard_test.dart` ②。
- **备注**：用户问题的答案：不用按任何按钮——游戏在库里、从库启动或 attach 到它的进程，hook 到的台词字数就自动进「学习活动」的 game 域；游玩时长与 Sessions 要等游戏退出 / 停止捕获且满 60 秒才结算一行。统计中心页只在打开与操作后重查，不会自动刷新。
