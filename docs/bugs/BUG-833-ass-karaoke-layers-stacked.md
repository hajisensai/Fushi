## BUG-833 · OP 多层卡拉 OK 同句三层被竖排堆叠成「三个字幕」
- **报告**：2026-07-15（用户：Kamiina Botan S01E07 `.ja.ass`「怎么有3个字幕op的时候」）
- **真实性**：✅ 真 bug。该 OP 每句歌词是 **3 条同刻 Dialogue**（ASS Layer 3/4/5）：光晕层 `\bord5\blur10\1a&HFF&`（填充全透明只剩模糊描边）+ 主文字层 `\iclip(...)` + 点缀层 `\c&H..&\clip(...)`（粉色只在小块路径内露出）。libass 语义：**碰撞（竖排避让）只发生在同层事件之间**，不同层同位叠画成一行特效。我们（修复前）：①`hibiki/lib/src/media/video/video_subtitle_overlay.dart` `_positionKey` 不含 Layer → 三层同锚点同组 → Column 竖排堆叠=「三个字幕」；②parser 不解析 Dialogue Layer 列、不消费 `\1a`（光晕层填充画成不透明）、`\clip` 静默丢弃（点缀层整行粉色盖主文字）。
- **[x] ① 已修复** — parser（`packages/hibiki_audio/.../ass_parser.dart` + `subtitle_markup.dart`）：解析 Layer 列 → `SubtitleMarkup.layer`；`\1a&HXX&`/`\alpha&HXX&` → `SubtitleSpan.fillOpacity`（op=1-a/255，\alpha 按主填充近似）；`\clip(...)` 置 `markup.hasClip`（`\iclip` 忽略=画全部近似）。overlay：`_positionKey` 掺 `:L<layer>`（Layer 0 不加后缀，srt/vtt 键字面不变）→ 不同层各自成组同锚点同位叠画、同层碰撞堆叠不变；`_styleForGrapheme` 把 fillOpacity 施于填充色（描边层不受影响=辉光正确）；`_buildSubtitleLayer` 丢弃「有同文本兄弟 cue 的 \clip 点缀拷贝」（真裁剪不支持时画全条=错色；独立 cue 的 \clip 仍照画忽略裁剪）。
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/video_subtitle_karaoke_layers_test.dart`：真实三层结构最小 .ass——parser 断言 layer=[3,4,5]/fillOpacity=0/hasClip 仅 \clip 层；widget 断言只剩 2 份拷贝（点缀被丢）、两份**同 top 同位叠画**（修复前红：三份竖排）、光晕层填充 alpha=0 且主文字不透明。
- **备注**：仍不支持真 `\clip`/`\iclip` 矢量裁剪（点缀色块丢失、iclip 挖孔不挖，观感近似）；`\alpha` 按主填充近似（不建模 \2a/\3a/\4a）。姊妹链：[[BUG-799]] [[BUG-800]] [[BUG-819]] [[BUG-820]] [[BUG-822]]。
