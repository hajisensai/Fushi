## BUG-4892 · 卷号后面跟副标题、卷号前夹标签、『』特典册的分卷不归组，整套散在书架上
- **报告**：2026-11-17（用户：书架截图，「週に一度クラスメイトを買う話」小说十卷 + 九本 BOOK☆WALKER 特典册全是散卡，「想办法根本性优化一下这些自动合集」）
- **真实性**：✅ 真 bug，用本机书库 142 本的真实书名复现。根因在结构：`parseBookSeriesKey`（`packages/fushi_engine/lib/media/collections/book_series_key.dart`）逐本书名跑一串**锚在结尾**的正则——`_splitVolumeSuffix` 只认「卷号是书名最后一段」，卷号匹配不上才剥**一层**结尾标签、剥完就停。书名只要不是「系列名 + 卷号」收尾，整串就成了系列键，各卷互不相同，`BookSeriesGrouper` 一组都凑不成。实际撞上的三种形态：
  - 卷号后面跟成对副标题，且同一套书中途换副标题：`週に一度クラスメイトを買う話２　～ふたりの時間、言い訳の五千円～` / `…５　～ふたりの秘密は一つ屋根の下～`；第 1 卷无卷号 `…話　～…～`。
  - 整个书名包在『』里再挂店铺特典后缀：`『週に一度クラスメイトを買う話２　～…～』BOOK☆WALKER限定書き下ろしショートストーリー`。
  - 卷号前夹着特典标签：`魔法少女にあこがれて【電子限定特典付き】 (1) [9fb54b5c]`（同系列 2–11 卷在合集里，1、9 两卷落单）。
- **[x] ① 已修复** — 重写系列键解析那一块，按书名文法从外往里剥，不再是互不相干的结尾正则：
  - `_splitVolumeSuffix` 改成循环剥：卷号（至多一个）、出版 / 版本标签、成对副标题（`～…～`、`─…─`、` -…-`）三者任意顺序，剥到剥不动；剥到系列名为空就不剥。副标题不进系列键。
  - 结尾认不出卷号时再认「卷号夹在系列名与自由副标题之间」（`ソードアート・オンライン3 フェアリィ・ダンス`、`魔法科高校の劣等生(3) 九校戦編`），数字前须是非 ASCII 字符或空白、数字后须有空白、至多三位。
  - 新增 `_seriesFromQuotedTitle`：`『正篇』+ 后缀` 的系列键 / 卷号取引号里的正篇，记 `BookSeriesKey.bonus`（特典册）；位置判据（`compareBookSeriesPosition` / `bookSeriesPosition`，AI 合集排序共用）加一档「正篇先于同卷特典册」，特典册与正篇不算位置冲突。
  - 目录语境（`parseBookVolumeFolderName`）走 `deep: false`，行为不变——卷号前那段要和系列目录名原样比较。
  - 本机书库实测（只读导出书名跑新解析）：小说 19 本、`円満家庭…` 正篇 + 特典册 2 本、`魔法少女ノ魔女裁判 クリエイターズアートブック -虚実- / -表裏-` 2 本成组，`魔法少女にあこがれて` (1)(9) 并入已有合集；已在合集里的 96 本归属不变。
- **[x] ② 已加自动化测试** — `fushi/test/media/collections/book_series_grouper_test.dart`：解析层四组（副标题 / 换副标题 / 无卷号首卷、『』特典册与位置、卷号前后夹标签、卷号夹在中间及六条反例），归组层两条（十九本乱序导入 → 一个合集且特典册紧跟同卷正篇、幂等；带标签的卷并进已有合集并按卷序排）。
- **备注**：
  - 行为变化：系列名不再带副标题，新建的合集名是 `週に一度クラスメイトを買う話` 而不是 `… ～ふたりの時間、言い訳の五千円～`；已有合集不改名。
  - 规则仍认不出、留给「AI 整理」的：续作改名（`ろりめし` / `ろりめし おかわり！`）、片假名数字（`マホウショウジョニーマルイチサン`）、罗马数字 + 上下卷（`リビルドワールドI＜上＞　誘う亡霊`）。
  - 未做设备复测（真机验证已取消）；书架页归组走的就是 `BookSeriesGrouper.groupAll`，由上面的内存库用例覆盖。
