## BUG-4284 · 无头服务端 bind 配成具体地址或 ::1 仍监听全部网卡
- **报告**：2026-11-10（用户：互联 host 安全审查 V-E4 / H7）
- **真实性**：✅ 真 bug。（行号按 94317ab6295）`packages/fushi_server/lib/src/headless_host.dart:414-421` 用 `_isLoopbackBind(config.bind)`（`:588-589` 只认 `127.0.0.1` / `localhost`）把 `bind` 压成一个布尔，只传 `allowLan: !_loopbackOnly` 给引擎；`packages/fushi_engine/lib/sync/fushi_sync_server.dart:816-850` 的 `_bindListener` 对非回环一律 anyIPv4（明文）/ 双栈 anyIPv6（TLS）。于是 `bind: 192.168.1.5`、`::1`、`127.0.0.2` 实际全网卡监听；`:553` 启动日志打印的是配置值而非实际地址；`config/server_srs_config.dart:169-170` 另有一份 `isLoopback`（多认 `::1`），两份判据不一致。修复前实测：`bind: ::1` + `p2p: true` 的 host `p2pStatus().reason` 为 `start_failed`（被当成对外监听去开隧道），而不是 `loopback_bind`。
- **[x] ① 已修复**（`9f20663d8fb`）— 引擎新增 `sealed class FushiListenScope`（`loopbackV4()` / `lan()` / `exact(address)`，`isLoopbackOnly`）；`FushiSyncServer` 构造加 `listenScope`（不给时由 `allowLan` 推出，app 不改），`_bindListener` 按 scope 分支，`loopbackV4` 与 `lan` 行为逐字不变，`exact` 只绑该地址、失败照常抛（不回落全网卡）；新 getter `boundAddress` / `listensBeyondLoopback`；`_hostAddresses` 改按 `listensBeyondLoopback` 判，`exact` 时网卡地址只保留监听的那一条（`publicUrls` / `extra` 不过滤）。无头：`config/server_config.dart` 新顶层 `parseBindSetting(bind)` → `({scope, warning})`（空 / `0.0.0.0` / `::` → lan；`localhost` / `127.0.0.1` → loopbackV4；其他 IP 字面量 → exact；主机名 → lan 并警告）；`ServerAnkiConnectConfig.isLoopback` 改用它；`headless_host.dart` 传 `listenScope`、删 `_isLoopbackBind`、`_loopbackOnly = !server.listensBeyondLoopback`（P2P `loopback_bind` 随之认 `::1` / `127.0.0.2`），启动日志打 `server.boundAddress`。
- **[x] ② 已加自动化测试** — `fushi/test/sync/fushi_sync_server_listen_scope_test.dart`（真 server：`exact(127.0.0.1)` / `exact(::1)` 只听回环且 `::1` 时 127.0.0.1 连不上；`exact(本机网卡 v4)` 时 127.0.0.1 连不上、该地址连得上；TLS + exact 时配对链接只公布该网卡地址；`lan()` / `loopbackV4()` / 只给 `allowLan` 不回归）；`packages/fushi_server/test/bind_setting_test.dart`（兼容表逐行、`localhost` 给 loopbackV4、主机名警告、`ServerAnkiConnectConfig.isLoopback` 认 `::1` / `127.0.0.2`）；`packages/fushi_server/test/headless_host_bind_test.dart`（真 HeadlessHost：`bind: localhost` 时 127.0.0.1 可连；`bind: ::1` + p2p 时 reason 为 `loopback_bind` 且 v4 不监听——修复前红）。
- **备注**：取舍 T7：写具体 IP / `::1` / 其他回环地址的部署升级后只听该地址，其他网卡连不上，启动日志打印实际监听地址；`0.0.0.0` / `::` / 空 / `localhost` / `127.0.0.1` 与升级前相同；主机名仍全网卡并打警告。
