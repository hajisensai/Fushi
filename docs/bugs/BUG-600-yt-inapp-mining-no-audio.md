## BUG-600 · 油管应用内制卡音频源指向audio-only DASH致stall无音频gif连坐
- **报告**：2026-07-07（用户：TODO-1301）
- **真实性**：✅ 真 bug。根因 `hibiki/lib/src/pages/implementations/video_hibiki_page.dart:1690`（原）——应用内播放路径 `_loadRemoteEpisode` **无条件** `setMiningAudioSourceOverride(urls.audioStreamUrl)`，把制卡音频源指向 YouTube audio-only DASH 流。resolver 自述（`youtube_source_resolver.dart:53-58`）：audio-only DASH 流 ffmpeg `-ss`(置 `-i` 前) HTTP seek 会 stall→撞 120s 超时→无句子音频（muxed itag18 抽音频 2s 成功）。`requireAudio` 默认 true → 音频抽取失败 → mine 整卡 abort → 已抽好的 GIF 连坐丢弃（故既没音频也没 GIF）。批量路径（`youtube_clip_miner.dart:65-67`）**正确**用守卫 `audioSource: miningVideoHasAudio ? null : audioStreamUrl`；应用内路径违反，且 `miningVideoHasAudio` 信号在 `UrlStreamVideoClient`、`RemoteVideoStreamUrls` 两个边界被丢（`stream_video_launch.dart:32-39` 构建 client 时未透传 `resolved.miningVideoHasAudio`）。
- **[x] ① 已修复** — 方向 A 信号接线（零引擎改动）：`YoutubeResolvedSource.miningVideoHasAudio` → `UrlStreamVideoClient` 新增字段（`url_stream_video.dart`）→ `RemoteVideoStreamUrls` 新增字段 + `fromJson` 解析（`hibiki_library_host_service.dart`）→ `stream_video_launch.dart` 构建 client 时透传（YouTube 分支传 `resolved.miningVideoHasAudio`、直链分支传 `true`）→ `video_hibiki_page.dart` 改为 `setMiningAudioSourceOverride(urls.miningVideoHasAudio ? null : urls.audioStreamUrl)`，与 `youtube_clip_miner.dart:67` 逐字一致。muxed 时制卡音频源置 null，引擎回落 miningSource(muxed 360p) 抽音频。提交：d76ed1c8e
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/youtube_inapp_mining_audio_source_test.dart`：①信号沿 `UrlStreamVideoClient.remoteVideoStreamUrls` 不丢（muxed=true 且 audioStreamUrl 非空的核心场景 → 选择公式得 null）；②`RemoteVideoStreamUrls.fromJson` 解析 `miningVideoHasAudio`（含缺字段/脏数据默认 false）；③`buildStreamVideoLaunch` 直链分支 → `miningVideoHasAudio=true`；④源码扫描守卫 `video_hibiki_page.dart` 复用批量守卫公式且不再无条件指向 audio-only 流。
- **备注**：方向 A 只做信号接线，未碰 1270 活跃区共享引擎文件（`immersion_mining_engine.dart` / `immersion_mining_request.dart` / `desktop_audio_clipper.dart` MiningMediaCompression / `app_model.dart` mine 方法），未改 `requireAudio` 语义或引擎降级逻辑（方向 B/C 需与 1270 协调，本任务不做）。真机联网待验证项：该视频 audio-only seek 补 reconnect 后是否仍 stall、该视频有无 muxed 流、方向 A 后 muxed 抽音频 2s 成否——均需真设备联网。
