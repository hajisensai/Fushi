## BUG-756 · 歌词模式唤不出隐藏底栏 + esc 退不出
- **报告**：2026-07-12（用户：歌词模式音频跟随失效，并且唤不出隐藏的底栏；esc 也没办法退出）。
- **真实性**：✅ **真 bug（歌词独立文档缺输入桥 + 手势抢焦点从不 reclaim）**。歌词模式把 WebView 整页 `loadData` 换成独立文档 `LyricsModeHtml`（`reader_hibiki/lyrics.part.dart` 的 `_loadLyricsPage`），该文档**唯一**回 Dart 的桥是中键 seek（`lyrics_mode_html.dart:391` `callHandler('onLyricsPointerSeek')`）。正文文档由 hoshiReader 转发一整套输入桥（`onTap`/`onTapEmpty`/`onSpaceKey`/`onSwipe`…，`reader_hibiki/webview.part.dart`），底栏唤出**只**挂在 `onTap`(`webview.part.dart:1585`)/`onTapEmpty`(`webview.part.dart:1628`) → `_toggleChrome`/`_handleFloatingChromeReveal`(`chrome.part.dart:852/957`)。歌词文档从不发这两个信号（`_lyTapEnd` 命中 `.cue` 才查词，命中空白旧码 `if (!cueEl) return;` no-op，`lyrics_mode_html.dart:347-359`），Flutter 侧又没有兜底 GestureDetector 包 WebView（`reader_hibiki_page.dart` build）→ **① 底栏一旦隐藏就再无任何手势能唤出**。第二半：桌面 WebView2 在 pointer 手势里抢走 OS 焦点，正文靠每个手势 handler 调 `_reclaimReaderFocusAfterGesture()`（`lookup.part.dart:80`，`_focusNode.requestFocus()`）把焦点夺回，ESC 才能到 `_handleKeyEvent` / 全局「Esc 退出整页」处理器（`shortcuts/global_navigation.dart:35`）。歌词 tap 路径**一处 reclaim 都没有** → 焦点滞留 WebView → **② ESC 到不了 Flutter，退不出**。两症状同根：歌词是二等输入公民。
- **[x] ① 已修复** — `c41330804`。① `lyrics_mode_html.dart` `_lyTapEnd`：命中空白（`!cueEl`）改为 `callHandler('onLyricsTapEmpty')`（不再 no-op return）。② `webview.part.dart` 新增 `onLyricsTapEmpty` handler：无条件唤/收隐藏底栏（挤压 `_toggleChrome`、悬浮 `_handleFloatingChromeReveal`）——**不看 `tapEmptyToHideChrome`**（那开关管正文点空白是否收起，歌词没别的唤出途径不能被它关死），收尾 `_reclaimReaderFocusAfterGesture()` 夺回焦点。③ `webview.part.dart` `_onChapterLoadComplete` 歌词分支就绪后即 `_reclaimReaderFocusAfterGesture()`，让 ESC 从进入歌词模式那刻起就能退（不必先点一下）。根因修（补齐缺失的输入桥 + 焦点纪律），非绕过。
- **[x] ② 已加自动化测试** — `test/pages/reader_lyrics_input_bridge_guard_static_test.dart`（3 用例：歌词 HTML 空白 tap 发 `onLyricsTapEmpty` 且旧 `if (!cueEl) return;` 消失；reader 注册的 `onLyricsTapEmpty` handler 体含唤/收底栏 + reclaim 焦点；`_onChapterLoadComplete` 歌词就绪分支含 reclaim）。reader 页含真 InAppWebView 无法 widget 挂载，最强可落地层是生成 HTML 契约 + 源码扫描守卫。
- **备注**：reader/WebView/桌面输入焦点类。代码 + 单测绿、`flutter analyze` 0 issue、`dart format` 0 改动。**真机肉眼复测原始失败路径**（开有声书 → 进歌词模式 → 底栏隐藏后点空白应唤出/再点收起、ESC 应能退出书）待用户后补——桌面 WebView2 焦点抢占是平台行为，必须真机验。与 BUG-757（歌词音频跟随 snap）同批修。
