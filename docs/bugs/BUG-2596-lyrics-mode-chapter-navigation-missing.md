## BUG-2596 · 歌词模式顶栏没有章节导航键，无法跳章
- **报告**：2026-09-19（用户：「歌词模式没有跳章节按钮」）
- **真实性**：✅ 真 bug（真实代码路径）。`fushi/lib/src/pages/implementations/reader_fushi/chrome.part.dart` `_shouldRenderReaderControl`（改前 `:1524-1526`）把 `navigation` 与 `gallery` 一起 `return !_lyricsMode`，歌词模式顶栏整颗导航键不渲染；且就算露出来也不能直接接 `_jumpToChapterAnchor`（`navigation.part.dart:734`）——它走 `_navigateToChapter` 把歌词文档换成 EPUB 章而 `_lyricsMode` 仍为真（歌词消失、cue 推进再找不到 `__lyricsSetCue`），导航抽屉里的书内搜索 / 字数跳转 / 跳到收藏（`chrome.part.dart` `_buildQuickSettingsSheet` 与 `_jumpToFavoriteSentence`）同样是正文导航。基线集成测试（Windows 离屏 runner，`win-itest-20260919-134250`）钉死：歌词模式唤出 chrome 后 `fushi_reader_navigation_button` 找不到。
- **[x] ① 已修复** — 顶栏导航键在歌词模式也渲染；`_jumpToChapterAnchor` 歌词分流到 `_jumpToChapterInLyricsMode`：把音频定位到该章首句（`_firstCueOfSection`：`fushi-cue://` 走 `sectionFirstCue`、独立 SRT 书走 `_srtChapterRanges` 分桶首句、SMIL/JSON 走 cue `chapterHref` 精确匹配，**不做文本模糊反查**），cue 推进把歌词高亮/窗口带过去；该章没有 cue 才退出歌词模式再正文跳章。导航抽屉在歌词模式不接书内搜索 / 字数跳转（歌词里没有落点，传 null 按面板既有契约不渲染）；「跳到收藏」歌词模式改为 `skipToCue` 到收藏所在句（与「播放收藏」共用 `_favoriteAudioCue`）。
- **[x] ② 已加自动化测试** — `fushi/test/pages/reader_lyrics_chapter_nav_and_stats_static_test.dart`（BUG-2596 组：分流顺序、首句定位、搜索/字数跳转不接线、收藏走音频、顶栏 key）+ `reader_lyrics_top_chrome_static_test.dart` 改为「导航在歌词模式在场、图集不在」；真机门 `fushi/integration_test/reader_lyrics_settings_and_chapter_nav_itest.dart`（进歌词模式 → 唤出顶栏断言导航键 → 先跳到第 4 句再 `debugJumpSection(0)` → 仍是歌词文档且音频回到章首句）。
- **备注**：有声书面板「章节」tab 原本就是「先文字跳章再 `skipToCue`」，歌词模式下同样经 `onJumpSection` → 本修复分流。
