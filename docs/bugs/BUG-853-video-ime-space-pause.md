- **真实性**：✅ 真 bug（症状真实），但 ⚠️ **下面这条根因已于 2026-08-02 被引擎源码证伪，当前真凶待定**——见「根因证伪」栏。以下保留原始记录以存档：根因 `hibiki/lib/src/pages/implementations/video_hibiki_page.dart` 视频页两条空格「播放/暂停」路径——media_kit controls 的 `keyboardShortcuts`（`buildVideoPlayerShortcutsFromRegistry`，`video_player_shortcuts.dart:134`）与页级 `_withPageSpaceOverride`（`video_hibiki_page.dart:5437` 附近）——都用 `SingleActivator(LogicalKeyboardKey.space)` 匹配 `logicalKey`。Windows 微软 IME 激活时裸 Space 的 `logicalKey` 被引擎改写成 `LogicalKeyboardKey.process`（与阅读器 TODO-847 同一现象，见 `hibiki/lib/src/shortcuts/reader_space_override.dart:16`），两条路径都匹配不上 → 按空格既不被内层消费也不被页级兜底消费 → 按了没反应。阅读器早已用物理键回退修好，视频页漏了。
- **根因证伪（2026-08-02，引擎源码级）**：上面那条「IME 把裸 Space 的 `logicalKey` 改写成 `process`」的前提**不成立**，本 bug 的真凶**待定**。证据：
  - `LogicalKeyboardKey.process` 是 **Flutter Web 专有**值。其裸 keyId `0x0010000070f` 在整棵 engine 树只出现 3 处：web 引擎 `lib/web_ui/lib/src/engine/key_map.g.dart:237`（唯一生产用）+ Android / embedder 两个 **test util**。Windows / Android / iOS / macOS / Linux-GTK 生产键表**全无**；框架侧同理只在 `keyboard_maps.g.dart` 的 `kWebToLogicalKey`（:2398）出现。
  - Windows 上被 IME 消费的键，由 `shell/platform/windows/keyboard_key_embedder_handler.cc:177-183` 在 `VK_PROCESSKEY` 时直接 `callback(true); return;`（注释原文 "not sent to Flutter"），keyup 同样在 `:255-260` 被丢弃。
  - ⇒ **引擎在本仓 5 个出包平台上永不产生 `logicalKey == LogicalKeyboardKey.process`**。守卫：`hibiki/test/shortcuts/ime_process_key_reachability_guard_test.dart`（BUG-1432）。
