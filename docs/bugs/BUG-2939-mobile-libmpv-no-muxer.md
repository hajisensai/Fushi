## BUG-2939 · Android/iOS/macOS 随包 libmpv 无 muxer，dump-cache 恒失败（#1953）
- **报告**：2026-10-04（用户：GitHub issue #1953，Android 16 / fushi 2.9.1，网络流视频制卡时日志 `mpv/recorder: Output format not found`）
- **真实性**：✅ 真 bug。在线视频制卡的缓冲副本 `snapshotCachedRange`（`fushi/lib/src/media/video/video_player_controller.dart:1247`）让 libmpv `dump-cache` 把这句写成 `.mkv`，需要 libavformat 的 matroska muxer。三端的随包 libmpv 都没有编入任何 muxer：
  - Android：`hajisensai/libmpv-android-video-build` 的 `buildscripts/flavors/full.sh:45` 是 `--disable-muxers`。旧 jar 扫符号：354 个 demuxer 都在，muxer 为 0。
  - iOS / macOS：`hajisensai/libmpv-darwin-build` 的 ffmpeg `meson.build` 先 `--disable-all`，`full` flavor 只开 demuxers，`--enable-muxers` 只在 `encodersgpl` 里。旧 xcframework 的 `Avformat` 里没有 matroskaenc 的任何字符串。
  - 失败在 `video_player_controller.dart` 的 `catch (_)` 里被吞掉、回退远端抽取，所以从不报红，但移动端这条优化从没生效过，每次制卡都白跑一次命令、留一条 error 日志。Windows 的 `libmpv-2.dll` 是完整构建，不受影响。
- **[x] ① 已修复** — 两个构建仓库各开 `hibiki/mkv-muxer` 分支（基于 W1ght 的 `hibiki/dovi-p5-gl`，DV 补丁保留），只加一行 `--enable-muxer=matroska`：Android `fe04fa11`（CI run 37180705201），darwin `865ef149`（CI run 37180707142）。产物按 `ffmpeg6.1.6-mkvmux-dovi` 命名新增到 `vendor-libmpv` release（旧资产未动）；app 侧在本分支改 `third_party/media_kit_libs_android_video/android/build.gradle`（四个 jar 的 URL / MD5）与 iOS / macOS 两个 `Makefile`（版本标签 / SHA256）。产物核对：四个 ABI 的 `libmpv.so` 都有 `ff_matroska_muxer`，demuxer 仍是 354 个，n6.1.6，TrueHD 解码器与 DV 补丁都在；iOS 两个切片和 macOS 的 `Avformat` 都带 matroskaenc 独有的字符串，Avcodec 6.1.6，Mpv 的 DV 标记与旧版一致。所有 URL 实际下载后 MD5 / SHA256 都对上了。`flutter build apk --debug` 打出的 APK 里三个 ABI 的 `libmpv.so` 都带 matroska muxer。
- **[x] ② 已加自动化测试** — `fushi/test/build/libmpv_mkv_muxer_guard_test.dart`：iOS / macOS 的 `MPV_XCFRAMEWORKS_VERSION` 必须含 `mkvmux`，Android 四个 jar 名必须含 `-mkvmux-`。换回不带 muxer 的产物会先在这里红，不会再静默失效。名字保留 `-dovi` 后缀，`dolby_vision_bundled_libmpv_guard_test.dart` 照旧通过。
- **备注**：没有在设备上实测 `dump-cache` 落盘（本机未接 Android 设备，也没有 iOS / macOS 真机），证据停在「产物里确有 muxer + 打包正确」这一层。两个构建分支还没有合进各仓库的默认分支；下次重建 libmpv 时要从 `hibiki/mkv-muxer` 起，否则 muxer 会丢——好在上面的守卫会拦住。同一事件里另一半「同步片段无声」见 BUG-2940（#1951）。
