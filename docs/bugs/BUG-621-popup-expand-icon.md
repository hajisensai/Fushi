## BUG-621 · 查词弹窗词典分组展开/收起图标渲染不出来
- **报告**：2026-07-08（用户：TODO-1337 用户反馈）
- **真实性**：✅ 真 bug（字体依赖脆弱性；**非** Niratan phase1 回归——已用 `git blame` 证伪：折叠三角 CSS `hibiki/assets/popup/popup.css` 自 `9cd8d2ef0f`(2026-04-23) 未变，phase1 `2f920a80a` 从未触碰）。根因 `hibiki/assets/popup/popup.css` 的 `.glossary-group > summary::before { content: '▶ ' }` / `[open]::before { content: '▼ ' }`：展开/收起三角是**字体字形**，会继承弹窗当前字体——含用户经 `popup_settings_injection.dart` 注入的自定义词典字体 `html,body{font-family:<custom>,...}`；若该字体缺 U+25B6/U+25BC 或按 emoji 呈现，Android WebView / 自定义词典字体 / emoji 回退等平台下三角渲染成空白/彩色 emoji/豆腐块 = 「图标渲染不出来」。同类脆弱性历史有据：`ecf8d7b1d`(TODO-867 F1 图标字形改单色符号字体)、`c2c5b7703`(TODO-617 图标符号字体回退)。用 headless Edge(=Windows WebView2 引擎) 实测：Windows 下默认字体与自定义 CJK 字体两种情况三角都能渲染，故 Windows in-app 不复现——问题在其它平台/字体组合，字体依赖是共性根因。
- **[x] ① 已修复** — 把折叠三角从字体字形改为**纯 CSS 边框三角形**（零字体依赖，全平台/全字体一致渲染，与 Niratan `.entry-current::before` 边框三角同法）：收起态 `border-left: 5px solid currentColor` + 上下透明边 = 右向三角▶；展开态 `border-top: 5px solid currentColor` + 左右透明边 = 下向三角▼。`currentColor` 随主题文字色。同步改三镜像：`hibiki/assets/popup/popup.css`（app 四端：阅读器/词典页/视频/全局查词共用一份 popup.css）+ 两份浏览器扩展 vendor 副本 `hibiki/assets/browser_extension/vendor/popup.css` 与 `tools/browser-extension/vendor/popup.css`（施加逐字节相同的改动，保持二者 mutual byte-identity；扩展 vendor 是 pre-phase1 快照，其 popup.js 制卡按钮本就是文本 ✓/+，无需镜像 TODO-1325 的 ✓✓↩ 还原）。headless Edge 渲染验证收起▶/展开▼两态三角在默认字体与自定义 CJK 字体下均正常。提交见分支 `todo1325-mining-marker-revert`（TODO-1337）。
