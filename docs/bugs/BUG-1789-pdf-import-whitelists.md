## BUG-1789 · PDF 导入白名单三处漏抄：漫画框选不中、拖放不认、文件夹扫描跳过
- **报告**：2026-08-23（用户：「导入单个漫画，现在不能导入 pdf……并且 pdf 也没办法单独导入」）
- **真实性**：✅ 真 bug。`ImportCarrier` 早就把 `.pdf` 当成一等书载体（`fushi/lib/src/media/import/import_carrier.dart:103` → `ImportCarrier.pdf` → `PdfImporter`），但「哪些扩展名算数」在仓库里被**手抄了四份**，只有书籍导入对话框那一份含 pdf：
  - `fushi/lib/src/media/manga/manga_import_dialog.dart:208`（派生自 `import_carrier.dart:61` 的 `kMangaCarrierFileExtensions`）：漫画框的文件选择器白名单无 `.pdf`；即使拖进去，`_adoptPath` 用 `carrier.isManga` 判定（`manga_import_dialog.dart:246`），PDF 被当「不支持的格式」toast 挡回。
  - `fushi/lib/src/media/drag_drop/drop_classification.dart:4` `kDragBookExtensions`：无 `pdf`，PDF 拖进书架/漫画库落进 `unknown` → 「本页面不支持」。
  - `fushi/lib/src/media/source_library/source_library_scanner.dart:68` `kScanEpubExtensions = {'epub'}`：「导入文件夹」把目录里每份 PDF 静默跳过，不报错也不计数。
- **[x] ① 已修复** — `e387f7cada`。四处收敛到同一个真相源：`kMangaCarrierFileExtensions` 加 `.pdf`；新增 `ImportCarrier.isMangaCapable`（= `isManga` + `pdf`）供漫画侧问「这东西能不能变成一本漫画」，`isManga` **保持不含 pdf** 供书籍框问「该不该转交漫画流程」（并进去会让书架选 PDF 被误转走）；`kDragBookExtensions` 加 `pdf`；`kScanEpubExtensions` → `kScanBookExtensions = {'epub','pdf'}` 且 `_importBooks` 按扩展名分流 `PdfImporter`。漫画侧 PDF 的执行是 `PdfImporter.importFromPath` + `BookFormatRebuild.convert(target: manga)` 两个现成零件串联（`fushi/lib/src/media/manga/import/manga_pdf_importer.dart`）——零新导入逻辑，且书目录里留着 `document.pdf`，「漫画 → 转回 PDF」往返仍成立；转化失败回滚掉刚建的行与书目录。
- **[x] ② 已加自动化测试** — `fushi/test/media/import/import_carrier_test.dart`（`.pdf` 身份仍是 pdf、`pdf.isManga` 恒 false、`isMangaCapable` 放行 pdf 而不放行 epub/text、`.pdf` 在真相源里、一批 PDF 的目录 → `mangaBatchFolder`）、`fushi/test/media/drag_drop/drop_classification_test.dart`（pdf → books 且不进 mangas/unknown）、`fushi/test/media/source_library/source_library_scanner_test.dart`（pdf 进 `plan.books` 且 `isPdf`、PDF 旁有同名字幕+音频也不挂有声书）。变异实测：把三处白名单/判据改回修复前，这三个文件恰好红 6 条，还原后 sha256 与备份逐字节一致。
- **备注**：`ScanBookItem.epubPath` 改名 `bookPath`（装 PDF 后旧名是句谎话），并加 `isPdf`；`isAudiobook` 对 PDF 恒 false——对齐拿 EPUB 章节正文与字幕逐句配，PDF 行的 `chaptersJson` 是 `'[]'`，喂进去只会产出一本空对齐的假有声书。真机未复测（本轮只跑单测 + analyze）。
