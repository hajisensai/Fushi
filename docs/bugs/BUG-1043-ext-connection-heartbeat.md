## BUG-1043 · 扩展未连接:app内存last-seen无心跳+MV3 SW空闲回收
- **报告**：2026-07-24（用户：app 里浏览器扩展显示「未连接」；hibiki 重启后更是一直未连接）
- **真实性**：✅ **真 bug（沿真实代码路径定位）**。app「插件已连接」判定唯一依据 `hibiki/lib/src/pages/implementations/browser_extension_page.dart:71 _isRecentlySeen`：`browserExtensionLastSeenAt` 在 `_seenWindow`（旧 120s）内即判已连接。该时间戳 `hibiki/lib/src/models/app_model.dart:4822 _browserExtensionLastSeenAt` **只在内存**（prefs 无此键，app 重启即归 null），只在扩展打 `_kExtensionSeenPaths`（`hibiki/lib/src/sync/yomitan_api_server.dart:42`：`/api/extension/status`、`/api/lookup/dictionary`、`/api/mine` 等）时经 `onExtensionSeen`（`app_model.dart:4801`）刷新。而扩展 `tools/browser-extension/background.js`（镜像 `hibiki/assets/browser_extension/background.js`）**无任何 `chrome.alarms`/定时器**，MV3 service worker 空闲 ~30s 被浏览器回收。综合两点：
  - **稳态**：不主动划词 → 扩展不打端点 → last-seen ~120s 后过期 → app 翻「未连接」，哪怕扩展好好装着能用。
  - **app 重启**：内存时间戳丢失 → 立刻「未连接」；而扩展 `chrome.runtime.onStartup` 只在**浏览器**启动时触发、不在 **app** 重启时触发，扩展不会主动重新报到 → 一直「未连接」直到用户下次划词唤醒 SW 打端点。本质：「已连接」指示器实际是「最近 120s 内查过词」的活跃度表，被当成「扩展是否已装好连上」显示。
- **[x] ① 已修复** — 根因修（给 last-seen 一个保活心跳，让连接指示真实反映「扩展已加载可达」）。`background.js` 两镜像：新增 `chrome.alarms.create('hibikiHeartbeat', { periodInMinutes: 1 })` + `onAlarm` 监听，每 60s（< 窗口）唤醒 SW 调 `checkVersionOnStartup()` 打一次 `/api/extension/status`（server 收到即刷新 last-seen，顺带比对版本）；`manifest.json` 两镜像加 `alarms` 权限。app 侧 `browser_extension_page.dart` `_seenWindow` 120s→150s（> 一个心跳周期 + 抖动，单次心跳丢包不误判）。效果：浏览器开着时 last-seen 恒新鲜、稳定显示已连接；app 重启后 ≤60s 心跳自愈，无需用户先划词。提交：5ccbfaf00
- **[x] ② 已加自动化测试** — `hibiki/test/build/browser_extension_connection_heartbeat_guard_test.dart`：两镜像 `manifest.json` 含 `alarms`、`background.js` 注册 `hibikiHeartbeat`/`periodInMinutes: 1`/`onAlarm` 且心跳调 `checkVersionOnStartup`；app 侧 `_seenWindow` = `Duration(seconds: 150)`。两镜像 `background.js`/`manifest.json` 字节一致由既有 `browser_extension_dict_media_mirror_guard_test.dart` 守卫。提交：5ccbfaf00
- **备注**：浏览器扩展连接生命周期类，与 [BUG-1044](BUG-1044-ext-reload-orphans-content-script.md)（自更新 reload 孤立已开页 content script）同批修、都由 app 重启触发但根因不同。**真机复测原始失败路径待用户**（桌面 Chrome/Edge）：装扩展 → app 里「浏览器扩展」页应稳定显示「插件已连接」，静置数分钟不划词仍连接；重启 hibiki 后 ≤1 分钟自动回「已连接」，无需先在网页划词。控制台里 `http://127.0.0.1` 的 Mixed Content 是 loopback 可信源的无害警告（浏览器放行），与本 bug 无关。
