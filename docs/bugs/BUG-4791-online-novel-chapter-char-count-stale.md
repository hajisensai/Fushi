## BUG-4791 · 在线小说书取章后内存字数不刷新，统计与进度按占位页算
- **报告**：2026-11-17（用户：小说 / 漫画 / 视频优化清单复核，novel-1）
- **真实性**：✅ 真 bug（沿代码路径确认，未在真机复现漏计数值）。在线小说书（LNReader）与网页小说书入库时每章都是占位页，书行 `chaptersJson` 里的 `characters` 是占位文案的字数。根因（行号按修复前的 `upstream/develop` @ 8d58da51da9）：
  - 阅读器只在开书时读一次每章字数：`fushi/lib/src/pages/implementations/reader_fushi_page.dart:3336-3346`（`charCountsFromChaptersJson`）→ `:3389` `_applyCharCounts`；之后只有口径重算（`:3615`）会再调，在线书的口径是当前口径，不走这条路。
  - 取章回来只丢两份缓存：`fushi/lib/src/pages/implementations/reader_fushi/webview.part.dart:328-348`（`_sanitizedHtmlCache.remove` + `discardCachedHtml`），不碰 `_chapterCharCounts` / `_chapterCumulativeChars` / `setChapterCharCountHints`。
  - 新字数只写了库：`fushi/lib/src/media/novel/online/lnreader_online_book.dart:613-626`（`_updateCharacterCount`）、`fushi/lib/src/media/novel/web/web_novel_library.dart:556-563`（整本重解析后写 `chaptersJson`）；接口 `OnlineNovelChapterLoader.ensureLoaded` 只回一个 bool，字数没有交回阅读器的通道。
  - 后果：`absoluteCharOffsetOf`（`reader_fushi_page.dart:734-749`）把章内偏移夹在「占位页字数」以内，读到第一页之后可见区间起止相等，`_refreshProgress` 的 `unitEnd > unitStart` 不成立、不入账——整章只入账占位文案那几个字；进度条总字数与章内进度（`navigation.part.dart` 的 `progress * _chapterCharCounts[_currentChapter]`）同样按占位页算。重开书才恢复（那时书行里已是正文字数）。
- **[x] ① 已修复** — `ensureLoaded` 改为返回 `OnlineNovelChapterLoaded?`（章号 + 正文字数），两个加载器都把刚算出的字数带回来；LNReader 后台预取的章把结果记在 `_unacknowledged` 里，等阅读器翻到那一章、经拦截层确认时才交出。阅读器在 `_ensureOnlineChapter` 确认取章的那一刻调 `_adoptOnlineChapterCharCount`：`_applyCharCounts`（重建累计前缀与总字数）+ 整表重注入 `setChapterCharCountHints`（仅当整表已是当前口径）+ `_readLedger.reset()`（这一章之后所有章的全书绝对偏移都平移了；已入账的沉没、不撤回）。时机只放在拦截层：此刻是导航中、上一章的单元已结算；后台预取落盘时不改（用户还在读上一章，`reset()` 会丢掉当前未结算的单元）。提交 `74a94c5c0fc`。
- **[x] ② 已加自动化测试** —
  - 加载器把字数交回来：`fushi/test/media/novel/lnreader_online_book_test.dart`（亲手取的章、后台预取后翻到的章都带字数，且与写进书行的一致）、`fushi/test/media/novel/web/web_novel_library_test.dart`。
  - 阅读器一侧：`fushi/test/reader/reader_online_chapter_char_count_test.dart`（换表纯函数 `charCountsWithLoadedOnlineChapter`；换表前偏移被夹、换表后按正文走；接线守卫：只在拦截层确认时换、顺序为换表 → 注入提示 → reset）；`fushi/test/reader/reader_read_ledger_wiring_guard_static_test.dart` 的 reset 调用点清单同步加上这一处。
  - 真 app 端到端：`fushi/integration_test/lnreader_novel_source_itest.dart` 加了「取章后阅读器内存字数 = 书行新字数」的断言（经新调试钩子 `ReaderFushiPage.debugChapterCharCounts`）。该集成测试走真网络，**本轮没跑**（见备注）。
- **备注**：
  - 待真机复测：在线书连读两章新章节后看统计页「本次字数」与进度条（paginated / continuous / vn 各一遍）。本轮 23 组并发、磁盘紧张，没有跑 Windows 离屏集成测试，也没有上真机。
