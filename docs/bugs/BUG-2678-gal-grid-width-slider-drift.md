## BUG-2678 · 调整格宽后字格消失且拉回后位置对不上
- **报告**：2026-09-25（用户：手动微调里的「调整格宽」太灵敏；往大拉到一定程度后格子消失，再往小拉也不回来；拉大再拉回同一个数值，框和原来的位置对不上）
- **真实性**：✅ 真 bug（源码确认）。`gal_lookup_samples_dialog.dart` `_setGridAdvanceRatio` 每次都按格宽的增量去改蓝框右边缘，而右边缘被截在截图边缘（`clamp(..., 1.0)`）。到边缘后格宽继续变大，字格超出蓝框，原生预览以越界拒绝，格子消失。往回拉时，蓝框从被截住的宽度按增量回缩，被截掉的那段不会补回来，于是数值相同、蓝框却更窄。滑条范围是 15%～200%，在三百来像素宽的滑条上，一个像素就是零点几个百分点；界面又只显示整数百分比。
- **[x] ① 已修复** — `3ead564609`：开始调整时记下格宽和蓝框宽度作为基准，之后蓝框宽度每次都由基准和格宽直接算出，不再累加。滑条范围限定为基准上下 15 个百分点，并且不超过截图边缘能容纳的最大值。步长 0.1%，显示一位小数，新增 − / + 按钮。拖动画布、自动对齐、重新框选都会重置基准。
- **[x] ② 已加自动化测试** — `fushi/test/pages/gal_lookup_samples_dialog_test.dart`：范围、步数和一位小数显示；超出上限的输入被截住，蓝框不越过截图；拉到边缘再拉回原值，格宽和蓝框位置精确还原；− / + 各走 0.1% 并能回到原值。
- **备注**：手感需要实机确认。
