## BUG-1252 · 刮削候选封面预览过小
- **报告**：2026-07-29（用户：匹配弹窗里的封面预览太小，无法辨识）
- **真实性**：✅ 真 bug。视频、书籍/漫画、游戏弹窗各自硬编码约 `46×66` 的缩略图；在桌面候选列表中只能看出色块，不能承担人工确认封面的职责。
- **[x] ① 已修复** — 新增共享 `hibiki/lib/src/media/metadata/scrape_cover_preview.dart:9`，三类弹窗统一使用 `80×112` 预览和同一失败占位。（提交：`73f17c48e`）
- **[x] ② 已加自动化测试** — `hibiki/test/media/video/scraper/cover_match_dialog_test.dart:247` 钉死共享预览的实际布局尺寸，三类弹窗复用同一个组件。（提交：`73f17c48e`）
- **备注**：弹窗内容宽度同步扩到 560，窄视口仍受 Flutter 对话框约束自动收窄。
