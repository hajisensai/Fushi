  - 同一份反馈的 gal 部分（整张卡一个串行作业、attached 表面 capture lease）已由 BUG-4045 / BUG-4046 修过；本条只处理「复习目标写入本身不能后台化」这一块。补充里「hook 文本界面停止」在 BUG-4046 修掉 attached 路径之后，剩下的游戏内查词卡（位图卡画在游戏里）动图模式 capture lease 持有整个采样窗口是已登记的产品取舍（BUG-4046 备注），本条未改。
