## BUG-2494 · 互联页没有词典下载入口：显式词典传输动作跳过互联通道
- **报告**：2026-09-13（用户：「互联里面没有下载词典的入口」）
- **真实性**：✅ 真 bug（UI / 触发链缺口，服务层完整）。host 端点（`packages/fushi_engine/lib/sync/fushi_sync_server/library.part.dart` `GET/PUT/DELETE /api/library/dictionaries[/<name>]`）、client API（`fushi/lib/src/sync/interconnect_sync_backend.dart` `listRemoteDictionaries` / `getRemoteDictionary` / `putRemoteDictionary`）与 orchestrator 的 live union（`fushi/lib/src/sync/sync_orchestrator/dictionaries.part.dart` `_syncDictionariesLive`，`SyncOrchestrator.syncDictionaries(direction)` 对 `InterconnectSyncBackend` 分流）都已存在。缺的是入口：
  - 互联页只有一个开关 `interconnect.upload_dictionary`（`fushi/lib/src/sync/sync_settings_schema.dart:570`），文案「上传词典」，实际驱动的是 `syncDictionaries(direction: both)`——用户看不出它会把对端词典拉下来，也没有一次性的显式动作；
  - 云备份页那行「词典 · 传输 ▾（上传 / 下载）」（`sync.dictionary_transfer`，`sync_settings_schema.dart:320-324`）在同步方式 = 互联时被 `visible: backendType != fushiServer` 藏掉；
  - 而且它调用的 `runManualAssetTransfer`（`fushi/lib/src/sync/sync_auto_trigger.dart:890`）写死 `if (channel.isInterconnect) continue;`——互联通道结构上永远跑不到资产传输，互联页不管加什么按钮都是死的（BUG-988 立的规矩是「云备份页的按钮不能推给对端」，但被实现成了「互联通道永不做资产传输」）。
- **[x] ① 已修复** —（本 PR）`runManualAssetTransfer` 新增 `SyncAssetChannelScope scope = cloud` 参数，按 `channel.isInterconnect != (scope == interconnect)` 二选一过滤通道：云备份页的既有调用不传 scope 仍只跑云通道（BUG-988 边界不变），互联页新加的行传 `interconnect` 只跑互联通道。`runAssetTransferWithFeedback` / `_AssetTransferMenuRow` 透传 scope。互联页「上传到互联对端」区在 `interconnect.upload_dictionary` 开关之后加 `interconnect.dictionary_transfer` 行（`_AssetTransferMenuRow(kind: dictionary, scope: interconnect)`，复用 `sync_asset_dictionary` / `sync_asset_transfer_hint` / 上传 / 下载既有文案，零新 i18n key），与整区同门控（互联开启且非 host）。下载走既有 `_syncDictionariesLive(direction: download)`：对端独有的词典按名拉 `.fushidict` 包经 `importDictionaryPackage` 落地。
- **[x] ② 已加自动化测试** — `fushi/test/sync/sync_settings_visibility_test.dart`：① 结构断言——上传区 id 序列含 `interconnect.dictionary_transfer` 且紧跟 `interconnect.upload_dictionary`、整区带 visible 门控；源码守卫钉住该行 `scope: SyncAssetChannelScope.interconnect` + `kind: SyncAssetKind.dictionary`；② `runManualAssetTransfer` 源码守卫：默认参数 `scope = SyncAssetChannelScope.cloud`、过滤式 `channel.isInterconnect != wantInterconnect`、旧的无条件 `if (channel.isInterconnect) continue;` 不得回来。
- **备注**：`interconnect.upload_dictionary` 开关的语义（双向 union）与文案（上传）仍不一致，本次不改开关语义——有了显式的传输行，用户要「只下载」有明确入口即可；开关文案是否改成「自动同步词典」留给上游定夺。
