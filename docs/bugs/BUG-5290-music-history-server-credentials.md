## BUG-5290 · music-history-server-credentials
- **报告**：2026-11-22（用户：最近播放把服务器曲目带凭据的流地址落库）
- **真实性**：✅ 真 bug。`fushi/lib/src/media/music/server/music_server_play_item.dart:34` 播放项 `path` = `browser.streamFor(track).uri.toString()`、`coverPath` = `browser.coverUri(...)`：Jellyfin 带 `api_key=<access token>`（`jellyfin_music_client.dart:376/396`），Subsonic 带 `u` + `t`（md5(密码 + 盐)）+ `s` 或 OpenSubsonic `apiKey`（`subsonic_music_client.dart` `_authParams`）。`fushi/lib/src/media/music/music_history.dart:18/26/30`（`musicPlayEventSnapshotOf`）把 `item.path` / `item.coverPath` / `source.cover`（服务器专辑 / 歌单页传的也是 `coverUri`）原样写进 `music_play_events.path / cover_path / source_cover`（v139 快照），随「音乐」备份类别导出、合并导入原样并入。其余持久化位置已核：`music_resume_points` 只存 trackUid（无路径）；`music_remote_tracks` 服务器行 v149 起只存身份 + `cover_ref`；音乐队列不持久化；统计只读播放流的时长列；小组件快照把封面下载成本地文件（文件名是哈希）。
