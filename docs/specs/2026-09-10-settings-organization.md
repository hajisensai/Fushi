# 设置分类与渐进展示

## 目的与范围

统一设置的归属、顺序、展开策略和搜索路径。保留现有业务偏好键、默认值、Profile 快照与运行期 setter；只改变设置呈现和导航。游戏分类继续仅 Windows 可见。

## 信息结构

| 分组 | 分类顺序 |
|---|---|
| 界面 | 外观与交互 |
| 内容 | 阅读、听书、漫画、视频、游戏（追踪仍遵守既有门控） |
| 学习 | 查词、制卡 |
| 连接 | 下载、在线服务 |
| 数据与设备 | 配置方案、同步与备份、设备互联、存储 |
| 应用 | 系统与关于 |

分类分组不折叠，隐藏分类过滤后不显示空组。Material 与内部 Cupertino 渲染器共用分组函数；宽屏使用主从导航，窄屏进入详情。分类顺序由 `_buildDestinations` 定义，不因使用频率改变。导航用非懒滚动容器保持全部有限分类的焦点节点挂载，避免滚出视口后无法通过 Tab 回到前面的分类。

页内优先展示核心行为，其后为外观体验、集成、高级参数与维护。视频字幕前移到播放之后。阅读高级排版放在末尾；查词音频源归发音，浏览器扩展归集成。数据目录在当前基线已归存储，本次保留此唯一归属。

## 展开与本机状态

`SettingsSectionPresentation` 明确区分 `alwaysExpanded`、`expanded`、`collapsed`。核心设置始终展示；进阶组可折叠；复杂配置使用 `SettingsNavigationItem.child` 子页复用原组件。可选功能总开关保持可见，参数由同一运行期启用状态决定是否显示。

分区使用与翻译、列表位置无关的稳定 ID。旧调用尚未提供分区 ID 时，`visibleCopy` 在过滤前以原首项 ID 生成稳定后备身份，避免动态隐藏行改变身份。全局页与快捷面板通过 destination scope 隔离展开偏好。

`SettingsExpansionState` 将用户主动操作保存到 SharedPreferences 的 `settings_section_expanded.` 前缀，独立于 Drift preferences、Profile 和云同步。异步加载期间的用户操作优先于磁盘旧值。多个分区可同时展开，重新进入后恢复用户选择。搜索触发的展开仅保留在本次访问，绝不写入偏好。

## 搜索与复杂表单

索引递归遍历 schema 子页，也遍历每页的 `bodySearchEntries`，保留从顶层到子页的完整路径。真实自绘表单行以 `SettingsSearchTarget` 挂点定位；只有已提供真实挂点的元数据才声明 `hasRevealTarget`。折叠的复杂正文通过 `SettingsSectionContainer.searchTargetIds` 展开包含目标的组，然后滚动并高亮。重复搜索使用独立 generation，避免同一目标只能定位一次。

Anki 的连接、字段、模板、媒体与维护，下载的连接、Tracker、引擎及完成后处理，在线服务凭据，以及 ASR/OCR 模型管理均沿用原业务组件。摘要区分“已配置”和“已连接”：有配置仅显示已配置，不能推断服务可用或已经连接。密钥内容不进入摘要、分组状态或新本机存储。

## 新增、移除与兼容

语音识别模型统一归「存储 → 模型与组件」，属于跨媒体共享资源，不随听书模块关闭而隐藏。听书分类只管理播放及听书行为。保留旧 `listening.asr_models` 搜索锚点，但其展示归属和子页身份均为存储；模型路径、下载与删除逻辑保持不变。

- 新增：六个导航分组、三态分区展示、本机展开记忆、自绘表单精确搜索挂点、服务配置状态摘要和节点加密标题。
- 移除：复杂配置在分类首页的整段平铺，改为摘要入口；核心分区的折叠箭头。
- 保留：原设置值、持久化键、业务默认值、移动端 AnkiConnect 默认折叠、模块门控、阅读器与视频快捷设置投影。
- 未删除任何仍有效的业务配置，以免重排误改变运行行为。并未添加新的后台网络请求。

## 验证

使用分组/顺序、运行期可见性、schema 缓存、真实偏好写入、子页隔离与搜索定位、展开状态竞争和宽窄布局测试。真应用焦点驱动入口为 `integration_test/settings_organization_itest.dart`，记录实际宿主宽度及截图；单一宿主不代表另一宽度或平台已经验收。执行结果以本轮测试日志为准。
