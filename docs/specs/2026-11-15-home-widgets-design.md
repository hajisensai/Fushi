# 首页小组件网格（2026-11-15）

所有者 2026-11-15 拍板「按你的建议做」。设计稿：worktree 内 `fushi/build/home_widgets_design/index.html`（gitignored，本地看）。

## 目标

首页正文从「固定分区（今日 / 继续 / 最近添加 / 同步卡）+ 4 个可选面板（`HomeDashboardPanel`）」改成**可自由增删、排序、调尺寸的小组件网格**。数据全部来自现有分区，不新增数据源。

不变的部分：页头（重设计外壳的页头大字 `_buildMastheadBar` / 旧外壳的浮动工具栏 `_buildFloatingToolbar`）、更新横幅、迁移横幅、新手引导卡（它们仍排在网格上方，不是小组件）、「继续」FAB。

- **连续尺寸**（所有者 2026-11-15 真机反馈「调节范围还不够多也不够好用」后改）：每种组件是一段连续范围，范围内任意列 × 行都合法（不再是离散档）。宽网格最多 6 列，窄网格宽度再封顶到 2 列（`HomeWidgetKind.maxFor`），高度一律不超过 4 行（`kHomeWidgetMaxRows`）。表里的范围是宽网格口径。
- **半栏**（所有者 2026-11-15 窄窗真机反馈「再支持一下半栏」后改）：所有组件最小都是 1 列（继续主角 / 最近添加 1×2，其余 1×1），窄网格里今日 / 近 7 天 / 复习 / 追踪 / AI 默认都占半栏。1 列宽（窄网格约 170、宽网格约 150–200，均小于 `kHomeWidgetWideWidth` 240）时：继续主角改排条目小行一列（不画主卡）；继续类单条为小封面 + 两行标题（高度够再挂进度）；追踪只放计数摘要（如「3 项待处理」）+ 一枚图标按钮；全景只留两枚图标按钮（高度够再放状态文案）；近 7 天柱宽按可用宽均分。文字按整行放，放不下的整行不放。
- 每个组件按格子的**实际宽高**（LayoutBuilder）排版，不按尺寸 switch；格子越大放得越多，任何允许的尺寸都不溢出、不留大片空白：
  - 继续·主角：够宽（宽 ≥ 460 且宽高比 ≥ 1.5）其余条目挂在主卡旁，否则高度够时挂在主卡下（主卡 ≥ 100 高、其余段 ≥ 64 / 色块 ≥ 96）；其余段只放得下一行时横滑（全部可达），放得下多行时铺成多行多列（主卡旁的封面卡行超过 300 高也改铺多列条目）。
  - 继续阅读 / 观看 / 游玩、最近添加：条目小行按高度算行数、按宽度算列数（行高 52–72、列宽 ≥ 220），放得下几条放几条；矮格（高 < 100，窄网格一行高）只放最近一条。最近添加最多取 24 条。
  - 近 7 天：柱高 = 内容区高。
  - 今日：内容区宽 ≥ 380 时结束侧挂近 7 天柱条，否则高 ≥ 130 时柱条挂在主体下面。
  - 复习 / AI / 追踪 / 全景：按宽（≥ 240 算宽格）/ 高（< 100 算矮格）决定挂不挂计数与按钮，文字行数按可用高度算。
- 同一种组件在一份布局里只能放一个（决策 7）。

## 网格

- 两份布局分开存：`compact`（2 列，手机竖屏 / 窄窗）与 `wide`（6 列；平板等中间宽度也用 wide，列宽随可用宽度伸缩）。断点沿用现有 `dashboardUsesTwoColumns` 判据：true → wide，false → compact。窗口跨断点时切换到另一份布局，不互相换算。
- 布局 = **有序列表** `[{kind, cols, rows}]`，渲染时按顺序做「密集装箱」（逐个放到第一个能放下的位置，自上而下、自起始侧到结束侧，RTL 镜像）。不存绝对坐标：增删 / 改尺寸后自动补位，不会出现重叠或悬空。
- 行高：compact 约 84dp、wide 约 118dp 的基准（可按宽度微调，但须是纯函数并有测试），间距与库页色块同一档 `kFushiCoverBlockSpacing`。
- 装箱、增删、移动、改尺寸（钳进范围 `clampHomeWidgetSize`、逐格 `resizeHomeWidgetBy`、拖角吸附 `homeWidgetDragSize`）、迁移、编解码全部写成纯函数（独立文件，例如 `models/home_widget_layout.dart`），单测覆盖。

## 编辑态

- 进入：页头动作组加「编辑首页」（`FushiIcons` 里找合适的编辑图标；走现有 `_toolbarItems`，放不下按优先级收进「⋯」）；或长按任意组件。
- 编辑态下：
  - 每块左上「−」移除（角标挂在圆角外沿，不压标题）。
  - 右下角是改尺寸的柄：**拖动**按格吸附（右下角落在哪格取哪格，四舍五入到最近格线），拖动中目标格子上显示预览框 +「3×2」标签，其余组件按装箱结果让位，松手提交（进撤销栈，拖回原尺寸不记操作）；柄按下即赢下手势竞技场，拖柄不会滚页、不会变成换位。**点按**柄弹出尺寸选择网格（像 Word「插入表格」）：画出该组件在当前网格允许的最大范围，悬停 / 聚焦时从左上角到那一格高亮并显示「c×r」，低于下限的格子画浅色、选中时钳到下限；点按 / Enter / 手柄 A 选定，Esc 取消。
  - 拖动换位：拿起的组件抬起（缩放 + 阴影），目标位置显示虚线占位，其余组件按装箱结果让位（动画时长只取 `fushiMotionDuration` / `FushiMotion`）。
  - 底部浮动工具栏**纯图标**（文字只进 tooltip 与 Semantics，命中区 ≥48dp）：添加 / 撤销 / 完成。页头右侧加「恢复默认」。
  - 撤销：编辑会话内的操作栈；「完成」落盘；退出编辑后撤销栈清空。
  - 组件内容在编辑态下不响应点击（不误开书）。
- 焦点驱动（硬要求）：每个组件是一个焦点停靠点；Enter / 手柄 A 拿起 / 放下，拿起时方向键（手柄十字键）移动位置（左右 = 列表前后一位，上下 = 跳到装箱后上 / 下一行最近的位置）；**Shift+方向键逐格改宽 / 高**（左右按阅读方向，RTL 镜像）；手柄 **LB / RB 减 / 加宽、LT / RT 减 / 加高**；X / Delete 移除，Esc / B 放下（拿着时）或退出编辑（没拿着时）。旧的 `[` `]` 循环换档已去掉。
  - 手柄按钮走 `GamepadButtonIntent`（桌面轮询与 Android 原生按键同一条路，LT/RT 是轴、过阈值当按钮发出）：每块在 Focus 之上挂 `GamepadButtonForwardingAction`，编辑态只消费上面这些键，其余（以及非编辑态的全部按键，如首页 LT/RT 换 tab）显式转发给祖先。
- 添加面板：手机底部弹层、宽屏居中对话框（用现有自适应 sheet / dialog 组件）；搜索框 + 分类（全部 / 学习 / 继续 / 工具）+ 每项显示**默认尺寸**的缩略比例与「可调范围 a×b – c×d」；点「添加」→ 按此刻网格的默认尺寸追加到列表末尾（装箱后落到第一个能放下的空位）并滚动到它，之后在网格里再调。已在当前布局里的组件置灰并标注「已在首页」。
- 删光时：网格位置显示空状态（`HomeEmptyState`）+「添加小组件」按钮（决策 1：「继续」也可删）。

## 显隐语义（决策 2）

- 组件放上首页（用户编辑并保存过的布局）就常驻，不再按「auto」判据整块消失；没有内容时组件自己收缩成一行说明（例：追踪无待办 →「同步正常」；复习 0 张 →「今日已完成」；继续无条目 → 空状态引导）。
- 例外：组件所属**功能模块被关掉**（`ModuleVisibility`）或被 iOS 合规门禁止等「不可用」情况（AI 未指派提供商**不算**：按 fushi/CLAUDE.md §13 入口照常可见，点击引导去设置），组件整块不渲染（也不出现在添加面板里），布局里仍保留它，模块重新打开就回来。

## 持久化（决策 3、4）

- 新偏好键 `home_widget_layout`（在 `preference_keys.dart` 注册并写注释）：JSON `{"v":1,"compact":[{"k":"today","c":1,"r":1},...],"wide":[...]}`。随 Profile 走、进备份 / 同步（与 `home_dashboard_panels` 同等待遇，不加进设备本地清单）。kind id 与 JSON 字段冻结。
- 解码容错：坏 JSON / 未知 kind → 丢弃该项；尺寸各轴钳进该组件在这份网格里的范围（存储格式 `c` / `r` 不变，范围内的任意尺寸原样保留）；重复 kind 只留第一个。
- 键缺失（从没编辑过）：由**迁移函数**按旧偏好 `home_dashboard_panels` 生成首个布局：默认模板（见下）里，旧档位钉成 `hidden` 的面板不放，钉成 `shown` 的放上；`auto` 的按面板现有默认判据决定放不放。迁移结果不落盘，直到用户第一次编辑才写入（以免同步把迁移态带到别的设备覆盖）；在那之前每次渲染都按判据**现算**，即没编辑过的用户沿用旧「自动」档的显隐（2026-11-21 拍板台 pr3464 定，取代原「迁移那一刻算一次、之后常驻」）。
  - 为什么不做「迁移那一刻的快照」：新装用户也全走迁移，快照会把「还没开始用 SRS / 还没配 AI」时的空模板永久冻住，之后开始用了组件也不出现；SRS 判据依赖异步卡组统计，首帧快照会把加载中的 false 冻进去；要防同步覆盖还得另加一份设备本地快照键。现算没有这些问题，且与用户升级前看到的首页一致。用户一旦编辑并保存，就进入上一条的「常驻」语义。
- 默认模板：
  - compact：`continue 2×2`；半栏组件 `today`、`week`、`srs_review`（若放）、`tracking`（若放）、`ai_agent`（若放）按此顺序各 1×1 两两并排，个数为奇数时最后一个放宽成 2×1，不留半格空洞；`panorama 2×2`（若放）。
  - wide：`continue 4×2`、`today 2×1`、`srs_review 1×1`、`ai_agent 1×1`、`week 2×2`、`recently_added 4×2`、`tracking 2×1`、`panorama 2×2`（各「若放」同上）。
- 旧键 `home_dashboard_panels` 保留只读（迁移用），不再写；`HomeDashboardPanelMode` 的消费端（各面板的 `resolve*Visible`）改为只管「不可用」判定，`auto/shown/hidden` 档不再影响渲染。

## 设计系统（决策 6）

- MD3（M3E）：上文描述。
- Apple（玻璃设计系统）：编辑态组件轻微抖动（iOS 主屏式），左上「−」；「减少动态效果」（`MediaQuery.disableAnimations` / 项目现有判据）下不抖。
