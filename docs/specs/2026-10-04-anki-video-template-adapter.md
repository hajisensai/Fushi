# Anki 视频模板适配

## 问题与入口

Kiku 等脚本模板会重新解析字段，单纯把 video HTML 写进 Picture 无法保证显示。
BUG-2923 的自动 GIF 回退继续作为未适配模板的兼容路径。本功能让用户在
「Anki → 字段映射 → 视频播放适配」显式选择字段、图片位置或背面底部、自动播放，
预览后应用。模板修改影响所有使用同一笔记类型的牌组，页面明确说明这一点。

## 媒体与模板契约

- `{card-video}` 标识由托管播放器消费的媒体字段。静态图片仍按普通图片处理；
  同步 WebM 的字段只提供无播放事件的媒体源，背面托管块负责创建唯一播放器。
- WebM 在卡内播放；MP4 继续交给 Anki 原生播放器，不承诺桌面卡内 H.264 解码。
  同步片段只有一个音画文件，不能另起一个句子音频播放器。
- 托管块有版本标记，应用幂等，可移除；原模板内容保留。模板被升级覆盖、字段映射
  不再匹配或标记损坏时，不把缺失播放器的模板判断为已支持。
- 普通模板走统一播放区；Kiku 图片位置通过实际 DOM 与开放 ShadowRoot 定位，
  找不到图片位置则放在背面底部。用 DOM 生命周期事件处理加载，不依赖延时重试。
- 翻面、换卡和卸载释放播放器与观察器，隐藏副本不自动播放。

## 修改与恢复

服务从真实后端读取笔记类型，绑定目标身份，并在写前核对预览时的模板快照。
先备份原模板和受影响字段映射，备份落盘失败则不写 Anki。应用后读回校验，
失败必须明确报告并保留恢复依据。再次应用保留首次修改前的映射；切换字段时恢复
此前由本功能写入的映射。恢复仅移除托管块、条件恢复本功能改过的映射，保留其它
用户修改。模板没有 CSS 修改需求，因此不重写用户 styling。

切换字段时保留原视频字段历史，旧卡可继续读取旧字段；当前字段包含图片等新媒体时
不回退旧视频。恢复模板表示停用播放器，之前制出的 WebM 媒体仍保留，重新启用可恢复
播放，页面在恢复操作旁说明这一影响。适配要求唯一句子音频映射，避免 MP4 重复进入
原生播放队列。部分模板写入失败时按每张卡精确回滚本次写入，保留其它外部编辑。

桌面 AnkiConnect 与原生 AnkiDroid 使用现有模板读写接口。AnkiMobile 直连没有模板
编辑接口；互联转发仓库的本机字段映射和主机模板不属于同一目标，本版本不允许在
该连接上执行适配，应在制卡目标设备配置。不能用本机映射配主机模板。

## 验证

纯函数测试覆盖应用/重复应用/移除、普通模板及真实 Kiku 发行模板、映射与标记一致性。
服务测试覆盖备份失败、并发修改、部分写入失败、字段切换和保留用户修改。
页面测试覆盖加载、应用、恢复、错误和忙状态。实际媒体与安装版 Anki 渲染内核验证
需与 Flutter 测试分别记录；未执行的移动端整机路径不计作通过。

预览是无外部脚本资源的布局示意，不替代 Kiku 完整模板运行；旧卡缺失的媒体无法从
模板恢复，必须重新制卡。

## 2026-10-04 本机验证记录

在隔离 Anki Collection 导入官方 Kiku v2.1.0，真实 FFmpeg 制作带音轨的 WebM，
用生产字段组合器和适配模板落卡，再由安装版 Anki 的卡片渲染与 QtWebEngine 6.9
加载官方 Kiku JS/CSS。合成素材长度 1.508 秒，结果如下：

| 场景 | 结果 |
|---|---|
| Kiku 原图位置、背面底部 | 唯一可见播放器，加载到 readyState 4，自动播放一次至结束 |
| 普通直接插值模板 | 唯一可见播放器，完整播放 |
| 切换字段后的历史卡，新字段已有旧文本 | 回退历史媒体字段，完整播放 |
| 关闭 WebM 自动播放 | 时间保持 0，点击重播才播放；切换卡面后暂停 |
| MP4 | Anki AV 列表只有一个 MP4；托管按钮触发一次 `play:a:0` |

页面通过 Flutter widget 测试和截图检查，含不同位置的静态预览、忙状态、恢复说明及
非法映射门控。服务验证部分写入回滚、外部修改保护、字段历史和停用后再次启用。
JS 行为回归执行实际托管脚本，覆盖单次自动播放、原生隐藏链接重播与换卡清理。

本次未运行 AnkiDroid/AnkiMobile 整机 E2E，未验证实际扬声器出声；不能由桌面渲染
结果推断所有客户端已验收。这里的 MP4 验证是原生播放队列和命令，不是卡内 H.264。
