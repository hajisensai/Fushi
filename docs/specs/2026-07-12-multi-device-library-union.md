# 多端库联合视图（远端书/视频混入主库 + 占位下载）

> 状态：**待拍板**（2026-07-12 用户贴群聊讨论：书架跨客户端显示一致；缺的书
> 占位可下载；没网保持现状；客户端专有书照常；「参照 git 那样搞？我想让他
> 远端书籍/视频混合进正常里面」）。
> 本文是设计评估，不实现。分支：`worktree-unified-collections-plan`。

## 0. Linus 三问

1. **真问题吗？** 真。远端书/视频现在挤在书架/视频页顶部的**独立分区**
   （`_buildRemoteBookSection` / `_buildRemoteVideoSection`），和本地库割裂；
   用户要的是「一个库 = 本地 ∪ 远端」的联合视图。
2. **「书架摆放位置同步」是伪需求。** 排序交互重设计后，**显示顺序 =
   f(排序模式, 条目元数据)**——不存在「摆放位置」这个状态。只要两端看到同一
   目录、同一元数据（进度/导入时间已在同步范围），选同一排序模式就显示一致。
   要同步的是**目录**，不是位置。
3. **「参照 git」对一半。** 对的一半：本地永远可用、离线照常改、联网后合并
   ——现有同步已是这个模型（newer-wins + 删除墓碑 + bookKey 跨端身份）。
   错的一半：git 的全历史/分支/三方合并对媒体库是过度设计；每实体 LWW +
   墓碑足够，**不引入**。

## 1. 现有地基（全部已存在，别重造）

| 能力 | 现状 |
|---|---|
| 跨端书身份 | `bookKey = sanitizeTtuFilename(title)`（EpubBooks 主键） |
| 远端书目录 | `RemoteBookInfo`（title/bookKey/封面/有声书徽章/tags），互联 host + 云后端两路 |
| 远端视频目录 | `RemoteVideoInfo`（title/封面/进度/分集/tags），互联可直接流播 |
| 内容下载 | 远端书区已有「点击下载 → 入库」全链（含进度徽章 remote_download_progress_badge） |
| 进度双向同步 | SyncManager newer-wins；BUG-686 修过书架刷新 |
| 删除防复活 | 墓碑（TODO-1195），重导入清墓碑 |
| 客户端专有书 | 本地行照常显示（同步是并集，不删本地） |

**缺的只有一件事：远端条目还没混进主网格。** 这是视图层改动，不是同步引擎改动。

## 2. 方案：联合视图三层

### 层1 书架/视频页主网格混排占位卡（核心）

- remote-only 条目（远端有、本地无 bookKey/uid）从独立分区改为**主网格占位卡**：
  正常卡尺寸 + 远端封面（`RemoteCoverImage` 已有）+ 云角标 ☁。
- 点击占位卡：书 → 走现有下载链，完成后原地变正常卡；视频（互联在线）→
  直接远端流播（现有能力），云视频 v1 不做下载（体积）。
- 两端都有的条目：显示本地卡（照常），不重复。
- 排序键：占位卡无本地 importedAt/lastReadAt → 用远端进度时间戳
  （`positionUpdatedAtMs` 已有）/远端目录序退化；合集归属 v1 不联合（层3）。
- 独立分区撤销（或保留为筛选器「仅远端」）。

### 层2 离线语义（= 群聊拍的「没网保持现状」）

v1：离线/未配对 → 远端条目不出现，只剩本地库（**即现状**，零新状态）。
可选 v2：缓存上次目录快照 + 「上次同步于 x」角标（占位卡置灰不可点）。
不做「离线可点占位」——点了也下载不了，假可用性。

### 层3 合集归属联合（后续）

远端书属于某合集时混进对应合集行（成员占位卡）。依赖目录接口携带合集归属
（host API 加字段），v1 不做——先让散卡联合跑通。

## 3. 不做的事

- **git 式历史/分支/冲突手解**：LWW+墓碑已够，不加。
- **「摆放位置」同步**：不存在该状态（见 §0.2）。排序模式偏好保持每端本地。
- **云视频下载**：体积不可控，互联流播已覆盖真实场景。
- **新 schema**：远端目录是易失视图（或 v2 一张快照缓存表），不动核心表。

## 4. 决策点（待拍板）

1. **混排开关**：远端占位混入主网格，设置加「显示远端条目」开关（默认开）。
   推荐接受——用户明确要混排，开关兜底「我只想看本地」。
2. **独立远端分区去留**：混排后撤掉独立分区（推荐，一个库一个视图）；
   还是保留一段过渡期。
3. **离线语义**：v1 = 离线只剩本地（推荐，零新状态）；还是直接做 v2 快照缓存
   （多一张缓存表 + 过期显示问题）。
4. **视频范围**：v1 = 互联在线流播 + 书籍可下载（推荐）；云视频占位仅展示。
