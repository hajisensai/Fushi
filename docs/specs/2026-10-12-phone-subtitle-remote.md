# 手机字幕遥控器

基线：上游 `develop`，`ce8b6306f9b7e4d434a0ea1bf26d86f068466e2a`。
本轮只实现 Fushi 互联遥控当前视频，不含投屏或实体手柄映射。

## 使用

电脑开启 Fushi 互联服务端并打开视频；手机配对电脑后，点击视频模块页头右上角
的遥控按钮。按钮只在至少一台已配对、可达且 `/api/capabilities` 声明
`videoRemoteControlV1` 的电脑存在时显示（同一台电脑的多条地址只算一台；本机
正开着互联服务端时不显示）；进入视频页、回到前台与配对清单变化时重探。一台
直接进入遥控页，多台先选择，默认选中上次那台（设备本地偏好，按 hostId 记）。
互联设置页不再提供遥控入口。电脑继续全屏，手机显示字幕与收藏两个页签。
字级点击查词、句子回放、收藏及制卡都在手机操作。手机不解码视频。
词典取自同一台电脑；制卡强制使用该电脑本地 Anki 配置，不使用电脑的跨设备
制卡转发或待发队列。未配置 Anki、素材抽取失败等情况在手机报告。

收藏默认显示当前视频，可切换全部视频收藏、搜索并批量取消（每批最多 200 条）。
跨视频回放或查词先在手机确认更换视频；目标页面继承全屏，按收藏的文本与
字幕起点解析对应轨道延迟。来源已删除或主副轨存在歧义时明确报错。

## 协议与所有权

引擎通过注入的 `VideoRemoteService` 提供能力 `videoRemoteControlV1`，没有
播放器装配的无头 host 不提供该能力。所有 `/api/video-remote/*` 请求为 POST，
只接受已配对设备凭据；控制者身份取自鉴权后的 token 摘要，不接受客户端自报身份。

接口包括 snapshot、events、subtitles、command、lookupBegin/lookupEnd、
mine/mineStatus、favorites/favoriteSet/favoritesRemove、openFavorite 与 disconnect。
手机固定选中的 host、凭据和证书指纹，不向其它电脑兜底：同一 host 的其它地址
若指纹不符或是明文（本进程 P2P 转发口除外）直接拒连，报证书不一致。events 长轮询最多
25 秒；正常播放位置最多每秒更新一次，显式播放操作及会话/轨道变化立即更新。
事件序号断档时重新取快照。字幕按 (sessionId, subtitleVersion) 分块
（每块 200 行）缓存在手机端客户端里，最多保留 3 个版本；重连或中断后只补缺失的块。

控制权租约为 35 秒，只允许一个配对设备控制；前后台与退出释放请求、连接和计时器。
网络失败仅重连读取状态，不自动重发有副作用的操作。会话 ID、字幕版本和 cue ID
共同约束命令；请求 ID 加内容摘要用于去重及防止同 ID 参数冲突。

查词上下文绑定选中句、轨道和时间范围，与电脑本地查词草稿独立。开始查词时
暂停电脑，结束时仅恢复自己造成的暂停。显式播放意图（包括重复暂停）、换集或
换轨取消恢复资格；断线租约到期也会清理上下文。弹框开着换行查词时，
`lookupBegin` 带 `replaceContextId`，电脑把旧上下文的暂停直接转交给新上下文，
不经“恢复再暂停”；不认这个字段的旧电脑照旧先结束旧上下文。手机试听过音频后，
关弹框时只在电脑没人动过（控制修订号仍是最后一次试听时的值；句尾自动停下不计）
的情况下回到查词前的位置并续播。制卡任务接受后固定源与时间窗（含词典媒体缓存：
冻结之后才写，落卡前等它写完），任务 ID 或原请求 ID 可查询结果；入队不算实际写卡成功。

## 渲染与性能

电脑和手机复用字幕列表的逐字 ASS 合并、精确去重与邻接特效链折叠规则。
手机使用虚拟列表、主题字号、当前句强调及短滚动动画；手动浏览后关闭跟随，
通过“回到当前句”恢复。没有模糊、动态背景和持续缩放。遥控 HTTPS 连接复用
证书钉扎客户端，后台关闭网络和本地播放头推算计时器。

现有歌词模式的发热原因尚无本轮测量结论。调试包的帧耗时不能当作发布包性能，
设备温度、耗电与持续播放掉帧必须通过真机持续测量后再下结论。

## 验证与限制

- `video_remote_engine_test.dart`：鉴权、吊销、租约、事件断档、请求去重与参数冲突。
- `video_remote_host_test.dart`：暂停所有权、旧会话拒绝、副轨延迟、任务查询、真实 Drift 收藏落库。
- `video_remote_client_test.dart`：固定设备、事件协议与远端错误保留。
- `video_remote_control_itest.dart`：实际 Windows 播放器、焦点驱动全屏、真实 HTTP
  模拟手机操作、实际 ffmpeg 素材提取、隔离 FakeAnkiConnect 写卡与实际应用收藏数据库。

Windows 测试中的 FakeAnkiConnect 不代表用户真实 Anki 已验证；模拟手机 HTTP
也不代表 Android 真机或双设备网络质量已验证。真机和持续性能结果以本轮证据为准。
本分支保持独立，不自动合并或发布。
