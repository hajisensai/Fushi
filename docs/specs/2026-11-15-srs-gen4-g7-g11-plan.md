## 0. 结论先行

1. **合入方式推荐「两段式」**：没有调用方的新模块逐个合进 develop（不需要功能门，和 G1–G6c 的做法相同）；所有「接线 / 删旧 / 换格式」的 PR 叠在一条集成分支 `pr/srs-gen4-switch` 上，**作为一次 develop 推送整批合入**。不推荐「合进 develop、用运行时或编译开关关着，最后一个 PR 打开门」，理由见 §3。
2. **新代 schema 号在整批合入的那次推送里冻结**，在此之前每个改 `gen4/schema.rs` 的 PR 各自 +1。这样同时消掉了 G7、G8、G9 三处关于冻结时机的矛盾。
3. **四个旧版本实测装置合成一个（★R0）**，现在就开工，第一件事是把旧二进制存档并记 sha256。fushi-debug-rolling 是滚动 release，下一次 develop 推送就会被覆盖。
4. **需要改分工的接口缺口有 11 处**（§1.2）。最要紧的四处：
   - 设备公钥表没人建：G8 验签、G11 导出、迁移灌入都要用；
   - G7 的迁移漏了三项灌入：公钥、加密位置记忆（BUG-4299）、media_at；
   - G7 要的「写 Salts」和 G9 的 `add_salts` 重复；
   - G10 要的「每实体视图读命令」G7 没列。
5. 需要所有者拍板的事去重后共 **34 条**（§4），设计稿矛盾去重后共 **23 条**（§5）。

## 3. 合入方式：推荐「两段式」，不推荐功能门

参照的事实：
- 设计稿 §8 末段：G7–G11 必须在同一个发布里出去，之前的 PR 都不改线上行为、可以逐个合。
- 所有者规则：develop 每次推送都会自动发 debug 包并上传 TestFlight，所以每次推送都等于一次发布。

**不推荐「合进 develop、开关默认关、最后一个 PR 打开门」**，原因有五条：
1. 删旧代码这件事关不住。G7-6 删旧投影，G9-5 删 `srs_profile_merge.dart`，G11-3 删 `sync2_export`。用门控就得新旧两套实现在 develop 上并存到开门那天，违反「不留 Dart 双份 / 不留回退」的仓规；而且开门 PR 还得同时删旧代码，开门这一步本身就是一次大改动。
2. 旧版本闸门必须和断代在同一次推送里。按 G11 的结论，主库 Drift schemaVersion 升档是已发布版本拒收新备份的唯一闸门。升档早了，中间的 debug 包会自己拒收同代备份；晚了，断代后的 debug 包会让旧版本删掉本机 srs.db。只有「升档和断代同一次推送」是安全的。
3. 运行时开关一旦进了 debug 包，就有人可能打开它，然后迁移掉 debug 用户的库。编译开关的话，CI 要跑两套，native-fsrs-gate 和 analyze 的成本都翻倍。
4. G7 的打开模式、G10 的能力位、G8 的围栏都是「一旦生效就不可逆」的东西：迁移和封存不可逆，位置上立了围栏也不可逆。门的价值在于能关回去，可这里关不回去。
5. 第一段已经用「新模块没有调用方」的办法把大部分代码量提前合了。第二段剩下的是接线和删除，集中评审反而更容易看清一致性。

**也不推荐「全部 G7–G11 叠放、最后整批一起合」**：几十个 PR 叠成一摞，接线以外的新模块（G8-1…6、G9-1…3、G11-1/2）没必要一起压着。它们与线 A、线 B 的冲突，越早进 develop 越小。

**两段式的代价**：
- 集成分支要合一次 develop（用 merge，不 rebase）：只在对 develop 开整批 PR 前合，与最后一批合流并成一步；中途不合、不量落后数，例外见 [rules-detail.md](../agent/rules-detail.md#集成分支不追-develop)；
- 整批 PR 的 CI 要手动触发 native-fsrs-gate 五个平台和 server-gate；
- 合并前要跑一次 `bug.dart settle`。

## 7. 风险前五（按影响排序）

1. **整批规模**：命令层实际是重写（约 37 个 Rust 文件、约 100 条命令、7 个 C 直出入口），sync2 的行为测试有 1.5 万行。缓解：G7-3b 和 G7-4 在第一段就作为新模块合进去，第二段只剩接线。
2. **旧版本残留写入**（D3），以及 v3.0.x 不读 minReader：只能靠名字守卫加实测兜底。
3. **加密位置回归到 BUG-4299**：G-2 漏灌加密位置记忆就会发生；G7-2 要有专门的测试。
4. **内存**：rebuild_all 峰值 238–327 MB，G9-1 / G9-2 之后还可能涨，小 VPS 和低端安卓上可能 OOM。
5. **旧二进制消失**：debug-rolling 滚动覆盖，服务端没有带复习功能的发行包。R0 必须先做。
