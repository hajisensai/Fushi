# Galgame 原声与截图制卡快速上手

Hibiki 可以配合 LunaTranslator，把 Galgame 中正在显示的台词制作成带完整语境的 Anki 卡片。完成一次制卡后，卡片可以同时包含：

- 查词词条与释义；
- LunaTranslator 捕获的完整台词；
- 游戏进程中的原始角色语音；
- 台词出现时的游戏窗口截图。

该功能目前仅支持 Windows。

## 工作方式

1. LunaTranslator hook 游戏文本，并把新台词自动写入系统剪贴板。
2. Hibiki 监听到新台词后立即开始一次制卡 occurrence：保存完整台词、标记音频位置，并在游戏仍位于前台时预先截取绑定窗口。
3. 用户在 Hibiki 查词结果中点击制卡。
4. Hibiki 导出句子音频、处理截图，并把媒体上传到 Anki。

截图发生在台词进入剪贴板时，而不是点击制卡按钮时。这样可以尽量避免 Hibiki 窗口出现在截图里。

## 准备工作

### Windows 与游戏

- 使用 Windows 10 1903 或更高版本。
- 建议使用窗口模式或无边框窗口模式运行游戏。
- 如果游戏以管理员权限运行，Hibiki 也应使用管理员权限运行。

### LunaTranslator

1. 在 LunaTranslator 中选择并 hook 游戏文本。
2. 开启新文本自动复制到剪贴板的功能。
3. 推进一句台词后，在记事本中粘贴，确认剪贴板内容会自动变成完整的新台词。

Hibiki 只读取剪贴板，不直接连接 LunaTranslator。因此，只要 LunaTranslator 能稳定更新剪贴板，后续流程就可以工作。

### Anki

1. 安装并启动桌面版 Anki。
2. 安装 AnkiConnect，附加组件代码为 `2055492159`。
3. 在 Hibiki 中进入“设置 → Anki 制卡”，刷新牌组与笔记类型。
4. 初次使用建议直接创建或选择 Hibiki 内置的 Lapis 笔记类型。

使用 Lapis 默认配置时，相关字段会自动映射：

| Anki 字段 | Hibiki 映射 | 内容 |
|---|---|---|
| `Sentence` | `{sentence}` | LunaTranslator 捕获的完整台词 |
| `SentenceAudio` | `{sentence-audio}` | 游戏原始角色语音 |
| `Picture` | `{card-image}` | 游戏窗口截图 |

旧配置中的 `{sasayaki-audio}` 和 `{book-cover}` 仍然兼容，不必仅为了名称变化修改已有模板。

## 首次配置

### 1. 开启剪贴板查词

进入“设置 → 查词 → 剪贴板与全局查词”：

1. 开启“桌面剪贴板查词”。
2. 将“剪贴板查词显示位置”设为“主窗口”最容易确认完整流程；熟悉后也可以改为悬浮面板或光标处弹卡。

### 2. 绑定游戏窗口

仍在“剪贴板与全局查词”区域，打开“Galgame 句子音频”：

1. 开启“捕获句子音频”。
2. 在“游戏音频进程”中选择真正播放游戏声音的窗口。
3. 确认页面状态显示“正在捕获：游戏窗口标题”。

虽然设置入口名为“Galgame 句子音频”，启用后会同时捕获句子音频和绑定游戏窗口截图。

如果列表中没有游戏窗口，先启动游戏，再点击右上角刷新按钮。

### 3. 检查媒体压缩

进入“设置 → Anki 制卡”，按需要设置“压缩制卡媒体”：

- 开启：截图最长边约 1000 像素，JPEG 质量 90，适合日常大量制卡。
- 关闭：截图最长边约 2000 像素，JPEG 质量 95，画面更清晰但卡片更大。
- 尺寸较小的截图可能保留为 PNG。

句子音频优先保存为 48 kbps 单声道 MP3；系统 MP3 编码器不可用时会回退为 WAV。

## 日常制卡流程

建议按下面的顺序操作：

1. 启动 Anki，并保持 AnkiConnect 可用。
2. 启动游戏和 LunaTranslator。
3. 启动 Hibiki，确认 Galgame 捕获状态为“正在捕获”。
4. 在游戏中推进到目标台词。
5. 确认 LunaTranslator 已显示完整台词，Hibiki 也已自动查到这句话。
6. 等角色语音播放完毕。
7. 在 Hibiki 查词结果中点击目标词条的制卡按钮。
8. 等待 Hibiki 显示制卡成功，再继续推进下一句。

Hibiki 会保留约 650 毫秒的句尾余量，降低语音末尾被截断的概率。不要在台词出现后等待很长时间再制卡，建议语音结束后立即操作。

## 成功后的卡片内容

在 Anki 浏览器中打开最新笔记，正常情况下应看到：

- `Sentence`：完整游戏台词；
- `SentenceAudio`：类似 `[sound:hibiki_audio_<哈希>.mp3]`；
- `Picture`：类似 `<img src="hibiki_cover_<哈希>.jpg">` 或 PNG 图片引用。

音频和截图都属于该 Galgame 制卡流程的必需媒体。任意一项捕获或上传失败时，Hibiki 会中止制卡，避免生成只有文本、没有原声或截图的半成品卡。

## 常见问题

### LunaTranslator 已显示新句，Hibiki 仍停在旧句

1. 把剪贴板内容粘贴到记事本，确认 LunaTranslator 确实写入了新句。
2. 确认“桌面剪贴板查词”仍处于开启状态。
3. 确认复制动作来自游戏或 LunaTranslator，而不是 Hibiki 自己的窗口。
4. 连续重复完全相同的台词时，确认 LunaTranslator 是否真的重新写入了剪贴板。

### 显示“音频捕获已停止”或“已配置的游戏未运行”

1. 先启动游戏。
2. 打开“Galgame 句子音频”页面并刷新窗口列表。
3. 重新选择游戏窗口。
4. 检查游戏是否重启后换成了新的子进程或窗口。

### 窗口截图失败或得到黑图

1. 使用窗口模式或无边框窗口模式，避免独占全屏。
2. 台词出现时保持游戏窗口可见，不要立即最小化或切换到其他窗口。
3. 让 Hibiki 与游戏使用相同的权限等级。
4. 某些 DirectX 游戏不支持 `PrintWindow`，Hibiki 会继续尝试 Windows Graphics Capture 和可见桌面区域回退；最后一种方式要求游戏画面没有被其他窗口遮挡。

### 卡片没有 SentenceAudio 或 Picture

新版本在必需媒体失败时通常不会创建卡片。如果卡片已经创建但字段仍为空，请检查自定义字段映射：

- `SentenceAudio` 应映射为 `{sentence-audio}` 或兼容别名 `{sasayaki-audio}`；
- `Picture` 应映射为 `{card-image}` 或兼容别名 `{book-cover}`；
- Anki 必须保持运行，AnkiConnect 端口 `8765` 不能被防火墙拦截。

### 制卡速度较慢

- 开启“压缩制卡媒体”。
- 保持 Anki 在本机运行，避免代理软件拦截 `localhost:8765`。
- 等待当前卡片显示成功或失败后再制作下一张。
- 首次制卡需要初始化捕获和媒体组件，后续通常会更快。

## 快速验收清单

首次配置完成后，建议用一条较短的有声台词测试：

- [ ] LunaTranslator 自动更新剪贴板；
- [ ] Hibiki 自动显示完整台词的查词结果；
- [ ] Galgame 捕获状态显示“正在捕获”；
- [ ] 语音结束后点击制卡并显示成功；
- [ ] 新笔记的 `Sentence` 是完整台词；
- [ ] `SentenceAudio` 可以在 Anki 中播放；
- [ ] `Picture` 显示台词出现时的游戏画面。

完成以上检查后，就可以按“游戏推进一句 → 等语音结束 → 点击制卡”的节奏持续使用。
