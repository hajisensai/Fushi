Behaviour

  • Off by default, not in the default layout. Sizes 1×1 to 6×4; the number of rows follows the height.
  • "Create cards (N)": favorites without a card yet, using the existing batch card creation. Shown only when card creation is on and the widget is wide enough.
  • Sentences from hidden media are left out (same rule as Collections). Updates live when a favorite is added or removed.
  • Motion: staggered list entrance, press scale; both the MD3 and Apple designs.
