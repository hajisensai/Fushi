Behaviour

  • Picks one favorite per day; the same pick stays all day. Older sentences and sentences without a card are preferred.
  • "Another" draws a new one. "Create card" uses the existing single-card flow and appears only when card creation is on.
  • Hidden media excluded; with no favorites the widget shows a short hint on how to add one.
