### Notes

- **Profile priority**: when a work is matched by several profiles, the order is now work > media type > language > default (it used to be work > language > media type)
- **Review library upgrade (protocol 4)**: on first launch, your review library is converted once to the new format; cards, history and settings are kept. Once any device on 3.4.0 syncs with a sync location, older Fushi versions stop syncing there and ask you to update. **Update every device and the Fushi server**; remote review from older versions is refused with "upgrade_required". Older versions cannot open the converted library
- **Dictionary format upgrade**: existing dictionaries are upgraded in place to a faster index; Fushi asks before doing it
- **Review gestures changed**: swipe down undoes on both sides, swipe up is unbound; on the answer side swipe left is Good and swipe right is Again; tapping left / right on the question toggles the top bar and no tap zone flips the card. Gestures are on by default. Previous custom bindings are kept
- **Daily limits**: daily limits now count reviews (answers) by default. Decks that used to count cards get a one-time prompt on the deck page; choose "Keep counting cards" there, otherwise they switch to counting reviews
- **RWKV model change**: the default RWKV model is now sm98 (Instant-Only). On first use after updating, RWKV decks download the new weights and replay your review history once. Deck settings › RWKV offers sm101 Tiny, which uses about 30% less memory
- **Music sources now include video files**: on the next rescan, video files (mkv / mp4 / avi / ts / webm …) already inside your music folders are added to the music library as MV tracks. If a music folder also holds videos that are not music videos, move them out of it before rescanning
- Web videos now open in Fushi's player by default
- The home page layout is replaced by the widget grid; arrange it with the edit button
- Simplified ↔ traditional Chinese cross-lookup is now a switch and is off by default
- Removed: "Examples from my library" in lookup; the lyrics corpus search in the music library remains
- Library layout now offers only Collage and Cover grid (default); the "regular color blocks" and "cover color" options are gone
- Settings were reorganized; option values are kept, but some items have moved to new categories
- Lyrics mode is a separate reading mode, and the "Page / Scroll" setting is now called reading mode
- Following the book's own layout from EPUB metadata is on by default; the reading capsule's "chars this session" and "chars per hour" are off by default
- Media tracking is off by default and turns on only if a tracking sign-in already exists; a saved Bangumi token moves into the Bangumi plugin
- Galgame hooking remains Windows-only; Linux only gets the external texthooker page
- iOS continues to exclude online extension sources, discovery and the general download center

### 注意事项

- **配置优先级**：一部作品同时命中多个配置时，生效顺序改为 作品 > 媒体类型 > 语言 > 默认（原为 作品 > 语言 > 媒体类型）
- **复习库换代（协议 4）**：更新后首次启动会把复习库一次性转换成新格式，卡片、复习记录与设置都保留。任意一台 3.4.0 设备接触某个同步位置后，旧版本 Fushi 在该位置停止同步并提示升级。**请把所有设备与 Fushi 服务端一起更新**；旧版本发起的远程复习会被拒绝（显示 upgrade_required）。转换后的复习库旧版本无法打开
- **词典格式升级**：已有词典会原地升级为更快的索引格式，升级前会先询问
- **复习手势调整**：两面下滑撤销、上滑不绑定；答案面左滑「良好」、右滑「重来」；问题面点左 / 点右改为切换顶栏，单击不再翻面。手势默认开启，已自定义的绑定保留
- **每日上限**：每日上限默认改按作答次数计。以前按卡片数计的存量牌组会在牌组页提醒一次，点「保持按卡片数」即可不变，不选则改按作答次数
- **RWKV 模型更换**：RWKV 默认模型换成 sm98（Instant-Only）。更新后首次使用时，RWKV 牌组会下载新权重并重放一次复习历史。牌组设置 › RWKV 中可选 sm101 Tiny，内存占用约少 30%
- **音乐来源开始收录视频文件**：下次重新扫描时，音乐文件夹里已有的视频文件（mkv / mp4 / avi / ts / webm …）会作为 MV 曲目加入音乐库；如果音乐文件夹里还放着不是 MV 的视频，请在重扫前移出
- 网页视频默认用 Fushi 播放器打开
- 首页布局换成小组件网格，可点编辑按钮自行摆放
- 中文简繁互查改为开关，默认关闭
- 已移除：查词的「我库里的例句」；音乐库的歌词语料搜索保留
- 库页布局只保留「拼贴」与「封面网格」（默认），移除「规整色块」与「封面取色」选项
- 设置页重新整理，配置值不变，但部分选项挪到了新的分类下
- 歌词模式成为独立阅读模式，原「翻页 / 滚动」设置改名为阅读模式
