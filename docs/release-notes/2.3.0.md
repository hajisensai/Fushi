## Fushi 2.3.0

### Speech-to-Subtitle — Experimental
> This feature is experimental. Accuracy varies by language, recording quality and speaker; please check the result before relying on it.

- Generate subtitles for any audiobook or video **on your own device** — no upload, no server
- 17 interface languages covered: dedicated models for Japanese, English, Mandarin, Cantonese, Korean, Russian, Vietnamese and Thai, plus a multilingual model for the rest
- GPU accelerated: a 30-minute English audiobook transcribes in a few seconds
- Transcription runs in the background — the app stays usable while it works
- Per-word timing feeds the audiobook matcher, so seeking lands where you expect
- You can pick the subtitle source per line and export the result

### Reader
- Redesigned desktop reading chrome — top toolbar, side navigation drawer, chapter progress, and a collapsible table of contents that remembers its state
- New image gallery: illustrations you haven't reached yet stay masked until you tap them
- Audiobook panel rebuilt: chapter durations, ±10s seek, alignment and transcription entry points
- Day/night mode selector restored; custom reader colors now actually apply
- Faster book opening

### Statistics
- Reading time and character counts rewritten around a **coverage ledger**: re-reading the same passage no longer double-counts, and going back then forward again restores what you already earned
- EPUB, manga and PDF all share the same accounting now
- Video watch time counts first-time coverage only — replays and rewatches don't inflate it
- Configurable daily reset hour; long-press a time entry to delete it

### Video
- Anime metadata now uses **MAL as the primary source with TMDB as fallback**, plus AniDB ED2K hash identification
- Clip export burns subtitles into the picture, so shared clips play anywhere
- Local files are probed for resolution, HDR, codec and audio tracks — shown on library cards and detail pages
- New "Updated, not watched" row on the video home: subscribed shows with unwatched episodes, one tap to the next one
- Hidden subtitles reveal on hover or click, and step aside while you're looking a word up

### Dictionaries & Lookup
- MDX import is fully streaming now — importing a large dictionary uses a fraction of the memory it used to
- Dictionary download failures finally tell you why instead of failing silently
- Global out-of-app lookup can be triggered by gamepad buttons and mouse side buttons
- Merged pitch-accent rows keep every dictionary source; nested lookup stays inside the popup

### Card Creation
- Netflix mining fixes: word audio no longer expires mid-session, gaiji images stop overlapping the sentence, multi-sentence selections come through as one card
- AnkiDroid parallel builds are recognized, so the permission dialog actually appears
- Audio preview added to the mining context dialog

### Windows Galgame (hooking and voice capture are Windows-only)
- New engine support: Unreal Engine (IoStore), Unity (Mono), CMVS, AOS/SFA, smash/fzmedia, Leaf
- KiriKiri lookup sensor rewritten — classic KAG3 titles that never installed the sensor now work
- Hunex titles get native per-character geometry, so lookup follows the text without manual framing
- Japanese locale switching is now **off by default** — it won't switch on your behalf unless you ask

### Sync, Backup & Setup
- Settings reorganized: sync/backup and interconnect each split into focused subpages with live summary rows
- Desktop cloud OAuth now shows a proper waiting dialog — copy the link, reopen the browser, or cancel
- Conflict comparison dialog: per-section counts, bulk resolution, "conflicts only" filter
- Profiles can be uploaded and downloaded between paired devices
- Recommended pack downloads survive leaving the wizard, show progress on the home screen, and can be resumed or abandoned

### Interface & Stability
- New app icon
- Custom themes redesigned
- Faster library, home and startup loading
- In-app updates fixed — the installer no longer fails silently on exit

## Fushi 2.3.0 更新公告

### 设备端语音转字幕 —— 实验性功能
> 该功能目前为实验性。识别准确度受语言、录音质量和说话人影响，使用前请自行核对结果。

- 有声书、视频都能**在本机**生成字幕，不上传、不联服务器
- 覆盖 17 种界面语言：日语、英语、普通话、粤语、韩语、俄语、越南语、泰语有专用模型，其余语言走多语模型
- 支持 GPU 加速：30 分钟英语有声书几秒转完
- 转录在后台跑，转录期间 app 照常使用
- 逐词时间戳接入有声书匹配器，跳播落点准确
- 字幕来源可逐行选择，转录结果可导出

### 阅读器
- 桌面端阅读界面重做——顶部工具栏、侧边导航抽屉、章节进度、可折叠且记住状态的目录
- 新图片库：还没读到的插图默认遮住，点一下揭开
- 有声书面板重做：章节时长、±10 秒跳转、对齐与转录入口
- 找回日夜模式选择器；阅读器自定义配色终于真正生效
- 开书更快

### 学习统计
- 阅读时长与字数改按**覆盖账本**记账：同一段重读不再重复计数，回翻后再前进会恢复已得额度
- EPUB、漫画、PDF 统一走同一套记账
- 视频观看时长只计首次覆盖，回放与重看不再灌水
- 「今日」的重置时刻可配置；时段明细可长按删除

### 视频
- 动画资料改为 **MAL 为主、TMDB 兜底**，并保留 AniDB ED2K 哈希识别
- 片段导出把字幕烧进画面，发出去在哪都能播
- 本地文件会探测清晰度、HDR、编码和音轨，标注在库页卡片与作品详情页
- 视频首页新增「已更新未看」行：订阅番剧有集没看即列出，点开直接播那一集
- 隐藏字幕支持悬停或点击显形，查词时自动让位

### 词典与查词
- MDX 导入改为全流式，导入大词典的内存峰值大幅下降
- 词典下载失败会说明原因，不再静默失败
- app 外全局查词支持手柄按钮和鼠标侧键触发
- 同音调型合并后仍保留全部词典来源；嵌套查词不再跳出弹窗

### 制卡
- 网飞制卡修复：单词音频不再中途过期、外字图不再压住正文、多句选中合成一张卡
- 认得出 AnkiDroid 并行版，权限框不再永远不弹
- 制卡上下文对话框加了试听

### Windows Galgame（Hook 与语音捕获仅支持 Windows）
- 新增引擎支持：Unreal Engine（IoStore）、Unity（Mono）、CMVS、AOS/SFA、smash/fzmedia、Leaf
- KiriKiri 查词传感器重做——原来装不上传感器的经典 KAG3 作品现在可用
- Hunex 系作品接入原生逐字几何，查词跟着文字走，不用再手动框范围
- 日文转区**默认改为关闭**，没选过就不会替你转区

### 同步、备份与配置
- 设置页重组：同步备份、互联各自拆成职责清晰的子页，主页留带实时摘要的入口行
- 桌面云盘 OAuth 增加等待对话框——可复制登录链接、重开浏览器或取消
- 冲突对比对话框：段头带计数、批量裁决、「只看冲突」筛选
- 配置文件可在已配对设备间上传下载
- 推荐包下载走完向导也不会被取消，首页常驻进度入口，可续传也可放弃

### 界面与稳定性
- 更换应用图标
- 自定义主题重设计
- 库页、首页、启动的加载更快
- 修复应用内更新静默失败
