## Fushi 2.7.0

### Reader
- Floating chrome redone: hidden means full-bleed text, and moving the mouse anywhere over the page brings the bars back; the audiobook panel and reading statistics move into a right-hand side sheet
- Image gallery regrouped by chapter with unlocked / total counts; reader toolbar buttons can be rearranged in a drag-and-drop layout editor
- Furigana has four modes: Off, Toggle (tap to reveal), Hidden and Dimmed; body font weight is adjustable
- Visual-novel mode gets its own settings: text reveal speed, sentences per screen, tap-blank-to-advance, keep the spoken sentence on one screen
- Chapter list and gallery can switch between volumes of the same collection without leaving the reader
- Lyrics mode shows the matched book text with furigana and keeps a way back to normal reading

### Manga
- Online manga is downloaded before it is read: per-chapter download / delete / retry on the series page, "download all", auto-OCR after download, subscriptions, and a manga section in the download center (not on iOS)
- OCR: horizontal text blocks are recognized line by line while vertical blocks are unchanged; progress banner on the series page, "show recognition range" in the reader, whole-volume OCR, and "recognize this chapter" re-runs on chapters that already have results
- Source login: log in inside the app, import an already-logged-in session from your browser through the Fushi extension (not on iOS)
- Extension repository: download counts, batch install, one-click update, sort by popularity; same-name sources in different languages are told apart (not on iOS)
- A paired device's manga library can be browsed as a source and read page by page
- Reader top bar redesigned with floating and pinned modes; Apple system OCR is available on iOS and macOS

### Audiobook & Speech-to-Subtitle
- Apple system speech recognition can be chosen as the transcription engine on iOS 26 / macOS 26
- Pick the model in the transcription sheet, add local models manually, CoreML acceleration on macOS, total elapsed time shown when done
- Generated cues no longer break in the middle of a word; "Export SRT" prefers the aligned version

### Video
- YouTube videos play again
- Multi-season collections fetch each season from its own MAL entry, and the episode panel gets a season switcher
- Scraping: identifier words (block / replace / episode offset) rescue files without renaming, per-source metadata language, lockable fields per work, titles follow the metadata language
- (Work in progress) Retime subtitles with the speech model: per-line alignment that fixes drift and cut-offs, saved as a new subtitle file
- Deleting a collection can also delete the original files; collections regain "set cover" and "rescrape"
- Windows: full-screen no longer freezes the window, F11 matches double-click, and only a left double-click toggles fullscreen

### Card Creation
- Video clips with sound: export the selected window as an MP4 with the sentence audio, played natively by Windows Anki, AnkiDroid and AnkiMobile
- Cards link back to where they were made: tap the source on the card to reopen the exact spot in the book, manga or video without touching your reading progress
- New cards can be reordered by word frequency automatically after mining
- Sentence audio head / tail padding is adjustable; sentence context can be edited line by line before the card is made
- AnkiDroid deck creation failures are reported instead of swallowed; AnkiMobile round trips on iOS work again

### Windows Galgame
- Siglus engine hooking (experimental): text and voice capture is implemented but not yet verified end-to-end on a real title
- CMVS Shift lookup
- Click-through overlay: no more dead zones inside a text block, the dialogue window stays above full-screen games, and the automatic flow no longer paints a calibration box over the game

### Dictionaries & Lookup
- Headwords, cross-reference links and kanji open in the same popup with ← → history, instead of stacking a new layer
- Dictionaries can be renamed; renames survive re-import and sync
- The source text bar highlights exactly the characters the engine matched, Yomitan-style
- New global hotkey (default Ctrl+Alt+F) brings the main window to the front on the lookup page
- Profiles can be bound by content language, between per-book and per-media-type
- E-ink: instant scrolling follows touch drag, the swipe-to-close animation can be turned off on its own, and in-book popups finally honor e-ink mode

### Sync & Interconnect
- New headless **Fushi Server** for Linux / Windows / macOS: an interconnect host with a web UI that takes downloads, transcription, OCR and subscriptions off your devices
- Video metadata syncs between paired devices, with remote scraping and write-back; whole collections can be downloaded from a peer
- Remote videos, books and manga keep their collection membership after download
- Backup gains a games category and includes study statistics; cloud sync carries manga content

### Browser Extension
- Subtitle search covers every online source (Jimaku, OpenSubtitles, AJATT), not just Jimaku
- Mobile: subtitle drawer and tap / hold lookup in Android browsers
- Drag the subtitle overlay anywhere on the video; the position is remembered
- Toolbar popup has a "Fushi subtitles on / off" switch

### Interface & Stability
- Update center: unread updates per domain, home banner, system notifications, and new-episode notifications with a screenshot that play on tap
- Turning off a feature module now hides every entrance to it, not just the tab
- Statistics center: unified layout across tabs, editable sessions, "clear all" with a safety check, and game-domain lookup / card / favorite counts
- Settings and theme surfaces reworked; macOS uses the same title bar as Windows
- Windows builds are fully code-signed, including every bundled exe and dll
- iOS: external discovery sources, online manga sources and the download center are removed for App Store compliance; the rest of the app is unchanged

## Fushi 2.7.0 更新公告

### 阅读器
- 悬浮控制栏重做：隐藏时正文满屏，鼠标在正文任意处移动即唤出；有声书面板和阅读统计改为右侧侧栏
- 插图册按章节分组，显示已解锁 / 全部；阅读器按钮可在设置里拖拽排布
- 振假名四态：关闭 / 点击显示 / 隐藏 / 淡显；正文字重可调
- 视觉小说模式补齐设置：文字显示速度、每屏句数、点空白推进、语音句不跨屏
- 章节列表与插图册可切换同合集的其他卷，不用退出阅读器
- 歌词模式显示匹配到的正文与振假名，并保留回到阅读模式的键

### 漫画
- 在线漫画改为下载后阅读：作品页逐章下载 / 删除 / 重试、「下载全部」、下载完自动识别、订阅，下载中心新增漫画分区（iOS 版不含）
- OCR：横排文字块改为逐行识别，竖排不变；作品页显示识别进度，阅读器可「显示识别范围」，支持整卷识别，「识别本章」对已有结果的章改为重新识别
- 漫画源登录：可在 app 内登录，也可经 Fushi 扩展把系统浏览器里已登录的会话导入（iOS 版不含）
- 扩展仓库：显示下载量、批量安装、一键更新、按热度排序；同名多语言源可区分（iOS 版不含）
- 已配对设备的漫画库可作为来源浏览，逐页在线读
- 阅读器顶栏重设计，悬浮 / 固定两态；iOS 与 macOS 可用系统 OCR

### 有声书与语音转字幕
- iOS 26 / macOS 26 可选苹果系统语音识别作为转录引擎
- 转录弹层可选模型、手动接入本地模型；macOS 有 CoreML 加速；完成后显示总耗时
- 生成的字幕不再在词中间切断；「导出 SRT」优先导出对齐后的版本

### 视频
- YouTube 视频重新能播
- 多季合集按季各取自己的 MAL 条目；播放器「选集」面板可切季
- 刮削：识别词（屏蔽 / 替换 / 集偏移）不改文件名也能救回识别、每个来源可设资料语言、作品字段可锁定、标题跟随资料语言
- （未完成）用语音模型重定时字幕：逐句对轴，修帧率漂移与分段偏移，产出新字幕档
- 删除合集可连原始文件一起删；合集找回「设置封面」与「重新刮削」
- Windows：全屏不再卡死整窗，F11 与双击全屏一致，只有左键双击切全屏

### 制卡
- 带声音的视频片段：把选定时间窗导出为含句子音轨的 MP4，Windows Anki、AnkiDroid、AnkiMobile 原生播放
- 卡片可回跳来源：点卡面上的来源即回到书、漫画或视频里制卡的那一处，且不动阅读进度
- 制卡后可自动按词频重排新卡
- 句子音频头 / 尾留白可调；制卡前可逐句手改上下文文本
- AnkiDroid 建牌组失败会如实报错；iOS AnkiMobile 回传恢复正常

### Windows Galgame
- Siglus 引擎 Hook（实验性）：文本与语音捕获已实现，尚未在真实游戏上完成端到端验证
- CMVS 支持 Shift 查词
- 穿透态浮窗：文字块内不再有漏点带，台词窗不再被全屏游戏压下去，自动流程不再往游戏上盖校准框

### 词典与查词
- 弹窗内点词头、交叉引用、汉字在原弹窗内跳转，顶栏 ← → 可回退前进，不再层层叠窗
- 词典可改名，改名在重新导入与同步后保留
- 查词页原文条用 Yomitan 式底框标出引擎实际匹配的字
- 新增全局热键（默认 Ctrl+Alt+F）：置顶主窗并打开查词页
- 配置方案可按内容语言绑定，介于按书与按媒体类型之间
- 墨水屏：瞬时滚动接上触摸拖动、滑动关闭动画可单独关掉、书内查词弹窗真正进入墨水屏模式

### 同步与互联
- 新增无头 **Fushi 互联服务端**（Linux / Windows / macOS）：作为互联主机提供 WebUI，把下载、转录、OCR 与订阅从你的设备上卸下来
- 视频刮削资料在已配对设备间同步，支持远程刮削与回写；可整合集下载对端成员
- 远端视频、书与漫画下载后保留合集归属
- 备份新增游戏类别并纳入学习统计；云盘同步补上漫画内容

### 浏览器扩展
- 查字幕接入全部在线来源（Jimaku / OpenSubtitles / AJATT），不再只有 Jimaku
- 手机端：Android 浏览器里有字幕抽屉，支持点按 / 长按查词
- 视频上的字幕覆盖层可拖到任意位置并记住
- 工具栏弹窗加「Fushi 字幕 开 / 关」

### 界面与稳定性
- 更新中心：按域列未读、首页横幅、系统通知；番剧新集通知带截图，点击直接播
- 关闭功能模块即关闭该模块的全部入口，不再只是隐藏底栏
- 统计中心：四个页签布局统一、会话可编辑、带防呆的清除全部、游戏域补齐查词 / 制卡 / 收藏计数
- 设置页与主题表面层级重整；macOS 顶栏与 Windows 同壳
- Windows 安装包与其中全部 exe / dll 均已签名
- iOS：按 App Store 要求移除外部发现源、在线漫画源与下载中心，其余功能不受影响
