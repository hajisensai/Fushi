## Fushi 2.2.4

### Onboarding
- New first-launch setup wizard — enable novels, manga, video, games, downloads, and dictionary lookup as you like
- Recommended resource packs now download over multiple mirrors in parallel
- One-click AnkiConnect install on Windows

### Manga & OCR
- Online manga can now be added to the manga shelf, with unified series, chapter, and progress tracking
- Redesigned manga discovery and series detail pages; improved Aidoku / Mihon extension sources
- OCR support completed for PDFs, local full-volume manga, and online manga; tap an unrecognized area to OCR and look it up
- Android can use the built-in system OCR — no model download required

### Video & Subtitles
- New Jellyfin, Emby, and WebDAV streaming support
- New web video player on Windows (subtitles, lookup, progress, card creation)
- New HDR, 10-bit output, and tone mapping on Windows; mpv Lua script support
- Redesigned subtitle search and download UI, configurable per episode or per series; new AJATT Japanese subtitle source
- Subtitle list now supports search, exporting favorite lines, and deleting external subtitles

### Discovery & Downloads
- Unified discovery entry point for novels, manga, video, and games
- Redesigned airing calendar, release selection, and subscription management; new tracker subscriptions
- Search, sorting, and priority management on the downloads page; the built-in engine is now preferred
- Deleting media can now also remove local files and related download tasks

### Lookup & Card Creation
- New dictionary lookup tutorial
- New visual dictionary style editor
- Improved Japanese deinflection, grammar notes, dictionary ordering, and English lemmatization
- Better popup layout, furigana, nested lookup, and consecutive lookups
- Fonts can be chosen automatically by content language, or set individually
- Improved browser extension sidebar lookup, auto text-to-speech, and subtitle search

### Windows Galgame (hooking and voice capture are Windows-only)
- Improved in-game lookup, dialogue overlay, and voice card creation
- Better support for SGRE, Ren'Py, KiriKiri, Siglus, and other engines
- New single-click lookup and configurable lookup triggers; paste a hook code directly

### Interface & Stability
- Choose a data storage location on a fresh Windows install
- Reorganized settings, storage management, and online service configuration
- Unified library navigation, desktop title bar, and card styles; greatly expanded translations
- Fixed startup, fullscreen, window resizing, touchpad, gamepad, and focus issues

## Fushi 2.2.4 更新公告

### 新手引导
- 新增首次启动向导，可自选启用小说、漫画、视频、游戏、下载、查词模块
- 推荐资源包支持多线路并发下载
- Windows 支持一键安装 AnkiConnect

### 漫画与 OCR
- 在线漫画可加入漫画架，统一管理作品、章节和进度
- 重做漫画发现页和作品详情页，改进 Aidoku / Mihon 扩展来源
- 补齐 PDF、本地整卷、在线漫画的 OCR；支持点击未识别区域直接识别查词
- Android 可用系统自带 OCR，无需下载模型

### 视频与字幕
- 新增 Jellyfin、Emby 媒体库和 WebDAV 在线播放
- Windows 新增网页视频播放器（字幕、查词、进度、制卡）
- Windows 新增 HDR、10-bit 输出与色调映射；支持 mpv Lua 脚本
- 重做字幕搜索下载界面，可按单集或整部作品配置；新增 AJATT 日语字幕源
- 字幕列表支持搜索、导出收藏台词、删除外挂字幕

### 发现与下载
- 统一小说、漫画、视频、游戏的发现入口
- 重做放送日历、资源选版和订阅管理；新增 Tracker 订阅
- 下载页新增搜索、排序和优先级管理；内置下载引擎改为首选
- 删除媒体时可同时删除本地文件和下载任务

### 查词与制卡
- 新增查词操作教程
- 新增词典样式可视化编辑器
- 改进日语变形、语法说明、词典排序和英语原形还原
- 优化弹窗排版、振假名、嵌套查词和连续查词
- 字体可按内容语言自动选择，也可分别指定
- 改进浏览器扩展侧栏查词、自动朗读、字幕搜索

### Windows Galgame（Hook 与语音捕获仅支持 Windows）
- 完善游戏内查词、台词浮窗和语音制卡
- 改进 SGRE、Ren'Py、KiriKiri、Siglus 等引擎适配
- 新增单击查词和可配置触发方式；支持直接粘贴 Hook Code

### 界面与稳定性
- Windows 全新安装可选择数据存储位置
- 重新整理设置页、存储管理和在线服务配置
- 统一库页导航、桌面标题栏和卡片样式；大幅补齐多语言翻译
- 修复启动、全屏、窗口缩放、触摸板、手柄和焦点问题
