## Fushi 2.9.0

### Browse & Online Sources
- The Downloads module becomes **Browse**: Sources / Extensions / Discover / Downloads for books, manga and video
- Online video sources via Aniyomi extensions: browse, play, add to library, download and mine cards (not on iOS)
- Online novel sources via LNReader plugins: read online or download chapters as EPUB (not on iOS)
- Online manga can be read directly without downloading first
- Drag a `.torrent` file onto the app to add a download

### AI
- AI download: name a work and it fetches the whole series — all seasons and movies, subscribing to anything still airing
- Identification uses web references (Wikipedia, Moegirlpedia, Anime News Network and more)
- A phone can hand AI downloads to a paired computer or Fushi Server
- AI can also write dictionary styles, card styles and themes

### Video
- Media servers: Jellyfin / Emby browsing by server tree, **Plex** support, multiple routes per server
- New sources: AList / OpenList, cloud-drive streaming, STRM and M3U / IPTV playlists, Blu-ray discs, audio files
- Scraping follows Shoko: AniDB by file hash is the default, series and movies are split automatically, season / episode can be pinned by hand
- Subtitles: SubDL added; downloaded subtitles auto-align to the embedded subtitle track
- Borderless mini window, screenshot shortcuts, hover lookup resumes playback when you leave

### Interconnect & Fushi Server
- Connect to your host from anywhere: automatic route selection across LAN / IPv6 / public addresses, with a P2P tunnel fallback
- Pair by QR code, link or NFC tag
- Adaptive transcoding for weak networks; downloads continue in the background
- A desktop app can download on behalf of a phone
- Fushi Server can download novels / manga / audiobooks, host audio libraries and run AI downloads

### Card Creation & Anki
- Cards made while Anki is unavailable are queued and delivered later — via another device, or synced straight to AnkiWeb / a self-hosted server without installing Anki
- Create cards from favorites in batches
- Video clip covers are real video clips instead of GIFs
- New `{glossary-first-2}` / `{glossary-first-3}` fields

### Reader
- Floating ball with reader buttons and the study timer; also available system-wide on Android and outside the app on Windows / macOS, with photo lookup
- Reading settings grouped into tabs; the top bar shows the current chapter
- Smooth mouse wheel and trackpad scrolling
- Shelf can filter by reading status

### Manga
- Reader settings aligned with Mihon, panel-by-panel navigation, Mokuro sidecar support
- OCR runs on the whole volume when opened, or as you read
- New local OCR models and a speed-up pack; GPU recognition on Windows; vertical text through Apple Vision on iOS / macOS

### Windows Galgame
- Support for more games

### Game Streaming (new, experimental)
- Stream a Windows game to Android, and look up words and create cards from its lines

### Dictionaries & Lookup
- English lookup handles irregular forms and phrasal verbs (gave up → give up)
- Global lookup overlay on macOS
- One-click update for all dictionaries
- Font library with live previews

### Statistics & Leaderboard
- **Fushi account & leaderboard** (experimental): rankings, public shelf, friends and shareable cards
- Statistics are kept per profile, with a selectable time range

### Browser Extension
- Subtitle appearance editor and themes, font download, resizable overlay
- Fushi button inside the site's player controls
- Web video watching counts as immersion time

### Interface
- Long-press the app icon for shortcuts on Android and iOS
- iOS: online video and novel sources and the Discover tabs are not included, for App Store compliance

## Fushi 2.9.0 更新公告

### 浏览与在线来源
- 「下载」模块改为**「浏览」**：来源 / 扩展 / 发现 / 下载，书、漫画、视频通用
- 在线视频源（Aniyomi 扩展）：浏览、播放、加入媒体库、下载、制卡（iOS 版不含）
- 在线小说源（LNReader 插件）：在线阅读，或按章节下载成 EPUB（iOS 版不含）
- 在线漫画可直接在线读，不必先下载
- `.torrent` 文件拖进 app 即可添加下载

### AI
- AI 下载：说出作品名，自动整套下载——全部季与剧场版，在播的自动订阅
- 识别作品时参考联网资料（维基百科、萌娘百科、Anime News Network 等）
- 手机可把 AI 下载交给已配对的电脑或 Fushi 服务端执行
- AI 还能生成词典样式、卡片样式和主题

### 视频
- 媒体服务器：Jellyfin / Emby 按服务器目录浏览，新增 **Plex**，支持多线路
- 新来源：AList / OpenList、网盘直接播放、STRM 与 M3U / IPTV 列表、蓝光原盘、音频文件
- 刮削对齐 Shoko：默认以 AniDB 文件哈希识别，系列与剧场版自动拆分，可手动指定季集
- 字幕：接入 SubDL；下载的字幕自动按内嵌字幕轨对齐时间轴
- 无边框小窗、截图快捷键、悬停查词离开即续播

### 互联与 Fushi 服务端
- 在外也能连回主机：自动在局域网 / IPv6 / 公网地址间选路，连不上时走 P2P 隧道
- 支持扫码、链接、NFC 贴纸配对
- 弱网自适应转码；下载可在后台继续
- 电脑端可替手机代下载
- Fushi 服务端可代下载小说 / 漫画 / 有声书、托管音频库、执行 AI 下载

### 制卡与 Anki
- Anki 不可用时卡片先排队，之后补发——经其他设备转发，或不装 Anki 直接同步到 AnkiWeb / 自建服务器
- 可从收藏批量制卡
- 视频片段封面改为真正的视频片段，不再是 GIF
- 新增 `{glossary-first-2}` / `{glossary-first-3}` 字段

### 阅读器
- 悬浮球：收纳阅读器按钮与学习计时；Android 可系统级悬浮，Windows / macOS 可悬浮于应用之外，支持拍照查词
- 阅读设置按标签页分组；顶栏显示当前章名
- 鼠标滚轮与触控板平滑滚动
- 书架可按阅读状态筛选

### 漫画
- 阅读设置对齐 Mihon；分镜逐格导航；支持 Mokuro sidecar
- OCR 可在打开时整卷识别，或边看边识别
- 新本地 OCR 模型与提速包；Windows 支持 GPU 识别；iOS / macOS 经 Apple Vision 识别竖排

### Windows Galgame
- 适配了更多游戏

### 游戏串流（新增，实验性）
- 把 Windows 上的游戏串流到 Android，并可对台词查词、制卡

### 词典与查词
- 英语查词支持不规则变形与短语动词（gave up → give up）
- macOS 新增全局查词浮窗
- 词典一键全部更新
- 字体库，支持实时预览

### 统计与排行榜
- **Fushi 账户与排行榜**（实验性）：排名、公开书架、好友、分享卡
- 统计按 Profile 隔离，可选时间范围

### 浏览器扩展
- 字幕外观编辑与主题、字体下载、覆盖层可调大小
- 站点播放器控制栏里出现 Fushi 按钮
- 网页看视频计入沉浸时间

### 界面
- Android 与 iOS 长按 app 图标出现快捷入口
- iOS：按 App Store 要求不含在线视频源、在线小说源与「发现」页签
