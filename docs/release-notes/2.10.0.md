## Fushi 2.10.0

Changes since 2.9.1:

- **Interface refresh**: M3 Expressive and Cupertino designs, updated navigation and panels, smoother interactions, reorderable modules and a swipe-paged bottom bar
- **Built-in review**: FSRS scheduling, deck management, Anki package import / export, sync and backup; mine cards to Anki, Fushi Review, or both
- **Read-aloud & Audiobook Studio**: sentence highlighting, multiple voices, AI speaker annotation, chapter generation and M4B export; Audiobookshelf support and automatic transcription after download
- **Advanced mining**: adjust deck, sentence context, audio boundaries, video frames and manga crops before sending; improved Anki video-template compatibility and clip export
- **Video & subtitles**: PGS / VobSub / DVB subtitle OCR, optional pause OCR, phone control for desktop playback and mining, Windows HDR, Blu-ray menus and Dolby / DTS passthrough
- **Reader & manga**: page-turn animations, customizable highlight strokes, improved position restoration, illustration viewing and whole-volume OCR
- **Collections**: automatic series grouping for local books, manga and audiobooks, batch actions and AI-assisted volume ordering
- **AI & models**: unified model settings, multiple API keys per provider, rate controls and retries; AI can be disabled as a module
- **Sync & desktop**: fewer redundant transfers, playback-progress conflict checks, remote-book recovery, screen OCR from desktop floating balls and new `fushi_cli` commands
- **Games**: experimental stream reception expands to iOS, macOS and Windows; more Windows galgame adapters. Streaming hosts and local hooking remain Windows-only
- **Feedback & statistics**: in-app reports with logs, screenshots and video, reply notifications and fix-release tracking; custom date ranges and per-title statistics
- **Fixes & performance**: reading highlights, subtitle timing, card audio, downloads and sync; browser-extension appearance and interaction improvements

### Notes

- Review is off by default; enable it under **Settings → Appearance → Modules**
- In-app GPT-SoVITS installation is experimental and Windows-only; the full installation flow still needs real-device validation
- The video "pause at subtitle end" mode has been removed
- Very old Hibiki databases must first be opened with **2.9.1** before upgrading
- iOS continues to exclude online extension sources, discovery and the general download center

## Fushi 2.10.0 更新公告

本次汇总 2.9.1 之后的更新：

- **界面焕新**：升级 M3 Expressive 与 Cupertino 设计，重做导航和各类面板，完善动效；模块可排序，底栏可分页滑动
- **内置复习**：FSRS 排程、牌组管理、Anki 包导入导出、同步与备份；制卡可发送至 Anki、Fushi 复习或两者
- **朗读与有声书制作台**：逐句高亮、多声音、AI 说话人标注、按章生成与 M4B 导出；接入 Audiobookshelf，支持下载后自动转录
- **高级制卡**：发送前调整牌组、上下文、音频起止、视频静帧与漫画裁图；改善 Anki 视频模板兼容与片段导出
- **视频与字幕**：图形字幕 OCR、可选暂停识别、手机遥控电脑播放与制卡；新增 Windows HDR、蓝光菜单和 Dolby / DTS 直通
- **阅读与漫画**：新增翻页动效、自定义高亮笔触，改善位置恢复、插图查看与整卷 OCR
- **合集管理**：本地小说、漫画和有声书自动归组，支持批量操作与 AI 辅助卷序排序
- **AI 与模型**：统一模型设置，支持多 Key 轮换、限速与重试；AI 模块可整体关闭
- **同步与桌面**：减少重复传输，检查播放进度冲突，支持远程书籍恢复、桌面悬浮球屏幕 OCR 与 `fushi_cli` 命令行
- **游戏**：实验性串流接收扩展至 iOS、macOS 与 Windows，补充 Windows Galgame 适配；串流主机与本机 Hook 仍仅限 Windows
- **反馈与统计**：应用内反馈可附日志、截图与视频，支持回复通知及修复版本追踪；统计支持自定义日期与逐作品明细
- **修复与优化**：改善阅读高亮、字幕时间轴、卡片音频、下载与同步，更新浏览器扩展外观及交互

### 注意事项

- 内置复习默认关闭，可在 **设置 → 外观 → 功能模块** 开启
- 应用内安装 GPT-SoVITS 仅限 Windows，属实验性，完整安装链路仍待真机验证
- 已移除视频「字幕暂停播放模式」
- 极旧的 Hibiki 数据库需先用 **2.9.1** 打开一次，再升级
- iOS 仍不包含在线扩展源、发现与通用下载中心
